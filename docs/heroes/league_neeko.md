## 现在的技能

下面是游戏里显示的技能说明（`league/text/champion.i18n` 的简体中文，去掉了颜色和图标），冷却、距离来自 `league/champion/league_neeko.data_champion`；1 秒 = 60 tick。

### 普攻 / 被动

*攻击间隔 1.53 秒 · 攻击距离 55000*

发射一颗魔法弹。两生花影：每第三次攻击额外造成45 + 50% 法强魔法伤害，并提高30%移动速度1秒。

### 技能1 · 盛开花种

*冷却 7 秒 · 施放距离 80000 · 施放：指定目标 · 敌人（不含防御塔）*

扔出一颗种子，落地炸开造成95 + 65% 法强魔法伤害。炸到英雄时会再次盛开，最多两次，每次40 + 25% 法强魔法伤害。

### 技能2 · 缠结倒刺

*冷却 11 秒 · 施放距离 90000 · 施放：指定目标 · 敌人（不含防御塔）*

投出一团贯穿的倒刺，路径上的敌人受到90 + 60% 法强魔法伤害并被禁锢1秒。穿过英雄后，后面的英雄多被禁锢0.75秒。

### 大招 · 怒放

*冷却 35 秒 · 施放距离 45000 · 施放：指定目标 · 敌方英雄*

蓄力0.75秒，获得护盾（附近每个敌方英雄额外40），然后跃起击飞周围敌人，落地造成260 + 115% 法强魔法伤害并晕眩0.83秒。

### 数值

攻击力 70（每级 +6）、法强 40（每级 +20）、生命 960（每级 +95）、护甲 21（每级 +7）、魔抗 22（每级 +4）、移速 900（每级 +9）。
