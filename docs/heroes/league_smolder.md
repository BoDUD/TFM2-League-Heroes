## 现在的技能

下面是游戏里显示的技能说明（`league/text/champion.i18n` 的简体中文，去掉了颜色和图标），冷却、距离来自 `league/champion/league_smolder.data_champion`；1 秒 = 60 tick。

### 普攻 / 被动（被动「龙之研习」）

*攻击间隔 0.93 秒 · 攻击距离 55000*

喷出小火球。被动龙之研习：技能命中英雄、龙息击杀单位各获得1层（阵亡清空），每层使龙息、喷嚏、扑棱火球各+0.75/1.65/0.25魔法伤害。龙息在10/25/40层时依次获得爆炸、反冲火球、灼烧。

### 技能1 · 超级灼热龙息

*冷却 5 秒 · 施放距离 55000 · 施放：指定目标 · 敌人（不含防御塔）*

喷吐火球，造成60+120% 攻击力物理伤害。10层：爆炸波及周围敌人；25层：向目标身后喷出反冲火球（50%伤害）；40层：灼烧3秒，每秒造成10+10% 攻击力+1%最大生命真实伤害。

### 技能2 · 阿嚏！ / 扑棱，扑棱，扑棱！

*冷却 10 秒 · 施放距离 80000 · 施放：指定目标 · 敌方英雄*

打喷嚏喷出火焰，造成40+40% 攻击力物理伤害并减速35%，命中英雄时爆炸，再造成40+40% 攻击力物理伤害。被近身或追击残血时改用扑棱，扑棱，扑棱！：飞起并加速40%，向残血敌人连发5枚火球，各10+30% 攻击力物理伤害。

### 大招 · 妈----！

*冷却 50 秒 · 施放距离 90000 · 施放：方向 · 敌方英雄*

呼唤妈妈沿直线喷火，造成110+80% 攻击力物理伤害，中心的敌人多受50%伤害并减速40%（2秒）。斯莫德站在中心线上时回复80+30% 攻击力生命。

### 数值

攻击力 100（每级 +20）、生命 900（每级 +90）、护甲 22（每级 +7）、魔抗 15（每级 +3）、移速 900（每级 +9）。

```bash
python tools/lol/extract_smolder.py
python tools/kit/build_smolder.py                  # 技能数据，数字都在脚本的参数表 P 里
python tools/kit/setup_smolder.py                  # 五种语言的文字、音效配置、共享文件里他的键
python tools/art/design_smolder.py                 # Codex 的原画切成造型
python tools/art/import_smolder_strips.py          # Codex 的动作细稿读回
python tools/art/rig_smolder.py                    # 1 倍帧和原密度的高清帧
python tools/art/ppu_hd.py --hero smolder          # hd_ / lo_ 帧
python tools/art/import_smolder_fx.py              # 特效
python addons/league_smolder/make_override.py      # 附加包的副本（主包的斯莫德改了就重跑）
```
