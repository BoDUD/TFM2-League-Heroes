## 开发记录

| 部分 | 内容 |
|---|---|
| 定位 | tft 包（`tft_cinderling`）的英雄，下路（远程，物理伤害，叠攻击力，灼烧和重伤）。金铲铲第 18 赛季的一费 `DA_Cinderling18`「绯红树怪」（峡谷野怪 / 猎人，繁中「樹精」，英文 Cinderling，射程 4）：红 buff 营地的小树怪，矮胖的深紫褐树皮小兽，前腿包着暖褐木甲和青苔，背上一排浅绿高尖叶，脸是圆木头面具（左边一只发光的大眼睛、右边螺旋纹、下面一排尖牙）。金铲铲原技能「刃叶」做技能1，羁绊的「绯红霸符」做被动；其余按用户同意的方案自己设计（2026-11-02，下路） |
| 普攻 / 被动 | **余烬叶**（距离 60000，打塔）：第 11 tick 甩出一片追踪的燃烧叶子，100% 攻击力物理伤害。**绯红霸符**（数据，league_talon 的叠层阶梯）：每放一个技能（Q、E、R）升一层，每层攻击力 +6，最多 4 层，8 秒不放技能全部清空；满层（`p_full`，叶尖冒火）时普攻多一个只打英雄的隐形弹，挂灼烧 |
| 灼烧 | 每秒目标最大生命 1% 的真实伤害，持续 2 秒（Fire `AddCasted` 的 `FixedAttack`）；只对英雄（按最大生命的伤害会融化大龙），用一个只落在 `EnemyChampion` 上的隐形追踪弹带过去 |
| 技能1 | **刃叶**（金铲铲原技能，冷却 6 秒，距离 60000，打兵和野怪）：第 13 tick 起五片叶刃从五个高度（扇形）先后飞向目标，共 80 + 110% 攻击力物理伤害；中间那片还施加重伤（受到治疗 −40%，3 秒）和灼烧 |
| 技能2 | **钻土突袭**（冷却 10 秒，距离 35000，打英雄：有人贴近时用）：钻进地里，第 6 tick 溅起泥土，30000 以内的敌人（追它的人）受 30 + 35% 攻击力物理伤害并减速 35% 1.5 秒；地下时受到伤害 −70%，向远离目标的方向退 30000（MoveBack 2500 × 12 tick），第 24 tick 钻出。原来设计成钻出时才减速，但那时身边已经没人了，改到钻下去那一下 |
| 大招 | **燎原叶暴**（冷却 40 秒，距离 60000，打英雄）：站起来点燃叶子，4 秒内攻速 +40%，每 0.5 秒朝 65000 以内随机敌人射 3 片燃烧叶刃，每片 20 + 25% 攻击力物理伤害，英雄被灼烧（挂在自己身上的周期效果：死了就停） |
| 数值 | 攻击 92（+18）、生命 820（+85）、护甲 20（+7）、魔抗 18（+3）、移速 920（+9），攻击间隔 70 tick，距离 60000 |
| 平衡 | 经典引擎模拟（下路，对原版弓箭手、火枪手、回旋镖猎手、毒镖猎手，两边三套阵容，纯数据版）：初稿 +0.95 / +1.15（种子 1–8 / 9–16）；钻土的伤害改到钻下去那一下（能打到追兵）+1.71；刃叶 80 + 110%、钻土 30 + 35% +0.94 / +1.33（和三费的锋喙鸟 +0.69 / +1.47 差不多）；再把攻击 96 → 92、霸符每层 8 → 6 **−0.11 / +1.22**，和同是一费的苍蓝哨戒（+0.24 / +0.47）接近 |
| tft.dll | [`addons/tft/src/cinderling.rs`](../../addons/tft/src/cinderling.rs)：被动 `tft_cinderling:scarlet` 只做数据做不到的两件事：倒下时的死亡叫声，霸符叠满时记日志。日志 `data/tft_cinderling.log`（SPAWN / FULL） |
| 塞拉斯 / 佛耶戈 / 俄洛伊 / 悠米 | 塞拉斯偷到的「燎原叶暴」就是数据版（特效表复制进附加包），按远程类；佛耶戈的灵魂（远程）、俄洛伊的灵魂、悠米坐在它头上的高度 18 |
| 精灵图（高清帧 PPU 2.33） | 参考是金铲铲客户端 TFTSet18 里它的模型（`tft18_cinderling`，73 个关节：四条腿、面具、三片背叶，皮肤借 SRU_RedMini，贴图按哈希找到）和 7 段动作（待机叶子起伏、往前一蹦、后腿站立、从地里钻出、翻倒；**没有跑步动作**）。第 0 步 Codex 画了 A（3/4）和 B（侧面），它自己的第二轮是参考稿，第一轮更好：A 按 8 px 读回 94×70。用户选 **A、30 游戏像素、PPU 2.33**（1:1，[`tools/art/design_cinderling_model.py`](../../tools/art/design_cinderling_model.py)）。第 2 步的骨架包按它自己的动作片段投影骨骼（[`tools/art/pack_cinderling_poses.py`](../../tools/art/pack_cinderling_poses.py)），Codex 画了 13 个姿势 |
| 动作 | [`tools/art/design_cinderling_poses.py`](../../tools/art/design_cinderling_poses.py)：Codex 的格子约 11.8 px 一格（按发光眼睛的面积量），每张按定稿的身体大小、调色板读回，贴上定稿的面具。[`tools/art/rig_cinderling.py`](../../tools/art/rig_cinderling.py)：跑步用它普攻那一蹦做成一蹦一蹦（蹲、蹬、空中、落地，480 ms 一圈）；普攻 167 + 233 ms；刃叶竖叶 200 + 甩出 200；钻土是钻地 → 地下只露叶尖（钻地帧再沉 20 行，切在地面）→ 钻出（Codex 画在地上，抬高 12 行）→ 落地，各 200 ms；大招站起 200 + 怒吼 300；挨打是待机闪白，死亡翻倒后四脚朝天、眼睛熄灭 |
| 特效 | 用户用 Gemini 画了一整张（每个特效 1–2 张图 + 3 个图标），[`tools/art/clean_cinderling_fx.py`](../../tools/art/clean_cinderling_fx.py) 按位置切出每块（裁剪框停在文字标签上方：标签的黑边会变成黑条）、缩到游戏格子、吸附到特效调色板，再用放大、变暗、外圈收缩消散、往上飘拼成帧；三张飞行的叶子转平、上下对称朝右，泥土（钻地、钻出、脚下泥巴）没有前后方向，保留原样不镜像（镜像后像一张脸），其余左右对称。大招的图里树怪自己被画进火里，挖掉只留火；火叶旋风只用前面那段弧，放在身体后面贴地；霸符满层的火冠缩到 3/4。[`tools/art/import_cinderling_fx.py`](../../tools/art/import_cinderling_fx.py) 导入，图标从原图缩到 64 |
| 音效 | [`tools/lol/extract_cinderling.py`](../../tools/lol/extract_cinderling.py) 的 16 段：峡谷红 buff 营地的小树怪在英雄联盟里有自己的声音（Map11 `npc_map11_redmini_sfx_`，事件名靠猜哈希：怒吼、待机、死亡），刃叶的叫声、钻出、大招的怒吼和死亡用它自己的；叶子用婕拉（普攻、种子、刺藤），灼烧和燃烧叶刃用布兰德，钻地和钻出用雷克塞，霸符叠满用红 buff 本体被拿到时的声音 |
