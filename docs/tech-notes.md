## 项目简介

团战经理2（Teamfight Manager 2）的英雄联盟英雄 Mod，mod_id 是 `league`。英雄都是数据；从 0.97.0 起主包带一个自己的 DLL（`league.dll`，源码 [`addons/league_main`](../addons/league_main/src/lib.rs)，`mod.mod_info` 是 `contains_code` / `native`，订阅时游戏会提示这是代码 mod），只做数据做不到的一件事：高清帧（见下）。DLL 只在它认得的游戏版本上挂钩（[`build.rs`](../addons/league_main/src/build.rs) 逐字节核对每一处要改、要调用的代码，现在认得 0.6.4 的 Windows 版；0.6.3 不再认，用户：「0.6.3不用适配了 直接0.6.4就行了」），别的版本（比如 0.7 测试版）什么都不改，英雄照旧画 1 倍的帧。

## 动态寻址

动态寻址（2026-10-20，用户：「变身的api 官方没提供的api 想个方法做个动态寻地址的 后面游戏更新了我们维护压力小一点」「包括ppu」，`league.dll` 0.7.71、主包 0.174.0）：`league.dll`（高清帧）和 15 个整身变身附加包（凯隐、奈德丽、杰斯、内瑟斯、乌鸦、佛耶戈、雷克塞、拉莫斯、奎因、芸阿娜、芮尔、艾尼维亚、悠米、厄斐琉斯、伊莉丝）以前按写死的地址找游戏里的函数，游戏一更新全部失效。现在共用一个 [`addons/game_places`](../addons/game_places/src/lib.rs)：加载时在 EXE 里按特征码找——取动画表 / 贴图、哈希、战场画身体、绘制命令扩容、显示更新函数和槽、战场和界面五处画英雄的调用点（[`sigs.rs`](../addons/game_places/src/sigs.rs) 由 [`tools/re/make_sigs.py`](../tools/re/make_sigs.py) 从 `build.rs` 列的版本离线生成：跳转、调用目标和 rip 相对位移用 capstone 判定后挖空；游戏里只做字节搜索，调用点靠扫 `call`，函数边界用 EXE 的 `.pdata`，界面五处按取尺寸的间距打分）。`build.rs` 列的版本照旧逐字节核对、直接用；对不上（游戏更新了）就动态找，日志 `game build: found at run time in … ms`，找不到或不唯一才退回 1 倍帧（和以前一样）。显示槽由第一个找到的 DLL 写进进程环境变量 `LEAGUE_DISPLAY_PLACES`，后面挂槽的 DLL 都读它（槽被换过以后就搜不到原指针了）。15 个变身附加包也合成一个显示钩子（`game_places::hook`）：每个 DLL 只换一次槽、每帧走一遍实体表，再交给每个登记的英雄；显示世界和实体值的偏移只留在这一处。`cargo test -p league_main` 拿游戏目录里的 EXE（现在是 0.6.5）跑一遍：动态找出的每个地址都和 `build.rs` 一致（约 2 秒）。结构体里的偏移（显示世界 +0x138 表、实体值各字段、+0x1b4 缩放）没改成动态，0.6.3 → 0.6.4 一个都没变；游戏改了代码形状时，仍用 `tools/re/find_build.py` 找、更新 `build.rs` 后重跑 `make_sigs.py`。

## 小技能的施放目标

对敌人放的小技能，施放目标是「敌人（不含防御塔）」，清线、打野时也会放；只有大招、德莱厄斯的 E（拉人）、阿木木的 Q（绷带）、锤石的 Q（钩子）、阿狸的 E（魅惑）、薇恩的 E（恶魔审判）、维迦的 E（扭曲空间）、凯特琳的 W（约德尔诱捕器）、卡莎的 W（虚空索敌）、基兰的 E（时光发条）、洛的 W（盛大登场，落地后接 E 轻舞成双）、阿利斯塔的 W（野蛮冲撞，撞完接大地粉碎）和布兰德的 E→Q（烈火燃烧接火焰烙印，清线交给 W 烈焰之柱）、劫的 W（影分身，一次施放接鬼斩和诸刃）、诺提勒斯的 Q（疏通航道，铁锚钩人）只对英雄放（莫甘娜的 Q 对什么都放，但射程内有敌方英雄时朝英雄射；贝蕾亚的 Q 也一样，射程内有敌方英雄时扑英雄；娜美的 W、Q 也是，射程内有敌方英雄时打英雄；黛安娜的 Q 也一样，射程内有敌方英雄时朝英雄射，E 带着月光再冲的第二下也先找英雄；菲奥娜的 Q、W 也一样，射程内有敌方英雄时冲向、刺向英雄；凯特琳的 Q 也一样，射程内有敌方英雄时朝英雄射；凯南的 Q 也一样，射程内有敌方英雄时锁定英雄射；伊芙琳的 W 也一样，射程内有敌方英雄时先给英雄挂印记；丽桑卓的 Q 也一样，射程内有敌方英雄时朝英雄射，W 身边没人时冰爪只滑向队友正在打的敌方英雄，否则只是扔出去打一下；韦鲁斯的 Q 也一样，射程内有敌方英雄时拉满弓朝英雄射，只有小兵野怪时快速出手；赛娜的 W 也一样，射程内有敌方英雄时朝英雄射；辛德拉的 W 也一样，射程内有敌方英雄时把法球掷向英雄、接着朝他推 E，Q 在 E 冷却好时也先砸英雄）；提莫的 W 是给自己加速和伪装，也只在敌方英雄靠近时放。最早几个英雄的小技能只对英雄放，打野时一直平 A 野怪，按玩家反馈改了。

## 待机动画
