0.1.3（2026-11-14，用户：「吉格斯和维克托按照联盟的重做」）：**定点爆破按英雄联盟扔到一点**（之前用户选的布局 A 里 W 只在脚下自爆，主包照旧），炸点把敌人往外推、炸到他自己就把他炸飞、低血量的塔直接炸掉；**弹跳炸弹往前弹**（主包第一次落在瞄准点，没炸到人就原地弹起）。下面的表和「怎么做的」都是新的；看 `league_ziggs.log` 的 `SATCHEL` / `BLAST` / `HEXPLODE` / `HOP` / `QBLAST`。

|---|---|---|

## 怎么做的

- **定点爆破**：副本的守望里没有数据的 W（脚下自爆）；被动 `league_ziggs:hexplode` 每 6 tick 看一次：他活着、3 级以上、没有数据的 `league_ziggs_w_cd`（W 在冷却）也没有 `league_ziggs_busy`（在放别的技能）、没被控住也没被推着走时，按顺序问：
  1. 敌方英雄贴身（`w_trig` 以内，身体边到边，和主包的触发一样）：炸点在两人之间、离他 `w_gap`；他会落下的地方（离炸点 `w_self`）在敌方塔下（75000 以内）或那里 40000 内还有两个以上别的敌方英雄就不扔；
  2. `w_hex_r` 以内有血量不到 `w_ex`% 的敌方防御塔：炸点在塔上（他站在攻击距离外打塔，自己不在爆炸里）；
  3. 生命 `w_catch_hp`% 以下的敌方英雄离他 `w_catch_lo`..`w_catch_hi`（中心距离，刚出他的普攻）：按那人最近 6 tick 的走向算出炸药包落地时他站在哪，炸点在那里身后，爆炸把他推到离吉格斯约 `w_keep`。他自己生命低于 35%、那人在敌方塔下、那人身边 60000 内敌方英雄比我方多就不扔。

  扔出：W 进冷却（`w_cd`，和数据的一样）、`busy`、他的动作（贴身用 W 的蹲下放包 `skill_w`，扔远用 E 的扔包 `skill2`）、声音和台词、一触即发少等三分之一（拿掉还在的最长的那个等待标记，主包的 `cut`）；`w_rel` / `e_rel` tick 后炸药包离手（`:throw`：主包雷包那张飞行图 `league_ziggs_w_throw`，每 tick `w_speed`，英雄联盟 1750 码/秒），落地就炸（`:blast`）：`w_dmg` + `w_ratio`% 法强的魔法伤害（走引擎的伤害流程），能推的（大型野怪不推、免控的不推）用强制位移从炸点往外推；炸到他自己时（没被定住、没被推着）往外炸飞，正好站在炸点上就背着最近的敌人飞。
- **弹跳炸弹**：副本第一次落地 2 tick 后数据没看到 `q_boom`（没炸到人）时调本包的 `:q_hop`（输入是第一落点）：按他现在站的地方到第一落点的方向和距离，第二、第三落点和两段空中的炸弹（主包的 `q_air<高度>`，每 3 tick 一帧，沿路贴）一起排好；第二次落地（`:q_land2`）旁边 `q_r`（加身体）内有敌人（防御塔不算）就炸并挂上 `league_ziggs_q_done`，后面的落地和空中的炸弹就不做；第三次（`:q_land3`）一定炸。伤害 `q_dmg` + `q_ratio`% 法强。他死了炸弹就停（和主包一样）。
- **打塔加成**：副本里被动强化弹打中时给他挂 2 tick 的 `league_ziggs_p_now`；本包的 `on_attack` 看到它、目标又是防御塔，就把这一下伤害 ×`p_tower`%（整下，含普攻本身的部分）。

参数写在英雄数据的 `passive.params`，由 `make_override.py` 从 `tools/kit/build_ziggs.py` 的参数表 `P` 写入（单元测试核对副本里的数就是本包的默认值）。本包**不按任何技能键**。

## 在游戏里测

1. 主包（League of Legends Heroes 0.140 以上）要装着并启用。
2. 用附加包合集 `league_addons`（里面已经包含本包），或者把整个 `league_ziggs` 文件夹放进 `<游戏目录>\mods\`
   （要有 `league_ziggs.dll`、`mod.mod_info`、`mod.override_info`、`override\`、`text\`）。
3. 进游戏，在 MOD 菜单里启用它（含代码的 mod 会弹一次确认），确认排在主包后面，重启游戏。
4. 看吉格斯的普攻和 Q 的说明：开头是「【附加包】」就说明换上了。
5. 日志在 `%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_ziggs.log`，每次启动游戏重写（上一次的留在 `.prev.log`）：
   - `SPAWN`：出生；`SATCHEL`：扔出炸药包（为什么 `Escape` / `Tower` / `Catch`、扔多远、飞几 tick）；`BLAST`：爆炸（炸到几个、推了几个、塔、他被炸飞多远）；`HEXPLODE`：炸掉一座塔；`HOP` / `BOUNCE` / `QBLAST`：弹跳炸弹往前弹、又没炸到、炸了；`FUSE`：强化弹打塔（加成前后的伤害）。

## 开发

- `python addons/league_ziggs/make_override.py`：从参数表重新生成 `override/` 和 `text/`（先核对主包的吉格斯和参数表一致）。
  主包的吉格斯改了以后要重跑。
- 在 `addons/` 下 `cargo test --release -p league_ziggs`：单元测试（参数、炸塔的血量线、距离、打塔倍率、从炸点往外推、贴身 / 炸塔 / 炸回来什么时候扔、不往塔下和人堆里飞、一触即发的冷却、往前弹的落点、空中炸弹的高度表）。
- 在 `addons/` 下 `cargo build --release -p league_ziggs`（Windows）得到 `target/release/league_ziggs.dll`；`league_addons` 合集也会编进本包。
- 经典 SDK 的模拟器跑不了原生代码，本包只做了单元测试，要在游戏里看日志确认。
