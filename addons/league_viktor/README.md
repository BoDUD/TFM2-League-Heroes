# 维克托附加包（测试版 v0.1.0）

主包 `league` 保持纯数据。用户 2026-11-14：「吉格斯和维克托按照联盟的重做」——之前选的「按等级依次升级」改成英雄联盟的海克斯碎片。数据数不了碎片（也存不住跨死亡的计数：死亡会清掉自定义增益），所以主包照旧按等级升级；这个附加包用原生代码按碎片升级。重力场的眩晕也一样：英雄联盟每个敌人各叠各的「沉重引力」，数据数不了每个人在场里待了多久：

| | 主包（不装附加包） | 装了附加包 |
|---|---|---|
| 光荣进化（被动） | 按等级：3 级 E 附带余波，5 级 Q 涡轮增压（护盾 ×1.6、加速 30%），7 级 W 磁化（Q、E、风暴首击减速 20%），9 级 R 完美风暴（风暴转移后变大、持续更久）；普攻里的护盾探针量他的等级 | **按海克斯碎片**（英雄联盟）：每补到一个小兵或野怪 `hex_unit` 个（用什么打死的都算），每次英雄击杀或助攻 `hex_takedown` 个，他最后一击的史诗野怪 `hex_epic` 个；每攒够 `hex_cost` 个按同样的顺序强化下一个（E → Q → W → R，英雄联盟 R 也在三个基础技能之后）。没有探针 |
| 重力场（W）的眩晕 | 落下 0.75 秒后生效、减速；落下 1.75 秒时还在场里的敌人都晕眩 1.5 秒 | **每人各算**（英雄联盟 V14.24：生效后每 0.25 秒叠一层沉重引力，第五层晕眩 1.5 秒，每次施放每人一次）：生效后在场里连着待满 `w_stun_at` tick（1 秒，五层）的敌人晕眩 `w_stun`，后走进来的也算，离开场就从头叠；减速照旧是数据的 |

## 怎么做的

- 副本（`override/`，`make_override.py` 从 `tools/kit/build_viktor.py` 的 native=1 生成）和主包一样，只是普攻里没有量等级的探针，被动换成本包的 `league_viktor:evolve`。四个强化还是主包数据里的旗子 `league_viktor_s1`..`s4`（数据用 `SwitchByBuff` 读施法者身上的），本包挂上去：死了复活旗子会没，每几 tick 补一次。
- 碎片：`on_unit_kill`（他拿到补刀的小兵、野怪）、`on_kill`（英雄；他最后一击的史诗野怪）、`on_assist`。英雄联盟的数是 1 / 10 / 20、一个强化 100 个；这个游戏的小兵不分炮车和超级兵，一律 `hex_unit`。
- 价钱：英雄联盟一局 30 分钟上下才攒齐四个强化，这里一局 10 分钟左右。经典引擎模拟（中路对三个原版法师，2026-11-14）里他平均 2 分钟 21 个碎片、4 分钟 65 个、5 分钟 101 个、7 分钟 161 个，一局 237 个（补刀 64、参与击杀 8.6 次）——英雄联盟 30 分钟大约 590 个，是这里的 2.5 倍，所以 `hex_cost` = 100 / 2.5 = 40：第四个强化在 7 分钟左右（主包的 9 级是 7.2 分钟），第一个在 2.75 分钟（主包 3 级在 1.1 分钟）。
- 强化时播主包的进化金光（`league_viktor_evo`）和声音。碎片和强化都存在他的被动里，死了也留着（英雄联盟也是）。
- 重力场：副本的重力场落地时不再有数据的眩晕，调本包的 `:field`：给他挂上带着落点的记号 `league_viktor_wf:<x>:<y>`（3 tick），被动取走、记下这个场（记在被动里，他死了场照样在，英雄联盟也是）；生效（`w_arm`）以后到落下 `w_t` tick，每 tick 数每个敌方单位（英雄、小兵、野怪；不含塔、水晶、选不中的）在场里（`w_r` 加身体）连着待了几 tick，满 `w_stun_at` 就晕眩 `w_stun`（每个场每人一次；正免控的等它过去再晕），场里晕到第一个人时在场中心播主包的晕眩爆发 `league_viktor_w_burst`，被晕的人身上播 `league_viktor_w_stun`。`:field` 告诉 AI 这个技能有 `w_stun` 的控制（副本的 W 里没有数据的眩晕了）。W → Q 的连招还是数据的（落下 1.75 秒后找被控的英雄）。
- 面板：攒着还没用掉的碎片挂成 `league_viktor_hex_<n>`。league.dll 的技能栏层数格（`tools/kit/stack_nums.py`）把他列进表以后就会显示这个数。

参数写在英雄数据的 `passive.params`（碎片 `hex_unit` / `hex_epic` / `hex_takedown` / `hex_cost`，重力场 `w_arm` / `w_stun_at` / `w_stun` / `w_r` / `w_t`），由 `make_override.py` 从参数表 `P` 写入。

## 在游戏里测

1. 主包（League of Legends Heroes 0.348 以上）要装着并启用。
2. 用附加包合集 `league_addons`（里面已经包含本包），或者把整个 `league_viktor` 文件夹放进 `<游戏目录>\mods\`（要有 `league_viktor.dll`、`mod.mod_info`、`mod.override_info`、`override\`、`text\`）。
3. 进游戏，在 MOD 菜单里启用它（含代码的 mod 会弹一次确认），确认排在主包后面，重启游戏。
4. 看维克托的普攻说明：开头是「【附加包】」就说明换上了。
5. 日志在 `%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_viktor.log`，每次启动游戏重写（上一次的留在 `.prev.log`）：
   - `SPAWN`：出生 / 复活（攒着的碎片、已经强化了几个）；`HEX`：得了碎片（从哪来、现在攒着多少、一共多少）；`EVOLVE`：强化了哪个技能；`FIELD`：重力场立起；`GRAVITY`：谁在场里叠满五层被晕。

## 开发

- `python addons/league_viktor/make_override.py`：从参数表重新生成 `override/` 和 `text/`（先核对主包的维克托和参数表一致；`--check` 只比较，CI 用）。主包的维克托改了以后要重跑。
- 在 `addons/` 下 `cargo test --release -p league_viktor`：单元测试（副本的参数、英雄联盟的碎片数、强化的顺序和上限、面板上的数、重力场的记号、每人叠满五层晕一次、离开场从头叠、免控等过去）。
- 经典 SDK 的模拟器跑不了原生代码，本包只做了单元测试，要在游戏里看日志确认。
