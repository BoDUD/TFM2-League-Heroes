# 拉莫斯附加包（测试版 v0.1.0，可选）

**不装这个附加包，主包里的拉莫斯也是完整的**：普攻翻身撞击（被动锥刺甲壳多一段魔法伤害）、W 尖刺防御（敌方英雄靠近时自动蜷起来，
双抗提升、反弹伤害）、Q 动力冲刺（缩成球冲向目标，撞上击退、减速）、E 狂乱嘲讽、R 冲天猛撞（跳起砸地、减速、余震，刚撞完时中心击飞）
都在主包数据里。主包是纯数据：**待机、跑步的动画不能在运行中换**（所以主包里他只在 Q 的冲刺动作里是球），**数据读不到护甲**（锥刺甲壳
只能按最大生命算）。这个附加包用原生代码把这两件事做成英雄联盟的样子（用户 2026-10-19：技能方案 A，做附加包）。

| | 主包（纯数据） | 装了附加包 |
|---|---|---|
| 动力冲刺 | 缩成球，一次冲到目标身上撞开 | **照英雄联盟滚**：缩成球后越滚越快（移速 +30% 到 +100%，2 秒加满，最多滚 4 秒），他照常走向目标，碰到第一个敌人（不算防御塔）就撞开；滚着时普攻也算撞上 |
| 滚球、蜷缩的样子 | 只在 Q 的动作条里是球，W 只有蜷起来的那一下 | **整身换形态**：滚着的时候站着、走着、挨打都是滚动的刺球（`b_idle` / `b_run` / `b_hit`），尖刺防御开着的 7 秒里是蜷着的防御姿势（`c_idle` / `c_run` / `c_hit`） |
| 锥刺甲壳 | 15 + 30% 法强 + 2% 最大生命 | **15 + 30% 法强 + 15% 护甲**（英雄联盟：10 + 15% 护甲） |

## 怎么做的

- `mod.override_info` 把主包的拉莫斯换成 `override/` 里的副本（`make_override.py` 用 `tools/kit/build_rammus.py` 的 `native=1` 生成，主包的拉莫斯改了就重跑）：
  被动是本包的 `league_rammus:shell`（数字在 `passive.params`，和 `src/lib.rs` 的常量由脚本核对）；普攻的锥刺甲壳是本包的 `league_rammus:spikes`；
  Q 只缩成球、挂 `league_rammus_q_ball`（240 tick），同时起一个每 tick 看一次的守望；普攻、技能1 的说明开头加【扩展包】。
- **滚球**：被动每 tick 看他身上有没有 `q_ball`：有就给他一个只活 3 tick 的加速 buff `league_rammus_q_rush`（每 tick 换一次，移速按滚了多久从 +30% 线性加到 +100%），
  每 24 tick 在他脚下放一次 `q_dust` 沙尘；身边 26000（≥ 普攻射程）内有敌方单位就挂 2 tick 的 `league_rammus_q_go`，Q 的守望看到就撞：伤害、击退、减速、
  他弹出球来（`skill_hit`）、摘掉 `q_ball`。滚着放 R（英雄联盟：动力冲刺中放冲天猛撞）会收起球，中心的敌人照「刚撞完」再受一次冲刺伤害并击飞（主包同样）。
- **整身换形态**（`src/view.rs`）：照雷克塞 / 芮尔 / 杰斯 / 奈德丽附加包的显示钩子，游戏每帧更新显示时，名字是 `league_rammus` 的实体身上有 `q_ball` 时把正在播的
  `idle / run / hit` 换成 `b_*`，有 `league_rammus_w_on`（主包数据的尖刺防御）时换成 `c_*`（滚球优先；高清帧由 league.dll 自动换成 `hd_b_*` / `hd_c_*`）。
- 日志：`%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_rammus.log`：`ROLL`（缩成球、撞上谁、滚了多久多远）、`SPIKES`（按多少护甲打了多少）、`FORM`（画面里换形态），都限了条数。

## 在游戏里测

1. 主包（League of Legends Heroes 0.163.0 以上）要装着并启用。
2. 用附加包合集 `league_addons`（里面已经包含本包），或者把整个 `league_rammus` 文件夹放进 `<游戏目录>\mods\`（文件夹里要有 `league_rammus.dll`、`mod.mod_info`、
   `mod.override_info`、`override\`、`text\`）。
3. 进游戏，鼠标停在拉莫斯的普攻或技能1 上，说明开头是【扩展包】就说明副本生效了；打一局后看日志里的 ROLL / SPIKES / FORM。
