# 拉莫斯附加包（测试版 v0.2.1，可选）

0.2.1（2026-11-21）：滚球从更远开、滚向英雄时碾过小兵，滚得久了（下面「0.2.1」一节）。

0.2.0（2026-11-21，游戏 0.7.3）：照英雄联盟 V26.21 改了锥刺甲壳、尖刺防御和动力冲刺（下面「0.2.0」一节）。用户：「龙龟好像也没完全还原吧」「按照你的建议直接改就行了」。

**不装这个附加包，主包里的拉莫斯也是完整的**：普攻翻身撞击（被动锥刺甲壳多一段魔法伤害）、W 尖刺防御（敌方英雄靠近时自动蜷起来，
护甲、魔抗提升、反弹伤害，放 Q、R 时收起）、Q 动力冲刺（缩成球冲向目标，撞上击退、眩晕、减速）、E 狂乱嘲讽、R 冲天猛撞（跳起砸地、
减速、余震，刚撞完时中心击飞）都在主包数据里。主包是纯数据：**待机、跑步的动画不能在运行中换**（所以主包里他只在 Q 的冲刺动作里是球），
**数据读不到护甲**（锥刺甲壳只能按最大生命算），**数据没有「被普攻时」**（尖刺防御只能反弹受到的每一下伤害的百分比）。这个附加包用原生代码
把这几件事做成英雄联盟的样子（用户 2026-10-19：技能方案 A，做附加包）。

两个包都照英雄联盟：放动力冲刺、冲天猛撞时尖刺防御收起（冷却从这时起算 7 秒），滚着的时候不会蜷起来；滚着放冲天猛撞，落点中心的敌人再吃一次动力冲刺的伤害并击飞。

守望要是也这样等就几乎不蜷了，所以附加包里不等，蜷着时 Q 来了就收起。

## 怎么做的

- `mod.override_info` 把主包的拉莫斯换成 `override/` 里的副本（`make_override.py` 用 `tools/kit/build_rammus.py` 的 `native=1` 生成，主包的拉莫斯改了就重跑）：
  被动是本包的 `league_rammus:shell`（本包读的数字在 `passive.params`，就是 `build_rammus.NATIVE_KEYS`，和 `src/lib.rs` 里的默认值由脚本核对）；普攻没有锥刺甲壳的魔法伤害，
  尖刺防御的 buff 没有百分比反伤；Q 只缩成球、挂 `league_rammus_q_ball`（360 tick），同时起一个每 tick 看一次的守望；普攻、技能1、技能2 的说明开头加【扩展包】。
- **锥刺甲壳**：被动每 tick 读他的总护甲、总魔抗（升级、装备、尖刺防御都算在里面），算出攻击力，和他身上的 `league_rammus_p_ad`（只有攻击力的永久 buff）不一样就换一个；
  死了 buff 会被清掉，复活后第一 tick 补回。
- **尖刺防御的回敬**：他身上有 `league_rammus_w_on`（数据的守望挂的）时，被动的 `on_damaged` 看每一下伤害是不是普攻。`on_damaged` 只给攻击者和伤害量，
  不给类型（物品的 `on_damaged_ex` 才有），所以按攻击者的冷却认：游戏在一个动作开始时把那个槽的冷却拉满，`冷却总长 − 剩余` 就是它出手了几 tick。
  攻击者是英雄：普攻在冷却、而且普攻之后没放过技能（三个技能槽里没有比普攻更晚开始冷却的）才算这一下普攻，出手的 tick 记下来，同一下普攻打出的几段伤害只回敬一次；
  小兵、野怪、召唤物只会普攻，每个普攻间隔最多回敬一次；防御塔、水晶不算。回敬在下一 tick 付（`deal_damage_typed`，魔法伤害，算技能），伤害按他这时的总护甲、总魔抗。
  经典引擎里拿引擎自己的伤害类型对过（`C:/t/ram_sim`，sim3ram 的 `chk_*`）：每局里一 tick 只挨一下、认得出攻击者的那些：英雄的普攻（同一下普攻算一次）93% 认得出来，认成普攻的 95% 是真的普攻；
  认错的是普攻别人时自己的持续伤害、慢弹落在他身上（算成普攻，同一下普攻最多一次），和远程普攻还在飞时攻击者放了技能（算成技能）。
- **滚球**：被动每 tick 看他身上有没有 `q_ball`：有就给他一个只活 3 tick 的加速 buff `league_rammus_q_rush`（每 tick 换一次，移速从 +0 开始每 tick 加「每秒加速 ÷ 60」：
  1 级每秒 25%，12 级每秒 40.83%，中间按等级线性；滚满 6 秒是英雄联盟的 150% / 245%），每 24 tick 在他脚下放一次 `q_dust` 沙尘；两个身子的空隙在 3000 以内有敌方单位
  （不算防御塔）就挂 2 tick 的 `league_rammus_q_go`，Q 的守望看到就撞：伤害、击退、眩晕、减速、他弹出球来（`skill_hit`）、摘掉 `q_ball`。滚着放 R 会收起球，
  中心的敌人照「刚撞完」再受一次冲刺伤害并击飞（主包同样）。
- **AI 钩子** `league_rammus:open`：从远处开球（最近的敌方英雄在 30000–45000、Q 好了）、AI 对已经贴着他的敌方英雄放的 Q 改成普攻（0.1.2），
  滚着的时候 AI 想放 E 改成普攻同一个人——滚着普攻就是撞上去（0.2.0）。蜷着时 AI 的 Q 照放，会收起尖刺防御（英雄联盟也是这样；
  经典引擎里试过蜷着时先压下 Q，他少了 Q 的眩晕、追着人走进人堆，死得更多，没留）。
- **整身换形态**（`src/view.rs`）：照雷克塞 / 芮尔 / 杰斯 / 奈德丽附加包的显示钩子，游戏每帧更新显示时，名字是 `league_rammus` 的实体身上有 `q_ball` 时把正在播的
  `idle / run / hit` 换成 `b_*`，有 `league_rammus_w_on`（数据的尖刺防御）时换成 `c_*`（滚球优先；高清帧由 league.dll 自动换成 `hd_b_*` / `hd_c_*`）。
- 旧存档里的 0.1.x 副本（`passive.params` 里没有 `p_ad_arm`）：锥刺甲壳还是数据里调的 `league_rammus:spikes`（本包还留着它），反伤还是数据的百分比，
  本包不加攻击力、不回敬，只按 0.2.0 的样子滚球；日志一行 `OLD COPY`。刷新存档里的英雄副本以后就是 0.2.0。
- 日志：`%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_rammus.log`：`SHELL`（按多少护甲、魔抗给了多少攻击力）、`CURL on / off`（蜷起时的双抗，收起时这次回敬了几下普攻、
  多少伤害，没算的技能 / 防御塔 / 同一下普攻的后几段各几下，是不是被 Q / R 提前收起）、`RETURN`（回敬了谁多少）、`ROLL`（缩成球、撞上谁、滚了多久多远多快）、
  `E HELD` / `OPEN` / `Q HELD`（AI 钩子）、`FORM`（画面里换形态）、`OLD COPY`，都限了条数。

## 在游戏里测

1. 主包（League of Legends Heroes 0.163.0 以上）要装着并启用。
2. 用附加包合集 `league_addons`（里面已经包含本包），或者把整个 `league_rammus` 文件夹放进 `<游戏目录>\mods\`（文件夹里要有 `league_rammus.dll`、`mod.mod_info`、
   `mod.override_info`、`override\`、`text\`）。
3. 进游戏，鼠标停在拉莫斯的普攻、技能1 或技能2 上，说明开头是【扩展包】就说明副本生效了；打一局后看日志里的 SHELL / CURL / RETURN / ROLL / FORM。

## 0.1.1：球真的滚起来（2026-11-05）

11-04 的日志：40 次 `ROLL hit` 里 38 次是「after 0 ticks」，每次 `ROLL over` 都是「0 rolled」——球从来没滚过。原因：`q_touch` 26000 是从他的中心量到对方身子的边（和普攻射程差不多），游戏的 AI 又正是在这个距离放 Q，蜷起的第一 tick 就算撞上了。改法：

- 撞上 = 两个身子碰到（中心距离 − 两个半径 ≤ `q_touch`，现在是 3000 的空隙；半径读不到按 6000）。参数表 `P` 的 `q_touch` 改成 3000（只进副本的 `passive.params`，主包的数据没变，`make_override.py` 核对过）。
- 蜷起那一 tick 已经贴着他的敌人（不是 Q 的目标）不算撞，离开过再贴上才算；Q 的目标由副本挂 `league_rammus_q_aim`（`q_curl` + 2 tick）认出来。
- 新加 AI 钩子 `league_rammus:open`：他没在滚、没在施法 / 蜷着，Q 解锁且好了，AI 想普攻或走路（不在回城、放技能），最近的敌方英雄离他 30000 到 45000（Q 的射程）：改成对他放 Q，先滚过去。日志 `OPEN`。

下一局看 `ROLL hit ... after N ticks`（N 该大于 0、`gap` 在 3000 以内）、`ROLL over ... rolled`（该大于 0）和 `OPEN`。

## 0.2.0：照英雄联盟 V26.21（2026-11-21）

用户：「龙龟好像也没完全还原吧 而且Q技能目前看起来不会在局内滚动」「你查出来后就按照你的建议直接改就行了 不用咨询我」。照英雄联盟维基（V26.21）对过一遍，
和这里不一样的都改了（看不出在滚是滚球的帧的问题，另外重画，不在这个包里）：

- **锥刺甲壳**：英雄联盟 V25.12 起是「额外攻击力 = 15% 总护甲 + 15% 总魔抗」，不再是普攻附带魔法伤害。副本的普攻去掉了 `league_rammus:spikes`，
  被动给他挂 `league_rammus_p_ad`（只有攻击力），每 tick 按他这时的总护甲、总魔抗对一遍。比例是 35%（英雄联盟 15%）：这个游戏的坦克护甲、魔抗比英雄联盟后期低得多（10 分钟里他平均约 165），15% 只给他平均 25 攻击力，比 0.1.x 每下普攻约 59 的魔法伤害少一大截，经典引擎里副本的击杀差从 +3.80 掉到 +2.40；35% 平均约 60 攻击力，回到 +3.85。
- **尖刺防御**：双抗改成英雄联盟的「固定 + 总量 %」：护甲 +42（+40%）、魔抗 +28（+40%）（引擎先加固定值再乘百分比，说明里写的是乘完以后的固定部分；
  主包也改了）。回敬改成英雄联盟的：只对普攻他的敌人造成 20 + 10% 护甲 + 10% 魔抗 魔法伤害（英雄联盟 15 + 10% + 10%），去掉了 25% 全伤害反弹
  （主包数据没有「被普攻时」，还是反弹 25%）。放动力冲刺、冲天猛撞时收起，冷却从这时起算 7 秒；滚着的时候守望不蜷（两个包一样）。
  主包的守望另外只在动力冲刺冷却时蜷（游戏的 AI 一好就放 Q，先蜷会被收掉）；副本不等，蜷着时 Q 来了就收起（一局 11.8 次蜷起里约 8 次）。
  **怎么认普攻**见上面「怎么做的」：按攻击者的冷却，经典引擎里对过，英雄的普攻 93% 认得出、认成普攻的 95% 是真的。
- **动力冲刺**：最多滚 6 秒（`q_ball_t` 240 → 360）；加速照英雄联盟从 +0 开始，每秒加 25%（1 级）到 40.83%（12 级），一 tick 一 tick 加
  （以前 +30% 起、2 秒加满 +100%）；滚着不能放狂乱嘲讽（AI 钩子把它改成普攻同一个人，滚着普攻就是撞上去）。撞上的效果、碰到第一个敌人就撞、
