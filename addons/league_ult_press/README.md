# 「备好式」大招替 AI 按（测试版 v0.1.0，可选）

用户：「莎弥拉和卡牌用附加包在合适时机替AI按R，主包保持现在这样」。

**不装这个附加包，主包里的莎弥拉、崔斯特也是完整的**：两人的 R 格都是 3 tick 的「备好」动作，真大招由主包数据在备好期间自己判断时机放出，用不上就退还冷却。经典模拟里 AI 每局会按好几次（莎弥拉 3.8 次、崔斯特 5.6 次），但游戏 0.6.4 换了新 AI，几乎不按这种格子。只读观察包测到：莎弥拉每 10 分钟 0.2 次、崔斯特 0.7 次，多数英雄是 3–9 次。

在格子里加东西也不管用：200 或 1000 的 1 tick 自身护盾、再加一次「搜敌方英雄」都试过，次数不变。锐雯同样的护盾是有用的。而且厄加特的 R 格和伊芙琳的一模一样（备好 + 退还），一个每 10 分钟 3.7 次、一个 1.4 次，格子里写什么并不决定 AI 按不按。所以这个附加包不改主包，只替 AI 按。

| | 主包（纯数据） | 装了附加包 |
|---|---|---|
| 莎弥拉的「炼狱扳机」 | 只有 AI 按下 R 格才会备好 / 放出，0.6.4 的 AI 几乎不按 | R 好了、她没被控住、**R 射程（50000）内有敌方英雄**就按。S 评价时这一下就放出大招，不到 S 就备好 330 tick，期间到了 S 再放 |
| 崔斯特的「命运」 | 同上：几乎不备好，也就几乎不传送 | 只在主包会传送的局面才按：**他身边 75000 内没有敌方英雄**、生命不低于 **40%**，而且离他 **100000–340000** 有队友 **50000 内贴着敌方英雄**（在打架）。按下后，揭示、引导、传送全按主包的数据来（主包的门槛：身边 70000 内没敌人、360000 内有被我方打过的敌方英雄、那人 60000 内有队友） |

## 怎么做的

- 不替换任何英雄（没有 `override/`），只注册一个 AI 钩子 `league_ult_press:ult`，只对 `league_samira`、`league_twistedfate` 生效。
- 每次 AI 思考时：R 冷却好、已解锁、本人活着、没被控住（眩晕、击飞、束缚、嘲讽、恐惧、魅惑、沉默）才考虑。冷却由钩子自己看，因为引擎的「输入合法」不看冷却（league_pyke 的教训）。条件满足就下「对那个敌方英雄放 R」的命令，引擎接不了时（`is_valid_input`）就不下。
- 她 / 他正忙时，引擎要几 tick 才接 R 的命令，钩子每 tick 再下一次；R 的冷却真的开始走才算按下去一次。

## 在游戏里测

1. 主包（League of Legends Heroes 0.129.0 以上）要装着并启用。
2. 用附加包合集 `league_addons`（里面已经包含本包），或者把整个 `league_ult_press` 文件夹（含 `league_ult_press.dll`、`mod.mod_info`）放进 `<游戏目录>\mods\`。
3. 日志：`%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_ult_press.log`，每次启动游戏重写，上一次的留在 `.prev.log`。
   - `R ORDER`：钩子按了，以及为什么（射程内的敌方英雄；或哪个队友在多远和谁交手）。
   - `R CAST`：冷却真的开始走了，写明是钩子按的还是 AI 自己按的。
   - `R FIRED`：莎弥拉的真大招放出来了（主包的 `league_samira_r_on`）。
   - `R TELEPORT`：崔斯特备好之后一 tick 内移动了 50000 以上（传送成功）。

```bash
cd addons && cargo test -p league_ult_press     # 什么时候按（莎弥拉的射程、崔斯特的「一个人 + 远处有人打架」）
```
