# 烈娜塔附加包（测试版 v0.2.0，可选）

**不装这个附加包，主包里的烈娜塔也是完整的**：被动物尽其用（普攻打中英雄挂印记，印记附近有两个她这边的英雄就引爆）、E 忠诚激励（两枚飞弹：
碰到敌人炸开减速，经过的队友得到护盾）、Q 铁腕竞合（抓住第一个敌人定身，再甩过她身边砸到地上）、被动自动放的 W 及时救难（队友被控或团战时：
加攻速移速、5 秒内不会阵亡、结束时回血）、R 恶意收购（看场面放：被化学波扫中的敌方英雄狂暴，不能攻击她这边、不能放技能，每 0.5 秒伤害身边的
自己人）都在主包数据里。主包是纯数据：**数据听不到队友的攻击**（所以印记按「附近有两个她这边的英雄」引爆）、**读不到生命和击杀**（所以救难只能
「不会阵亡、结束回血」）、**没有让单位打自己人的效果**（所以狂暴是一圈魔法伤害）。这个附加包用原生代码把这三件事做成英雄联盟的样子
（用户 2026-10-17：「方案可以，全按推荐做（辅助、Util，布局 A，做扩展包，PPU 1.5）」）。

| | 主包（纯数据） | 装了附加包 |
|---|---|---|
| 物尽其用 | 印记附近有两个她这边的英雄时引爆 | **队友真的打中它才引爆**（普攻或技能）：魔法伤害 + 最大生命 3% 的真实伤害 |
| 及时救难 | 队友被控或团战时：攻速 +40%、移速 +20%，5 秒内不会阵亡，结束时回复 200 + 60% 法强 | **英雄联盟的规则**：给危急的队友（身边有敌方英雄，被硬控或生命不到 45%），5 秒内受到致命伤害就回满生命，3 秒内烧光，烧的时候敌人照样打得死；这 3 秒里参与击杀就止住、生命定在 20%，没参与就阵亡 |
| 恶意收购的狂暴 | 不能攻击她这边、不能施法，每 0.5 秒对身边的自己人造成魔法伤害 | **真的转身打自己人**：走向最近的队友（英雄优先），按他自己的攻击间隔、用他自己的攻击力打；打死队友的击杀和助攻算烈娜塔的（和英雄联盟一样） |

## 怎么做的

- `mod.override_info` 把主包的烈娜塔换成 `override/` 里的副本（`make_override.py` 用 `tools/kit/build_renata.py` 的 `native=1` 生成，主包的烈娜塔
  改了就重跑）：普攻照样挂印记（数据不再引爆）、数据不再放 W、狂暴照样禁攻击禁技能（不带数据的乱打），被动是本包的 `league_renata:glasc`
  （数字在 `passive.params`）；普攻、大招的说明开头加【附加包】。
- **物尽其用**（league_braum 读队友普攻的做法）：被动每 tick 看她这边每个玩家的冷却，普攻冷却跳起来就是出手了——他身边最近的敌方单位是带印记的
  英雄就记下；技能冷却跳起来就记下他身边带印记的敌方英雄；10 tick 后（前摇加飞行）还带着印记就引爆、去掉印记，播主包的 `p_pop`。
- **及时救难**（league_zilean_rewind / league_sion 的「不死」和回满）：她活着、W 不在冷却（25 秒）时每 15 tick 找一次 8 格内危急的队友，挑生命比例
  最低的，挂主包的 buff `league_renata_w_buff`（攻速、移速、不死，画面照主包），她播施法动作。生命掉到 1（身上没有别人的「不死」）就回满，buff
  换成不带「不死」的同名 buff（烧的时候敌人照样打得死他），每 tick 扣最大生命的 1/180；他的击杀 + 助攻数变多就止住、生命定在最大生命的 20%
  （`w_keep`，和致命一击同一 tick 的击杀也算），到时没变就阵亡（算离他最近的敌方英雄的，附近没有敌方英雄才算最近的敌方单位；补刀照死歌的
  做法：清护盾、生命设 1、一刀 1001 真实伤害，下一 tick 还站着就再补，30 tick 还不行就把生命设成 0，他真倒下了才记 `DOOMED`）。她在致命一击之前
  阵亡：剩下的时间换成不带「不死」的 buff（被动停了，没人回满，留着「不死」队友就白白不死到 5 秒结束）；她阵亡时正在烧的（或那一 tick 正好
  被救下的），烧的状态写在他身上的 buff 名字里（`league_renata_w_doom:…`），排进效果队列的 `league_renata:burn` 每 tick 接着烧到底。
- **和别的「不死」的先后**（0.2.0）：死歌、塞恩、艾尼维亚、扎克、扎恩、tft 石甲虫的被动一直挂着护身「不死」（名字以 `_p_guard` / `_rv_guard`
  结尾），它们自己的复活都等别人的「不死」先用掉；基兰的时光符文也等别人。救难不等这两种（英雄联盟的顺序：及时救难先救），致命一击照样回满、
  开始烧；烧到 1 血时他的被动 / 基兰的倒流才接手（`BURN HANDED OVER`：他死进了别人的救命里，本包放手，不再补刀）。千珏的大招、凯尔的大招、
  索拉卡的护身那种有时限的「不死」照样等它们过了再救。已经在死后形态里的人（塞恩的尸体、死歌的灵体、艾尼维亚的蛋、扎克的一滩、扎恩的复活、
  石甲虫的碎块、基兰的倒流）、放逐的、已经停在 1 血的不救（救了就是真复活）。
- **狂暴**：被化学波扫中的敌方英雄身上有主包的 `league_renata_r_berserk`。AI 钩子 `league_renata:berserk`（问所有玩家，优先级最高）让他走向
  12 格内最近的自己人，到 4 格内站住；被动按他自己的攻击间隔用他自己的攻击力打那个自己人，让他挥一下、播主包的 `r_lash_hit`。这一下算烈娜塔
  出手（`deal_damage_typed` 的攻击者是她），击杀、助攻记在她头上，和英雄联盟一样（Riot 的开发文章 *Getting Guts: Berserk*）。
- **0.1.1 改了什么**（2026-10-17 反汇编游戏 0.6.4 查的）：0.1.0 用狂暴的人自己当攻击者，引擎也照收同队伤害（宿主不查阵营、两边实体在就返回
  true，所以「被拒就算她的」的退路从来不会走到），可引擎把死者算给最近一次伤他的英雄，不管是不是同队：被狂暴的人打死的队友，个人击杀、赏金和
  助攻都落到那个敌人自己的玩家身上（只有团队比分照样记给对面）。现在挥打一律算她的。另外：没保住的人改成算离他最近的敌方英雄打死的（0.1.0
  会选到小兵、野怪）；和致命一击同一 tick 拿到的击杀也算保住。
- 引擎细节：`deal_damage_typed` 只把伤害排进当 tick 的效果队列，返回 true 不代表已经扣血（出手后马上读生命读不到变化）；击杀、助攻计数在单位
  死亡结算那一步里加（和击杀记录、团队比分同一处），被动每 tick 读，救难的 3 秒来得及。经典引擎（mod SDK 0.5.1 的 game_core）对照：AI 钩子按
  优先级从低到高问，后一个拿到前一个的结果，最后的 Replace 生效；被禁攻击、禁技能的人移动指令照样有效，狂暴的人确实走向队友。
- 日志：`%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_renata.log`：`POP`（谁打中谁引爆）、`BAILOUT`（给谁，生命多少）、`REFILL`（致命一击回满、开始烧）、
  `BURNED`（烧的时候被打死）、`SAVED`（参与击杀止住，生命从多少定到多少）、`DOOMED`（没参与，补刀后真倒下了，算谁的；`DOOM RETRY` / `DOOM FORCED` 补刀没一下成）、
  `BURN HANDED OVER`（烧的时候别人的救命接手：死歌的灵体、基兰的倒流……）、`BURN on … goes on without her`（她阵亡，效果队列接着烧）、`BERSERK`（狂暴的人走向谁、离他多远，每秒一行）、`LASH`（打了谁、多少），都限了条数。

- **0.1.4（2026-11-03 的日志）**：待命没用上的 R 从来不退冷却：数据在待命标记过期的那一 tick 才看它（n tick 的标记只看得到 n−1 tick，champion-data 第 8 节），11-02 夜里 league_ult_press 记的退还全是 0；现在提前 3 tick 看（主包 0.298.0 的同一处，本包的副本重新生成）。
- **0.1.5（2026-11-03 玩家反馈「她的W技能直接就把英雄复活了，而不像在《英雄联盟》原版里那样的机制」）**：回满之后的 3 秒还带着「不死」，敌人怎么打
  都打不死，参与击杀后又留着几乎满的血，看起来就是复活。现在照英雄联盟（「生命回满，但承受会把他烧死的真实伤害」）：回满后不再不死，烧的时候
  敌人照样打得死（日志 `BURNED`）；参与击杀止住，生命定在最大生命的 20%（新参数 `w_keep`）；她在致命一击之前阵亡，剩下的时间只给攻速、移速。
  日志的 `REVIVE` 改名 `REFILL`。说明文字跟着改（5 种语言）。
- **0.2.0（2026-11-05 用户「烈娜塔的复活也查一查 真的修好了吗」，按代码复查）**：正常路径 0.1.5 已经对了（11-03 夜里 Quinn `REFILL` 180 tick 后
  `DOOMED`）。剩下的：(1) 救难等身上任何别的「不死」，死歌 / 塞恩 / 艾尼维亚 / 扎克 / 扎恩 / 石甲虫一直挂着的被动护身也算，他们又等救难——
  队友停在 1 血谁也不动，5 秒后救难「没用上」、他的被动才触发；现在不等 `_p_guard` / `_rv_guard` 和基兰的符文（见上）。(2) 救难会给尸体塞恩、
  灵体死歌、蛋里的艾尼维亚等（塞恩的尸体被救 = 回满 = 真复活），现在跳过死后形态、放逐的、已停在 1 血的。(3) 到期补的那一刀 `hp + 1000`
  护盾、减伤能吃掉，日志却记了 `DOOMED`；现在清护盾、生命设 1、补刀、再补、30 tick 后设 0，真倒下才记。(4) 先看到期再看生命：到期那一 tick
  的致命一击不救；现在先看生命。「没用上」时拿掉 W 的 buff。(5) 她和队友同一 tick 倒下 / 她在烧的时候倒下：以前只换 buff 或当场判定，现在
  照样回满、烧到底（效果队列接手）。(6) 烧的状态过期（被动没跑）以前只撤掉，现在到期就补刀。只装主包不装本包：数据版的 W 是「5 秒不死 +
  结束回血」，看着就像复活，这是主包纯数据做不到致命伤害判定的折中，不改。
- **0.1.6（2026-11-03 夜里的日志：`REFILL #1: league_kindred caught at 1 hp ...` 之后再没有一行）**：阵亡的英雄实体多半下一 tick 就没了，
  救难读不到他就悄悄结束；现在照样记一行（`BURNED ... (gone)` / `BAILOUT ended: ... died anyway (gone)`，她阵亡时 `BAILOUT ended: ... dead too
  (Renata died)`），名字在救难开始时记下。玩法不变。

## 在游戏里测

1. 主包（League of Legends Heroes 0.136.0 以上）要装着并启用。
2. 用附加包合集 `league_addons`（里面已经包含本包），或者把整个 `league_renata` 文件夹放进 `<游戏目录>\mods\`（文件夹里要有 `league_renata.dll`、
   `mod.mod_info`、`mod.override_info`、`override\`、`text\`）。
3. 进游戏，鼠标停在烈娜塔的普攻或大招上，说明开头是【附加包】就说明副本生效了；打一局后看日志里的 POP / BAILOUT / REVIVE / SAVED / DOOMED /
   BERSERK / LASH（BERSERK 的距离一行比一行近就是走过去了；LASH 后面写「refused」才是宿主没收）。

开发：`cd addons && set CARGO_TARGET_DIR=C:\t\rn_target && cargo test --release -p league_renata && cargo build --release -p league_renata`（工作区路径太深，
链接器要短的目标目录）。
