# 烈娜塔附加包（测试版 v0.1.0，可选）

**不装这个附加包，主包里的烈娜塔也是完整的**：被动物尽其用（普攻打中英雄挂印记，印记附近有两个她这边的英雄就引爆）、E 忠诚激励（两枚飞弹：
碰到敌人炸开减速，经过的队友得到护盾）、Q 铁腕竞合（抓住第一个敌人定身，再甩过她身边砸到地上）、被动自动放的 W 及时救难（队友被控或团战时：
加攻速移速、5 秒内不会阵亡、结束时回血）、R 恶意收购（看场面放：被化学波扫中的敌方英雄狂暴，不能攻击她这边、不能放技能，每 0.5 秒伤害身边的
自己人）都在主包数据里。主包是纯数据：**数据听不到队友的攻击**（所以印记按「附近有两个她这边的英雄」引爆）、**读不到生命和击杀**（所以救难只能
「不会阵亡、结束回血」）、**没有让单位打自己人的效果**（所以狂暴是一圈魔法伤害）。这个附加包用原生代码把这三件事做成英雄联盟的样子
（用户 2026-10-17：「方案可以，全按推荐做（辅助、Util，布局 A，做扩展包，PPU 1.5）」）。

| | 主包（纯数据） | 装了附加包 |
|---|---|---|
| 物尽其用 | 印记附近有两个她这边的英雄时引爆 | **队友真的打中它才引爆**（普攻或技能）：魔法伤害 + 最大生命 3% 的真实伤害 |
| 及时救难 | 队友被控或团战时：攻速 +40%、移速 +20%，5 秒内不会阵亡，结束时回复 200 + 60% 法强 | **英雄联盟的规则**：给危急的队友（身边有敌方英雄，被硬控或生命不到 45%），5 秒内受到致命伤害就回满生命，3 秒内流失到 1；这 3 秒里参与击杀就保住，没参与就阵亡 |
| 恶意收购的狂暴 | 不能攻击她这边、不能施法，每 0.5 秒对身边的自己人造成魔法伤害 | **真的转身打自己人**：走向最近的队友（英雄优先），按他自己的攻击间隔、用他自己的攻击力打 |

## 怎么做的

- `mod.override_info` 把主包的烈娜塔换成 `override/` 里的副本（`make_override.py` 用 `tools/kit/build_renata.py` 的 `native=1` 生成，主包的烈娜塔
  改了就重跑）：普攻照样挂印记（数据不再引爆）、数据不再放 W、狂暴照样禁攻击禁技能（不带数据的乱打），被动是本包的 `league_renata:glasc`
  （数字在 `passive.params`）；普攻、大招的说明开头加【附加包】。
- **物尽其用**（league_braum 读队友普攻的做法）：被动每 tick 看她这边每个玩家的冷却，普攻冷却跳起来就是出手了——他身边最近的敌方单位是带印记的
  英雄就记下；技能冷却跳起来就记下他身边带印记的敌方英雄；10 tick 后（前摇加飞行）还带着印记就引爆、去掉印记，播主包的 `p_pop`。
- **及时救难**（league_zilean_rewind / league_sion 的「不死」和回满）：她活着、W 不在冷却（25 秒）时每 15 tick 找一次 8 格内危急的队友，挑生命比例
  最低的，挂主包的 buff `league_renata_w_buff`（攻速、移速、不死，画面照主包），她播施法动作。生命掉到 1（身上没有别人的「不死」）就回满、每 tick
  扣最大生命的 1/180；他的击杀 + 助攻数变多就保住，到时没变就阵亡（算离他最近的敌方英雄的）。
- **狂暴**：被化学波扫中的敌方英雄身上有主包的 `league_renata_r_berserk`。AI 钩子 `league_renata:berserk`（问所有玩家，优先级最高）让他走向
  12 格内最近的自己人，到 4 格内站住；被动按他自己的攻击间隔用他自己的攻击力打那个自己人（`deal_damage_typed`；引擎不认同队伤害就算在烈娜塔
  头上），让他挥一下、播主包的 `r_lash_hit`。
- 日志：`%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_renata.log`：`POP`（谁打中谁引爆）、`BAILOUT`（给谁，生命多少）、`REVIVE`（被救下）、
  `SAVED`（参与击杀保住）、`DOOMED`（没参与，阵亡）、`BERSERK` / `LASH`（狂暴的人走向谁、打了谁，是不是他自己的伤害），都限了条数。

## 在游戏里测

1. 主包（League of Legends Heroes 0.136.0 以上）要装着并启用。
2. 用附加包合集 `league_addons`（里面已经包含本包），或者把整个 `league_renata` 文件夹放进 `<游戏目录>\mods\`（文件夹里要有 `league_renata.dll`、
   `mod.mod_info`、`mod.override_info`、`override\`、`text\`）。
3. 进游戏，鼠标停在烈娜塔的普攻或大招上，说明开头是【附加包】就说明副本生效了；打一局后看日志里的 POP / BAILOUT / REVIVE / SAVED / DOOMED /
   LASH（LASH 后面写着「its own hit」就是引擎认了同队伤害，「credited to her」就是算在她头上）。

开发：`cd addons && set CARGO_TARGET_DIR=C:\t\rn_target && cargo test --release -p league_renata && cargo build --release -p league_renata`（工作区路径太深，
链接器要短的目标目录）。
