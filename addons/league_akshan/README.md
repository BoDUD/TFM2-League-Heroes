# 阿克尚扩展包（测试版 v0.1.0）

用户：「技能方案按 A 做（带扩展包）」「大招改rust也做不了吗」「做成复活队友的吧 游戏更新你就做动态寻址 方便自动找」。主包 `league`
的阿克尚是纯数据，不装这个包也完整可玩；这个扩展包用原生代码补数据做不到的部分：

| | 主包（纯数据） | 扩展包 |
|---|---|---|
| 无所不用（第 3 下） | 数他打中任何人的次数（打 A、B、A 也算 3 下） | 每个目标分别数 3 下（英雄联盟） |
| 恩怨相抵的子弹 | 前面每打中一发，后面的子弹 +30%（近似） | 按目标已损失生命：最低伤害到 3 倍（少 67% 生命时封顶，英雄联盟） |
| 恩怨相抵什么时候开火 | 蓄满 2.5 秒才开火 | 存的子弹打得死射程里血最少的英雄、或者他快跑出射程，就提前开火 |
| 什么时候放大招 | 对“刚被队伍打过”的英雄放（数据读不到生命） | 射程里有英雄生命 ≤ 50%（或存满打得死），身边没有贴脸的敌人、自己生命 ≥ 40% 才放 |
| 骄行荡寇的摆荡 | 钩索扔向目标，分段往前冲 | 钩点挂在他身边（偏离指向目标的方向 60 度、画面上在他上方），他绕钩点荡 120 度（半径 42000）到离目标最近的一端，每 tick 一节绳子从他手到钩点；被硬控就松手（英雄联盟的钩点是墙，团战经理的地图没有墙） |
| 骄行荡寇 | 没有刷新 | 参与击杀英雄后冷却刷新到 0.5 秒 |
| 赴险夺人 | 被 2 个以上敌方英雄围住时伪装加速 | 另外：杀了队友的敌方英雄成为恶徒 60 秒（头上有标记）；阿克尚在恶徒附近加速；阿克尚参与击杀恶徒时，被这个恶徒杀死、还在等复活的队友 **1 秒后在泉水复活**，阿克尚得 100 金 |

## 复活怎么做到的

稳定接口里没有改复活时间的函数（`player_respawn_time` 只读）。游戏给每个阵亡玩家记着“还剩几 tick 复活”，每 tick 减 1，
减到 0 时游戏自己在泉水重新生成这个英雄（新英雄、满血、等级装备不变）。本包把这个数改小到 60 tick（1 秒）：

- **动态寻址**：运行时读游戏自己的 `player_respawn_time` 和 `player_is_alive` 两个函数的机器码（从扩展接口给的函数表拿地址），
  认出“按编号取玩家”的虚表槽、存活标记和剩余 tick 的偏移，两个函数交叉核对一致才用（`decode`；游戏 0.6.4 是 +0x158 /
  +0x898 / +0x8a0）。游戏更新后偏移变了也能自己找到；认不出就不写，日志里记一行 `LAYOUT NOT FOUND`。
- **每次写之前**：玩家必须阵亡、内存里的存活标记是“阵亡”、读到的剩余 tick 必须等于游戏接口读到的值、而且 ≥ 1；只改小、
  绝不写 0（0 减 1 会变成永远不复活）；写完用游戏接口读回核对。只读的模拟（AI 思考时）不写。
- **比赛会重算好几遍**（预演、观看、回放）：只在模拟里阿克尚的被动里写，用的都是模拟里的数据（击杀记录），每遍结果一样。
- 最坏情况只是“不复活”，不会让游戏出错。

击杀记录里的“位置”按分路（上 / 野 / 中 / 下 / 辅）找玩家；对不上时日志里记 `kill log ... no player in lane`。

## 按键

- AI 钩子 `league_akshan:ult`：只在 R 已解锁、冷却好、5 级以上时按 R（低等级按会让游戏 AI 崩溃）；AI 自己想在不合适的时候放 R，
  就改成普攻那个目标（打不到就原地不动）。

## 日志

`%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_akshan.log`，每次启动游戏重写（上一次的留在 `.prev.log`）：`LAYOUT`、`MARK`、
`REVIVE`（复活前后的剩余 tick，或拒绝的原因）、`REFRESH`、`THIRD HIT`、`BULLET`、`R FIRE`、`R CAST` / `R HELD`。

## 命令

- `python addons/league_akshan/make_override.py`：从参数表重新生成 `override/` 和 `text/`（先核对主包的阿克尚和参数表一致）。
- 在 `addons/` 下 `cargo test --release -p league_akshan`：单元测试（游戏 0.6.4 真实机器码的解码、换寄存器 / 短位移也认得、对不上
  就拒绝、第 3 下、子弹伤害、副本的参数）。
- 在 `addons/` 下 `cargo build --release -p league_akshan`（Windows）得到 `league_akshan.dll`；`league_addons` 合集也会编进本包。
