## v0.2.0：国际赛每年换赛制、LPL 赛制

### 0.2.1（同一天，第二轮审查后）

- 打完的比赛 `running_state` 是 `{"End":…}`：0.1.x 当它「在打」（`Run::Other`），0.2.0 的 LPL 因此停在第一阶段。现在算打完。
- 碰不了的半年（游戏重排过）里留着瑞士轮 / 双败：下一次抽签那届也写成瑞士轮 / 双败（整年读起来一致，不写出游戏读不了的样子）。
- 挪过日子、又被游戏放回原来日子的半年：按没挪认，浮动核对再挪一次（0.1.x 的 applied again）。
- 两种事件各自定位（一种认不得只放过那一种）；公告的决赛日按这届的赛制（双败改单败早一周）。
- LPL 中途放弃：挪走的那场改回原来的对阵；第一阶段已经打完就留在常规赛之后那天打。进度里场次重复、骑士之路不够 3 场都不做。
- 用审查做的假游戏（真 SDK 接口 + 真实 2026-2029 日程）跑完整个 LPL 赛季：分组、骑士之路 BO5、季后赛 1-6 号种子、升降级都对。

用户 2026-11-26：「LPL赛制没有和英雄联盟一样」「各种大型赛事每年都是一样的有点无聊了」，选了「按登峰/涅槃做」「每年轮换」。

### 游戏怎么定赛制（查过 0.7.3 的 EXE，和 0.5.1 带符号的 game_core 对过）

新建生涯时选的联赛季后赛（单败 / 双败）、国际赛小组赛（瑞士轮 / 4 组循环）、淘汰赛（单败 / 双败）先写进每年的日程，
游戏建比赛时再从**这一年的整份日程**读回来：

| 建什么 | 函数 | 怎么判断 |
|---|---|---|
| 联赛季后赛（开赛季时） | `0x179f1d0`（league.rs） | 有 `LeaguePlayoff` 的 round > 4：双败 8 场，否则单败 5 场 |
| 国际赛小组赛（小组赛抽签） | `0x192e2e0` | 有 `TournamentGroupMatch` 的 round > 1：瑞士轮 33 场，否则 4 组单循环 24 场 |
| 国际赛淘汰赛（淘汰赛抽签） | `0x1925ec0` | 有 `TournamentMatch` 的 round > 2 或 index >= 4：双败 14 场，否则单败 7 场 |

0.5.1 里生成日程的 `generate_tournament_matches` 写的样子：分组是 round 0、1 各 index 0..11；单败是 round 0 四场、
round 1 两场、round 2 一场。比赛按每场自己的日期打（各联赛的比赛日、时间都不一样；压缩赛程也只是改每场的日期）。

### 国际赛（`formats.rs`）

- 每年 MSI、全球总决赛各抽一种，不和去年一样（没定过的年份当游戏原版：瑞士轮 + 双败）：
  - 全球总决赛：瑞士轮 + 单败（2023 年起的真实世界赛）45、4 组小组赛 + 单败（2015—2022）30、瑞士轮 + 双败（原版）25；
  - MSI：瑞士轮 + 双败 40、小组赛 + 双败 35、小组赛 + 单败 25。
  - 用存档的 salt 另起一串随机数，0.1.x 已经定下的别的规则不变（测试拿用户存档里 2029 年的规则对过）。
- 原版是什么样看这一年游戏自己的日程（用户的存档 2026-2028 是瑞士轮 + 双败，**2029 年淘汰赛已经是单败**，生涯设置改过），
  每种样子的日子都从它推（`half_days`）：
  - 双败 14 天 → 单败用第 0-3、7、8、11 天（就是游戏自己单败的排法：八强 4 天，隔 6 天半决赛 2 天，再隔 7 天决赛）；
  - 单败 7 天 → 双败：跨度够 17 天一天一场排开，最后一场在单败决赛那天（2029 春：5-29 到 6-15，夏季赛 6-16 开始）；
    不够就用游戏压缩赛程的排法（0.5.1 的 `generate_tournament_matches`，6 天打完）；
  - 小组赛 8 天：瑞士轮每天 4/4/4/4/4/4/6/3 场，分组每天 3 场。
- 日程：抽签前把这半年的小组赛、淘汰赛事件写成这一届的样子（`shapes`）。因为游戏看整年，下一次抽签的那一届要分组 / 单败时，
  另一届的瑞士轮 / 双败事件先写成分组 / 单败的样子，抽完再换回来；还在打的那一种不动。
- 只碰本包认得的半年：主赛事抽签那天和原版一样，两种比赛事件都是某种样子挪 k 天（`half_of`）；游戏自己重排过的不碰（日志
  `SCHEDULE … left as it is`）。生成的事件有一个不在这半年里（抽签之后、下个赛季开始 / 赛季补丁之前）就不换，不会越写越多。
- 0.1.x 的赛程浮动核对在原版样子上做（`canonical`），一次写进去再读回来对照。关掉 `cup_formats`：换回原版样子（还在打的不动）。
- 「不和去年一样」比的是去年实际打的（那一届的场数：小组赛 33 场是瑞士轮、淘汰赛 14 场是双败；没有就看规则、再看原版日程）。
- 拿用户存档里真的 2029 年日程（0.1.1 存的原版 + 现在的）试过 9 种组合：认得出、不定赛制时一个事件不动、重复跑不变。
- 0.1.x 定过规则的年份（用户的 2029 年）：还没抽签的那几届补上赛制，发一条「国际赛新赛制公告」。
- 洲际赛和同半年的大赛一起抽签，赛制一样。瑞士轮、小组赛全程 BO1（`swiss_bo1`），淘汰赛局数归 series_length。

### LPL（`lpl.rs`，只动 LPL 这一个联赛）

| 阶段 | 场次 | 说明 |
|---|---|---|
| 第一阶段 | 常规赛按日期前 45 场 | 10 队单循环 BO3（游戏排的前 45 场不是单循环、又已经开打的那一届不做） |
| 第二阶段 | 后 45 场里的 42 场 | 按第一阶段排名：登峰组前 6、涅槃组后 4，组内双循环 BO3（日期不动，同一天里一队只打一场） |
| 骑士之路 | 剩下 3 场，挪到常规赛和季后赛之间 | BO5：登峰 5 vs 登峰 6（胜者进季后赛）、涅槃 1 vs 涅槃 2（负者出局），前一场负者 vs 后一场胜者（胜者进季后赛） |
| 季后赛 | 游戏的 8 场 | 6 队双败：「常规赛第 1-4 名」换成登峰前四，「第 5、6 名」换成骑士之路两个胜者 |
| 升降级 | 游戏的 2 场 | LPL 这边换成涅槃组第 3、4 名 |

- 组内排名按总战绩：胜场、小分差、小分胜场、相互胜负、队伍编号。积分榜还是游戏的一张总表（两组场数不一样）。
- 开赛季时（`start`）先把以后每一步都查一遍：第一阶段是单循环（新的一届可以重排）、第二阶段 42 场排得进、骑士之路在季后赛前有
  空档、挪走的场次放得下；有一样不行这一届就不做（日志 `LPL <届> -> skip`），一场比赛都不动。
- 排对阵（`fit_tracks`）：一天一天地挑，同一天一队只打一场，每组最多提前一轮，两组进度尽量齐；一天 1-4 场都排得开（一天 5 场
  第二阶段本来就排不下：登峰组每队 10 场，42 场只有 9 天）。
- 第一阶段最后一场打完马上分组（`MatchFinished` 事件）；和它同一天的第二阶段场次开赛季时就挪到常规赛之后（以后是骑士之路），
  原来的日子和对阵记在进度里，中途放弃就改回去。放弃时进度保留：骑士之路排好以后放弃，骑士之路还是 BO5。
- 两边的队伍一起写：第二边写不进去，第一边改回原样。
- 骑士之路的对阵先写成「总排名第 5 对第 6」「第 7 对第 8」占位，第二阶段打完换成真正的对阵。
- 进度存在存档键 `lpl:<联赛届 id>`（p1 → p2 → kr → done），每一步发新闻。
- 局数：第一、二阶段 BO3，骑士之路 BO5（不跟每年的常规赛局数）。

### 设置、日志

- `settings.ini` 新加 `cup_formats`（国际赛每年换赛制）、`lpl_format`（LPL 赛制），1 开 0 关。
- 日志新行：`FORMATS`（补赛制）、`SCHEDULE`（写日程的样子）、`LPL <届>`（每一步写了什么、读回来对不对）、
  `MATCH FINISHED`（这次载入第一条比赛结束事件的内容）。

## 游戏原来的赛事

- **联赛**：6 个赛区（韩国、中国、欧洲、北美、南美、日本），各有一个一级、一个二级联赛，每个 10 支队伍。
  - 每年春季、夏季两个赛季，有季后赛和升降级赛。
  - 来源：`asset/base/setting/data_setting` 的 `leagues`。
- **国际赛**：4 个，都是 16 队瑞士轮（5 轮：8 / 8 / 8 / 6 / 3 场）加 8 队双败淘汰（14 场）。
  - 东部 / 西部挑战者杯（`ChallengersEastern` / `ChallengersWestern`）、大师赛（`Masters`）、冠军赛（`Champions`）。
  - 上半年大师赛和两个挑战者杯同时打，下半年冠军赛和两个挑战者杯同时打。
  - 来源：同一个文件的 `tournaments`。
- **全年日程**：每年一条 `YearSchedule` 记录，是一串（日期，事件）。
  - 事件有 13 种：`StartRecruit` / `EndRecruit`、`LeagueScheduleCreate {ty}`、`LeagueMatch {index, round}`、
    `LeaguePlayoff {round}`、`LeaguePromotion`、`DrawingTournamentGroup {ty}`、`DrawingTournament {ty}`、
    `TournamentGroupMatch {index, round}`、`TournamentMatch {index, round}`、`MinorPatch` / `MajorPatch` / `SeasonPatch`。
  - 每年都一样（只按星期对齐）。
- **对局长度**：每场比赛的 `need_win`（BO1 = 1，BO3 = 2，BO5 = 3，BO7 = 4）。

### 存档里看到的（0.0.1 的探测）

- 抽签（`DrawingTournamentGroup` / `DrawingTournament`）时整届比赛一次建好，每场带日期。
  - 主赛事（大师赛 / 冠军赛）比赛的日子就是日程里 `TournamentGroupMatch` / `TournamentMatch` 事件的日子：
    `{index, round}` 是这一轮的第几场，一天 4 场（13 / 15 / 17 / 19 点）。
  - 挑战者杯的日期比主赛事早：小组赛早 4 天，淘汰赛早 3 天。所以比赛是按自己的日期打的，日程事件只是排日期用。
- 瑞士轮的局数是游戏自己定的：BO1，决定晋级、淘汰的场次 BO3（2027 年秋天起；2026 年还是全程 BO3）。
- 每个杯赛每届一条 `TournamentCompetition`，抽签那天才有。春天没有冠军赛那一届，游戏照样走日程。

## v0.1.0：每年的赛制

每年第一次有比赛等着打的时候定这一年的规则（`Rules`），存进存档（本包自己的存档区），读档不变。随机种子每个存档一个，
所以不同的生涯每年不一样。

| 每年定的 | 怎么定 |
|---|---|
| 各联赛常规赛 | BO1 或 BO3：一级联赛三成 BO1，二级联赛一半一半 |
| 洲际赛（东 / 西挑战者杯） | 上半年、下半年各自三成停办：没进国际赛的队伍休整 |
| 国际赛赛程 | 上半年往前挪 0-3 天；下半年往前 3 天到往后 2 天 |
| 主办地 | MSI、全球总决赛各一个赛区（首尔、上海、柏林、洛杉矶、圣保罗、东京），不连着两年同一个，两项不在同一个 |
| 奖金池 | MSI 原版的 90-130%，全球总决赛 90-140%（Tournament 记录的 `prize_money`） |

- 瑞士轮不随年份变：全程 BO1（0.1.1，用户看到 0.1.0 公告的「瑞士轮全程 BO3」后：「瑞士轮应该改成BO1吧？淘汰赛BO7就行」）。
  `settings.ini` 的 `swiss_bo1 = 0` 回到游戏原版（BO1，决定晋级、淘汰的场次 BO3）。
  - 0.1.0 存下的规则里还带着每年的瑞士轮赛制（`swiss_bo3`）：0.1.1 读到就去掉；公告过「全程 BO3」而瑞士轮还没打的，
    补发一条「国际赛赛制调整」新闻。
- 定好后往用户球队的新闻里发一条年度公告（`news_push`）。
- 装上那一年联赛已经开打：常规赛和上半年照原版，只定下半年；这一年秋天的赛程一定挪（试验）。
- 赛程能挪多少看日程的空当：
  - 前面：挑战者杯的小组赛（比主赛事早 4 天）不能早于升降级赛的第二天；
  - 后面：决赛不能晚于下一个赛季开始（上半年）或赛季补丁（下半年）的前一天。
  - 原版日程上半年后面没有空当，所以只往前挪。

### 局数怎么改

每 10 秒（或者比赛总数变了）看一遍还没打的比赛（`running_state` 是 `Wait`）：

- 常规赛：开着的联赛的 `matches`，按这一年这个联赛的 BO1 / BO3 改 `need_win`；
- 瑞士轮：开着的杯赛（主赛事和洲际赛）的 `group_matches` 全改成 1（BO1）；`swiss_bo1 = 0` 时不碰；
- 淘汰阶段一律不碰。

### 赛程怎么改

改之前的日程存进存档（`orig_schedule:<年>`），改的地方分两步，防的是游戏不按改过的日程排比赛：

1. **抽签之前**（定规则时）：
   - 往前挪：只挪瑞士轮的日子；
   - 往后挪：瑞士轮、淘汰赛抽签、淘汰赛一起挪；
   - 洲际赛停办：去掉它这半年的小组赛抽签和淘汰赛抽签。
2. **抽签之后**（新的一届出现时）核对主赛事第一场小组赛的日子：
   - 在挪过的日子上：往前挪的这时把淘汰赛抽签和淘汰赛也挪过去；
   - 不在（游戏按自己的日子排了）：挪过的事件都放回原来的日子，发一条「赛程调整没有生效」的说明；
   - 洲际赛停办了却还是抽了签：把它的淘汰赛抽签加回去，说明里写「洲际赛照常举办」。
3. 淘汰赛抽签后再核对一次淘汰赛第一场的日子（只记日志）。

每次写日程都会再读一遍，和写进去的对照。抽签前日程要是被游戏改回去了，再改一次。

## 设置

本包文件夹里的 `settings.ini`，1 开 0 关，改完重启游戏：

- `yearly_formats`：每年变赛制（关了整个 0.1.0 都不动，只剩名字）；
- `schedule_float`：赛程浮动、洲际赛停办；
- `swiss_bo1`：瑞士轮全程 BO1；
- `probe`：每次载入写一份只读探测（`league_esports_probe.json`）。

## 日志

`league_esports.log`，在游戏 `log.log` 旁边（`%APPDATA%\TeamSamoyed\TeamfightManager2\data`）：

- `RULES`：这一年的规则；`NEWS`：公告原文；`PRIZE`：奖金池；
- `FLOAT A`：抽签前改日程（挪了几天、洲际赛办不办、写进去读回来是否一样）；
- `CHECK B` / `CHECK C`：抽签后核对小组赛 / 淘汰赛的日子；
- `NEED_WIN`：改了多少场的局数；`SEASON ROLLOVER`：赛季切换。
