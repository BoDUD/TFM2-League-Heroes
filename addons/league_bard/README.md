# 巴德「神奇旅程」避墙附加包（v0.1.0，可选）

用户：「巴德的传送别乱放啊 逻辑改一改」，选了「往己方后撤，不穿墙」。主包是纯数据：被近身时开门，巴德背向最近的敌方英雄强制位移，
身边的友方英雄被拉过去；引擎的强制位移不管地图的墙，模拟里四成左右穿过野区的石头、落在石头里，看着像乱传。数据读不到墙，所以由这个附加包挑出口。

**不装这个附加包，主包里的巴德也是完整的**（门照开，只是可能穿墙）。

| | 主包（纯数据） | 装了附加包 |
|---|---|---|
| 什么时候开门 | 身边 30000 内 2 名或 15000 内 1 名敌方英雄（16 秒一次） | 照旧（同一套数据） |
| 往哪走 | 背向最近的敌方英雄 60000，可能穿石头 | 背向身边敌人中心、左右 80° 内 48 个方向，每个方向从 60000 缩到 30000，取一路不碰墙、落点不在墙里也不贴地图边的点；挑落地后离敌人最远、又朝己方最近的塔走得多的那个；都不行就不动 |
| 队友 | 被拉到他身边（可能穿石头） | 门边 25000 内的友方英雄走同样的位移；那里有墙就落在他出口旁，再不行就不带 |

## 怎么做的

- `mod.override_info` 把主包的巴德换成 `override/` 里的副本（`make_override.py` 从主包生成，主包的巴德改了就重跑）：
  `tools/kit/build_bard.py` 的 `native=1`：门、动作、画面、音效、加速、出口门的时刻都和主包一样，去掉 MoveBack 和拉人，开门 9 tick 后给他
  3 tick 的标记 `league_bard_e_go`；`passive` 挂本包的被动 `league_bard:door`（参数 `e_tick`、`e_far`、`e_min`、`e_ride`、`e_near`）；
  技能 2 的说明换成 `description.league_bard.skill2`（开头「【避墙版】」），游戏里看说明就知道副本生效了没有。
- 被动 `door`（`src/lib.rs`）看到标记就挑出口，`e_tick`（15）tick 内强制位移过去；宿主没挪人时逐 tick 自己走一步（泰隆的做法）。
  墙是卡蜜尔钩墙附加包的那份地图（`league_camille_wall/src/maps.rs`，5v5 地图 90 格，每格 32000）。
- 测试：`cargo test -p league_bard`（含在真实 5v5 地图上逐点检查出口不碰墙）。

## 在游戏里测

1. 主包（League of Legends Heroes 0.108.0 以上）要装着并启用；玩家装的是附加包合集 `league_addons`，巴德的部分和这里一样。
2. 看巴德技能 2 的说明：开头是「【避墙版】」就说明副本生效了。
3. 日志在 `%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_bard.log`，每次启动游戏重写（上一次的留在 `.prev.log`）：
   - `DOOR #2: (412000,288000) -> (452000,281000) (40610, map 0, home (368000,592000)), allies [#21 ...]`：开门后的出口和跟着走的队友；
   - `DOOR #3: no exit clear of rock ...`：四面都是墙，没动。
