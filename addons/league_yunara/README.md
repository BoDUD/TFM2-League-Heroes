# 芸阿娜附加包（测试版 v0.1.0，可选）

**不装这个附加包，主包里的芸阿娜也是完整的**：被动初生之誓（念珠附带的魔法伤害也会暴击，基础暴击 10%）、Q 灵蕴拳（攒满灵蕴自动开启：
攻速、额外魔法伤害、溅射周围敌人）、W 善恶轮 / 超凡形态的寂灭掌射线、E 明踪步 / 超凡形态的夜影翻冲刺、R 定圣诀（团战中进入超凡形态 15 秒）都在主包数据里。
主包是纯数据：**数据只能往后冲刺一段**（往前冲固定距离做不出来）、**读不到她实际往哪跑**、**读不到当前血量**，**待机、跑步的动画不能在运行中换**。
这个附加包用原生代码把这几件事做成英雄联盟的样子（用户 2026-10-17：「方案可以，全按推荐做（……做附加包，R 形态换待机/跑步……）」）。

| | 主包（纯数据） | 装了附加包 |
|---|---|---|
| 夜影翻（超凡形态的 E） | 敌方英雄贴身（35000 内）就往后冲，不然只加速 | **按情况选方向**：最近的敌方英雄残血（35% 以下）又快出射程就往前冲把它拉进射程；它贴身、或她自己残血（40% 以下）就往后冲 |
| 明踪步 | 释放时攻击距离内没有敌方英雄算「追击」，给 +60% 移速，不然 +40% | **读她实际的移动**：+40%，她真的朝最近的敌方英雄跑时（方向偏差 45° 以内）再加 20%（英雄联盟的 1.5 倍） |
| 定圣诀 | 附近有 2 个以上敌方英雄、或目标被控制才开 | **另外按真实血量**：大招射程内有敌方英雄残血（40% 以下），或她自己残血（50% 以下）而攻击距离内有敌方英雄，也开 |
| 超凡形态的样子 | 脚下和身后的金光（view_buffs `r_on`） | 另外**站着、跑着都画成带金边和头后光环的她**（游戏 0.6.4） |

## 怎么做的

- `mod.override_info` 把主包的芸阿娜换成 `override/` 里的副本（`make_override.py` 用 `tools/kit/build_yunara.py` 的 `native=1` 生成，主包的芸阿娜改了就重跑）：
  被动是本包的 `league_yunara:faith`（数字在 `passive.params`）；技能 2 和大招的说明开头加【附加包】。
- **夜影翻**：被动每 tick 看她身边（攻击距离 1.4 倍内最近的、看得见的敌方英雄），超凡形态中给她挂 `league_yunara_re_f`（往前）或 `league_yunara_re_b`（往后），
  5 tick，每 3 tick 刷新；副本的夜影翻读到标记就播翻身的动作并挂 `league_yunara_re_go`，本包看到后按当时的方向逐 tick 挪她（`re_v` x `re_t`）。
  两个标记都没有时副本照主包。被硬控就停（用硬控列表，不是 `cc_count() > 0`：游戏把正在播的施法动作也算成控制）。
- **明踪步**：副本里明踪步只给 `e_ms`%；她身上有 `league_yunara_e_ms`、3 tick 里走了 300 以上、方向朝最近的敌方英雄时，本包挂 4 tick 的
  `league_yunara_e_toward`（移速 +`e_ms2 - e_ms`%），一直跑就一直刷新，不朝它跑了就摘掉。
- **定圣诀**：条件满足时本包挂 6 tick 的 `league_yunara_r_ok`（每 3 tick 刷新），副本的大招门槛先看它，再看主包的人数和控制。
- **整身超凡**（`src/view.rs`）：照雷克塞 / 芮尔 / 杰斯附加包的显示钩子，游戏每帧更新显示时，名字是 `league_yunara`、身上有主包的 `league_yunara_r_on`
  的实体，正在播的 `idle / run / attack / hit` 换成图里的 `r_idle / r_run / r_attack / r_hit`（高清帧由 league.dll 自动换成 `hd_r_*`；普攻、挨打是 0.1.1 加的，原来金边会闪掉）。技能在超凡形态里是主包自己的 `skill_r` / `skill2_r`，阵亡照主包。
- 状态都在被动自己的实例里，同一局的两份预模拟和画面互不干扰。
- 日志：`%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_yunara.log`：`DASH`（往哪冲、为什么）、`DASH DONE`（实际挪了多远、被拒几步）、`TOWARD`（明踪步加成开关）、
  `RISE`（大招开了，是本包的 r_ok 还是主包的条件）、`FORM`（画面里换形态），都限了条数。

## 在游戏里测

1. 主包（League of Legends Heroes 0.131.0 以上）要装着并启用。
2. 用附加包合集 `league_addons`（里面已经包含本包），或者把整个 `league_yunara` 文件夹放进 `<游戏目录>\mods\`（文件夹里要有 `league_yunara.dll`、`mod.mod_info`、
   `mod.override_info`、`override\`、`text\`）。
3. 进游戏，鼠标停在芸阿娜的技能 2 或大招上，说明开头是【附加包】就说明副本生效了；打一局后看日志里的 DASH / DASH DONE / TOWARD / RISE / FORM。
