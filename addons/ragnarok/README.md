# ragnarok 包的代码（`ragnarok.dll`）

ragnarok 包（mod_id `ragnarok`，源文件在 [`ragnarok/`](../../ragnarok/)）是原生 mod：终末的女武神（Record of Ragnarok）的角色，数据做不到的地方写在这个 crate 里，编成 `ragnarok.dll` 跟着包一起装（`python tools/package_mod.py --src ragnarok ...` 会编好带上）。和金铲铲包一样，一个英雄一个模块；新英雄在 `src/` 加模块，在 `src/lib.rs` 的 `init` 里调用它的 `register`。

第一个英雄是吕布奉先（2026-11-20，用户：「codex/ragnarok-lubu-assets-v02 开始做新的mod了 codex完成了部分美术了 技能代码逻辑之类的都需要你来做」）。美术、图标、音频是 Codex 做的（[`assets/source/lubu/`](../../assets/source/lubu/README.md)），技能、数据、原生代码、高清帧接入和平衡是这里做的。

**高清帧**：[`src/hd.rs`](src/hd.rs) 是本包的高清帧表，`init` 先把它交给三个包共用的 [`hd_engine`](../hd_engine/src/lib.rs)：游戏里第一个加载的包 DLL 自己挂钩，后加载的把表交给它（[`share.rs`](../hd_engine/src/share.rs)），所以只开本包也有高清帧，和英雄联盟、金铲铲包一起开也不抢。现在十八个人都是两倍密度（一格 256，脚底点 (128, 232)），个子和原来一样：宙斯照 Codex 的原画按两倍重出（`tools/art/zeus_repixel.py`，共用的取样在 `tools/art/ragnarok_repixel.py`），吕布、索尔、亚当是 Codex 照动画第一季重画的（`assets/source/<英雄>/rebuild/`，`tools/art/<英雄>_rebuild_fix.py` 修成同一个头、收到 64 色），波塞冬是 Codex 按同样标准画的两倍身体（`tools/art/poseidon_rebuild_fix.py` 收色、特效按两倍从原画重出）。小次郎、赫拉克勒斯、杰克、雷电为右卫门、湿婆、释迦、零福、哈迪斯、秦始皇、别西卜、尼古拉·特斯拉、列奥尼达斯、阿波罗是 Codex 直接按两倍画的（`tools/art/<英雄>_fix.py` 收色；零福的斧爻、哈迪斯待机的双叉枪、列奥尼达斯的盾、阿波罗的光弓和女神像在那里重贴过）。PPU：吕布 3.233、索尔 2.225，其余十六人 2.75（2026-11-22 整包放大到联盟英雄的个子：用户「我发现女武神在格子里普遍偏小 不像英雄联盟那样」「放大到联盟大小」，联盟待机中位数 41.5 个游戏像素、本包原来 35，PPU 都除以 1.2，同样的像素画成 1.2 倍大、彼此的高矮不变；特效图不放大，贴在自己身上的几处按新个子重新对位；放大后选人卡挡腿的四个人在 `UI_SIZES` 里缩小，见 `src/hd.rs`。下面各节写的 PPU 和游戏像素是放大前的，乘 1.2 就是现在的；哈迪斯以后的六个人一开始就按 2.75 接）；1 倍帧是从高清帧缩出来的后备。打在别人身上的特效图（`EFFECTS` / `DRAWN_EFFECTS`）也是高清的：吕布 3.3、索尔 2.67、其余 3.3。重画的帧在格子里站的位置和原来不一样的（跑步前后滑、出手往前跳），`import_*.py` 的 SHIFT 整帧挪回去。引擎的日志：`%APPDATA%\TeamSamoyed\TeamfightManager2\data\ragnarok.log`。

数据：[`tools/kit/build_lubu.py`](../../tools/kit/build_lubu.py)（参数表 P，数值是 10 分钟经典引擎模拟调出来的，见文件头），文本和音效：[`tools/kit/setup_lubu.py`](../../tools/kit/setup_lubu.py)，图：[`tools/art/import_lubu.py`](../../tools/art/import_lubu.py)。

| 技能 | 做法 |
|---|---|
| 普攻 | 方天画戟重击，单体 100% 攻击力物理伤害 |
| 横扫（Q） | 第 0.42 秒戟扫前方扇形（半径 38000、左右各约 66°），50 + 130% 物理伤害、减速 40% 1.5 秒 |
| 破阵（E） | 第 0.34 秒朝目标冲 35200 单位、穿过去（引擎自己的冲刺，墙照样挡），路上的敌人 40 + 100% 物理伤害、击飞 0.6 秒 |
| 天喰（R） | 举戟蓄力 1.2 秒（不受控制、受到的伤害降低 30%），然后朝目标斩一刀：75000 长的一条线上的敌人 200 + 280% 物理伤害、眩晕 0.8 秒。一刀，不是持续激光；蓄力时被打死就不斩 |
| 被动 盾牌破坏者 | 下表 |

被动 `ragnarok_lubu:breaker`（参数 `p_pen` / `p_shield` / `p_break` 从数据的 `passive.params` 来）：

- **无视护甲**：每条命一出来就挂 `ragnarok_lubu_p_pen`（护甲穿透 15%，永久）。
- **打盾加倍**：他每一下（普攻和技能，`on_attack`）打到带护盾的敌人，对护盾多算 100%：只加到刚好打掉护盾为止，碎了以后的部分照常打血，不会越过护盾多打（护盾 s、这一下 d：加 min(d, s/2)）。
- **真的打碎才算**：下一拍再读目标的护盾，确实是 0 才算打碎：播碎盾的画面和声音，补 30% 攻击力的物理伤害。没碎就不播，日志记一行 `HELD`。
- **配音**：关智一的原声十句里，一局第一次和敌方英雄交手说「呂布の戦、しかと見届けよ」，杀英雄轮流说三句，复活说「この呂布奉先」，放破阵时三成概率说一句；每类有自己的冷却，任意两句至少隔 8 秒。天喰蓄力那句「全身全霊」是数据自己放的。

经典引擎跑不了原生代码，平衡模拟用 `build_lubu.py --plain`（护甲穿透改成第一个技能挂上，没有护盾那部分）。

## 宙斯

数据：[`tools/kit/build_zeus.py`](../../tools/kit/build_zeus.py)（参数表 P，数值是 10 分钟经典引擎模拟调出来的，见文件头），文本和音效：[`tools/kit/setup_zeus.py`](../../tools/kit/setup_zeus.py)，图：[`tools/art/import_zeus.py`](../../tools/art/import_zeus.py)（Codex 的五张图合成一张：老人的标签原样、膨胀 `mu_*`、阿陀磨须 `ad_*`、变身 `expand` / `ult` / `revert`）。

一个英雄、三种身体：形态是他身上的 buff（`ragnarok_zeus_mu` 膨胀、`ragnarok_zeus_ad` 阿陀磨须，都没有就是老人）。

| 技能 | 做法 |
|---|---|
| 被动 肌肉膨胀 | 每条命开始、阿陀磨须结束后是老人；老人打满几拳（数据里的施法者标记 c1、c2 …），下一拳改成膨胀：播 `expand`（1.02 秒，不受控制、减伤），完成时脚下一圈震伤周围的人并减速，此后这条命一直是膨胀（攻击、护甲、魔抗提高） |
| 普攻 | 快拳，100% 攻击力 |
| 连拳（Q） | 第 0.18、0.315 秒两拳；膨胀时第二拳减速，阿陀磨须时第二拳眩晕 |
| 超越时间之拳（E） | 伤害和眩晕在放的那一刻就打到，0.4 秒后才看见出拳（拳比时间快） |
| 阿陀磨须（R） | 压缩 1.04 秒（`ult`，不受控制、减伤；老人先播膨胀再压缩），完成时击飞周围的人，换成阿陀磨须几秒（攻击、双抗、攻速、吸血）；时间到播 `revert`（0.93 秒）变回老人，重新数拳；变身中被打死就什么都不发生 |

`ragnarok_zeus:voice`（没有参数）：
- **显示钩子**（`game_places::hook`，联盟包纳尔、奈德丽附加包的做法）：显示世界里名字是 `ragnarok_zeus` 的实体，按 buff 把正在播的 idle / run / hit / dead / attack / skill / skill2 换成 `mu_*` 或 `ad_*`；变身过程数据播，不碰；阵亡时 buff 清掉，尸体按倒下前的身体画。本 DLL 在 init 里先 `hd_engine::defer_display()`，真正换槽等第一帧（`Frame` 扩展），和别的 mod 共存不看加载顺序。
- **配音**：高木涉的原声，一局第一次出场、肌肉膨胀、放连拳时三成概率、杀英雄、复活各一句，各有冷却，任意两句至少隔 8 秒；宣传口号那句只放演示页（Codex 的建议）。死的时候放倒地声（对上死亡动作第 6 帧着地）。
