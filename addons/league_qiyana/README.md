# 奇亚娜附加包（测试版 v0.2.0，可选）

**不装这个附加包，主包里的奇亚娜也是完整的**：普攻和被动凌人贵气、Q 以绪塔尔之锋（三种元素：河流定身减速、岩石加伤、草丛伪装加速）、
E 天纵之勇（突进时用方圆塑令给武器附上元素、刷新 Q）、大招惊才绝景（冲击波击退再晕眩）和连招 E → Q、R → E → Q 都在主包数据里。
主包是纯数据：**读不到地图，元素只能按草丛 → 河流 → 岩石轮换**；`SwitchByBuff` 只读施法者自己，**凌人贵气只能是她自己的冷却**
（触发一次后 4 秒内对谁都不加伤）；**读不到目标的生命**，岩石只好对谁都多打一点。这个附加包用原生代码把这三件事做成英雄联盟的样子
（用户 2026-10-22「插件按局势选」；同一天改成「按地形：E 落地看附近的草丛、墙、河，附近都没有就退回按局势选。河先查地图数据，
没有就按中间斜带算」）。

| | 主包（纯数据） | 装了附加包 |
|---|---|---|
| 元素 | 每次突进按草丛 → 河流 → 岩石轮换 | **按身边的地形**（英雄联盟的 W 朝哪块地形放就拿哪种）：天纵之勇落地时看她身边两格（64000）内——**草丛**格子给草丛，**墙**格子和地图四边的石墙给岩石，**河道**给河流；几种都在时拿局势想要的那种（下一行），不在身边就拿最近的一种。**身边什么都没有时按局势选**：她自己生命 35% 以下（或 60% 以下且身边两名以上敌方英雄）选草丛（伪装加速脱身）；目标是生命 50% 以下的英雄选岩石（斩杀）；其他英雄选河流（定身）；野怪和小兵选岩石 |
| 凌人贵气 | 一次触发后 4 秒内谁都不加伤 | **每个敌人单独算**：对同一个敌人 10 秒内只加一次（英雄联盟：对每个敌人的第一次普攻或技能） |
| 岩石 | 对谁都多打 25 + 40% 攻击力 | 只对**生命 50% 以下**的敌人多打，加倍为 50 + 80% 攻击力，50% 以上不加 |

## 怎么做的

- `mod.override_info` 把主包的奇亚娜换成 `override/` 里的副本（`make_override.py` 用 `tools/kit/build_qiyana.py` 的 `native=1` 生成，
  主包的奇亚娜改了就重跑；它也核对 `src/lib.rs` 里 `Params` 的默认值和参数表 P 一样）：天纵之勇落地时的附魔换成本包的
  `league_qiyana:element`，每一下命中里的凌人贵气换成 `league_qiyana:royal`，岩石的额外伤害换成 `league_qiyana:rock`；被动是本包的
  `league_qiyana:empress`（只把数字 `passive.params` 留给这三个原生效果）；普攻、Q 和 E 的说明开头加【附加包】。
- **地形**（`src/terrain.rs`）：地图自定义钩子读地图文档的 `walls`（墙格子）和 `bushes`（草丛格子），和雷恩加尔、奈德丽的附加包一样，
  每种模式记一张，当前对局取站进墙里的单位最少的那张；格子 30 × 30，一格 32000。**河流先在地图文档里找**（`river`、`water` 等键）；
  2026-10-22 读到的地图文档只有 walls、bushes、nexus_pos、fountains、towers、camps，**没有河**，所以 5v5 地图按中间那条斜带算：从左上斜到
  右下、穿过两个大野怪（Morgard (288000, 288000) 和 Serpen (672000, 672000)，英雄联盟河道里的大龙小龙）、和两边水晶的连线垂直，墙格子里
  这条斜线两边一格内没有墙——|x − y| ≤ 48000 算河里。5v5 地图上约 97% 的地方两格内有墙或石墙，草丛也常见，只有两边基地附近什么都没有。
  合集 `league_addons` 一个 mod 只能有一个地图钩子：合集的 `MapReaders` 也调用本包的读法。
- **元素**：`league_qiyana:element` 读她落地的位置身边的地形、她自己的生命、她身边 40000 内的敌方英雄数、突进目标是不是英雄和它的生命，
  挑一种元素，去掉身上的元素、挂上主包的 `league_qiyana_el_on`（攻速 +25%）和那一种元素的 flag（`el_g` / `el_w` / `el_r`，数据读它们：普攻的
  附魔伤害、Q 消耗哪一种）。紧接着的 Q（E → Q 连招）在同一 tick 读到新元素。
- **凌人贵气**：`league_qiyana:royal` 记着（局、她、敌人）上一次加伤的 tick，过了 600 tick 才再加；加伤时播主包的 `p_hit` 画面和音效。
- **岩石**：`league_qiyana:rock` 读目标现在的生命，50% 以下时造成 2 × (25 + 40% 攻击力) 物理伤害（`deal_damage`，过护甲）。

## 在游戏里测

日志：`%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_qiyana.log`，每次启动游戏重写（上一份改名 `.prev.log`）。

- `SPAWN`：插件版奇亚娜出场（参数）。
- `== map mode=…: walls …, bushes …, river … ==`：读到的地图（每种模式一行）；河流不在地图数据里时写出地图文档有哪些键、用的是斜带。
- `ELEMENT Grass/River/Rock by Terrain/Situation at (x, y): grass … rock … river …; Spot {...}`：每次附魔选了什么、按地形还是按局势、
  身边三种地形各有多远（`-` 是两格内没有）、局势（她的生命、身边敌人、目标是不是英雄、目标的生命）；同一种元素 2 秒内只记一次。
- `ROCK #id: hp x/y`：岩石的斩杀打中英雄。

## 构建

`cargo build --release -p league_qiyana`（单独的 `league_qiyana.dll`），或者随合集包 `league_addons` 一起（`league_addons/src/lib.rs` 已登记）。
测试：`cargo test -p league_qiyana`（按地形和按局势挑元素、格子距离、河道斜带和地图边、当前对局的地图、岩石只在半血以下、凌人贵气每个敌人
单独算、参数读法、名字长度）。
