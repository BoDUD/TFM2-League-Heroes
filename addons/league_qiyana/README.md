# 奇亚娜附加包（测试版 v0.1.0，可选）

**不装这个附加包，主包里的奇亚娜也是完整的**：普攻和被动凌人贵气、Q 以绪塔尔之锋（三种元素：河流定身减速、岩石加伤、草丛伪装加速）、
E 天纵之勇（突进时用方圆塑令给武器附上元素、刷新 Q）、大招惊才绝景（冲击波击退再晕眩）和连招 E → Q、R → E → Q 都在主包数据里。
主包是纯数据：**没有地形，元素只能按草丛 → 河流 → 岩石轮换**；`SwitchByBuff` 只读施法者自己，**凌人贵气只能是她自己的冷却**
（触发一次后 4 秒内对谁都不加伤）；**读不到目标的生命**，岩石只好对谁都多打一点。这个附加包用原生代码把这三件事做成英雄联盟的样子
（用户 2026-10-22「插件按局势选」）。

| | 主包（纯数据） | 装了附加包 |
|---|---|---|
| 元素 | 每次突进按草丛 → 河流 → 岩石轮换 | 按局势选：**她自己生命 35% 以下**（或 60% 以下且身边两名以上敌方英雄）选**草丛**（伪装加速脱身）；**目标是生命 50% 以下的英雄**选**岩石**（斩杀）；**其他英雄**选**河流**（定身）；**野怪和小兵**选**岩石** |
| 凌人贵气 | 一次触发后 4 秒内谁都不加伤 | **每个敌人单独算**：对同一个敌人 10 秒内只加一次（英雄联盟：对每个敌人的第一次普攻或技能） |
| 岩石 | 对谁都多打 25 + 40% 攻击力 | 只对**生命 50% 以下**的敌人多打，加倍为 50 + 80% 攻击力，50% 以上不加 |

## 怎么做的

- `mod.override_info` 把主包的奇亚娜换成 `override/` 里的副本（`make_override.py` 用 `tools/kit/build_qiyana.py` 的 `native=1` 生成，
  主包的奇亚娜改了就重跑；它也核对 `src/lib.rs` 里 `Params` 的默认值和参数表 P 一样）：天纵之勇落地时的附魔换成本包的
  `league_qiyana:element`，每一下命中里的凌人贵气换成 `league_qiyana:royal`，岩石的额外伤害换成 `league_qiyana:rock`；被动是本包的
  `league_qiyana:empress`（只把数字 `passive.params` 留给这三个原生效果）；普攻、Q 和 E 的说明开头加【附加包】。
- **元素**：`league_qiyana:element` 读她自己的生命、她身边 40000 内的敌方英雄数、突进目标是不是英雄和它的生命，挑一种元素，
  去掉身上的元素、挂上主包的 `league_qiyana_el_on`（攻速 +25%）和那一种元素的 flag（`el_g` / `el_w` / `el_r`，数据读它们：普攻的附魔伤害、
  Q 消耗哪一种）。紧接着的 Q（E → Q 连招）在同一 tick 读到新元素。
- **凌人贵气**：`league_qiyana:royal` 记着（局、她、敌人）上一次加伤的 tick，过了 600 tick 才再加；加伤时播主包的 `p_hit` 画面和音效。
- **岩石**：`league_qiyana:rock` 读目标现在的生命，50% 以下时造成 2 × (25 + 40% 攻击力) 物理伤害（`deal_damage`，过护甲）。

## 在游戏里测

日志：`%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_qiyana.log`，每次启动游戏重写（上一份改名 `.prev.log`）。

- `SPAWN`：插件版奇亚娜出场（参数）。
- `ELEMENT Grass/River/Rock: Spot {...}`：每次附魔选了什么、为什么（她的生命、身边敌人、目标是不是英雄、目标的生命）；同一种元素 2 秒内只记一次。
- `ROCK #id: hp x/y`：岩石的斩杀打中英雄。

## 构建

`cargo build --release -p league_qiyana`（单独的 `league_qiyana.dll`），或者随合集包 `league_addons` 一起（`league_addons/src/lib.rs` 已登记）。
测试：`cargo test -p league_qiyana`（元素的挑法、岩石只在半血以下、凌人贵气每个敌人单独算、参数读法、名字长度）。
