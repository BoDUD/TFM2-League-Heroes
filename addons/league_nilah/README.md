# 尼菈附加包（测试版 v0.1.1，可选）

**不装这个附加包，主包里的尼菈也是完整的**：鞭刃普攻、Q 游刃万变（直线鞭击 + 4 秒强化普攻扇形顺劈回血）、E 纵情逐流（2 层冲刺，
落地接旋斩）/ W 轻纱飞漾（闪避普攻）、R 神恩激荡（旋转、拉人、给友方回血加护盾）都在主包数据里。主包是纯数据，有几件事做不到，
这个附加包用原生代码补上：

| | 主包（纯数据） | 装了附加包 |
|---|---|---|
| 喜色川流（被动） | 只有 Q 强化期间的普攻回血 | 另外**她和附近友方英雄每次回血、得到护盾都多 15%**（英雄联盟的「乐无止境」：她给的、给她的治疗和护盾都更强） |
| 轻纱飞漾什么时候放 | E 两层用完，AI 想放技能 2 就放 | E 两层用完后，**只有刚被敌方英雄打中才放**（0.75 秒内），没被打就先普攻，留着 W 躲集火 |
| 纵情逐流冲向谁 | AI 选的目标 | 射程内**血量比例最低的**敌方英雄 |
| 神恩激荡什么时候放 | 射程里有敌方英雄就放 | 圈里有 **2 个以上**敌方英雄才放；只有 1 个时，他血量不到一半、她自己血量不到 40%、或者附近没有别的敌方英雄会赶来，也放；最多等 1.5 秒 |

## 怎么做的

- `mod.override_info` 把主包的尼菈换成 `override/` 里的副本（`make_override.py` 用 `tools/kit/build_nilah.py` 的
  `native=1` 生成，主包的尼菈改了就重跑）：加上本包的被动 `league_nilah:joy`（参数 `amp` 15、`near` 100000），普攻、技能 2、
  R 的说明开头加【附加包】。
- **喜色川流**（被动 `joy`）：SDK 给被动的接口里没有「被治疗时」，所以每 tick 比对她和 `near` 以内的友方英雄的生命和护盾：
  涨了就按涨的量的 15% 补一次（`heal` / `entity_add_shield`，护盾持续 3 秒，和 R 的护盾一样），补的这份记进这一 tick，
  不会被下一 tick 再算一次；零头按百分之一攒着。复活、升级（最大生命变了）、一 tick 不到 3 点的自然回血不算；一下涨的护盾比最大生命还多的也不算——那是别的英雄数据里测等级 / 吸伤害用的机制护盾（维克托、卡莎、凯尔、卡兹克、辛德拉、崔丝塔娜的 1000000 点、1 tick 的护盾；v0.1.0 在游戏里给维克托补了 151537 点、3 秒，v0.1.1 修掉）。治疗和护盾
  不分来源（她自己的 Q 吸血、R、队友的技能和装备都算）。
- **被敌方英雄打中**：被动的 `on_damaged` 看到攻击者是敌方英雄时，给她挂 45 tick 的记号 buff `league_nilah_struck`（没有属性）。
- **挑时机、挑目标**（AI 钩子 `league_nilah:play`）：
  - AI 要放技能 2、E 两层都在充能（主包的 `league_nilah_e_x1` 和 `_e_x2` 都在）、W 不在冷却、身上没有记号：不放，改成普攻 AI
    原来的目标（打不到就走过去）。
  - AI 要放技能 2、E 还有层数：换成射程（55000）内血量比例最低的敌方英雄。
  - AI 要放 R：按上表判断；不放就普攻原来的目标，记下等了多久，等满 90 tick 就放。
- 原生代码只做判断和补量，伤害、闪避、拉人、R 的治疗护盾都在数据里。

## 在游戏里测

1. 主包（League of Legends Heroes 0.107.0 以上）要装着并启用。
2. 把整个 `league_nilah` 文件夹放进 `<游戏目录>\mods\`，文件夹里要有 `league_nilah.dll`、`mod.mod_info`、
   `mod.override_info`、`override\`、`text\`（或者用附加包合集 `league_addons`，里面已经包含本包）。
3. 进游戏，在 MOD 菜单里启用它（含代码的 mod 会弹一次确认），确认排在主包后面，重启游戏。
4. 看尼菈普攻的说明：开头是「【附加包】」就说明换上了。
5. 日志在 `%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_nilah.log`，每次启动游戏重写（上一次的留在 `.prev.log`）：
   - `JOY 某人#id: healed a -> +b, shield c -> +d`：给谁补了多少；
   - `STRUCK by …`：被敌方英雄打中，W 可以放了；`W HELD: no enemy champion has hit her`：W 压住了；
   - `E … -> … AIM`：E 换了目标；
   - `R CAST: …`（为什么放）/ `R HELD: …`（为什么等）。

## 开发

- `python addons/league_nilah/make_override.py`：从参数表重新生成 `override/` 和 `text/`（先核对主包的尼菈和参数表一致）。
- 在 `addons/` 下 `cargo test --release -p league_nilah`：单元测试（参数、哪些涨算治疗 / 护盾、零头、E 的目标、R 的时机）。
- 在 `addons/` 下 `cargo build --release -p league_nilah`（Windows）得到 `target/release/league_nilah.dll`；`league_addons`
  合集也会编进本包。
- 工作区路径太长时链接会失败（LNK1104），用短的 `CARGO_TARGET_DIR`（如 `C:\t\nl`）。
- 经典 SDK 的模拟器跑不了原生代码，本包只做了单元测试，要在游戏里看日志确认。
