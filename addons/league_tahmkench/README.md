# 塔姆附加包（测试版 v0.1.0，可选）

**不装这个附加包，主包里的塔姆也是完整的**：舌头抽打、培养品味的三层标记、巨舌鞭笞（回血、减速、三层眩晕）、深渊潜航、
厚实表皮的减伤和护盾、大快朵颐（救队友或吞敌人）都在主包数据里。主包是纯数据，有几件事做不到，这个附加包用原生代码补上
（用户 2026-10-15「附加包要」）：

| | 主包（纯数据） | 装了附加包 |
|---|---|---|
| 培养品味的层数 | 数他自己最近打中英雄的次数（换目标不清零），鱼标记画在被打的人头上 | **每个敌方英雄各自记层**（最多 3 层，5 秒），鱼标记按那个人自己的层数画 |
| 巨舌鞭笞打 3 层的人 | 大招上膛时留着层数，否则眩晕 | **大招冷却好了就留着层数给大招吞**，否则眩晕并吃掉层数 |
| 厚实表皮 | 固定少受 15% 伤害；被两名敌方英雄围住时给一个固定护盾 | **真的灰色生命**：受到伤害的 30% 存起来（最多最大生命的一半），3 秒没挨英雄打就慢慢回成生命；被两名敌方英雄围住、或生命低于 40% 且身边有敌人时，把存的全部加 160 + 80% 法强变成护盾（冷却 12 秒） |
| 大快朵颐吞谁 | 上膛后：被控住、身边有两个敌人的队友；没有就吞叠满 3 层的敌人 | **按真实生命判断**：生命低于 35% 且附近有敌人、或 1 秒内掉了四分之一以上生命、或被控住且身边两个敌人的队友（生命最低的先）；没有就吞近身 3 层的敌人；都没有就不放（改成普攻） |
| 吞着人的时候 | 塔姆照常打；被吞的人在被吞的地方吐出来 | 吞着队友**往远离敌人的方向走**，吞着敌人**往队友那边走**；吐出时把人放到他身边（队友在他背后，敌人在他前面） |
| 深渊潜航 | 身边一个队友且目标被控，或身边两个以上队友 | 同样的条件，再加上**落点附近的敌方英雄不多于身边队友加一**、**他自己生命不低于 30%**；不放时改成普攻或回到队友身边 |

## 怎么做的

- `mod.override_info` 把主包的塔姆换成 `override/` 里的副本（`make_override.py` 用 `tools/kit/build_tahmkench.py` 的 `native=1`
  生成，主包的塔姆改了就重跑）：
  - 普攻、W 命中英雄叠层调本包的 `league_tahmkench:taste`，Q 命中英雄调 `league_tahmkench:lash`；
  - 没有主包的固定减伤和护盾（被动 `league_tahmkench:skin` 按真实伤害做）；
  - W、R 都改成普通的点目标施放，目标由本包的 AI 钩子 `league_tahmkench:ai` 挑（或者不放）；R 的吞下本身还是数据（放逐只有
    数据能做）：一个只落在队友身上的探针、一个只落在敌方英雄身上的探针，各带那一边的效果，并调 `league_tahmkench:devour`
    记下吞了谁；
  - 普攻、技能 2、大招的说明开头加【附加包】，游戏里看说明就知道附加包有没有生效。
- 吐出：被放逐的单位不会动，本包在放逐结束的那一刻用 `entity_set_pos` 把他放下一次。塔姆死了，嘴里的人当场吐出。
- 数值：被动和大招的数字从英雄数据的 `passive.params` 来，`tests::the_numbers_match_the_kit` 读主包的参数表核对。

## 日志

`%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_tahmkench.log`，每次启动游戏重写：`STACK`（叠层）、`STUN` / `KEEP`（Q 打
3 层的人）、`SHIELD`（厚实表皮）、`R PICK` / `R HELD`（大招吞谁、不放的原因）、`DEVOUR` / `SPIT`（吞下、吐出）、`W KEPT` /
`W HELD`（潜航的时机）、`CARRY`（吞着人往哪走）。

## 构建

```bash
cd addons
cargo test -p league_tahmkench
cargo build --release -p league_tahmkench     # 单独的 DLL；合集 league_addons 也编进了它
python league_tahmkench/make_override.py      # 主包的塔姆改了就重跑
```
