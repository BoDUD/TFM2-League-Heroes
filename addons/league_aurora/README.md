# 阿萝拉附加包（`league_aurora`）

用户（2026-10-23）选技能方案时定了：「W 灵纱洞开并入被动：残血时跳开 + 隐身 + 加速（有冷却）」。2026-11-04：「阿罗拉的大招机制逻辑也是不太一样」——双界合一改成英雄联盟（V26.21）的规则。

主包的阿萝拉是纯数据：数据读不到生命，所以主包里的灵纱洞开只看「有敌方英雄贴身」（`w_near` 内）就后跳；数据也找不到领域的边界、挪不了她，所以主包的领域只是她站在里面时减速其中的敌人。这个附加包按她真实的生命来，领域照英雄联盟的边界来：

| 技能 | 主包（纯数据） | 附加包 |
|---|---|---|
| 灵纱洞开（并入被动） | 普攻或怪奇喷涌开头，`w_cd` 过了、`w_near` 内有敌方英雄，就往后跳开、隐身 `w_inv` tick、加速 `w_ms`% | 同样的跳法，但还要她**生命低于 `w_low`%**（默认 35%），英雄联盟「残血时跳开」 |
| 双界合一的领域 | 朝目标跃出 15000、加速 30% 4.5 秒，前方 25500 的冲击波（伤害、减速 30% 2 秒）留下领域 3.25 秒：**她站在里面、活着时**每 15 tick 减速其中的敌人 30%，有一次查到她不在里面就关掉（数据找不到边界） | 同样的跃出和冲击波；领域按英雄联盟的**边界**：敌人碰到边界**减速 50% 1.75 秒**（一次穿越一次，顶掉冲击波的 30%），里面、外面都不减；**她碰到边界就冲到对面**（0.4 秒，免伤免控），走不出去；她死了、到了外面（闪现、被敌人带出去）就关 |

用户（2026-10-24）：「阿罗拉大招逻辑怎么和LOL里面高手的不太一样」。游戏的 AI 见到射程里有敌方英雄就按 R（满血的坦克、敌方塔下、对面一堆人中间都放）。英雄联盟里会玩的阿萝拉把双界合一留着开团、收残血、自保。本包加一个 AI 钩子
`league_aurora:realm`（`src/realm.rs`）替 AI 挑时机。0.3.0 起 R 不再跳到目标身上，领域开在她落地处前方 25500（`centre`），下面「领域里」都按那个中心算：

| 时机 | 条件 | 日志 |
|---|---|---|
| 自保 | `PEEL_R`（22000）内有敌方英雄贴着她、她生命不到 50%：朝贴得最近的那个放（领域罩住他，边界和冲到对面帮她拉开） | `R PEEL` |
| 开团 | 她生命不低于 40%；朝 R 射程里的某个敌方英雄放时，领域（中心 43000 内）罩住两个以上敌方英雄，中心 60000 内至少有一个我方英雄，敌方人数不比我方（含她）多一个以上，中心不在敌方塔下：挑罩住人最多的方向（一样多挑血最少的目标） | `R TRAP` |
| 收残血 | 她生命不低于 30%；R 射程里生命不到 40% 的敌方英雄，身边 30000 内敌方英雄不超过两个，领域中心不在敌方塔下（不到 20% 的除外）：挑血最少的 | `R KILL` |
| 按住 | AI 自己想按 R，以上都不成立：不放，改成普攻目标（打不到就走过去） | `R HELD` |
| 领域里放风筝 | 领域开着，45000 内有敌方英雄（生命不到 25% 的除外：收掉他），她的普攻没好或 AI 不是要打射程里的英雄：往边界走（沿半径最近的那点，那人挡路就背着他走），碰到边界冲到对面 | `RIFT KITE` |
| 不出领域 | 领域开着、没人贴身，AI 要走出领域（走路、或走去打射程外的人）：只走到边界里 6000 停下（碰到边界会被送到对面） | `RIFT STAY` |

前四条在 AI 没想按 R 时也按。回城、被控住、正在放技能时不管；冲到对面的那 0.4 秒不管。

## 怎么接上的

`mod.override_info` 把主包的阿萝拉换成 `override/` 里的副本（`make_override.py` 用 `tools/kit/build_aurora.py` 的 `native=1` 生成）：

- 灵纱洞开的判断多读一个标记 `league_aurora_low`；
- 领域：冲击波中心那根隐形的线（`league_aurora_r_rift`）停下时不再开主包的减速区，改调本包的原生效果 `league_aurora:rift`：它把中心写进她身上的 `league_aurora_rift_new:<x>,<y>`，被动下一 tick 读走（`src/rift.rs`）；领域开着时被动每 tick 在她身上续 `league_aurora_rift:<x>,<y>`，AI 钩子据此在领域里走；
- `passive` 是本包的 `league_aurora:veil`，参数 `w_low`、`r_t`、`r_edge`、`r_edge_t`、`r_wrap_t` 来自主包参数表 P：每 tick 读她的生命，低于 `w_low`% 就挂上 3 tick 的 `league_aurora_low`（先摘再挂，只留一个），回血后 3 tick 自己消失；领域开着时管边界：
  - 敌人碰到边界（离中心 38000 ± 8000，画出来那一圈）：挂 `league_aurora_r_edge`（减速 `r_edge`% `r_edge_t` tick，脚下的霜雾），离开边界再碰才再挂；先摘掉冲击波的 `league_aurora_r_slow1`（英雄联盟的减速取最强的，TFM2 的相加）；
  - 她离中心 36000 以上：沿直径冲到对面离中心 30000 处（落点在墙里就往中心退），`r_wrap_t` tick 的强制位移、`veil` 的姿势，`league_aurora_r_wrap`（免伤、免控、穿墙：TFM2 里选不中只有放逐，放逐的单位挪不动）；她自己的后跳（怪奇喷涌、灵纱洞开：副本的数据给她挂 `league_aurora_own_hop`）撞上边界一样冲过去，被敌人击退、拉扯时不冲（不白白解控）；被眩晕、定身、嘲讽、恐惧、魅惑、击飞、禁止位移时等控制过去；两头各开一扇门（`league_aurora_r_blink`）；宿主没挪她就自己一步步挪，冲完离落点还远就直接放上去；
  - 关闭：她死了；到了 44000 以外（闪现、被敌人带出去）；开的时候她不在里面；`r_t` 到了（正在冲就冲完再关）。领域的画面是数据放的，提前关时照样放完；
- 普攻和大招的说明换成附加包自己的文字（`description.league_aurora.attack` / `.ult`，写着生命低于多少才跳、领域的边界），游戏里看说明就知道副本有没有生效。

计时都在被动自己身上（被动跟着单位、每局一份，游戏并行跑的几局互不相干），不用全局变量。英雄联盟里领域开着 1 秒后可以再按 R 提前关，TFM2 的大招没有再按，没做；Realm Hopper 的幽灵（穿过单位）也没有对应的字段。

## 检查

- 在 `addons/` 下 `cargo test --release -p league_aurora`：单元测试（参数、残血的界线、标记的名字、领域的几何（碰边界、对面、敌人碰边界、落点避开墙）、大招的四种时机按领域中心算、领域里放风筝和不出领域、R 射程、跃出距离、领域半径与参数表一致）。
- 主包的阿萝拉改了以后重新跑 `python addons/league_aurora/make_override.py`（它先核对主包的 `league_aurora.data_champion` 和参数表一致、`src/lib.rs` 的默认参数和 P 一致）。
- 日志：`%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_aurora.log`（你看的那场每行都写，预模拟每种前 40 行、之后每 100 行一行）：`SPAWN`、生命掉到界线以下 `LOW`、回到界线以上 `UP`；大招 `R PEEL` / `R TRAP` / `R KILL` / `R HELD`（带领域开在哪、罩住几个）；领域 `RIFT OPEN`（开在哪、她离中心多远）、`RIFT CROSS`（从哪冲到哪、是不是被墙挡了、是不是截住了她自己的后跳）、`RIFT EDGE`（谁碰到边界被减速）、`RIFT CLOSED`（时间到 / 她死了 / 她出去了，冲了几次、减速了几次）、`RIFT KITE` / `RIFT STAY`。
