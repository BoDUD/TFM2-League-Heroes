## 怎么做的

- `mod.override_info` 把主包的佐伊换成 `override/` 里的副本（`make_override.py` 用 `tools/kit/build_zoe.py` 的 `native=1` 生成，主包的佐伊改了就重跑）：
  被动是本包的 `league_zoe:sparkles`（数字在 `passive.params`）；Q、E、R 的说明开头加【扩展包】。
- **睡眠**（0.6.0）：副本和主包一样，困倦结束时数据在被打中的英雄身上落下眩晕（副本 135 tick，主包 120 tick 带睡泡）。副本里气泡打中英雄时另挂
  `league_zoe_e_mark`（困倦那 1.4 秒）；被动看见新的标记，眩晕落下就挂 `league_zoe_e_zz`（睡泡的画面）、记下他的生命 + 护盾；睡着时少了（任何伤害）
  就叫醒：只解除这一份眩晕（`kept_after_wake`，一起落下的队友控制留着），摘掉睡泡，放 `e_wake` 的画面和声音，那一下掉的再补一遍真实伤害（最多
  `e_cap` + `e_cap_ratio`% 法强，英雄联盟打醒的第一下双倍、有封顶）。被净化掉的也摘睡泡。
- **飞星**：副本里飞星打中的单位挂 2 tick 的 `league_zoe_q_hit`，伤害只算近的一档；出手时她身上有 `league_zoe_q_go`。被动在 `q_go` 出现时记下她的位置，
  看到新的 `q_hit` 就按出手点到被打中的人的距离补魔法伤害。大招门口的飞星不变（主包就是满伤）。
- **碎片**：被动每 tick 看每个敌方英雄的大招冷却，从 0 跳到 60 以上就是放了大招，在他站的地方放一块碎片（每 15 tick 重放一次 `league_zoe_w_shard` 的画面）；
  她活着、走到碎片 18000 以内就捡起：每 5 tick 一颗飞弹（直接造成伤害，放 `w_hit` 的画面和 `w_shot` 的声音），并挂 `league_zoe_w_haste`（移速 +40%）。
- 日志：`%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_zoe.log`：`STAR`（打中多远、倍数、补了多少）、`SLEEP`（谁睡着了）、`WAKE`（谁被打醒、
  那一下掉了多少、补了多少真实伤害）、`FREED`（睡眠被净化）、`MISS`（困倦结束后没睡着：困倦时被净化或免疫控制）、`SHARD` / `PICK`（谁掉了碎片、
  她捡了几块）、`SUMMON`（召唤师技能）、`WATCH`（每 30 秒的计数），都限了条数。

## 在游戏里测

1. 主包（League of Legends Heroes 0.165.0 以上）要装着并启用。
2. 用附加包合集 `league_addons`（里面已经包含本包），或者把整个 `league_zoe` 文件夹放进 `<游戏目录>\mods\`（文件夹里要有 `league_zoe.dll`、`mod.mod_info`、
   `mod.override_info`、`override\`、`text\`）。
3. 进游戏，鼠标停在佐伊的技能上，说明开头是【扩展包】就说明副本生效了；打一局后看日志里的 STAR / SLEEP / WAKE / SHARD / PICK。

## 重新生成

```bash
python tools/kit/build_zoe.py                 # 主包的佐伊（参数表 P）
python tools/art/draw_zoe_spells.py           # 召唤师技能的三张图（--sheets spells,spells_1x 不画要 assets/ 的图标）
python addons/league_zoe/make_override.py     # 本包的副本和说明
cargo test -p league_zoe --release            # 在 addons/ 下
```

## 游戏 0.7.0

- 0.3.1：醒的时候只解除她自己的昏睡（稳定接口只能一次清掉全部控制，以前叫醒会把一起落下的队友眩晕、击飞也清掉）。
- 0.4.0（用户：「新控制"睡眠"……冲突就直接调用官方的」「这两个顺带一起改了」）：改用游戏的官方睡眠，主包也是。官方规则是任何伤害都打醒、打醒那一下
  +100%（不再有英雄联盟的封顶）；自己的昏睡、打醒和补真实伤害都去掉了，0.3.1 的 `kept_after_wake` 也用不着了。官方睡眠是 0.7.0 才有的原生效果，
  所以新的佐伊要游戏 0.7.0。

## 0.5.1：她死后陷阱不再抓人（2026-11-02）

气泡没打中人时留在地上的陷阱是落地时开的区域，她死了也照样跑完；死人身上的标记冻住，`e_tdone`（抓过人了）在她死时还没挂上，就再也挂不上，陷阱每 3 tick 把踩进去的人再抓一次（伤害、催眠、出声）。陷阱在这个标记后面先问她还活着没有（`alive()`），改在 `tools/kit/build_zoe.py`，主包和本包的副本一起（查茂凯树苗「死后无限音效」时一起查出来的）。

## 0.5.2：召唤师技能的画面按原尺寸画、碎片只在她附近掉（2026-11-03）

用户：「佐伊好像有点bug？」「还有这个召唤师技能为什么满屏幕有 佐伊的」「大橙圈是召唤师技能屏障特效 你弄的太大了吧」「还有地上的召唤师技能图标
也太大了吧」「缩成小块外面用圆圈包裹着不是更美观吗」。

- **画大了 2–3 倍**：偷来的召唤师技能的画面（`league_zoe_spells`，PPU 2）和图标（`league_zoe_spell_icons`，PPU 3）10-22 登记成高清特效，
  可 league.dll 的 `DRAWN_EFFECTS`（按 1 / PPU 缩着画的特效表）只有艾翁的小菊和沙兵，其余高清特效一个格子画成一个游戏像素：屏障的金壳
  画成 88 × 104（设计 44 × 52，她身高的三倍），地上碎片的图标 34 px（和她一样高，设计 11 px），还往右下偏。league.dll 0.9.3 把这两张
  加进表里，所有召唤师技能的画面按设计的大小画、居中（和审图 GIF 一样）。
- **屏障贴身**：金壳从 44 × 52 缩到 30 × 44（`tools/art/draw_zoe_spells.py` 的 `barrier()`），像英雄联盟一样包着她。
- **地上的碎片**：图标改成圆形小徽章（`badge()`：图标切成圆，一圈技能颜色的圆环、上半边亮，外面一圈深色边），浮在碎片的小水晶上，
  约 12.7 px。以前地图上谁放大招都掉碎片，她去不了的远处也躺着；现在离她 `SHARD_NEAR`（150000）以内放的大招才掉。
- **睡眠的统计**：11-03 那局每一行 WATCH 都是 `sleeps 0`——不是游戏的睡眠没报成眩晕，就是睡眠没落下，日志分不出来。现在困倦结束后
  没看见睡着时记一行 `MISS`，写下他当时身上的控制（`种类代码:剩余 tick`），WATCH 也多一项 `missed sleeps`，下一局就知道是哪一种。

## 0.6.0：睡眠真的能睡着、召唤师技能的画面回到人身上（2026-11-05）

用户：「佐伊问题很大 好像不能催眠别人？另外捡起来的召唤师技能的技能特效完全错位你完全没改好」。

- **睡不着**：11-05 的日志里 24 行 `MISS`，困倦结束后目标身上的控制是 `[]`（一次也没落下），`sleeps` 一直是 0。0.4.0 起困倦结束时数据里落下的是
  催眠师 E 的原生效果 `hypnotist_skill2`。查了游戏 0.7.1 的 EXE（0x19f8726）：它在一个**点**上放一个范围（`hypnotist_sleep_area`，`delay` 后睡着
  范围里的敌人），点从输入目标来——位置（催眠师自己的 E 是 `Position` 施法）先拉回到这一招 `range` 以内（以施法者为起点），方向就取那么远，
  **单位什么都不取**：气泡打中的英雄是单位，范围落在佐伊自己脚下，半径 3000，只有贴着她的敌人才会睡。就算用落点抛射物把他的位置递过去，也会被
  拉回到 E 的 75000 以内，而困倦结束时目标多数在那之外（经典 SDK 模拟 18 局 199 次命中：困倦结束时离她 75000 以内的只有 43 次，中位 101500）。
  所以和莉莉娅一样用自己的睡眠：数据落眩晕（主包 2 秒、带睡泡、打不醒；副本 2.25 秒），附加包挨打就叫醒并补真实伤害（0.3.1 的做法，封顶
  `e_cap` 100 + `e_cap_ratio` 60% 法强）。主包和副本里不再有 `Native`，也就不再要求游戏 0.7.0。
- **画面错位**：0.5.2 把 `league_zoe_spells` 加进 league.dll 的 `DRAWN_EFFECTS`，可这张表只在「视图节点绘制」里缩小——在一个点上放的画面（地上的
  图标、闪现）走那里，日志有 `league_zoe_spell_icons: effect picture drawn x0.333`；**buff 的画面**（治疗、点燃、虚弱、幽灵疾步、屏障）和**跟着人的
  画面**（净化）不走那里：11-05 那局这些都放过，`league_zoe_spells` 一行缩小的记录也没有（悠米骑乘的 `league_yuumi_ride` 也一样）。它们照旧按
  1 / PPU 的帧大小放左上角、按图的真实像素画：大一倍、从她身上往右下挂一半的大小（屏障的罩子中心在她脚下 17 px）。现在这些画面画在一张
  1 倍的普通图 `league_zoe_spells_1x`（不登记进 league.dll，游戏自己画、以人为中心）：`draw_zoe_spells.py` 按原来的大小一格一个游戏像素重画
  （把高清图隔一格取一格会断线、左右不对称）；闪现的画面（在点上放）留在高清的 `league_zoe_spells`，地上的图标不变。
