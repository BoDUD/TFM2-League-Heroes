# 库奇智能火箭 + 脱身方向附加包（测试版 v0.1.0）

主包 `league` 保持纯数据、全平台可用；数据读不到敌人站在哪、血量多少，主包的火箭朝 AI 选的英雄直线飞（Q 炸到人时改打「刚被打过的
英雄」），瓦尔基里俯冲只能「背对身边那个英雄往后跳」，不看墙、塔和队友。英雄联盟里高手把火箭打向能炸到最多人的地方、大火箭留给残血，
俯冲往安全的地方飞——要读每个单位的位置和血量，只能用原生代码，所以放在这个附加包里（合集 `league_addons` 也带着它）。

- 火箭出手那一 tick，主包副本（`override/`，tools/kit/build_corki.py 的 native=1）不朝 AI 的目标打，改调本包的 `league_corki:aim`
  （每第 3 发的大火箭 `league_corki:big`，计数照主包）：对射程内每个敌方英雄试一条线，火箭停在线上第一个敌人身上（线宽 3000 + 身体
  6000），按那里爆炸炸得到的敌人打分（英雄 10 分 + 残血分：普通火箭 4 x 少掉的血、大火箭 12 x；小兵和野怪 0.5 分），取分最高的线。
- 火箭（主包的 `r_missile` / `r_big_missile` 画面）每 tick 6000 飞过去，到了那一 tick 爆炸：主包的爆炸画面和音效，半径 13000
  （大火箭 20000）+ 身体 6000 内每个敌人（塔除外）受到 55 + 30% 法强魔法、40% 攻击力物理伤害（大火箭 x200%），走引擎的伤害流程。
  他在火箭到之前死了就不炸。
- 瓦尔基里俯冲起飞那一 tick 改调 `league_corki:escape`（弹药包 `league_corki:package`）：24 个方向里路上没墙、在地图里、能飞满
  40500（弹药包 65000）的点，按「落地后离最近的敌方英雄多远」打分，朝队友的重心加分，落在敌方塔 60000 内扣分，然后用强制位移送他过去。
  主包的火焰带、弹药包的击退和加速照旧。

## 在游戏里测

1. 主包（League of Legends Heroes 0.102 以上）要装着并启用。
2. 用合集 `league_addons`（推荐），或把整个 `league_corki` 文件夹放进 `<游戏目录>\mods\`（两者不能同时启用）。
3. 看库奇大招和技能二的说明：开头是「【智能】」就说明副本生效了。
4. 日志在 `%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_corki.log`：`AIM` / `BIG` 是选好的线（瞄准点、停在哪、分数），
   `BOOM` / `BIG BOOM` 是爆炸（打中几个敌人、每人多少伤害），`ESCAPE` / `PACKAGE` 是俯冲（从哪到哪、落地后离最近的敌人多远）。

## 开发

- `python addons/league_corki/make_override.py`：从主包重新生成 `override/` 和 `text/`。主包的库奇改了以后要重跑。
- 在 `addons/` 下 `cargo test --release -p league_corki`：单元测试（停在第一个敌人、挑没被挡的线、大火箭打残血、两个英雄站一起优先、
  背对敌人飞、朝队友、避开敌方塔、不出地图、数值和主包一致）。
