# 黑默丁格附加包（测试版 v0.3.1，可选）：炮台射击、塔边加速、炮台有了身体

**不装这个附加包，主包里的黑默丁格也是完整的**：普攻和每第 3 次普攻的 W 海克斯科技微型导弹、Q H-28G 进化炮台（最多 3 座，
受控英雄挨光束）、E CH-2 电子风暴手雷、R 升级！！！（刷新 Q、E 并升级下一个够得着英雄的技能：Q 放 H-28Q 巨型炮台、E 连掷 3 颗 CH-3X 手雷、普攻射出导弹群，先来的那个）、被动海克斯科技亲和和连招

## 怎么做的

- `mod.override_info` 把主包的黑默丁格换成 `override/` 里的副本（`make_override.py` 用 `tools/kit/build_heimerdinger.py` 的 `native=1`
  生成，主包的黑默丁格改了就重跑；它也核对 `src/lib.rs` 里 `Params` 的默认值和参数表 P 一样）：炮台保留画面、音效和 a / b / c
  三个槽位，但没有区域；Q 放炮台和升级的 Q 放巨型炮台那一 tick 跑本包的 `league_heimerdinger:q` / `:x`；被动是本包的
  `league_heimerdinger:affinity`（数字在 `passive.params`）；加上三种炮弹的 `view_projectiles`（画在主包的 `league_heimerdinger_fx`
  里，主包没用）；Q 的说明开头加【扩展包】。
- **炮台朝哪边**：`:q` / `:x` 算出的方向往左时给他挂 `league_heimerdinger_t_face_l` / `_x_face_l`（30 tick），副本的隐形弹落地时
  据此画 `league_heimerdinger_turret_l` / `_apex_l`，否则 `_r`。这四张是主包里的特效表（hd.rs EFFECTS，PPU 1.75），由
  `tools/art/design_heimerdinger_side_turrets.py`（英雄联盟模型 70 度侧面渲染，黑白两底抠图，缩到 20 / 30 游戏像素 x 1.75，16 色
  平涂加分界线，颜色往正面造型靠）和 `tools/art/import_heimerdinger_fx.py`（同样的升起、炮口闪光、开火后坐、损坏，朝左是镜像）生成。
  炮口离炮台点的位置写在 `assets/source/heimerdinger/hd/side_muzzles.json`，`src/lib.rs` 的 `T_MUZZLE` / `X_MUZZLE` 照它（`make_override.py` 核对）。
- **炮台站在哪**：`:q` / `:x` 拿施法的输入（Q 的方向），和数据的隐形弹一样朝那边 `q_place` 远、`q_place / q_speed`
  tick 后站下，和数据放的炮台图是同一个点。原生效果按（这局的种子、模拟的来源、比赛、局、他的编号）把炮台交给被动。
- **出手**：站下 `t_first` / `x_first` tick 后第一发，之后每 `t_per` / `x_per`（和炮台图的炮口闪光对齐）。受控制（游戏
  `EnemyChampionInCC` 的六种：击飞、眩晕、禁锢、强制位移、恐惧、魅惑）的英雄挨光束，否则最近的敌方英雄，再否则最近的小兵、野怪
  （防御塔不打）。`spawn_projectile` 从炮台的点（往南挪到炮口的高度）飞向目标，到了用 `deal_damage_typed` 造成魔法伤害，
  播主包的命中画面和音效；巨型炮台的等离子弹再挂主包的 `league_heimerdinger_x_slow`。他阵亡后炮台照旧打到寿命结束（主包的区域也是）。
- **海克斯科技亲和**：他活着时每 `p_per` tick 看一次，自己站稳的炮台 `p_r` 内或己方活着的防御塔 `p_tr` 内，就换上主包的
  `league_heimerdinger_haste`（+`p_ms`% 移速 `p_t` tick，画面照旧）。
- **R 的升级给谁**（`src/combo.rs`，用户 2026-10-24 把 R 改成「升级下一个技能」）：AI 钩子 `league_heimerdinger:combo`（优先级 110，
  排在 league_ult_press 之后）在他身上挂着 `league_heimerdinger_upg` 时替游戏的 AI 按：E 好了、`e_range` 内有一名敌方英雄身边
  `re_r` 内还有别的敌方英雄 → 朝身边人最多的那名按 E（`E CLUMP`）；不然 Q 好了、`q_range` 内有敌方英雄 → 朝最近的那名按 Q
  （`Q APEX`）；Q 没好、E 好了 → 朝最近的按 E（`E ONE`）。被控住、正在放技能、回城时不管。

## 在游戏里测

1. 主包（League of Legends Heroes 0.205.1 以上）要装着并启用；本包随附加包合集 `league_addons` 一起装，或单独装。
2. 看日志 `%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_heimerdinger.log`：`SPAWN`（他出场和参数）、`PUT`（炮台站下的点和
   施法输入的种类）、`SHOT`（炮台出手打谁、炮弹还是光束、多少伤害）、`HASTE`（炮台旁还是塔旁加速）、`WATCH`（每 30 秒的计数）、`E CLUMP` / `Q APEX` / `E ONE`（钩子替 AI 按的：引擎接下施放前钩子每 tick 都再按一次，一串只记一行——
   同一种离上一次按不到 30 tick 算同一串；0.2.2 以前每 tick 一行，一次 Q 记了 21 行）。
3. 看炮弹是不是从炮口飞出去、落在炮台图上的炮台是不是在打（`PUT` 的点该在炮台图下）。

## 炮台有了身体（v0.3.0，2026-11-14）

用户：「召唤物的全做啊 剩下的一批英雄也做了啊 都做完了装进去了再测」。召唤物第二轮（公用模块 `summon.rs`）。附加包的代码 + 主包两张单位图 `league/champions/league_heimerdinger_h28g`、`league_heimerdinger_h28q`（`tools/art/unit_heimerdinger_turrets.py`：侧面炮台 PPU 1.75 的高清方块当 1 倍帧——游戏今天就是一格一像素地画它们，所以和今天一样大、一样清楚，不用在 league.dll 里登记；名字不能用特效图的 `league_heimerdinger_turret` / `_apex`：league.dll 只按资源名的最后一段找高清帧，那两个是登记过的特效）。**要和带这两张图的主包一起装**。

- 英雄联盟（wiki 现行页面）：H-28G 进化炮台生命 130–700（+5–53% 法强）、护甲 10–110、魔抗 25–86，最多 3 座，一直留到被打掉（他走远了会休眠），打掉给 5 金币；H-28Q 巨型炮台生命 725–1825（+50% 法强）、护甲魔抗 30–100、留 8 秒、给 25 金币；英雄的普攻和防御塔打炮台多 40% 伤害。
- 副本的 Q（和升级的 Q）放下炮台时跑本包的 `:q` / `:x`：在隐形弹停下的地方（朝目标 `q_place` 远）当场生成身体 `league_heimerdinger_h28g` / `_h28q`：移速 1、攻击 0（射程、节奏是炮台的，只为了朝着敌人、播开炮的动作），生命是他上限的 26% + 30% 法强（巨型炮台 85% + 50%），护甲 90% / 110%、魔抗 125% / 150% 他的（英雄联盟的数字对他的数字），留到炮台的时间结束（隐形弹 5 tick + `t_life` / `x_life`）。成功了给他挂 12 tick 的 `league_heimerdinger_t_unit` / `_x_unit`：副本的数据在隐形弹落地时读它（`make_override.py` 给侧面炮台图套上 `SwitchByBuff`），不再画侧面的炮台。
- 射击照旧由本包按原来的节奏打：从身体**现在**站的地方（被推开、拉走也跟着）、朝目标那边的炮口（`TU_MUZZLE` / `XU_MUZZLE`，从单位图量出来的）射出。身体被打掉（`OVER … KILLED`），这座炮台就停火，Q 还去掉它占的槽位标记（`league_heimerdinger_ta_busy` / `tb` / `tc`：英雄联盟里打掉一座就能再放）；到时间的和原来一样结束。
- 退路：宿主没有 `spawn_unit`、失败、读不成单位、测试开关 `unit=off`——不挂标记，数据照旧画侧面的炮台，本包照旧从那个点射击。
- 日志（都以 `TURRET` 开头）：第二行 `TURRETS: … - ON`（测试开关）；`TURRET SPAWN #`（身体的单位 id、位置、数字）→ `TURRET #n LOOK #`（读回来的名字、种类、能不能选中、生命、攻击间隔、`speed` 是不是 1）→ 每秒一行 `TURRET #n #k:`（`walked` 应该一直是 0、生命掉了多少、身边的敌人）→ `TURRET #n OVER #`（被打掉还是到时间、敌方那一 tick 拿了多少钱、`stops firing`、`slot … free again`）→ `WAKE #`；`TURRET HOOK #`（引擎把身体那一下 0 伤害的攻击告诉被动没有）；`WATCH` 行多了「几座有身体」；失败时 `TURRET SPAWN FAILED` / `TURRET LOST`。
- 测试开关：日志旁边的 `league_heimerdinger.cfg`（`unit=off` 不生成身体、`name=<名字>` 换单位名；身体本来就是移速 1）。
- 还没做：英雄的普攻和防御塔打炮台多 40%（没有只对普攻、防御塔加伤的属性）、他走远了炮台休眠、炮台一直留到被打掉（这里还是 `t_life` 10 秒）、炮台出现时升起来的动作（单位一出来就是站着的样子）。

## 炮台的身体站稳了再接手（v0.3.1，2026-11-14）

第一批真实对局数据（游戏 0.7.2 的预模拟）：新单位生成那一拍和下一拍，最大生命、攻击、防御、移速都读成 1，那时设的生命会被盖掉（悟空的分身生成后一拍读到 `hp 1851/1 attack 1 def 1 mr 1 speed 1`）。公用的 `Flock`（萨科附加包 0.3.1 的 `summon.rs`）现在等单位站稳（最大生命读出来）才接手：`TURRET #n LOOK` 晚一两拍、是身体自己的数字（5 次还没站稳就照样接手，行末写 `(its health cap still reads 1 after 5 looks)`）。射击照旧由附加包从炮台站的地方打，不等身体。代码没改，测试没改（假宿主里单位一生成就站稳）。
