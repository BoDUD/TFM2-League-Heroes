# 奎因附加包（测试版 v0.1.0，可选）

**不装这个附加包，主包里的奎因也是完整的**：普攻（被动侵扰：每 8 秒华洛标记一次，下一箭他俯冲到目标头上多一段伤害，之后 W 敏锐感知
加攻速移速）、Q 炫目攻势（华洛飞出去在第一个敌人处爆开，打中的英雄缴械）、E 旋翔掠杀（冲到目标身上踢一下再空翻拉开）、R 深入敌后
（召来华洛骑上，直接冲到敌方英雄身边落地施放鹰翼天翔）都在主包数据里。主包是纯数据：**待机、跑步的动画不能在运行中换**，**buff 到期时
数据什么也做不了**，所以主包里她只在大招的冲刺动作里骑着华洛。这个附加包用原生代码把大招做成英雄联盟的样子（用户 2026-10-19：大招主包
冲刺 + 附加包换形态）。

| | 主包（纯数据） | 装了附加包 |
|---|---|---|
| 深入敌后 | 骑上华洛一次冲到目标身边，落地施放鹰翼天翔 | **照英雄联盟骑着跑**：骑上华洛 6 秒，移速 +80%，她照常走位；骑着时下一次普攻、技能 1 或技能 2 会先施放鹰翼天翔，6 秒到了也会自动落地施放 |
| 骑乘的样子 | 只在大招的冲刺动作里骑着 | **整身换形态**：骑着的 6 秒里站着、走着、挨打都是骑在华洛背上（`r_idle` / `r_run` / `r_hit`） |

## 怎么做的

- `mod.override_info` 把主包的奎因换成 `override/` 里的副本（`make_override.py` 用 `tools/kit/build_quinn.py` 的 `native=1` 生成，主包的奎因改了就重跑）：
  被动是本包的 `league_quinn:ride`（数字在 `passive.params`，和 `src/lib.rs` 的常量由脚本核对）；大招只叫来华洛骑上、挂 `league_quinn_r_ride`
  （360 tick，移速 +80%），同时起一个每 tick 看一次的守望；普攻、技能 1、技能 2 开头先看 `r_ride`，骑着就施放鹰翼天翔（落地动作、伤害、标记、华洛回到头顶）；
  大招的说明开头加【扩展包】。
- **到时落地**：被动每 tick 看她身上有没有 `r_ride`，骑了 358 tick 还没出招就挂 2 tick 的 `league_quinn_r_end`，大招的守望看到就施放鹰翼天翔。
- **整身换形态**（`src/view.rs`）：照拉莫斯 / 雷克塞 / 芮尔 / 杰斯 / 奈德丽附加包的显示钩子，游戏每帧更新显示时，名字是 `league_quinn` 的实体身上有 `r_ride` 时
  把正在播的 `idle / run / hit` 换成 `r_*`（高清帧由 league.dll 自动换成 `hd_r_*`）。
- 日志：`%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_quinn.log`：`RIDE`（骑上、怎么落地、骑了多久多远）、`FORM`（画面里换形态），都限了条数。

## 在游戏里测

1. 主包（League of Legends Heroes 0.167.0 以上）要装着并启用。
2. 用附加包合集 `league_addons`（里面已经包含本包），或者把整个 `league_quinn` 文件夹放进 `<游戏目录>\mods\`（文件夹里要有 `league_quinn.dll`、`mod.mod_info`、
   `mod.override_info`、`override\`、`text\`）。
3. 进游戏，鼠标停在奎因的大招上，说明开头是【扩展包】就说明副本生效了；打一局后看日志里的 RIDE / FORM。
