# 厄斐琉斯附加包（测试版 v0.1.0，可选）

**不装这个附加包，主包里的厄斐琉斯也是完整的**：五把月石武器（每把 20 发，打空换下一把）、五个武器技能（Q）、W 月相轮转（主副手互换）、
R 清辉夜凝都在主包数据里。主包是纯数据：**游戏按名字自动播的待机、跑步、受击动作换不了**（数据只能用 `CasterAnimation` 换出招的动作），
**换枪只能按固定的循环**，**主动换枪只看技能冷却**。这个附加包用原生代码把这三件事做成英雄联盟的样子（用户 2026-10-16：「方案可以，全按推荐做（下路 ADC，做附加包，PPU 1.5）」）。

| | 主包（纯数据） | 装了附加包 |
|---|---|---|
| 武器在手里 | 出手时手里是主手武器；站着、跑着、挨打时都是通碧背在身后的样子 | **整身换武器**：主手是断魄 / 坠明 / 荧焰 / 折镜时，站着、跑着、挨打、出手的第一刻都画成那把武器在手里（只在游戏 0.6.4 上） |
| 打空换枪 | 按固定循环通碧 → 断魄 → 坠明 → 荧焰 → 折镜，换上副手以外的下一把 | **先进先出的队列**（英雄联盟）：打空的那把排到队尾，换上队列最前面的那把；W 换过手以后和固定循环不一样 |
| 残血 | W 只在主手 Q 冷却、副手 Q 好了、身边有敌方英雄时才换手 | 另外**生命低于 35%、副手是断魄、60000 内有看得见的敌方英雄时直接换上断魄**（吸血），每 6 秒最多一次 |

## 怎么做的

- `mod.override_info` 把主包的厄斐琉斯换成 `override/` 里的副本（`make_override.py` 用 `tools/kit/build_aphelios.py` 的 `native=1` 生成，主包的厄斐琉斯改了就重跑）：
  被动是本包的 `league_aphelios:queue`（主手武器的射程、吸血、攻速和残血换枪的数字在 `passive.params`）；普攻、技能2 的说明开头加【附加包】。
- **武器状态**：主包把主手、副手各记成一个永久 buff（`league_aphelios_mw_<武器>` / `league_aphelios_ow_<武器>`，主手那个带着武器自己的属性：
  通碧的射程、断魄的吸血和攻速）。本包每 tick 读这两个 buff。
- **队列**：数据换了主手、副手没变（打空换枪）时，按队列该换上的不是数据挑的那把，就把主手 buff 换成队列里那把（`entity_remove_buff` + `add_buff`，
  属性照主包的参数）；主手和副手互换（W、残血换断魄）时队列不动；看不懂的变化（复活后重新拿枪）按现在的手重排队列。
- **整身换武器**（`src/view.rs`，杰斯 / 奈德丽 / 凯隐的做法）：挂在游戏显示世界的更新函数上（0.6.4 的槽，加载时核对函数开头），名字是
  `league_aphelios` 的画面实体按主手 buff 把正在播的 `idle` / `run` / `hit` / `attack`，以及 W / R / 阵亡的 `skill2` / `ult` / `dead`（0.1.2）换成图里的 `<武器>_idle` / `_run` / `_hit` / `_attack` / `_skill2` / `_ult` / `_dead`（阵亡时数据 buff 被清掉，按倒下前记下的那把）
  （[`tools/art/rig_aphelios.py`](../../tools/art/rig_aphelios.py)：通碧从背上拿下、那把武器在抬起的手里，荧焰低低地握在身侧）。
  高清帧不用另管：`league.dll` 把登记英雄动画表里的每个动作就地换成它的 `hd_` 帧。别的游戏版本什么都不做。
- 状态在被动实例里（每个模拟、每个英雄各一份），同一局的几份预模拟互不影响。
- 日志：`%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_aphelios.log`（每次启动游戏重写，上一次的在 `.prev.log`）：`QUEUE`（数据换枪，
  和队列一致 / 改成队列那把）、`LOW`（残血换断魄）、`FORM`（显示里的武器形态），都限了条数。

## 在游戏里测

1. 主包（League of Legends Heroes 0.124.0 以上）要装着并启用。
2. 把整个 `league_aphelios` 文件夹放进 `<游戏目录>\mods\`，文件夹里要有 `league_aphelios.dll`、`mod.mod_info`、`mod.override_info`、`override\`、`text\`
   （或者用附加包合集 `league_addons`，里面已经包含本包）。
3. 进游戏，鼠标停在厄斐琉斯的普攻上，说明开头是【附加包】就说明副本生效了；打一局看他换枪后站着、跑着手里是不是那把武器，日志里的 QUEUE / LOW / FORM。

```bash
cargo test -p league_aphelios          # 队列、残血换枪、形态名的单元测试（在 addons/ 下跑）
python addons/league_aphelios/make_override.py
```
