# 奥瑞利安·索尔附加包（`league_aurelionsol`）

用户（2026-10-24）选技能方案时定了：被动「星海焕然：星尘永久叠层强化各技能」，技能 2「星芒凝汇：黑洞拉人，中心处决残血」。
2026-11-04 用户：「龙王是不是不能边飞行边放Q 和英雄联盟也不太一样？」——星穹流丽（W）做成他自己的技能，边飞边喷。

主包的奥瑞利安·索尔是纯数据：数据读不到生命，也没有「复活时」这个时机，TFM2 又只有三个技能格，所以主包里有三处只能近似。这个附加包把它们做成英雄联盟的样子：

| 技能 | 主包（纯数据） | 附加包 |
|---|---|---|
| 星海焕然（星尘） | 每层是一个永久 buff（`league_aurelionsol_d1`…`d30`，前 `d_ap_n` 层各带 `d_ap`% 法强，每 `grow_n` 层大招和黑洞大一档），死亡时引擎清掉全部 buff，每条命从零叠起 | 活着时记下每一层，死亡清掉后原样补回（最多 `d_max` 层，范围的档位跟着回来） |
| 星芒凝汇（黑洞中心） | 中心每秒打英雄最大生命的 `e_exec`%（真实伤害，处决的替身） | 同样的伤害，另外英雄生命低于 `e_low`% + 每层星尘 `e_low_d`%（只算前 `e_low_n` 层：默认 5% + 1%/层，最多 20%）就直接处决 |
| 星穹流丽（W） | 没有技能格，并进被动：击杀他伤过的英雄后起飞 `w_t`（4 秒），移速 +`w_ms`%、无视地形，龙息冷却重置；飞行中龙息没有冷却、引导 `q_t_f`（2.5 秒）、每段伤害 `q_fdmg`%（+10%）。数据挪不动引导中的他，喷龙息时悬在原地 | 他自己的技能（英雄联盟 V26.21）：冷却 1 级 `w_cd1`（22 秒）匀着降到 12 级 `w_cd12`（14 秒），开局 `w_start`（15 秒）内不飞；本包看局面起飞——残血逃生、追龙息够不着的残血、飞进队友已经在打的团——沿直线飞 `w_len` + 每层星尘 `w_len_d`（150000 + 750/层），飞越地形，起飞重置龙息；每 tick `w_v`（2000），喷龙息时减半，龙息的姿势一路跟着飞：**边飞边喷**；击杀返还剩下冷却的 `w_refund`%（90%） |

天瀑的充能（`league_aurelionsol_c1`…）不记：放天瀑时主包自己会清掉它们，死后从零充。

### 为什么以前飞的时候不喷龙息

经典引擎模拟（7 局，24 次起飞）：起飞不重置龙息的冷却，而击杀多半就是龙息打出来的，24 次起飞里 22 次龙息还在冷却；只有 11 次
飞行里喷过一口，都在起飞 53–233 tick 后（冷却走完了），而且龙息的施法动作把他钉在原地 90 tick——飞行的移速一点用不上，
从来没有边飞边喷过。主包现在起飞时重置冷却、飞行中龙息没有冷却（他在飞行里就能喷），但喷的时候仍然停在原地：数据里让他边引导
边移动只有冲刺（强制位移，会打断龙息），让 AI 自己走（卢锡安大招的做法）在模拟里伤害少了 18%（AI 把他带出了龙息够得着的地方）。

## 星穹流丽怎么飞

- **什么时候、往哪飞**（`src/flight.rs`，纯计算有单元测试）：被动每 3 tick 看一次，W 好了、没被控（击飞、晕眩、定身、嘲讽、恐惧、
  魅惑、强制位移、禁止位移技能，或选不中）就按顺序挑：
  - **逃生**：生命 ≤ 30% 而 60000 内有敌方英雄，或者生命 ≤ 45%、75000 内两名以上敌方英雄比那里的队友多：16 个方向里挑落地后离
    最近的敌方英雄最远（至少比现在远 40000）、越正对着背离敌人越好、靠自己的塔、不落在敌方塔下的那个，飞满全程；
  - **追残血**：他生命 ≥ 40%，生命 ≤ 35% 的敌方英雄在 70000 外（龙息够不着）、飞得到：停在他前面 50000（龙息 75000 够得着），
    落点旁除了他最多一名敌方英雄，不在敌方塔 75000 内；
  - **进场**：他生命 ≥ 55%，85000 外的敌方英雄身边 60000 内已经有队友在打：同样停在他前面 50000，落点旁的敌方英雄不比队友（加上他）
    多一个以上，不在敌方塔下。
  只看看得见、选得中的敌方英雄。落点在墙里就往前飞出墙（最多再飞 48000），出不去就退回墙前；地图外不去。墙是游戏的内置地图
  （`league_camille_wall/src/maps.rs`，泰隆翻墙附加包也用），当前对局取站进墙里的单位最少的那张。
- **起飞**：挂 `league_aurelionsol_w_fly`（无视地形；画面是主包的 `w_trail` 星尘拖尾）和起飞的星云 `league_aurelionsol_w_up`
  （buff 画面 `w_lift`：原生代码播的画面游戏里看不到，巴德的门的教训），去掉主包的 `q_cd`（龙息冷却重置），放起飞的音效和台词
  （台词和数据共用 `vo_cd`，隔 600 tick），W 进冷却。给 AI 钩子的：落点 `w_to:<x>,<y>`、飞向谁 `w_at:<id>`、逃生 `w_esc`。
- **飞**：逐 tick 把他沿直线挪过去（`entity_set_pos`，卡莉丝塔跳的做法），每 tick `w_v`，身上有主包的 `q_ch`（在喷龙息）时减半。
  副本里飞行中的龙息施法动作有 `q_t_f` 长（和引导一样），所以他是摆着喷龙息的姿势一路飞过去的；落地后龙息照常喷完。
  飞向的那个在龙息里倒下了，这口龙息就停（去掉 `q_ch`，施法动作是他身上唯一的控制时一起清掉），他全速飞完剩下的路。
  被硬控、被放逐、死亡就落地。
- **飞行中按龙息**（AI 钩子 `league_aurelionsol:flight_ai`，`src/flight_ai.rs`，在 ult_press、奎因之后）：飞着、没在喷（没有
  `q_ch` / `q_live`）、没在出招时，对龙息够得着、看得见的敌方英雄按技能 1——先对飞向的那个，没有就挑生命最低的；逃生时只喷生命
  不到 25% 的追兵（喷着飞速度减半）。喷不了的时候，游戏的 AI 让他走路或普攻就改成朝落点飞（身体朝着飞的方向）。黑洞、大招照游戏的
  AI 放。
- **击杀返还**：副本的击杀检查（3 秒内他伤过的英雄阵亡，谁补的刀都算）不再起飞，只挂 `league_aurelionsol_w_td`，本包把 W 剩下的
  冷却去掉 `w_refund`%。

## 怎么接上的

`mod.override_info` 把主包的奥瑞利安·索尔换成 `override/` 里的副本（`make_override.py` 用 `tools/kit/build_aurelionsol.py` 的 `native=1` 生成）：

- 黑洞中心每次打到英雄时多跑原生效果 `league_aurelionsol:core`：读目标真实的生命和护盾，低于处决线就打出「生命 + 护盾 + 最大生命」的真实伤害，再按他身上的减伤放大（伤害下一 tick 才结算，盖过这一 tick 的回血、护盾和减伤；原来的「生命 + 护盾 + 1」让梅尔 48 次处决有 5 次没打死；减伤 100% 时先不处决，日志 `EXECUTE HELD`）；处决线按他身上的星尘层数算；
- `passive` 是本包的 `league_aurelionsol:stardust`，参数 `d_max`、`e_low`、`e_low_d`、`e_low_n` 和飞行的 `q_range`、`w_cd1`、`w_cd12`、`w_len`、`w_len_d`、`w_v`、`w_start`、`w_refund` 来自主包参数表 P：记下他身上每一层 `league_aurelionsol_d<n>`，少了就补回（卑尔维斯附加包的做法：层数只会变多，所以少了只会是死亡清掉的）；出生时把参数按（这局的种子, 单位）记一份给原生效果；星穹流丽（上面）；
- 副本的击杀检查只挂 `w_td`（不再由数据起飞），起飞的星云多一个 buff 画面 `league_aurelionsol_w_up`；
- 普攻和技能 2 的说明换成附加包自己的文字（`description.league_aurelionsol.attack` / `.skill2`，写着「死亡后保留」、星穹流丽的冷却和处决线），游戏里看说明就知道副本有没有生效。

记下的层在被动自己身上（被动跟着单位、每局一份，游戏并行跑的几局互不相干）。

## 0.3.2：大招一下都没打中过（2026-11-06）

星落 / 天瀑的爆炸（`r_blast` / `r_blast2`）、拿星尘的判定（`r_tw` / `r_tw2`）、天瀑的冲击波（`r_shock`）是「落地打一下」的区域：只存在 2 tick、周期 30、`first_delay` 0。第一下要等 30 tick，区域早就没了——经典模拟里 9 次星落一次都没打中，伤害、击飞、星尘全都没有。现在 `first_delay` 1：落地下一 tick 打一下。经典 SDK 实测（2026-11-06，`trace.exe` 逐 tick 看每个区域第一次生效）：区域出现后第 `first_delay` tick 才第一次生效，写 0 等于晚整整一个周期（从飞行物落点生成的晚 `period` tick，从延迟或技能里直接生成的晚 `period - 1` tick）。改成 1 后，从落点生成的落地下一 tick 就生效，从延迟里生成的出现当 tick 就生效。主包的数据跟着改，本包的副本用 `make_override.py` 重新生成；DLL 没变。

**数值跟着重调**（主包，`tools/kit/build_aurelionsol.py`）：以前每一次平衡模拟里大招都是 0 伤害，Q、E 是被调高来补的。大招能打中后按旧数值击杀差 +8.29（240 局，s.e. 0.34；场均伤害 15290，以前 6483、+1.38）。现在大招回到英雄联盟的数字（星落 150 + 65% 法强、天瀑 187 + 81%、冲击波 40 + 15%），冷却 2100 → 4200 tick（和玛尔扎哈、加里奥、奥莉安娜、辛德拉、维克托的大招一样；英雄联盟 120–100 秒），Q、E 回到最初的草稿（14 + 9%、8 + 5%）：+3.29（s.e. 0.43）。击飞保留 1 秒（用户 2026-11-03 要的）；试过大招八成伤害 +3.12、击飞 0.75 秒 +3.40，差别都在误差里。下一局看：大招落地有没有击飞、有没有伤害。
