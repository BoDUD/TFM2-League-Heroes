# 亚恒附加包（`league_zaahen`）

用户（2026-10-26）：亚恒「和英雄联盟不一样的地方都要做附加包」——和斯卡纳、特朗德尔、克烈一样。2026-11-12：「亚恒确定完美还原英雄联盟了吗」→「全部按联盟改」（见 [0.2.0](#020全部按英雄联盟改2026-11-12)）。

主包的亚恒是纯数据：数据数不清每一下伤害、看不到致命伤害、三个技能位放不下第四个技能、回血只能按攻击力算，所以主包里有四处只能近似。这个附加包把它们做成英雄联盟的样子：

| 机制 | 主包（纯数据） | 附加包 |
|---|---|---|
| 不落之志（果决） | 一串标记一层一层叠：控制器每 3 拍看一次，同一拍里的几下只算一层；每层攻击力 +`det_ad`%，满 `det_n` 层换成 +`full_ad`%（英雄联盟的翻倍）；5 秒没打中英雄一下清空 | **每一下打在敌方英雄身上的伤害**都算一层（普攻、Q 的每一斩、上挑、W 的两段、E、R），每层攻击力 **+1.5%–2.95%（随等级）**，最多 `det_n` 层、叠满翻倍（1 级 36%、18 级 71%）；最后一下之后 `det_t` 拍没打中英雄开始掉，**每 30 拍掉 1/2/3/4/5 层**（越掉越快，约 2.5 秒掉光） |
| 叠满后的复活 | 数据看不到致命伤害：叠满时给一个 `rv_sh` + `rv_sh_r`% 攻击力的护盾（每 `rv_sh_cd` 拍一次：英雄联盟复活冷却的 11–15 级那一档） | **叠满时受到致命伤害就倒下**：生命停在 1，放逐 `rv_rise` 拍（无敌、选不中、不能行动），慢慢回到最大生命 **30/45/60/75%**，再展翼站起来、果决叠满；冷却 **300/240/180/120 秒**（1/6/11/16 级起）。别人给的「不死」在身上时不触发 |
| 赤金突袭（E） | 三个技能位放不下：并进 W，拽完人原地绕身一斩 | **有自己的技能位**：每 `e_cd` 拍一次，`e_reach` 内有敌方英雄、他能行动时，朝最近的那个冲过去（最多 `e_dash`，停在让对方正好落在外圈的地方），落地绕身斩：内圈 `e_r0`、外圈 `e_r`，`e_dmg` + `e_ratio`% 攻击力，外圈多 `e_out`% 并加最大生命 `e_pct`% 的魔法伤害；W 不再带绕身斩 |
| 暗裔长刀的回血 | 第一斩回固定的 `q_heal` + `q_heal_r`% 攻击力（一次 Q 一次） | 一次 Q 回**最大生命 5–9%**（随技能等级：英雄联盟主升 Q，1/4/5/7/9 级；打英雄，别的单位一半） |
| 大赦的护甲穿透 | 固定 `r_pen`% | **10/20/30%**（随大招等级：英雄联盟 6/11/16 级，这里 11 级前都是 10%；副本的 `own` 给 `r_pen_n`%，本包按等级再加） |

两连斩和上挑、W 的两段（刺出去打一次，刺到尽头再打一次、眩晕、往回拽一小段）、大招的升空 / 免控减伤 / 插刀 / 每个英雄回血两边一样。英雄联盟没有的四个连招（W 拽中英雄 → Q 马上好；Q 挑飞英雄 → 大招冷却缩短；大招砸中英雄 → 果决涨 4 层；果决叠满 → Q、W 马上好）2026-11-12 起两边都去掉了。

## 怎么接上的

`mod.override_info` 把主包的亚恒换成 `override/` 里的副本（`make_override.py` 用 `tools/kit/build_zaahen.py` 的 `native=1` 生成），`passive` 是本包的 `league_zaahen:darkin`，参数（`build_zaahen.NATIVE_KEYS`）来自主包参数表 P，`src/lib.rs` 的默认值和它核对：

- 副本里没有果决的标记阶梯和护盾：本包在 `on_attack`（他打出的每一下伤害）里给敌方英雄算层，挂 `league_zaahen_det` / `league_zaahen_full`（攻击力，按他现在的等级算，升级时马上改），叠满时挂 `league_zaahen_fill`，数据看到就播叠满的画面；
- 复活：叠满且冷却好了时一直挂「不死」`league_zaahen_rv_guard`，生命停在 1 就放逐他（先去掉大招的 `r_guard`：免控时放逐会被拒），放逐的画面是数据的 `league_zaahen_rv_rise_r` / `_l`（`league/effects/league_zaahen_rise`，高清特效表：他倒下、拄刀跪起、展翼站起来，光柱在后面；特效图不会镜像，所以左右各画一份，按最近的敌方英雄选朝向），结束时播 `p_full`；
- 赤金突袭：本包冲刺时挂 `league_zaahen_e_rush`（数据播冲刺的动作 `dash`），用 `entity_set_pos` 一拍一拍把他挪过去（期间定身、禁普攻、禁技能），落地挂 `league_zaahen_e_go`（数据播绕身斩 `skill3` 和画面），`e_hit` 拍后本包结算内外圈的伤害；
- 暗裔长刀：副本的第一斩给打中的单位挂 3 拍 `league_zaahen_q_mark`，本包看到就回血（一次 Q 一次）；
- 大赦的护甲穿透：副本的 `own` 给 `r_pen_n`%，本包按等级再挂 `league_zaahen_pen`（`defence_penetration`，死后复活补回）。

## 0.2.0：全部按英雄联盟改（2026-11-12）

用户：「亚恒确定完美还原英雄联盟了吗 分析一下」→「全部按联盟改」。对照英雄联盟维基上现在的亚恒（25.23 上线），改了下面这些。主包和附加包一起改，主包里数据做不到的仍然近似。

- **四个连招去掉**（英雄联盟没有）：
  - W 拽中英雄不再让 Q 马上好；
  - Q 挑飞英雄不再缩短大招冷却；
  - 大招砸中英雄只算一下伤害（一个英雄一层果决，原来一下 4 层）；
  - 果决叠满不再刷新 Q 和 W。
- **W 两段**：
  - 第一段：刺出去时沿途打一次（`w_dmg` + `w_ratio`%）；
  - 第二段：刺到尽头再打一次（`w2_dmg` + `w2_ratio`%）、眩晕 0.25 秒，并往他那边拽 `w_pull_v` × `w_pull_t`（15000）。英雄联盟是 850 里拽 225，约四分之一，拽的时间和眩晕一样长。原来是一段，直接拽到身边。
  - 第二段是从尽头飞回来的看不见的一条线，2 拍内扫过整条线。两段各算一层果决。
- **Q 回血一次**：英雄联盟是一次强化普攻回一次。原来每斩都回，一次 Q 回两次。
  - 附加包：最大生命 5–9%，随技能等级（主升 Q：1/4/5/7/9 级）；
  - 主包：第一斩回 `q_heal` + `q_heal_r`% 攻击力。
- **果决（附加包）**：
  - 每层攻击力 1.5%–2.95%，随等级（原来固定 1%），叠满翻倍；
  - 5 秒没打中英雄后，每 0.5 秒掉 1/2/3/4/5 层，越掉越快（原来每 0.5 秒 1 层）。
  - 主包的满层从 +30% 改成 +48%（每层 2% × 12 层再翻倍）。
- **复活（附加包）**：
  - 回到最大生命 30/45/60/75%，冷却 300/240/180/120 秒（1/6/11/16 级起），原来固定 50%、60 秒；
  - 主包的替代护盾改成每 180 秒一次（原来 60 秒）。
- **大赦**：
  - 砸地半径 22000 → 36000：英雄联盟 550，按这个英雄 W / R 射程的比例（约 66 倍）换算。他的砸地特效本来就画到 32 游戏像素宽，不用重画。
  - 每打中一个英雄回血改成伤害的三分之一（英雄联盟的算法）。
  - 护甲穿透（附加包）10/20/30%，随等级。
- **赤金突袭**：内圈 / 外圈 11000 / 20000 → 13000 / 25000（英雄联盟 200 / 375）。
- **数值**：
  - 去掉连招后，同样的数值击杀差从 +0.45 掉到 −0.75（经典引擎，上单，种子 1–24 / 1–16）。
  - 所以 Q、W、E、R 的伤害都提高约 25%：
    - Q 每斩 38 + 105%（原 30 + 85%）；
    - W 两段 62 + 62% 和 50 + 38%（原一段 90 + 80%）；
    - 赤金突袭 88 + 88%（原 70 + 70%）；
    - 大赦 250 + 225%，每个英雄回 83 + 74%（原 200 + 180%、60 + 40%）。
  - 三批种子平均 +0.62，原来是 +0.45，差别在误差以内。
  - 附加包的规则在这个引擎里跑不了。

## 0.2.1：复活期间的生命按英雄联盟（2026-11-12）

11-12 晚上的日志（用户：「和前几次一样 分析一下今天跑的日志 看看有没有bug」）：一次复活站起来时 2564 / 3073（83%），按 12 级该回到 60%。原因是放逐期间别的治疗还在加血。

英雄联盟里复活期间他的生命被强制成复活的进度，别的治疗不起作用。现在 `rise_hp` 每拍把生命设成「1 + 已经过去的每一步」，站起来时正好是这一级的 30/45/60/75%。单元测试 `the_rise_forces_its_running_total`。
