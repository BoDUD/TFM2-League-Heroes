# 悠米附加包（测试版 v0.2.1，可选）

**不装这个附加包，主包里的悠米也是完整的**：普攻射出书页光弹（被动猫的博爱：每 6 秒普攻英雄多一段魔法伤害并回血，下次附身时队友也回）、
Q 摸鱼飞弹（飞得够久就强化：伤害更高、减速更强）、W 悠米出动！+ E 旺盛精力（冲到交战中的队友身上附身 4 秒：放逐自己、跟着他走、他头上出现
趴在书上的小猫，他每秒回血，同时拿到护盾和攻速移速；时间到她跳下来）、R 魔典终章（把书立起来朝目标连发 5 道波纹，伤敌治友，第 3 道定身）都在
主包数据里。主包是纯数据：**附身只能是一段定时的放逐**——放逐期间她不能出招，时间一到就得下来。这个附加包用原生代码把附身做成英雄联盟的样子
（用户 2026-10-19 选的「放逐跟随 + 出招时现身」）。

| | 主包（纯数据） | 装了附加包 |
|---|---|---|
| 附身多久 | 4 秒，到时间跳下来 | **不限时**，队友死了才跳下来；骑着时**看局势换人**：宿主闲着就跳去打架的队友，去救快死的队友，跟着中单 / 下路 |
| 附身时能不能出招 | 不能（放逐中） | **能**：Q、R、再给他一次旺盛精力（护盾 130 + 60% 法强 3 秒、攻速 +20%、移速 +10%），都从他头上放 |
| 附身时谁能打到她 | 谁都打不到（放逐） | 平时谁都打不到（一段一段地放逐）；出招的那一小段受到的伤害 -100%、免控 |
| 附身时队友回血 | 每秒 45 + 15% 法强，4 秒 | 每秒 45 + 15% 法强，一直回 |
| 猫的博爱 | 只有普攻 | 普攻或**摸鱼飞弹**命中英雄（附身时她不普攻） |

## 怎么做的

- `mod.override_info` 把主包的悠米换成 `override/` 里的副本（`make_override.py` 用 `tools/kit/build_yuumi.py` 的 `native=1` 生成，主包的悠米
  改了就重跑）：被动是本包的 `league_yuumi:bond`（数字在 `passive.params`）；W 跳到队友身上时给他挂 3 tick 的 `league_yuumi_w_host`，不再放逐
  自己、不再定时传送；附身时（她身上有 `league_yuumi_w_on`）再放 W 只给队友旺盛精力（副本在她身边 8000 内找队友，她骑在他身后 22000，
  够不着：0.2.0 起由本包给，见下）；Q 多一道只打英雄的影子飞弹，带着猫的博爱；普攻和 W 的说明
  开头加【扩展包】。
- **附身**：被动看见队友身上的 `w_host` 就附身：她挂 `league_yuumi_w_on`，队友挂 `league_yuumi_w_ride`（头上的小猫，主包的画面），每 tick 把她摆到
  队友的位置，一段一段地放逐她（每段 20 tick，快结束时续上），每 60 tick 给队友回血（`w_heal` 的画面）。队友死了就下来：她这一段放逐结束时出现在
  原地，放 `w_land` 的画面和 `w_off` 的声音。
- **出招时现身**：Q / R 好了且队友身边（Q 80000、R 80000）有敌方英雄，或者 W 好了、75000 内有敌方英雄，就不再续放逐；这一段放逐结束后 AI 钩子让
  她对最近的敌方英雄出这一招（不普攻、不回城、不走开），期间挂 `league_yuumi_w_safe`（受到的伤害 -100%、免控）。冷却从 0 跳起来算出了招，这一招
  的动作（Q 28、W 18、R 30 tick）放完接着放逐；等了 24 tick 还没出招也接着放逐。
- **画面**（`src/view.rs`，只在游戏 0.6.4 上）：附身时她自己的每个动作都换成图里空白的 `a_*`（`tools/art/rig_yuumi.py --ride-tags`），头上的小猫
  一直由队友身上的 buff 画面画——出招那一小段她站在队友的位置上，不换的话会在队友脚下多出一只猫。别的游戏版本里这一小段她照常画在队友脚下。
  **选手名跟着队友**（0.1.24，用户 2026-11-01：「猫附身后 选手ID会留在原地」）：她的选手名画在她显示实体的位置上，游戏不挪被放逐单位的这个位置，
  附身时名字就一直停在她跳上去的地方；现在附身期间每帧把这个位置摆到头上有小猫的队友上方 12 游戏像素，名字浮在队友的名字上方跟着走。
- 日志：`%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_yuumi.log`：`ATTACH` / `DETACH`（附在谁身上、为什么下来）、`WINDOW`（为哪一招解除
  放逐、出没出招）、`AI casts`、`FORM`（显示钩子换没换上）、`FOLLOW`（名字开始跟着哪个队友）、`WATCH`（每 30 秒的计数），都限了条数。

- **骑着再放 W 的旺盛精力**（0.2.0，用户 2026-11-01：「悠米的W的护盾现在给上了吗」）：副本骑着时的 W 只在她身边 `w_on_r`（8000）内找队友给
  旺盛精力，0.1.0 她就坐在队友身上，10-20 起骑在他身后 `BESIDE`（22000，挨着走会互相推），够不着，11-01 的日志里她在队友头上放了 19 次 W
  都落空。现在被动看见她出了 W（冷却从 0 跳起来），11 tick 后（副本的 W 在动作第 9 tick 生效，再等 2 tick）他身上没有 `league_yuumi_e_on`
  就由本包给：`entity_add_shield` 130 + 60% 法强 180 tick、`league_yuumi_e_haste`（攻速 +20%、移速 +10%，180 tick）、`e_on` 和命中的画面
  声音。数字是常量 `E_SH` / `E_AP` / `E_T` / `E_AS` / `E_MS`，测试核对副本里骑着那一段的数；英雄数据没改，存档不用迁移。

- **看局势换人**（0.2.1，用户 2026-11-01：「还有个问题猫会智能附身吗 现在我感觉会长时间附身在一个人身上」——0.2.0 骑上一个人
  就骑到他死，日志里有一次骑了 21355 tick）：骑着、没在出招时每 30 tick 看一次，同一个人至少骑 300 tick（5 秒），两次换人隔
  600 tick（10 秒，英雄联盟 W 的冷却；附加包没法让 W 进冷却），在宿主 70000（副本 W 的距离）内的队友里照英雄联盟悠米的习惯挑
  （`switch_pick`）：① 宿主身边 60000 内没有敌方英雄而别人在打，跳去身边敌人最多的（再比血量低的）；② 宿主血量 60% 以上、
  旁边打架的队友掉到 35% 以下，跳去救血最少的；③ 宿主不是中单 / 下路，而中单 / 下路打的敌人不比他少，跳去跟大哥。换人时猫从
  他头上跳到新宿主头上（起跳的画面、附身的声音），她仍在放逐里，回血跟着换人，不给旺盛精力（那是 W 的事）。

## 在游戏里测

1. 装主包 `league` 和这个附加包（league_addons 合包里已经带着它），开一局有悠米的比赛。
2. 看悠米冲到队友身上后是不是一直骑着：队友头上一直有趴在书上的小猫，她自己看不见、谁都打不到；队友死了她才下来。
3. 骑着的时候她会不会放 Q、R（波纹从队友身上发出去）、再给队友旺盛精力，放的时候队友脚下不多出一只猫。
4. 读 `league_yuumi.log`：`ATTACH` 有没有（括号里带着队友那时的护盾，跳上去的旺盛精力给上了就不是 0）、`WINDOW` 后面有没有 `cast`、
   `ZOOMIES`（骑着放的 W：队友的护盾从多少到多少）、`SWITCH`（从谁换到谁、为什么）、`FORM` 的显示钩子有没有换上。
