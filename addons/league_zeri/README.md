# 泽丽附加包（测试版 v0.1.5）：W 撞墙激光 + 被动偷盾

0.1.5（2026-11-05）：待命式大招没用掉时的冷却退还不稳：原来在窗口结束前 1 tick 读待命标记（n tick 的标记只有 n - 1 tick 看得见），经典 SDK 追踪里悟空 53 次过期有 7 次读到时标记已经没了、白等完整冷却；塞恩、艾尼维亚等在前 3 tick 读的 177/177 都退了。现在统一在窗口结束前 3 tick 读（`tools/kit/build_zeri.py`），副本跟着主包重新生成；DLL 没变。看 `league_ult_press.log` 的 `R ARMED … refunded (not used)`。

用户选泽丽技能时说：「打到小兵/野怪就变激光 这个可以做附加包」「普攻充能+强化弹+护盾 这个也是」。主包 `league` 保持纯数据：
数据读不到地图的墙，也读不到敌人身上的护盾，所以主包里

- W「强穿激光」的脉冲**先打中小兵或野怪**时才在那里化为长激光（小兵代替墙）；
- 被动「内能迁转」的电击弹打中英雄时给自己一个**小护盾**（代替偷盾）。

这个附加包把主包的泽丽换成 `override/` 里的副本（`make_override.py` 用 `tools/kit/build_zeri.py` 的 `--native` 生成：技能一样，
只是 W 的脉冲飞出时在她身上挂 `league_zeri_w_go`、她身上有 `league_zeri_w_wall` 时脉冲什么都不打；电击弹不再给小护盾；普攻和
W 的说明写上偷盾和撞墙），被动 `league_zeri:battery` 每 tick 看一次：

- **撞墙激光（英雄联盟原版）**：看到 `w_go`，找出她刚射出的脉冲（下一 tick 飞了约一步的那个投射物），之后逐 tick 跟着它；
  它这一 tick 走过的线段碰到**墙格**（引擎的碰撞墙，30×30 格、每格 32000，`src/maps.rs` 是 game_core 0.5.1 的内置地图，
  与游戏 0.6.2 相同）或 **5v5 地图四边的墙面**，就在那里挂 `w_wall`（数据的脉冲到此为止），并从碰到的地方沿原方向射出
  100000 长的激光（穿透的投射物 `league_zeri_w_wall`），打中的每个敌人受到 60 + 110% 攻击力的物理伤害并减速 35% 2 秒
  （同主包的 W）。脉冲先打中了单位（数据照常处理：小兵、野怪化激光，英雄单体伤害）或飞完了，就不再跟。小兵化激光照旧保留。
- **偷盾（英雄联盟原版）**：她的伤害（普攻、技能都算）打到带护盾的敌人时，被护盾挡下的那部分的 **45%** 变成她自己的护盾，
  持续 3 秒，身上显示护盾的图。电击弹的移速照旧。

数字从英雄数据的 `passive.params` 来。只有单元测试（经典 SDK 跑不了原生代码），要在游戏里看日志：
`%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_zeri.log`（`map:` 认出的地图；`W #n: pulse fired` 每次 W；
`the pulse met a wall at ... - laser to ...` 撞墙出激光；`STEAL #n` 偷了谁的护盾、多少；0.1.1 起每 30 秒一行
`DMG 30s: … dealt - E on … , R on … , plain …; attacks started … (… charged); dead … ticks`：这 30 秒打出的伤害按她开着
E / R / 都没开分，其中打英雄的、命中次数、开始的普攻次数和死着的 tick——用户说「泽丽突然没伤害」时看是哪一段掉的）。
`SPAWN`、`map:`、`W`、`STEAL` 你看的那场每条都记，服务器的预模拟整个游戏先记 60 条、之后每 200 条记一条（0.1.4 起 `SPAWN`、`map:`
也限：11-01 的日志里各 888、226 行）；10-14 的诊断 `DIAG`（你看的那场每个泽丽前 16 次普攻、8 次 W 的弹道）整个游戏连你看的那场
一起先记 40 行、之后每 200 行记一行（诊断早就做完了，11-01 还写了 2036 行，占日志一半）。

## 在游戏里测

1. 主包（League of Legends Heroes 0.93 以上）要装着并启用。
2. 把整个 `league_zeri` 文件夹放进 `<游戏目录>\mods\`，文件夹里要有 `league_zeri.dll`、`mod.mod_info`、`mod.override_info`、
   `override\`、`text\`（或者用附加包合集 `league_addons`，里面已经包含本包）。
3. 进游戏，在 MOD 菜单里启用它（含代码的 mod 会弹一次确认），确认排在主包后面，重启游戏。
4. 看泽丽 W 的说明：写着「先打中小兵、野怪或撞到墙时」就说明换上了。

## 开发

```bash
python addons/league_zeri/make_override.py      # 主包的泽丽或她的说明改了就重跑
cd addons && cargo test --release -p league_zeri && cargo build --release -p league_zeri
```

## 普攻和 W 不再跨过人（0.1.6，2026-11-06）

游戏 0.7.1 的投射物判定（拿 11-05 阿克尚 R 的子弹对出来的，见 league_akshan 0.2.7）：投射物每 tick 跳 `speed` 那么远，只打圆心在它这一 tick 位置 `radius` 以内的单位——不扫两个 tick 中间，也不算单位的体型。`speed` 大于两倍 `radius` 时，站在两 tick 之间的人整个被跨过去；圆比英雄的体型（10000）小很多时，要几乎正中才打得到。

主包的连射子弹 `league_zeri_a_burst` / `e_shot` / `r_shot` 圆 3000、W 的脉冲 `league_zeri_w_pulse` 圆 4000，都是每 tick 飞 9000：站着不动的英雄三个里有一个被跨过去（子弹飞到 80000 才停，可能打到后面的单位）。主包 `build_zeri` 的 `burst_r`、`w_r` 都改 6000（≥ 速度的一半，英雄联盟的子弹加体型），副本重新生成。

## 走路也充电（0.1.8，2026-11-14）

用户看了「和英雄联盟不一样的地方」清单后说「全改吧」，又说「接着做」（能做的小项都做）。英雄联盟的内能迁转 "generates 1 charge for every 40 units she travels by any means"（满 100，放连射 +10）；主包只有每次普攻充一格（5 格满），她的普攻树正在被另一边量，一点不能动。现在被动每 tick 量她走了多远（一 tick 超过 `JUMP` 40000 的算回城、复活这种瞬移，不算；E 的冲刺算），每攒够 `p_walk`（51200：一格 = 100 / `p_need` = 20 电 = 英雄联盟 800 码，按地图比例 ×64，5v5 图 960000 对峡谷约 15000）就替她挂上主包电池的下一格旗子 `league_zeri_c1`..`c4`，最后一格换成 `league_zeri_p_full`（播主包的充满画面和声音）——和普攻充的是同一组旗子，下一次普攻照主包的数据打电击弹。满了就不再攒。`p_need`、`p_walk` 写在副本被动的参数里（`build_zeri.py` 的参数表 P）。普攻的说明加了「走路也充电」（英文的偷盾那句缩短了才放得下）。日志多一种 `WALK`。
