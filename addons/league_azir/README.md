# 阿兹尔附加包（`league_azir`）

用户（2026-10-23）选技能方案时定了：方案 C，「太阳圆盘」并进被动做附加包；大招「要会正推和反面推 可以推回来英雄」，禁军用侧面。

主包的阿兹尔是纯数据：数据看不到防御塔，也看不到禁军墙往哪边冲、敌人在沙兵哪一边（特效图不翻转，主包的禁军永远朝右，沙兵正面朝镜头、刺的时候不动）。这个附加包补上这三件：

| 部分 | 主包（纯数据） | 附加包 |
|---|---|---|
| 太阳圆盘（并入被动，英雄联盟的「恕瑞玛的传承」） | 没有 | 开局记下我方每座塔；每局一次，某座塔倒了、阿兹尔走到废墟 `d_near`（60000）内、废墟 `d_range`（45000）内有敌人时，圆盘从沙里升起，立 `d_life` tick（45 秒）：每 `d_per` tick（1 秒）打最近的敌人（先打英雄，没有英雄再打小兵和野怪，不打塔），`d_dmg` + `d_ap`% 法强（50 + 35%）魔法伤害。圆盘不跟着阿兹尔死，立满时间才消失 |
| 禁军之墙的禁军 | 永远朝右 | 按阿兹尔到大招目标的方向朝左或朝右（反推时他已经绕到目标身后，禁军就朝回冲）；伤害还是数据那道墙的。墙停下后再立 3 秒，敌方英雄走不过去；墙打中的敌人被带到墙停下的地方外面（正推推离阿兹尔，反推推进他的队伍里），回不来（0.1.4 到 0.1.6） |
| 沙兵（用户：「沙兵没攻击动作 你想办法补吧 不让codex了 还有不面向敌人」） | 正面朝镜头，刺的时候不动（只在被刺的人身上出沙矛） | 从侧面画：升起，之后每 `ss_stand` tick（4）盖一次站姿，朝 60 像素内最近的敌人（先英雄，敌人正好在它上下方时不转）；刺过以后下一次改放刺击（`ss_stab` tick，16：往后收矛、刺出、停住、收回），朝被刺的那个。三个沙兵站一处（狂沙猛攻以后）时按槽位错开一点。伤害还是数据的 |
| 沙兵和他之间的线（用户 2026-10-30：「沙皇和召唤的士兵之间没连接线 LOL是有的」） | 没有（数据画不了两个会动的点之间的线） | 照英雄联盟（牵引半径 660 内的沙兵和阿兹尔之间连一道流沙光束）：他和 66000 内每个站着的沙兵之间连一条金色流沙线，沙粒朝沙兵流；沙兵还在升起、离他超过 66000、他死了就不连（0.1.7） |

## 怎么接上的

`mod.override_info` 把主包的阿兹尔换成 `override/` 里的副本（`make_override.py` 用 `tools/kit/build_azir.py` 的 `native=1` 生成），其他技能和主包一模一样：

- `passive` 是本包的 `league_azir:disc`，参数（`d_life d_per d_range d_dmg d_ap d_near r_speed r_len r_stamps s_step ss_stand ss_rise ss_stab`）来自主包参数表 P、写在英雄数据的 `passive.params` 里，本包不另记一份。圆盘的状态（记下的塔、用没用过、立到哪个 tick）在被动自己身上（每个阿兹尔一份，游戏并行跑的几局互不相干）；升起时放 `d_rise` 和 `disc_rise`，立着时每 `s_step` tick 重新盖一次 `disc` 和脚下光环 `d_glow`，每一下太阳光束放 `d_beam` 和声音；
- 大招的禁军墙出墙那一刻调本包的 `league_azir:r_wall`（输入是大招的目标），不再自己盖朝右的禁军：本包算出墙的路线（`r_len` 分 `r_stamps` 跳，速度 `r_speed`，和数据那道墙一样），在每一跳停下的地方、停下的那个 tick（`queue_effect` 排好）盖上朝冲锋方向的禁军（朝右 `r_guards_a/b`，朝左 `r_guards_la/lb`，两步轮流）和脚下的沙尘 `r_dust`。墙的数字由被动在出生时按单位编号存一份（每个阿兹尔的数字都来自同一张参数表）；
- 沙兵：副本里每个槽位（a / b / c）的沙兵升起、每个检查点（`s_step` tick）、每次刺都调本包的 `league_azir:rise_<槽>` / `sold_<槽>` / `stab_<槽>`（升起和检查点拿到沙兵站的地方，刺拿到被刺的单位），不再放主包的正面沙兵。本包按（这局的种子、模拟的来源、比赛、局、施放的单位、槽位）记下每个沙兵，自己排一串 `league_azir:ss_<槽>`，每一下盖一张侧面的画（`league_azir_soldier_side` 的 `stand` / `rise` / `stab`，`_r` 朝右、`_l` 朝左），再排下一下；狂沙猛攻把沙兵挪走时新的升起换一条串，旧的那条自己停；检查点不来了就停。谁放的都画（佛耶戈附身阿兹尔时也一样），不靠被动；
- 普攻的说明换成附加包自己的文字（加上太阳圆盘那句），游戏里看说明就知道副本有没有生效。
- 流沙线（0.1.7）：被动每 tick 给每个站着的沙兵（升起完、盖章链还接着）放一段投射物画面 `league_azir_tether_<像素>`（8 到 64，每 2 一档），放在他和沙兵画的地方的中间，游戏把图转向它飞的方向，1 tick 就到头、下一 tick 再放（阿克尚的绳子、俄洛伊的灵魂线的做法）；两头都抬高 5 像素、各往里收 3 像素，画在单位下面（z -1），两头被身体盖住。图是本包自己的 `effects/league_azir_tether`（[`tools/art/fx_azir_tether.py`](../../tools/art/fx_azir_tether.py)），主包不动；合集照旧把它带进 `league_addons`。`make_override.py` 往副本里加这 29 个画面，命中效果是空的 `league_azir:noop`。

- 主包的阿兹尔改了以后重新跑 `python addons/league_azir/make_override.py`（它先核对主包的 `league_azir.data_champion` 和参数表一致、`src/lib.rs` 的默认参数和 P 一致）。

## 0.1.1：沙兵不再一闪就没、大招会挑时机

用户 2026-10-23：「沙皇召唤出来的小兵会瞬间消失 和英雄联盟不一样」「沙皇不会主动R大招反推回来 不像盲僧」「沙皇大招逻辑太差了」。

- **沙兵画面**：侧面沙兵每张「站着」只有 4 tick，靠本包一张接一张排下去（`queue_effect`）；接力的编号塞在位置输入的目标编号里，
  一旦没传回来整条链就断，沙兵升起后就看不见了，数据的检查点又只延长它的寿命、不重画。现在按「下一张该在哪个 tick」接力，
  不看那个编号；数据每 `s_step` tick 的检查点发现它 `REDRAW`（6）tick 没画过就当场补画、重新接上。日志 `STAMP`、`REDRAWN`。
- **大招时机**（AI 钩子 `league_azir:shurima`，`src/combo.rs`）：
  1. `R INSEC`：E 冲到英雄身上打开的反推窗口（`r_win`）里立刻按 R，绕到他身后把他推回队友那边；
  2. `R PEEL`：有人贴脸（22000 内）而他生命不到一半或身边两个以上敌人：正推出去；
  3. `E INSEC`：R、E 都好、有沙兵、60000 内有队友、生命过半：E 冲向 E 射程里（25000 以外）、不在敌方塔下、身边敌人不超过两个、
     生命最少的英雄，下一刻接第 1 条；
  4. `R HELD`：AI 自己想放 R 但以上都不成立：不放，改成普攻它的目标（打不到就走过去）。

## 0.1.4、0.1.5：墙立住，把打中的人带到墙外

用户 2026-10-28：「沙皇推开别人后 别人马上就回到那位置」「反推也推不回去」；2026-10-29（装上 0.1.4 以后）：「压根推不走人也推不回来人」。

- **0.1.4 墙立住**：数据那道墙冲到头就没了。本包让它在最后一跳停下的地方再立 `r_hold` tick（180，3 秒），横向 `r_half`（30000）宽，
  禁军一直站着；敌方英雄走进墙里就放回他那一边的墙面外（`entity_set_pos`），正在被推、在冲刺的不挡。**反推绕对方向**：副本的反推冲刺
  改调本包的 `league_azir:r_behind`，冲到目标背对他的队伍（90000 内的我方英雄，没有就最近的我方塔）`r_behind`（15000）远的地方。
- **0.1.5 带到墙外**：0.1.4 只让墙立住，推人还是数据的击退，从被打中的地方推 0 到 54000，墙却冲 60000 才立住。经典模拟器 3 局里
  24 次打中英雄有 12 次停在立住的墙前面：正推的人就站在墙这边，直接走回阿兹尔身边；反推的人落在墙线上，被墙放回哪边全看运气。
  副本把击退换成本包的 `league_azir:r_carry`（`r_wall` 排到墙的最前面，带人时这道墙已经记下了）：墙打中谁，就用强制位移把他带到
  墙停下的地方再往外 10000（`WALL_THICK` 6000 + `CARRY_PAST` 4000，横向不动），墙立住那一刻到（最快每 tick 12000），之后墙挡着他
  回不来。免疫控制的不带。被地形挡住、离墙还远的算阿兹尔这边，不会被墙瞬移过去。
- **反推冲刺不冲过头**：强制位移走的是「速度 x tick」，dx / dy 只管方向；原来按 `r_rush` 的速度凑整 tick，要冲 10770 实际冲了 16000。
  现在速度按距离和 tick 数算。
- **日志**：屏幕上那场（观看、观战、回放）的 `WALL`（多了墙立在哪、从哪个 tick 起）、`CARRY`（谁、离墙多远、带到哪、几 tick；
  没带的写原因）、`WALL DOWN`（挡回来几次；被带走的英雄最后离墙多远，+ 在墙那边，- 在阿兹尔这边）、`BEHIND` 每条都记；服务器的
  预模拟照旧先记 30 条，之后每 50 条记一条。

## 0.1.6：本包自己扫墙的路线带人

用户 2026-10-29（装上 0.1.5 以后）：「沙皇的大还是有问题啊 看日志」「局内效果反正不对」。

- **0.1.5 的带人一次都没发生**：那两场一共 104 道墙，日志里 `CARRY` 一条都没有，`WALL DOWN` 全是 `carried []`。0.1.5 把数据的击退
  换成了 `league_azir:r_carry`，只靠数据那道墙打中人时调它，它一次都没被调到，墙就一个人都没推动。0.1.5 还把 `r_wall` 挪到了
  墙的最前面（之前一直在最后，那时墙打人、推人都是好的）。这两处哪一处让它没调到，日志分不出来。
- **现在不靠那一条路**：他的被动每 tick 自己扫一遍墙的路线（`sweep`：圆心和数据那道墙一样，从他站的地方每 tick `r_speed` 走，
  半径 `r_w` 20000，墙立住那一刻为止），扫到的敌方单位（英雄、小兵、野怪，不算塔）2 tick 后带到墙外（先让数据那道墙打中他，
  伤害在它身上；带走以后它就追不上了）；免疫控制的不带。
  `r_wall` 放回墙的最后。`r_carry` 留着当第二条路，一道墙只带一次（`take`）。
- **日志**：`CARRY` 后面写是哪条路带的（`by the sweep` 本包扫到的，`by the wall's hit` 数据那道墙打中的）；`r_carry` 拿到的不是被
  打中的单位时记 `r_carry got input kind`；`WALL DOWN` 写出这道墙带走了几个单位、被带走的英雄最后离墙多远。下一场看日志就知道
  两条路各通不通。

## 0.1.7：沙皇和沙兵之间的流沙线

用户 2026-10-30：「沙皇和召唤的士兵之间没连接线 LOL是有的」。

- **英雄联盟的样子**：本地客户端的 Azir.wad.client 里，沙兵的 `Azir_Base_W_SoldierIndicator` 是一道光束（`Beam_Core` + `OuterBeam_1`，
  贴图 `Azir_base_Z_Beam_Core` / `_Outer`：金色的流沙一缕缕往前卷）；`azir.bin` 的 `SoldierDeactivationRange` 是 660，维基上 Arise!
  的 TETHER RADIUS 660（V7.19 把沙兵的指挥距离从 800 改成 660）。这里按 1 码 = 100（英雄联盟 525 的攻击距离在这里是 52500）
  取 66000。
- **画法**：每个沙兵每 tick 一段，长度按他到沙兵的距离挑（8 到 64 像素，每 2 一档），比俄洛伊那样一串 10 像素的小段省（三个沙兵一 tick
  只多三个投射物；服务器的预模拟也照样画，和你看的那场算的一样）。一段图：1 像素的金色沙芯，每 3 像素一颗浅色沙粒，上下各一排错开的深金
  沙粒，像一股拧着的沙；颜色都取自 `league_azir_fx`。试过三种配色放在草地、沙地、灰地上：浅色沙芯在沙地上几乎看不见，金色沙芯三种地上都清楚。
  沙粒每 2 tick 朝沙兵挪 1 像素（这一段的起点往前挪，每 3 档回一次，沙粒每 3 像素一颗，看上去一直往前流）。
- **什么时候连**：沙兵升起完（`ss_rise` 20 tick 以后）、它的盖章链还接着、数据的检查点还在来、他活着、两人相距不超过 66000。
  狂沙猛攻把沙兵挪走时，新地方的沙兵升起完再连。我们的沙兵离他超过 66000 照样会刺（玩法没改），只是不连线。
