# 斯维因附加包（测试版 v0.1.0，可选）

**不装这个附加包，主包里的斯维因也是完整的**：被动狂食鸦群（帝国视界、永不复行拉到英雄、他打过的英雄阵亡时得到魂屑：回血、加最大生命）、
Q 解脱之触、E 永不复行（飞出飞回、禁锢、拉近）、被动自动放的 W 帝国视界、R 恶魔升华（**看场面才变身**：身边两个敌方英雄，或队友在围攻被控住的
敌方英雄；按 R 只是待命 6 秒，没用上就退还冷却）都在主包数据里。主包是纯数据：**引擎在他死亡时清掉身上所有 buff**（所以主包里魂屑每条命从零攒起，
说明里写着「死后清空」），**待机、跑步、受击的动画不能在运行中换**（所以主包里两次出招之间他还是斯维因；翅膀画在恶魔的帧里，2026-10-22 起不再有单独的翅膀光环）。这个附加包用原生代码把这两件事
做成英雄联盟的样子（用户 2026-10-17：「全按推荐」，做附加包）。

| | 主包（纯数据） | 装了附加包 |
|---|---|---|
| 魂屑 | 每块最大生命 +15，死亡时清空，每条命重新攒 | **永久保留**：死了、复活后一块不少（英雄联盟的规则） |
| 恶魔升华 | 普攻、Q、E、恶魔耀光是带翅膀的恶魔动作，站着、走着、挨打还是斯维因 | **整个身体换成恶魔**：站着、走着、挨打都是恶魔手臂、红眼的他（游戏 0.6.4），形态结束换回 |
| 开大时机 | 看场面（见上） | **不变**，照主包（用户：「是乌鸦看情况开大吧」），日志里记下每次变身时身边几个敌方英雄 |

## 怎么做的

- `mod.override_info` 把主包的斯维因换成 `override/` 里的副本（`make_override.py` 用 `tools/kit/build_swain.py` 的 `native=1` 生成，主包的斯维因改了就重跑）：
  技能一字不改，被动是本包的 `league_swain:flock`（数字在 `passive.params`）；普攻、大招的说明开头加【附加包】。
- **魂屑留到死后**（league_veigar_power 的做法）：每块魂屑是他身上一个永久的 `league_swain_frag`（最大生命 +`p_hp`）。被动活着时把每块原样记下（记在被动里，
  被动在玩家身上、每份模拟各一份，死了不丢），身上比记下的少（死亡、复活时引擎清掉）就用 `add_buff` 原样补回。魂屑只会变多，所以「少了」只会是死亡清掉的。
- **整身换形态**（`src/view.rs`）：照芮尔 / 杰斯附加包的显示钩子，游戏每帧更新显示时，名字是 `league_swain`、身上有主包的恶魔形态 buff `league_swain_r_on` 的实体，
  正在播的 `idle / run / hit` 换成图里的 `b_*`（高清帧由 league.dll 自动换成 `hd_b_*`）。普攻、Q、E、恶魔耀光数据自己播恶魔的 `r_*`；阵亡时 buff 已经没了。
- 日志：`%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_swain.log`：`KEEP`（补回的魂屑）、`FRAG`（攒到第几块）、`RISE`（变身时身边几个敌方英雄）、
  `FORM`（画面里换形态），都限了条数。

## 在游戏里测

1. 主包（League of Legends Heroes 0.132.0 以上）要装着并启用。
2. 用附加包合集 `league_addons`（里面已经包含本包），或者把整个 `league_swain` 文件夹放进 `<游戏目录>\mods\`（文件夹里要有 `league_swain.dll`、`mod.mod_info`、
   `mod.override_info`、`override\`、`text\`）。
3. 进游戏，鼠标停在斯维因的普攻或大招上，说明开头是【附加包】就说明副本生效了；打一局后看日志里的 FRAG / KEEP / RISE / FORM。
