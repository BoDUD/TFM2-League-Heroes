# 古拉加斯大招智能落点附加包（测试版 v0.1.0）

主包 `league` 保持纯数据、全平台可用；数据找不到「目标身后的一点」，主包的爆破酒桶落在目标脚下，爆炸把周围的敌人拽向古拉加斯。
英雄联盟里高手把酒桶扔到敌人身后、把人炸进自己的队伍——要读每个敌人的位置，只能用原生代码，所以放在这个附加包里（合集
`league_addons` 也带着它）。

- 大招出手那一 tick，主包副本（`override/`，tools/kit/build_gragas.py 的 native=1）不扔主包的酒桶，改调本包的 `league_gragas:cask`：
  在射程内每个敌方英雄身后（从古拉加斯看过去）0 / 9000 / 16000 处各试一个落点，按炸得到的敌人打分（英雄 10 分、离他每远
  10000 多 1 分——后排优先；小兵和野怪 0.5 分），取分最高的；同分取更靠后的。落点离他最远 88000。
- 酒桶（主包的 `r_cask` 画面）沿直线飞过去，16 tick 后在落点爆炸（`boom`）：主包的爆炸画面和音效，半径 26000（+ 身体 6000）
  内每个敌人（塔除外）受到 240 + 80% 法强的魔法伤害（走引擎的伤害流程），并被拽向古拉加斯（每 tick 3000、12 tick）。
- 他在酒桶落地前死了就不炸。

## 在游戏里测

1. 主包（League of Legends Heroes 0.96 以上）要装着并启用。
2. 用合集 `league_addons`（推荐），或把整个 `league_gragas` 文件夹放进 `<游戏目录>\mods\`（两者不能同时启用）。
3. 看古拉加斯大招的说明：开头是「【智能落点】」就说明副本生效了。
4. 日志在 `%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_gragas.log`：`CASK at` 是选好的落点（目标、身后多远、够得着几个英雄），
   `BOOM at` 是爆炸（打中几个敌人、每人多少伤害）。

## 开发

- `python addons/league_gragas/make_override.py`：从主包重新生成 `override/` 和 `text/`。主包的古拉加斯改了以后要重跑。
- 在 `addons/` 下 `cargo test --release -p league_gragas`：单元测试（单个目标落在身后、连后排一起炸、英雄比一波兵重要、不超过射程、
  数值和主包一致）。
