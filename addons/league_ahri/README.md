# 阿狸附加包（测试版 v0.1.0，可选）

**不装这个附加包，主包里的阿狸也是完整的**：被动摄魂夺魄、Q 欺诈宝珠加妖异狐火、E 魅惑妖术、R 灵魄突袭（15 秒内连放 3 次，参与击杀再给 1 次）都在主包数据里。
主包是纯数据，**只认得出阿狸自己打出的最后一击**，所以有两处只能近似：
- 小兵、野怪只数普攻打死的，Q、狐火、精魄弹打死的数不到；
- 英雄阵亡用佛耶戈的击杀窗口（她 3 秒内打过的英雄死了就算），**同一个窗口里只认一个**。

这个附加包用原生代码按英雄联盟现在的规则数（用户 2026-10-24：「需要补附加包的话也补」）。

| | 主包（纯数据） | 装了附加包 |
|---|---|---|
| 精魄（9 层回血） | 普攻打死的小兵、野怪 | 她补到的每一个小兵、野怪，用什么打死的都算 |
| 参与击杀回血 | 她 3 秒内打过的英雄阵亡；一个窗口只认一次 | 她的**每一次**英雄击杀和助攻，几个人同时阵亡各算一次 |
| 灵魄突袭多给 1 次 | 同上（窗口开着时） | 同上（窗口开着时） |

## 怎么做的

- `mod.override_info` 把主包的阿狸换成 `override/` 里的副本。副本由 `make_override.py` 从主包生成，主包的阿狸改了就重跑：
  - 普攻的击杀检查、每次命中英雄的窗口标记去掉；
  - 被动换成本包的 `league_ahri:essence`（数字在 `passive.params`）；
  - 普攻（带被动）的说明开头加【附加包】。
- **精魄**：`on_unit_kill`（她补到小兵、野怪）记一层，第 9 层时给她挂 60 tick 的 `league_ahri_k_go`。6 层以上身上亮主包的精魄画面 `league_ahri_et_ready`。层数死了也留着。
- **参与击杀**：`on_kill`（死的是英雄）和 `on_assist` 各挂一次 `league_ahri_tk_go`；几个同时来就排队，上一个被取走了再挂下一个。
- 回血、灵魄突袭的加次数都在主包数据里：她的普攻、Q、E、R 每次都在自己身上挂一个监视器，第一个看到标记的把它取走，然后回血（R 窗口开着时再给一次、窗口至少再开 10 秒）。原生代码只负责数数、挂标记。
- 状态都在被动自己的对象里，游戏 0.6.4 同时跑的两份预模拟各算各的。

## 在游戏里测

1. 主包（League of Legends Heroes 0.208.0 以上）要装着并启用。
2. 把整个 `league_ahri` 文件夹放进 `<游戏目录>\mods\`。文件夹里要有 `league_ahri.dll`、`mod.mod_info`、`mod.override_info`、`override\`、`text\`。也可以用附加包合集 `league_addons`，里面已经包含本包。
3. 进游戏，在 MOD 菜单里启用它（含代码的 mod 会弹一次确认），确认排在主包后面，重启游戏。
4. 看阿狸普攻的说明：开头是「【附加包】」就说明换上了。
5. 日志在 `%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_ahri.log`，每次启动游戏重写（上一次的留在 `.prev.log`）：
   - `SPAWN`：这局用的是附加包的阿狸；
   - `UNIT` / `KILL #id` / `ASSIST`：补到一个单位、击杀、助攻，后面是现在的层数和排队中的奖励。

## 开发

- `python addons/league_ahri/make_override.py`：重新生成 `override/` 和 `text/`；`--check` 只比较。
- `cargo test -p league_ahri`（在 `addons/` 下；仓库在很深的路径里时设 `CARGO_TARGET_DIR` 到一个短路径，不然链接器打不开参数文件）。
