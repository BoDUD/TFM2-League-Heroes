# 蕾欧娜附加包（v0.1.0）

主包 `league` 保持纯数据。用户 2026-11-14 看了「和英雄联盟不一样的地方」清单后说「全改吧」，再说「接着做」（能做的小项都做）。英雄联盟的日光（被动，wiki：她的技能给命中的敌人挂 2.5 秒的标记，"Allied champions' damaging attacks and abilities against a marked target" 引爆它，32–151 魔法伤害随等级）要等**队友**打中才引爆；数据分不清是谁打中了带标记的敌人，主包只能做成「被她技能命中的敌人 1.5 秒内受到的所有伤害 +10%」。这个附加包用原生代码补上队友引爆这一步：

| | 主包（不装附加包） | 装了附加包 |
|---|---|---|
| 日光（被动） | 被她的 Q、E、W 爆发、R 命中的敌人 1.5 秒内受到的所有伤害 +10%（每个技能各挂一层，她自己的伤害也算） | **队友引爆**：命中的敌人挂上日光 2.5 秒（不再增伤），友方英雄（不算她自己）的普攻或技能打中它时引爆，造成 32–151（随她的等级）魔法伤害，日光摘掉 |

## 怎么做的

- 副本（`override/`，`make_override.py` 从主包的 `league/champion/league_leona.data_champion` 生成）和主包一样，只是挂日光的四处（Q、E 的剑光、W 的爆发、R 的光柱）挂的 `league_leona_sunlight` 不带增伤、挂 `MARK_T`（150 tick = 2.5 秒）；被动换成本包的 `league_leona:sunlight`，普攻（写着被动）的说明换成本包的。日光的画面照主包。
- 谁打中了带日光的人：游戏的接口读不到「这一下是谁打的」，本包照 league_renata / league_braum 的做法看出手——每 tick 读她这边每个友方英雄的冷却，普攻冷却跳起来 = 他刚出手普攻，打的是他身边（75000 内）最近的敌方单位；技能冷却跳起来 = 他刚放了技能，打的是他身边（90000 内）最近的带日光的敌方单位。10 tick 后（前摇加飞行）那个人还带着日光就引爆。
- 引爆：摘掉日光（同名的几层一起），按她的等级造成 `DMG_MIN` + (`DMG_MAX` − `DMG_MIN`) × (等级 − 1) / 11 的魔法伤害（英雄联盟 1–18 级的 32–151 线性摊到这个游戏的 1–12 级：1 级 32、6 级 86、12 级 151），伤害算她的；目标身上播主包 Q 的日光闪（`league_leona_q_hit`）。
- 她阵亡时被动不跑：那段时间队友打中带日光的人不引爆，日光照样到时消失。
- 彩蛋（league_eggs 的墨镜、league_zyra 的光合作用）认的还是 `league_leona_sunlight` 的层数，照样生效；只是装了本包后日光不再增伤，墨镜那 1% 减伤就成了白送的。

## 在游戏里测

1. 主包（League of Legends Heroes 0.354 以上）要装着并启用。
2. 用附加包合集 `league_addons`（里面已经包含本包），或者把整个 `league_leona` 文件夹放进 `<游戏目录>\mods\`（要有 `league_leona.dll`、`mod.mod_info`、`mod.override_info`、`override\`、`text\`）。
3. 进游戏，在 MOD 菜单里启用它（含代码的 mod 会弹一次确认），确认排在主包后面，重启游戏。
4. 看蕾欧娜的普攻说明：开头是「【附加包】」、被动写着「友方英雄的攻击或技能打中它时引爆」就说明换上了。
5. 日志在 `%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_leona.log`，每次启动游戏重写（上一次的留在 `.prev.log`）：`SPAWN`：出生 / 复活；`POP`：哪个队友引爆了谁、多少伤害、她几级。

## 开发

- `python addons/league_leona/make_override.py`：从主包重新生成 `override/` 和 `text/`（`--check` 只比较，CI 用）。主包的蕾欧娜改了以后要重跑（主包的日光变了脚本会停下）。
- 在 `addons/` 下 `cargo test --release -p league_leona`：单元测试（伤害随等级、冷却跳起算出手、副本的日光不带增伤、挂 2.5 秒、调本包的被动）。
- 经典 SDK 的模拟器跑不了原生代码，本包只做了单元测试，要在游戏里看日志确认。
