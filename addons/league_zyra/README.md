# 婕拉附加包（测试版 v0.1.0，可选）

**不装这个附加包，主包里的婕拉也是完整的**：普攻甩出荆棘种子；Q 致命棘刺在目标点炸出棘刺，落点长出荆棘喷射者；E 缠绕之根禁锢一条线上的
敌人，落点长出藤蔓鞭击者；R 绞杀之藤召唤密林，2 秒后击飞还在里面的敌人，并激怒她的植物。主包是纯数据：**数据不能在地上留东西**，所以
主包里每次 Q、E 都当场种一颗种子、马上长成植物（英雄联盟 W + Q / W + E 的连招）；植物是落点上的周期区域，每秒打区域里先轮到的一个敌人
（小兵可能排在英雄前面），伤害不随等级变。这个附加包用原生代码把英雄联盟的**种子**做出来（用户 2026-10-20：技能方案 A、中单、做附加包）。

| | 主包（纯数据） | 装了附加包 |
|---|---|---|
| 荆棘花园 / 狂野生长 | 每次 Q、E 当场长一株植物 | 主包的照旧；另外**种子掉在她身边的地上**：每 10 秒一颗（有敌方英雄在附近就掉在朝他的方向），在地上留 30 秒、最多 4 颗；**她参与击杀敌方英雄时马上掉一颗**（英雄联盟：击杀缩短狂野生长的充能） |
| Q 致命棘刺 | 落点长一株荆棘喷射者 | 落点 24000 内的种子**也都长成荆棘喷射者** |
| E 缠绕之根 | 落点长一株藤蔓鞭击者 | **藤蔓经过的线上**（她到落点再往前 20000）的种子都长成藤蔓鞭击者 |
| 种子长的植物 | — | 活 5 秒，每秒出手一次，**先打范围内最近的敌方英雄**，没有英雄才打小兵、野怪（不打塔）；**伤害随她的等级成长**（1 级 20、18 级 100，+12% 法强，英雄联盟 20–100）；荆棘喷射者**吐出一根看得见的刺**、飞到才扣血，藤蔓鞭击者抽打并减速 30% 1 秒 |
| R 绞杀之藤 | 植物 5 秒内伤害提高 50% | 主包的照旧；密林范围里种子长的植物 5 秒内**出手间隔减半**（英雄联盟：密林里的植物攻速提高） |

## 怎么做的

- `mod.override_info` 把主包的婕拉换成 `override/` 里的副本（`make_override.py` 用 `tools/kit/build_zyra.py` 的 `native=1` 生成，主包的
  婕拉改了就重跑）：被动是本包的 `league_zyra:garden`（数字在 `passive.params`）；普攻、Q、E 的说明开头加【扩展包】。
- **落点**：数据告诉不了原生代码 Q、E、R 落在哪里（弹道的信息里没有名字），所以副本里 Q、E、R 出手那一 tick 给目标挂 2 tick 的
  `league_zyra_q_aim` / `e_aim` / `r_aim`（落点就是目标那时站的地方）；被动每 tick 看一遍敌方单位，新挂上的标记就是一次落地。
- **种子**：被动记下每颗种子的位置，`s_show` tick 重放一次 `league_zyra_s_seed` 的画面（种子的图一轮正好这么长），掉落时放
  `league_zyra_s_drop` 的声音（英雄联盟 W 种下种子的声音）。
- **植物**：长出来时在种子的位置放主包的 `t_plant` / `v_plant` 画面（它们的动画就是 5 秒的一生）和声音；之后被动自己数时间出手：
  荆棘喷射者 `spawn_projectile` 从植物身上吐出 `league_zyra_t_spit`（只是画面，效果是空的 `league_zyra:noop`），按距离算好飞到的 tick 再
  `deal_damage_typed` 扣血、放 `t_hit`；藤蔓鞭击者当场扣血、挂 `league_zyra_v_slow`（减速 30%）、放 `v_hit`。她死了种子和植物照样留着
  （英雄联盟的）。
- 游戏 0.6.4 的 `deal_damage_typed` 只把伤害排进效果队列，下一次 on_update 之前才扣血（莉莉娅 0.1.2 的教训）。
- 日志：`%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_zyra.log`：`SEED`（掉种子）、`GROW`（种子长成植物）、`STRIKE`（植物出手）、
  `RAGE`（激怒）、`TAKEDOWN`（参与击杀掉种子）、`WATCH`（每 30 秒的计数），都限了条数。

## 在游戏里测

1. 主包（League of Legends Heroes 0.177.0 以上）要装着并启用。
2. 用附加包合集 `league_addons`（里面已经包含本包），或者把整个 `league_zyra` 文件夹放进 `<游戏目录>\mods\`（文件夹里要有 `league_zyra.dll`、
   `mod.mod_info`、`mod.override_info`、`override\`、`text\`）。
3. 进游戏，鼠标停在婕拉的技能上，说明开头是【扩展包】就说明副本生效了；打一局后看日志里的 SEED / GROW / STRIKE / RAGE / TAKEDOWN。

## 重新生成

```bash
python tools/kit/build_zyra.py                 # 主包的婕拉（参数表 P）
python addons/league_zyra/make_override.py     # 本包的副本和说明
cargo build --release -p league_zyra           # 在 addons/ 下
```
