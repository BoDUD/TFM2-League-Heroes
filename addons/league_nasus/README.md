# 内瑟斯附加包（测试版 v0.1.0，可选）

**不装这个附加包，主包里的内瑟斯也是完整的**：被动吞噬灵魂（生命偷取）、Q 汲魂痛击（击杀叠层，叠层加伤害）、E 灵魂烈焰（燃烧、减护甲）、
被动自动放的 W 枯萎（逐渐加深的减速和减攻速）、R 死神降临（**看场面才变身**：身边两个敌方英雄，或正在和敌方英雄交战；按 R 只是待命 10 秒，没用上就
退还冷却）都在主包数据里。主包是纯数据：**引擎在他死亡时清掉身上所有 buff**（所以主包里 Q 的层数每条命从零叠起，说明里写着「死后清空」），**数据里的
技能冷却 buff 同时作用于 Q 和 E**（所以主包的大招把 Q、E 冷却都减半），**待机、跑步、受击的动画不能在运行中换**（所以主包里两次出招之间他还是原来的大小，
只有身边的沙暴光环）。这个附加包用原生代码把这三件事做成英雄联盟的样子（用户 2026-10-17：「全按推荐做」，做附加包）。

| | 主包（纯数据） | 装了附加包 |
|---|---|---|
| 汲魂痛击的层数 | 击杀单位 +4、击杀英雄 +10，死亡时清空，每条命重新叠 | **永久保留**：死了、复活后一层不少（英雄联盟的规则） |
| 死神降临的冷却 | Q 和 E 冷却都减半 | **只有 Q 冷却减半**（英雄联盟的规则），E 照常 |
| 死神降临的身体 | 普攻、Q、E、W 是大号的动作，站着、走着、挨打还是原来的大小，身边沙暴光环 | **整个身体变大**：站着、走着、挨打都是变大、眼睛和宝石发光的他（游戏 0.6.4），形态结束换回 |
| 开大时机 | 看场面（见上） | **不变**，照主包，日志里记下每次变身时身边几个敌方英雄 |

## 怎么做的

- `mod.override_info` 把主包的内瑟斯换成 `override/` 里的副本（`make_override.py` 用 `tools/kit/build_nasus.py` 的 `native=1` 生成，主包的内瑟斯改了就重跑）：
  技能一字不改，被动是本包的 `league_nasus:soul_eater`（数字在 `passive.params`），大招的 buff 不带「技能冷却 +100」；Q、大招的说明开头加【附加包】。
- **层数留到死后**（league_veigar_power / league_swain 的做法）：每次 Q 击杀是他身上一个永久的 `league_nasus_q_stack`（法术强度 +`q_s`，英雄 +`q_sc`；
  Q 的叠层伤害按法术强度算，他没有别的法术强度）。被动活着时把每一层原样记下（记在被动里，被动在玩家身上、每份模拟各一份，死了不丢），身上比记下的少
  （死亡、复活时引擎清掉）就用 `add_buff` 原样补回。层数只会变多，所以「少了」只会是死亡清掉的。
- **大招只减 Q**：大招期间（主包的 buff `league_nasus_r_on`）每 tick 用 `entity_reduce_cooldown` 给 Q 的冷却多减 1 tick（冷却快一倍 = 减半）；旧游戏没有这个接口时
  退回主包的做法（挂一个 2 tick 的技能冷却 +100，Q、E 一起减半）。
- **整身换形态**（`src/view.rs`）：照斯维因 / 芮尔附加包的显示钩子，游戏每帧更新显示时，名字是 `league_nasus`、身上有 `league_nasus_r_on` 的实体，
  正在播的 `idle / run / hit` 换成图里的 `b_*`（高清帧由 league.dll 自动换成 `hd_b_*`）。普攻、Q、E、W 数据自己播大号的 `b_*`；阵亡时 buff 已经没了。
- 日志：`%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_nasus.log`：`KEEP`（补回的层数）、`STACK`（叠到多少层）、`RISE`（变身时身边几个敌方英雄）、
  `QCD`（大招期间 Q 冷却加速）、`FORM`（画面里换形态），都限了条数。

## 在游戏里测

1. 主包（League of Legends Heroes 0.135.0 以上）要装着并启用。
2. 用附加包合集 `league_addons`（里面已经包含本包），或者把整个 `league_nasus` 文件夹放进 `<游戏目录>\mods\`（文件夹里要有 `league_nasus.dll`、`mod.mod_info`、
   `mod.override_info`、`override\`、`text\`）。
3. 进游戏，鼠标停在内瑟斯的 Q 或大招上，说明开头是【附加包】就说明副本生效了；打一局后看日志里的 STACK / KEEP / RISE / QCD / FORM。
