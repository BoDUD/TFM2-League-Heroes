# 诺拉附加包（`tft_norra`）

用户（2026-10-26）：「你要参照手游的技能啊」「不一致的地方就做附加包」——诺拉的技能照英雄联盟手游（Wild Rift）做，数据做不到的地方放进这个附加包。

金铲铲包（`tft`）的诺拉是纯数据：数据读不到「琐物一个一个在哪」「谁身上已经有线缕」「冷却还剩多少」，也不能让一个球沿一条线飞，所以主包里有几处只能近似。这个附加包把它们做成手游的样子（规则按手游现在的诺拉：Wild Rift wiki 和 7.3 的改动记录）：

| 机制 | 主包（纯数据） | 附加包 |
|---|---|---|
| 寄情琐物（被动） | 落点放**一片**琐物，走进去的敌方英雄各挨一次 | 落点**撒 3 个**（手游按等级 2/3/4 个）：中间茶杯、左右各一个水晶，敌方英雄**踩到哪个，哪个飞到他身上**炸开，别的还在 |
| 琐物冷却 | 固定 `p_cd` | 技能（Q、W、E）**命中敌方英雄**，冷却减少总冷却的 20% |
| 回忆涌现（Q） | 落点周围一圈打琐物伤害 | 对**已有线缕**的英雄多打最大生命 `q_bonus`‰；蓄满的 Q **打中英雄**，地上的琐物变成「附近有人就炸」：敌方英雄走到 `q_prime_r` 以内就飞过去 |
| 奇异旅程（W，并进被动） | 只在**她普攻**、身边有敌方英雄时开门 | 敌方英雄**一贴身**就开门（她活着、能被选中、不在控制里、冷却好了） |
| 传送门欢腾！（R） | 每波打**裂隙里所有**敌方英雄 | 每波两个毛线球从裂隙**两头沿一条线对飞**（线穿过裂隙里的一个敌方英雄，每波轮到下一个），路上敌人每波挨一次，**每个球碰到的第一个英雄**减速 |

两边一样的：普攻、伤害数字、线缕（变大、减速）、思乡线缕的范围、W 放逐 1.5 秒后减速 80% 0.75 秒（手游 7.2，数据也做得到，主包也有）。

## 怎么接上的

`mod.override_info` 把金铲铲包的诺拉换成 `override/` 里的副本（`make_override.py` 用 `tools/kit/build_norra.py --native` 生成）；`passive` 是本包的 `tft_norra:trinkets`，参数来自主包参数表 P（`build_norra.NATIVE_KEYS`）。副本在这些地方调用本包的效果（`Native`）：

- 琐物冷却好了的 Q / E 落地：`tft_norra:drop`（落点，撒琐物）；每个琐物是一个每拍重排一次的效果 `tft_norra:trinket`，位置、到期的拍、哪一块、撒下的拍、引爆了没有都记在它的输入里；
- Q 的命中：`tft_norra:surge`（最大生命加伤、挂线缕、引爆琐物、减琐物冷却），副本里不再有挂线缕的那一圈和主包的引爆；
- E 的命中：`tft_norra:refund`（减琐物冷却）；
- 裂隙落地：`tft_norra:rift`（排 4 波 `tft_norra:volley`，每波 `spawn_projectile` 两个毛线球 `tft_norra_r_ball`，命中 `tft_norra:yarn_l` / `_r`，第四波 `yarn4_l` / `_r`），副本里不再有主包的 4 波；
- 普攻不开门：被动每拍自己看要不要开奇异旅程（`entity_banish`，门的图 `w_lock` / `w_out`，放逐前挂上 `w_t` + `w_slow_t` 拍的减速，放逐期间不在场上，回来才感觉得到）。

会变的东西都在模拟里（排着的效果、身上的状态），只有参数按诺拉的单位编号记一份给效果用（服务端预模拟和你看的那场是同一份数字）。图（`tools/art/import_norra_fx.py`）：琐物的三块 `p_trinket_l` / `_c` / `_r` 从主包那张琐物图切出来，飞的毛线球 `r_ball` 从主包的毛线球图切出来，都在主包的 `tft_norra_fx` 里。说明文字用诺拉自己的 id（和主包同一个键，合并时盖过主包的），四个技能都带【附加包】，游戏里看说明就知道副本有没有生效。

本包是**单独的原生 mod**（`tft_norra.dll`，依赖 `tft`），不在 `league_addons` 合集里：合集只收 `league_*`，依赖的是主包 `league`。

## 检查

- 在 `addons/` 下 `cargo test -p tft_norra`：单元测试（参数、伤害和冷却的数、三个琐物的位置、琐物装进输入再取出来、自己那发 Q 不引爆自己的琐物、最近的英雄、毛线球的线、名字）。
- 主包的诺拉改了以后重新跑 `python addons/tft_norra/make_override.py`（它先核对 `tft/champion/tft_norra.data_champion` 就是参数表 P 的那一份、`src/lib.rs` 的默认参数和 P 一致；`--check` 只核对不写）。
- 日志：`%APPDATA%\TeamSamoyed\TeamfightManager2\data\tft_norra.log`：`SPAWN`、撒琐物 `DROP`、琐物飞出 `TRINKET`、引爆 `PRIMED`、减冷却 `REFUND`、Q 的加伤 `SURGE`、开门 `JOURNEY`、裂隙 `RIFT`、每波 `VOLLEY`、毛线球命中 `YARN`。
