# 厄加特附加包（测试版 v0.1.0，可选）

**不装这个附加包，主包里的厄加特也是完整的**：普攻霰弹和被动回响烈焰（腿上的霰弹轮流喷）、Q 腐蚀电荷（打中自动开 W 净除的机枪）、
E 鄙弃（护盾冲锋、晕眩、甩到身后）、R 超越死亡的恐惧（钻头拴住、拽回来处决、恐惧周围）都在主包数据里。主包是纯数据：**数据分不清目标在他哪个方向**，
**读不到敌人当前的血量**。这个附加包用原生代码把这两件事做成英雄联盟的样子（用户 2026-10-16：「方案可以，全按推荐做（上单，W 并进 Q/E，做附加包，PPU 1.5）」）。

| | 主包（纯数据） | 装了附加包 |
|---|---|---|
| 回响烈焰 | 六条腿共用一个冷却（3 级起 3 秒、3 级前 8 秒），轮流喷 | **六条腿各朝一个方向（每条 60°）、各自冷却**：子弹落在哪边，就由朝那边的两条腿里冷却好的那条喷（英雄联盟：普攻落在哪条腿的扇形里就是哪条）；每条腿冷却是主包的 2 倍，朝着目标的两条轮流，平均下来和主包一样快 |
| 超越死亡的恐惧 | 拴满 4 秒就拽回来，造成目标最大生命 25% 的真实伤害（生命低于 25% 的必死，多的也吃这一下） | **只处决生命低于 25% 的**（英雄联盟的处决线）：拴满时读目标当前生命，低于 25% 才拽回来处决；血多的只吃钻头的伤害和减速 |

## 怎么做的

- `mod.override_info` 把主包的厄加特换成 `override/` 里的副本（`make_override.py` 用 `tools/kit/build_urgot.py` 的 `native=1` 生成，主包的厄加特改了就重跑）：
  被动是本包的 `league_urgot:legs`（数字在 `passive.params`）；普攻和大招的说明开头加【附加包】。
- **按方向选腿**：普攻和净除的每一发调 `league_urgot:leg`。本包按目标相对厄加特的方向算出朝着它的两条腿，挑冷却好的那条，
  让厄加特身上出现 1 tick 的 `league_urgot_leg_go`，数据接着喷扇形火焰；两条都在冷却就不喷。3 级前后的冷却和数据一样用技能 2 是否解锁来判断。
- **真处决**：拴满时数据调 `league_urgot:mercy`，目标当前生命低于最大生命的 25% 时让厄加特身上出现 1 tick 的 `league_urgot_r_low`，
  数据接着拽回来、造成最大生命 25% 的真实伤害（一定致死）、处决成功就恐惧周围敌人；不低于 25% 什么都不做。
- 游戏 0.6.4 同一局有两份预模拟和画面同时跑，实体编号一样：本包出生时给厄加特挂一个模拟编号 buff（`league_urgot_sim:<n>`），腿的冷却按（模拟，厄加特）分开记。
- 日志：`%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_urgot.log`（SPAWN、LEG 每次喷的是哪条腿、EXECUTE / SPARED 拴满时目标的血量）。

## 在游戏里测

1. 主包（League of Legends Heroes 0.126.0 以上）要装着并启用。
2. 把整个 `league_urgot` 文件夹放进 `<游戏目录>\mods\`，文件夹里要有 `league_urgot.dll`、`mod.mod_info`、`mod.override_info`、`override\`、`text\`
   （或者用附加包合集 `league_addons`，里面已经包含本包）。
3. 进游戏，鼠标停在厄加特的普攻或大招上，说明开头是【附加包】就说明副本生效了；打一局后看日志里的 LEG / EXECUTE / SPARED。
