# 卡特琳娜附加包（测试版 v0.1.0，可选）

**不装这个附加包，主包里的卡特琳娜也是完整的**：普攻、Q 弹射之刃（瞬步就绪时跳到落地的匕首）、W 伺机待发（瞬步就绪时先瞬步切入）、
R 死亡莲华、被动贪婪和捡匕首旋斩都在主包数据里。主包是纯数据：**地上的匕首在哪里数据看不见**，瞬步只能在 Q、W 两个技能里顺带用；
贪婪用佛耶戈的击杀窗口，**同一个窗口里只认一个阵亡**。这个附加包用原生代码把这两件事做成英雄联盟的样子（用户 2026-10-15 选「要附加包」）。

| | 主包（纯数据） | 装了附加包 |
|---|---|---|
| 瞬步 | 只在 Q（跳到这把 Q 落地的匕首）和 W（先切到目标英雄身边）里用 | 另外**瞬步一好就自己判断**：射程内哪把匕首旁有敌方英雄就跳过去（那里生命比例最低的英雄优先），落地捡刀旋斩、冷却缩短，接着跳下一把——**匕首循环**；生命低于 30% 而身边有敌方英雄时，跳到离敌人最远的那把匕首撤离；匕首旁 3 名以上敌方英雄、她生命又不到 60% 时不跳进人堆 |
| 贪婪 | 被她伤过的英雄 3 秒内阵亡，Q、W 刷新、瞬步就绪；一个窗口里只认一次 | **她参与的每一次英雄击杀**（击杀或助攻）都刷新，几个人同时阵亡各算一次 |

## 怎么做的

- `mod.override_info` 把主包的卡特琳娜换成 `override/` 里的副本（`make_override.py` 用 `tools/kit/build_katarina.py` 的 `native=1` 生成，主包的卡特琳娜改了就重跑）：
  击杀窗口去掉、被动是本包的 `league_katarina:blades`（数字在 `passive.params`）；普攻（被动）的说明开头加【附加包】。
- **认出地上的匕首**：原生代码看得到投射物的位置和施放者，看不到名字。她自己的投射物里，**连续两次（隔 3 tick）看到停在同一个地方的**就是插在地上的匕首
  （主包的拾取区，活 4 秒）；飞刀、大招的匕首在动，1 tick 的探测区和 W 的锚点只出现一次。她走到拾取范围内（被主包捡起）或 4 秒到了就不算了。
- **瞬步**：起点、落点播主包的 `e_out` / `e_in`，瞬步的动作和音效（台词照主包间隔），落地对 30000 内最近的敌人造成主包 E 的魔法伤害，
  主包的冷却标记 `league_katarina_e_cd` 重新计时；落在匕首上由主包的拾取区当场捡起、旋斩、把冷却缩短。被控、引导大招时不跳。
- **贪婪**：`on_kill`（死的是英雄）和 `on_assist` 时把 Q、W 的冷却清零、去掉瞬步的冷却标记，播主包的 `p_reset` 和音效。
- 状态都在被动自己的对象里，游戏 0.6.4 同时跑的两份预模拟各算各的。

## 和用户最初的方案不一样的地方

- **大招只打最近的 3 个英雄**：大招的匕首画面和伤害都在主包数据里（对半径内每个敌方英雄），原生代码改不了数据挑谁；主包里这个圈内通常不超过 3 个英雄，附加包没有改。
- **Q 的匕首落在第一个目标身后 350 码**：主包改成落在飞刀打中第一个目标时他站的地方（数据的投射物都从她身上出发，算不出「目标身后」）；原生代码也挪不动数据的投射物，附加包没有改。

## 在游戏里测

1. 主包（League of Legends Heroes 0.115.0 以上）要装着并启用。
2. 把整个 `league_katarina` 文件夹放进 `<游戏目录>\mods\`，文件夹里要有 `league_katarina.dll`、`mod.mod_info`、`mod.override_info`、`override\`、`text\`
   （或者用附加包合集 `league_addons`，里面已经包含本包）。
3. 进游戏，在 MOD 菜单里启用它（含代码的 mod 会弹一次确认），确认排在主包后面，重启游戏。
4. 看卡特琳娜普攻的说明：开头是「【附加包】」就说明换上了。
5. 日志在 `%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_katarina.log`，每次启动游戏重写（上一次的留在 `.prev.log`）：
   - `SPAWN`：这局用的是附加包的卡特琳娜；
   - `BLINK #n in: (x,y) -> (x,y) (距离), hp 80%, hit Some(id)`：瞬步到一把匕首（`in` 进攻、`out` 撤离），落地打中了谁；
   - `RESET #n (killed #id / assist)`：贪婪刷新。

## 开发

- `python addons/league_katarina/make_override.py`：重新生成 `override/` 和 `text/`（先核对主包的卡特琳娜和参数表一致）。
- `cargo test -p league_katarina`（在 `addons/` 下；仓库在很深的路径里时设 `CARGO_TARGET_DIR` 到一个短路径，不然链接器打不开参数文件）。
