# 阿利斯塔附加包（v0.1.0）

主包 `league` 保持纯数据。用户 2026-11-14 看了「和英雄联盟不一样的地方」清单后说「全改吧」，再说「接着做」（能做的小项都做）。英雄联盟的凯旋怒吼（被动，wiki）：他的技能每眩晕 / 击飞一个敌方英雄得 1 层「凯旋」，身边每死一个敌方小兵或非史诗野怪也得 1 层，身边的敌方英雄或史诗野怪阵亡一下得 7 层，满 7 层怒吼回血；冷却里照样叠，他死了清零。数据看不到他身边谁死了，主包只数控制命中英雄、3 次就吼。这个附加包用原生代码按英雄联盟叠层：

| | 主包（不装附加包） | 装了附加包 |
|---|---|---|
| 凯旋怒吼（被动） | 控制命中敌方英雄 3 次后怒吼（5 秒一次），自己回复 40 + 20% 法强、身边的友方英雄 50 + 30% 法强 | **英雄联盟的叠层**：控制命中敌方英雄、身边的敌方小兵或野怪阵亡各 1 层，身边的敌方英雄或史诗野怪阵亡 7 层，满 7 层怒吼；冷却里照样叠，他死了清零；治疗照主包 |

## 怎么做的

- 副本（`override/`，`make_override.py` 从主包的 `league/champion/league_alistar.data_champion` 生成——主包是 `tools/kit/build_alistar.py` 的输出再过 `tools/fix` 的脚本，所以从文件改，不重新生成）和主包一样，只是四处「控制命中一个英雄：怒吼阶梯上一级或怒吼」（Q 的砸地、W 的头槌和落地砸地、E 的眩晕拳）换成本包的原生效果 `league_alistar:cc`，数据里的阶梯（`p1`、`p2`）和怒吼不再有；被动换成本包的 `league_alistar:roar`，普攻（写着被动）的说明换成本包的。
- `:cc`：命中的英雄活着、身上没有免控（`cc_immune`）就给他挂一层旗子 `league_alistar_p_cc`，被动下一 tick 取走，算 1 层（英雄联盟：对免控的目标控制失败不算）。
- 身边阵亡：被动每 3 tick 记一次他 `NEAR`（75000，英雄联盟 1000 码按他这套技能约 ×75 的比例）内的敌方小兵、野怪、英雄、史诗野怪；上次在身边、这次死了的就算——小兵、野怪 1 层，英雄、史诗野怪 7 层；走出范围还活着的不算。最多 7 层。
- 怒吼：满 7 层、冷却（`p_cd` 300 tick）过了就吼：层数清空，自己回复 `p_heal` + `p_ap`% 法强，`p_r`（40000）内的其他友方英雄各回复 `p_ally` + `p_ally_ap`% 法强（这些都是主包参数表的数，`make_override.py` 核对），他身上播主包的怒吼、每个被治疗的人身上播主包的治疗光、放主包的吼声。
- 治疗量照主包（英雄联盟是自己 5% 最大生命、友军 7% 他的最大生命）：现在小兵死也叠层，吼得比主包勤，没再加大每一下。

## 在游戏里测

1. 主包（League of Legends Heroes 0.354 以上）要装着并启用。
2. 用附加包合集 `league_addons`（里面已经包含本包），或者把整个 `league_alistar` 文件夹放进 `<游戏目录>\mods\`（要有 `league_alistar.dll`、`mod.mod_info`、`mod.override_info`、`override\`、`text\`）。
3. 进游戏，在 MOD 菜单里启用它（含代码的 mod 会弹一次确认），确认排在主包后面，重启游戏。
4. 看阿利斯塔的普攻说明：开头是「【附加包】」、被动写着「身边的敌方小兵或野怪阵亡各得1层」就说明换上了。
5. 日志在 `%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_alistar.log`，每次启动游戏重写（上一次的留在 `.prev.log`）：`SPAWN`：出生 / 复活（层数清零）；`TRIUMPH`：得了几层、从哪来（控制、谁死在身边）、现在几层；`ROAR`：怒吼回了谁多少；`TRIUMPH none`：控制打在免控的人身上。

## 开发

- `python addons/league_alistar/make_override.py`：从主包重新生成 `override/` 和 `text/`（`--check` 只比较，CI 用）。主包的阿利斯塔改了以后要重跑（阶梯的个数、主包说明里的叠层规则变了脚本会停下）。
- 在 `addons/` 下 `cargo test --release -p league_alistar`：单元测试（每种阵亡给几层、最多 7 层、冷却里照样叠、治疗的数、走出范围的不算、副本四处调本包、没有数据的阶梯和怒吼）。
- 经典 SDK 的模拟器跑不了原生代码，本包只做了单元测试，要在游戏里看日志确认。
