# 薇古丝附加包（测试版 v0.2.0，可选）

**不装这个附加包，主包里的薇古丝也是完整的**：普攻射出暗影弹（敌方英雄靠近时这一下换成 W 生人勿近：护盾 + 震一圈）、被动终焉暮气（每隔
一段时间下一个技能击倒并恐惧）、Q 寒心波云（先慢而宽、再快而窄，穿过一条线上的所有敌人）、E 溟濛渐染（影子飞过去扩散：伤害、减速、暮气）、
R 愁煞（飞弹标记英雄，再冲过去打一下、落地放生人勿近）都在主包数据里。主包是纯数据：**数据只读得到她自己身上的状态**——读不到敌人身上的暮气、
读不到等级（只有到没到 3 级）、看不到别人在突进、刷新不了大招。这个附加包用原生代码把这些做成英雄联盟（V26.13）的样子
（用户 2026-10-20：技能方案 A，做附加包；2026-11-26：「检查一下阿罗拉和薇古丝完美还原英雄联盟了没有」）。

| | 主包（纯数据） | 装了附加包 |
|---|---|---|
| 暮气挂在谁身上 | E 打中英雄后她身上开一个窗口（数据读不到敌人身上的 buff） | **每个被 E 打中的敌人**（小兵、野怪也算），还有**她 1600 码（160000）内突进或闪现的敌方英雄和野怪**（被别人击退、拉过去、推走的不算） |
| 暮气怎么引爆 | 窗口里她第一下打中英雄的普攻、Q 或 W 补伤害 | 她的**普攻、Q、W 打中带暮气的那个人**才引爆（E、R 不引爆）；伤害**按等级**（26–107 + 25% 法强），**对小兵、野怪打 40–60%**（按等级）；终焉的等待缩短 **25%**（对非英雄 **10%**） |
| E 打死人 | 不管 | 落地那一圈里死掉的：终焉等待缩短 **10%**，英雄 **25%** |
| 终焉 | 固定每 15 秒，恐惧固定 0.75 秒，减速 80% | 冷却**按等级**（英雄联盟 25 / 22 / 19 / 16 的比例：20 / 17.6 / 15.2 / 12.8 秒；暮气和 E 击杀还会缩短它，一局下来用的次数和主包差不多），复活时就绪；恐惧**按等级** 0.75 / 1 / 1.25 / 1.5 秒；**E 带的恐惧背着 E 的中心跑**；恐惧时减速**离她越远越大**（60% 到 99%） |
| 击倒 | 终焉打中的先 2 tick 击飞（打断冲刺） | 同左（数据里的） |
| 愁煞冲不冲上去 | 停在他 48000 外（佐伊大招的跳），从那里打 | **冲上去这一下能杀他、他身边别的敌方英雄不超过 1 个**才冲到他身上（冲刺时免控），不然和主包一样停在外面 |
| 愁煞刷新 | 冷却照常（35 秒） | 被标记的英雄 **8 秒**内阵亡（谁杀的都算，飞弹自己打死的也算）：0.5 秒后能再放；副本里愁煞的冷却放长到 **42 秒**（刷新补回来，一局放的次数和主包差不多；英雄联盟的大招也是长冷却靠刷新） |

## 怎么做的

- `mod.override_info` 把主包的薇古丝换成 `override/` 里的副本（`make_override.py` 用 `tools/kit/build_vex.py` 的 `native=1` 生成，主包的
  薇古丝改了就重跑）：被动是本包的 `league_vex:gloom`（数字在 `passive.params`，来自主包参数表 P）；普攻、E、R 的说明开头加【扩展包】。
  副本和主包的区别都在 build_vex.py 里（`native`），make_override.py 只核对主包没漂、写文字。
- **暮气**：E 打中的单位挂 `league_vex_g_mark`（主包也挂，画面是身上的暗影雾）。副本里她的普攻、Q（两段都算）、W 打中的单位挂 2 tick 的
  `league_vex_v_hit`；被动每 tick 看一遍敌方单位，上一 tick 就带着暮气、这一 tick 被她打中的就引爆：摘掉暮气，补魔法伤害
  （`g_pop` 的画面和声音），把她身上终焉的等待 `league_vex_p_wait` 剩下的时间缩短。主包数据里的替代做法（她身上的 `g_win` 和只打英雄的
  影子弹）在副本里拿掉了。
- **突进**：被动记下每个敌方英雄和野怪上一 tick 的位置和那一 tick 走了多远；连着两 tick 平均每 tick 走了至少 2200、也至少是他移速的 2 倍
  （引擎偶尔一 tick 不动、下一 tick 补两步，这样不会当成突进），一 tick 不到 100000（回城、复活不算），离她不到 `p_dash_r` 的就挂上暮气。
  被别人推着走的不算：有强制位移却没在放技能（这个引擎里自己的突进也是强制位移，但带着施法动作；击退、拉人和别的附加包的推不带，
  league_poppy 的 external_push 一样的分法）。击飞不当成被位移：它不挪位置，英雄自己的跳跃有时也带着击飞。
- **终焉**：数据用掉终焉时给她挂 `p_wait`（`p_cd1` tick）；被动看到新挂上的就按她的等级改（1–4 级 / 5–7 / 8–10 / 11 级以上），
  她复活时清掉；等完了放 `p_ready` 的画面和声音（副本不再用数据的延时放）。
- **恐惧**：副本里终焉的 Q / W 打中的挂 2 tick 的 `league_vex_f_q`、E 打中的挂 `league_vex_f_e`（数据的恐惧拿掉了，击倒照旧）；被动给它
  `apply_cc` 一个恐惧（方向：从她 / 从 E 的中心指向他；身上有免控 buff 的不吃），再挂 `league_vex_f_slow` 减速。宿主的 `apply_cc` 不吃韧性（league_skarner 读过
  0.7.2 的 exe），英雄联盟的恐惧吃韧性，这里没减。
- **E 的落点**：副本里 E 出手时给目标挂 2 tick 的 `league_vex_e_aim`，被动记下他站的地方当影子的落点，`e_fly` tick 后落地；落地前 2 tick
  记下那一圈（`e_r` + 15000）里活着的，落地后 2 tick 看谁死了。
- **愁煞**：飞弹打中的英雄先挂 `league_vex_r_mark` 再扣血；被动第一次看到他身上的标记时估算冲上去那一下（冲击 + 好了的生人勿近，按他的
  魔抗）能不能杀他、他身边 60000 内还有几个敌方英雄，要冲就给她挂 `league_vex_r_in`，数据 `r_wait` tick 后冲刺时读它。标记的人在
  `r_reset` tick 内死了，把她的大招冷却减到 `r_free`。英雄联盟里刷新的那次 12 秒内不放就作废，这里没做（宿主只能减冷却、不能加回去）。
- 游戏 0.6.4 的 `deal_damage_typed` 只把伤害排进效果队列，下一次 on_update 之前才扣血：引爆补的伤害不挂 `v_hit`，不会连环引爆。

## 在游戏里测

1. 主包（League of Legends Heroes，带 `q_wave` / `q_dart` 两段 Q 的版本）要装着并启用；副本用了主包新的画面。
2. 用附加包合集 `league_addons`（里面已经包含本包），或者把整个 `league_vex` 文件夹放进 `<游戏目录>\mods\`（文件夹里要有 `league_vex.dll`、
   `mod.mod_info`、`mod.override_info`、`override\`、`text\`）。
3. 进游戏，鼠标停在薇古丝的技能上，说明开头是【扩展包】就说明副本生效了。

## 游戏里看日志（0.2.0）

`%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_vex.log`，每次启动游戏重写，上一次的在 `league_vex.prev.log`。每种行前 10 条都写，
之后每 25 条写一条（`DOOM` 的「好了」「用掉」前 6 条）。

| 行 | 什么时候 | 看什么 |
|---|---|---|
| `=== league_vex v0.2.0 (Vex as in League V26.13 ...` | 游戏加载 | 版本对不对 |
| `SPAWN: the add-on's Vex ... Params {...}` | 每局她出生 | 参数是不是 P 里的（`p_dash_r: 160000`、`r_reset: 480`…） |
| `DOOM: spent at level L, back in N ticks` | 她用掉终焉 | N 按等级：1–4 级 1200、5–7 级 1056、8–10 级 912、11 级以上 768 |
| `DOOM #k: ready` / `DOOM: back on respawn` | 终焉好了 / 复活 | 头上睁开影子的眼睛；复活那一下就绪 |
| `GLOOM #k: #id (champion/unit) popped for D magic at level L; Doom wait Some((原来, 现在))` | 引爆 | 对英雄缩短 25%、对小兵野怪 10%；D 对英雄是 26–107 + 25% 法强，对别的 40–60% |
| `DASH #k: #id moved S within R of her -> Gloom` | 突进挂暮气 | S 是冲刺 / 闪现的一步（几千到几万），R 不超过 160000；走路不该出现 |
| `FEAR #k: #id T ticks at level L, away from her / the E spot (dx,dy), D off her -> slow S%` | 终焉的恐惧 | T 按等级 45 / 60 / 75 / 90；E 的写 `the E spot`；S 在 60–99 之间，离得越远越大 |
| `EKILL #k: #id (champion/unit) died under Looming Darkness; Doom wait ...` | E 落地打死人 | 英雄缩短 25%、别的 10% |
| `SURGE #k: #id hp H vs ~E (W ready/down), N more near him, D off her -> onto him / stop outside` | 愁煞打中 | H ≤ E 且 N ≤ 1 才 `onto him`；画面上要冲到他身上（冲刺时不吃控制） |
| `RESET #k: #id died X ticks before the mark ran out -> ult cooldown C -> 30` | 被标记的人死了 | X ≥ 0（8 秒内）；30 tick 后大招能再放 |
| `WATCH: Gloom pops ..., dashes marked ..., Doom ready ..., fears ..., E kills ..., surges ..., ult resets ...` | 每 30 秒 | 一局下来各项都该有数 |

画面上要看的：Q 先是大的慢波，飞到 4 万左右时从前沿冲出一道小的快波；E 带终焉时，影子落点周围的人往外跑（不是背着她跑）；
愁煞能杀时她冲到人身上再打（说明里写着「能击杀就冲到他身上」）。

## 重新生成

```bash
python tools/kit/build_vex.py                 # 主包的薇古丝（参数表 P）
python addons/league_vex/make_override.py     # 本包的副本和说明
cargo build --release -p league_vex           # 在 addons/ 下
```
