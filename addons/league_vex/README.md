# 薇古丝附加包（测试版 v0.1.0，可选）

**不装这个附加包，主包里的薇古丝也是完整的**：普攻射出暗影弹（敌方英雄靠近时这一下换成 W 生人勿近：护盾 + 震一圈）、被动终焉暮气（每隔
一段时间下一个技能附带恐惧）、Q 寒心波云（穿过一条线上的所有敌人）、E 溟濛渐染（影子飞过去扩散：伤害、减速、暮气）、R 愁煞（飞弹标记英雄，
再冲过去打一下、落地放生人勿近）都在主包数据里。主包是纯数据：**数据只读得到她自己身上的状态，读不到敌人身上的暮气**（所以主包里 E 打中
英雄后，她下一次技能打中任何英雄就补暮气伤害），**看不到别人在突进**，**也刷新不了大招**。这个附加包用原生代码把这三件事做成英雄联盟的样子
（用户 2026-10-20：技能方案 A，做附加包）。

| | 主包（纯数据） | 装了附加包 |
|---|---|---|
| 暮气 | E 打中英雄后的一段时间里，她下一次技能（Q、W、R）打中英雄补一次暮气伤害 | **照英雄联盟**：暮气挂在每个被 E 打中的敌人身上（小兵、野怪也算），**她身边突进的敌方英雄也被挂上**；她之后打中带暮气的敌人（普攻也算）就引爆：补暮气伤害，**终焉的等待缩短 25%** |
| 终焉 | 固定每 15 秒一次 | 同上，引爆暮气会缩短等待 |
| 愁煞 | 冷却照常 | **被愁煞打中的英雄 6 秒内阵亡就刷新愁煞**（谁杀的都算） |

## 怎么做的

- `mod.override_info` 把主包的薇古丝换成 `override/` 里的副本（`make_override.py` 用 `tools/kit/build_vex.py` 的 `native=1` 生成，主包的
  薇古丝改了就重跑）：被动是本包的 `league_vex:gloom`（数字在 `passive.params`）；普攻、E、R 的说明开头加【扩展包】。
- **暮气**：E 打中的单位挂 `league_vex_g_mark`（主包也挂，画面是身上的暗影雾）。副本里她的每一下伤害（普攻、Q、W 的冲击波、R 的飞弹和冲击，
  E 不算）给打中的单位挂 2 tick 的 `league_vex_v_hit`；被动每 tick 看一遍敌方单位，上一 tick 就带着暮气、这一 tick 被她打中的就引爆：摘掉暮气，
  补魔法伤害（`g_pop` 的画面和声音），把她身上终焉的等待 `league_vex_p_wait` 剩下的时间缩短 `g_cut`%。主包数据里的替代做法（她身上的
  `g_win` 和只打英雄的影子弹）在副本里拿掉了。
- **突进**：被动记下每个敌方英雄上一 tick 的位置，一 tick 里移动了 2200 到 20000（走路约 1000、冲刺 2500 起；闪现、传送不算，波比附加包量的）、
  离她不到 `p_dash_r` 的就挂上暮气。
- **终焉回来**：副本里不再用数据的延时放「终焉好了」的画面（等待会被缩短），被动看见 `p_wait` 消失时放 `p_ready` 的画面和声音。
- **愁煞刷新**：飞弹打中的英雄挂 `league_vex_r_mark`；被动记下他，`r_reset` tick 内他死了就把她的大招冷却清零。
- 游戏 0.6.4 的 `deal_damage_typed` 只把伤害排进效果队列，下一次 on_update 之前才扣血：引爆补的伤害不挂 `v_hit`，不会连环引爆。
- 日志：`%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_vex.log`：`GLOOM`（引爆、终焉剩下的等待）、`DASH`（突进挂暮气）、`DOOM`
  （终焉好了）、`RESET`（大招刷新）、`WATCH`（每 30 秒的计数），都限了条数。

## 在游戏里测

1. 主包（League of Legends Heroes 0.176.0 以上）要装着并启用。
2. 用附加包合集 `league_addons`（里面已经包含本包），或者把整个 `league_vex` 文件夹放进 `<游戏目录>\mods\`（文件夹里要有 `league_vex.dll`、
   `mod.mod_info`、`mod.override_info`、`override\`、`text\`）。
3. 进游戏，鼠标停在薇古丝的技能上，说明开头是【扩展包】就说明副本生效了；打一局后看日志里的 GLOOM / DASH / DOOM / RESET。

## 重新生成

```bash
python tools/kit/build_vex.py                 # 主包的薇古丝（参数表 P）
python addons/league_vex/make_override.py     # 本包的副本和说明
cargo build --release -p league_vex           # 在 addons/ 下
```
