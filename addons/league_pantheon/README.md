# 潘森附加包（测试版 v0.1.0，可选）

**不装这个附加包，主包里的潘森也是完整的**：被动矢志不退（满 5 层强化下一个技能）、Q 贯星长枪（近戳 / 远投）、W 斗盾跃击（跳过去晕眩）、
E 神佑枪阵（举盾连刺 + 盾击）、R 大荒星陨（待命，遇到团战跳过去）都在主包数据里。主包是纯数据：**数据分不清伤害从哪个方向来**，
**读不到敌人当前的血量**，**算不出敌人最密集的落点**。这个附加包用原生代码把这三件事做成英雄联盟的样子（用户 2026-10-16：「方案可以，全按推荐做（上单，做附加包，PPU 1.5）」）。

| | 主包（纯数据） | 装了附加包 |
|---|---|---|
| 神佑枪阵 | 举盾期间四面都减伤（`e_red`%） | **只挡正面**：盾朝最近的敌方英雄，从盾那一侧的半圆打来的伤害全部还回去，背后来的不挡，防御塔打的也不挡（英雄联盟：免疫来自该方向的非防御塔伤害） |
| 贯星长枪 | 固定伤害 | 另外**对生命低于 20% 的目标再造成一份 Q 的伤害**（英雄联盟里对残血敌人伤害约翻一倍） |
| 大荒星陨 | 待命期间随机看一个正在交战的敌方英雄，身边有友军在打就跳过去 | **挑落点**：离潘森至少 `r_min`，身边有友军在打的里面，**落点敌方英雄最多的优先**，一样多时挑血量比例最低的（第一版没有友军、落点两个敌人也跳：游戏日志里 41 次有 35 次是一个人跳进敌人堆，几乎都在半分钟内阵亡） |

## 怎么做的

- `mod.override_info` 把主包的潘森换成 `override/` 里的副本（`make_override.py` 用 `tools/kit/build_pantheon.py` 的 `native=1` 生成，主包的潘森改了就重跑）：
  被动是本包的 `league_pantheon:will`（数字在 `passive.params`）；Q、W/E、R 的说明开头加【附加包】。
- **只挡正面**：数据举盾时挂 `league_pantheon_e_hold`（同时免控）。本包每 tick 让盾朝最近的敌方英雄（90000 以内），受伤钩子 `on_damaged` 看攻击者在不在盾那一侧，
  在就把这次伤害直接加回血里（`entity_set_hp`，布隆、赵信附加包的做法：不飘治疗数字、不吃重伤）；副本里去掉了数据四面减伤的 buff。
- **斩杀**：Q 的每一下命中都调 `league_pantheon:spear`，目标当前血量低于最大生命的 20% 时再造成 `q_dmg` + `q_ratio`% 攻击力的物理伤害。
- **落点**：R 待命期间每次轮询，数据对每个敌方英雄调一次 `league_pantheon:starfall`；本包同一 tick 只算一遍，选中的那个让潘森身上出现 1 tick 的
  `league_pantheon_r_this`，数据接着下蹲、起跳、落下。
- 判断「被控」只看硬控（击飞、晕眩、定身、嘲讽、恐惧、魅惑、强制位移），不用 `cc_count() > 0`（游戏把正在播的施法动作也算成控制）。
- 游戏 0.6.4 同一局有两份预模拟和画面同时跑，实体编号一样：本包出生时给潘森挂一个模拟编号 buff（`league_pantheon_sim:<n>`），落点按（模拟，潘森）分开记。
- 日志：`%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_pantheon.log`（SPAWN、BLOCK 正面挡下的每一下、SHIELD 每次举盾挡了多少、LOW 斩杀、STARFALL 选的落点）。

## 在游戏里测

1. 主包（League of Legends Heroes 0.121.0 以上）要装着并启用。
2. 把整个 `league_pantheon` 文件夹放进 `<游戏目录>\mods\`，文件夹里要有 `league_pantheon.dll`、`mod.mod_info`、`mod.override_info`、`override\`、`text\`
   （或者用附加包合集 `league_addons`，里面已经包含本包）。
3. 进游戏，鼠标停在潘森的技能上，说明开头是【附加包】就说明副本生效了；打一局后看日志里的 BLOCK / LOW / STARFALL。
