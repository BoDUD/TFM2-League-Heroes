# 卡莉丝塔附加包（测试版 v0.1.0，可选）

**不装这个附加包，主包里的卡莉丝塔也是完整的**：普攻和 Q 穿刺插矛、E 撕裂（攒够矛自动拔）、W 灵魂绑定（被动）、武术姿态（每次投矛后往后跳）、
R 命运的召唤都在主包数据里。主包是纯数据：**数据只能往后跳**（往前跳会一路冲到目标身上），**记不住和谁立了誓约**，**算不出一个落点让队友飞过去**。
这个附加包用原生代码把这几件事做成英雄联盟的样子（用户 2026-10-15：「这个得做啊 附加包 往前还是往后灵活判断啊」）。

| | 主包（纯数据） | 装了附加包 |
|---|---|---|
| 武术姿态 | 每次投矛后背离目标往后跳（风筝） | **每次投矛后自己判断往前还是往后**：最近的敌方英雄残血（40% 以下），或者它在逃（越跑越远）而且快跑出射程（超过攻击距离 80%），就往前追；其余都往后跳开；身边没有敌方英雄时照主包往后跳 |
| 誓约者 | 没有誓约：大招拉 70000 内随机一个队友 | **开局绑定一名队友**（辅助位优先，没有就最近的队友英雄，每条命出生时重新看），大招对誓约者施放 |
| 命运的召唤 | 对敌方英雄施放：把队友拉进来保护，然后用拉扯区把他甩向施放时的目标位置 | 把誓约者拉进来保护、定身，然后**逐 tick 飞向离她最近的敌方英雄现在的位置**（90000 内，没有就两倍范围），到了就在脚下击飞周围敌人 |
| 撕裂 | 攒到 3 根矛自动拔 | 另外**按护甲算拔矛伤害，够杀就立刻拔**（矛不够 3 根也拔） |

## 怎么做的

- `mod.override_info` 把主包的卡莉丝塔换成 `override/` 里的副本（`make_override.py` 用 `tools/kit/build_kalista.py` 的 `native=1` 生成，主包的卡莉丝塔改了就重跑）：
  被动是本包的 `league_kalista:oath`（数字在 `passive.params`）；普攻和大招的说明开头加【附加包】。
- **往前 / 往后跳**：本包每 tick 判断方向，给她挂 `league_kalista_hop_f` 或 `hop_b`（3 tick 内刷新）；数据在投矛出手时按标记播往前 / 往后跳的动作和音效，
  挂 `hop_go`，本包看到就逐 tick 把她挪 `hop_v` x `hop_t`（数据里没有 MoveBack 了）。跳在出手后 5 tick 才开始，让甩矛那一帧露出来。
  第一版只看距离超过射程 80% 就往前跳，用户进游戏看到几乎每下都往前扑（射手本来就站在射程边上打），现在要它真的越跑越远才追；
  第一版站在射程里舒服的位置就不跳，用户：「平A 前进后退的动作没了吗？这符合LOL的设定吗？」「前跳后跳」——照英雄联盟改成每次都跳。
- **大招**：AI 钩子 `league_kalista:fate` 把大招目标换成誓约者（在 `r_bind` 内、能选中时）；数据拉人、保护、定身，到甩出那一刻挂 `r_launch`；
  本包找身上挂着 `r_safe` 的队友，挑落点，逐 tick `entity_set_pos` 把他飞过去，到 `r_catch` 内（或 40 tick 后）挂 `r_landed`；
  数据看到 `r_landed` 就在他脚下放击飞区、落地画面和音效，接着能拔矛就拔矛。
- **撕裂斩杀**：`on_attack` 记下她对每个敌方英雄插了几根矛（每根 `sp_t` tick），按 `n x (e_dmg + e_ratio% 攻击力) x 100 / (100 + 护甲)` 算，
  够杀就挂 `e_ok` 让数据立刻拔；数据拔矛（`e_pop`）后计数清零。
- 状态都在被动自己的对象里，游戏 0.6.4 同时跑的两份预模拟各算各的。

## 和用户最初的方案不一样的地方

- **Q 击杀后矛转到下一个目标**：主包里 Q 打死第一个单位后，由一支看不见的投射物把伤害带给后面的单位；矛是数据挂在目标身上的独立实例，
  原生代码挪不了，附加包没有改。

## 在游戏里测

1. 主包（League of Legends Heroes 0.117.0 以上）要装着并启用。
2. 把整个 `league_kalista` 文件夹放进 `<游戏目录>\mods\`，文件夹里要有 `league_kalista.dll`、`mod.mod_info`、`mod.override_info`、`override\`、`text\`
   （或者用附加包合集 `league_addons`，里面已经包含本包）。
3. 进游戏，在 MOD 菜单里启用它（含代码的 mod 会弹一次确认），确认排在主包后面，重启游戏。
4. 看卡莉丝塔普攻的说明：开头是「【附加包】」就说明换上了。
5. 日志在 `%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_kalista.log`，每次启动游戏重写（上一次的留在 `.prev.log`）：
   - `SPAWN`：这局用的是附加包的卡莉丝塔；
   - `OATH bound to …`：绑了谁（`support` 辅助 / `nearest` 最近）；
   - `HOP forward / back …`：往哪跳、为什么、离最近的敌人多远；
   - `FATE target … -> the Oathsworn …`、`FATE … hurled at …`、`FATE … landed after n ticks`：大招拉谁、飞到谁身边、飞了几 tick；
   - `REND n spears in … would deal … against … hp: rip now`：斩杀拔矛。

## 开发

- `python addons/league_kalista/make_override.py`：重新生成 `override/` 和 `text/`（先核对主包的卡莉丝塔和参数表一致）。
- `cargo test -p league_kalista`（在 `addons/` 下；仓库在很深的路径里时设 `CARGO_TARGET_DIR` 到一个短路径，不然链接器打不开参数文件）。
