# 蒙多附加包（测试版 v0.1.2，可选）

**不装这个附加包，主包里的蒙多也是完整的**：被动的免控和药罐、病毒屠刀、电击疗法和灰色生命、大力行医打飞尸体、极限剂量都在
主包数据里。主包是纯数据，**读不到生命**，蒙多的技能又几乎全按生命算，这个附加包用原生代码补上（用户 2026-10-16「方案可以，
全按推荐做（上单，做附加包）」）：

| | 主包（纯数据） | 装了附加包 |
|---|---|---|
| 想去哪就去哪 | 第一个控制照样吃，被控后马上 1.5 秒免控、丢下药罐（数据只能在控制落下后反应，清不掉已经在身上的控制） | **控制落下的那个 tick 就清掉**（只认硬控：击飞、眩晕、定身、嘲讽、恐惧、魅惑、强制位移），扣**当前生命**的 7%，丢药罐；生命不满 85%、身边没有敌方英雄时**走回去捡药罐**（该放大招时先放大招） |
| 病毒屠刀打英雄 | 加目标最大生命的固定 % 真实伤害 | 按目标**当前生命**的 20% 算魔法伤害（至少是 Q 的基础伤害） |
| 大力行医 | 固定的额外伤害 | 按他的**已损生命**最多再翻一倍；攻击力随**额外生命**（装备给的）涨 2.5% |
| 电击疗法的灰色生命 | 每次检查时挨了打就记一份固定的灰色生命 | 存**真实受到伤害**的 75%（最多最大生命的一半），结束时电到英雄全回、只电到小兵野怪回一半 |
| 极限剂量的时机 | 伤害传感：几秒内连续吃下 3 × 150 伤害、身边有敌方英雄才放 | 按**真实生命**：低于 40%，或 1 秒内掉了 25% 以上，且身边有敌方英雄才放；放出时回复**已损生命**的 25% |

## 怎么做的

- `mod.override_info` 把主包的蒙多换成 `override/` 里的副本（`make_override.py` 用 `tools/kit/build_drmundo.py` 的 `native=1`
  生成，主包的蒙多改了就重跑）：
  - Q 打中英雄调本包的 `league_drmundo:saw`，E 的强化普攻调 `league_drmundo:bonk`，W 开启 / 结束调 `league_drmundo:zap` /
    `league_drmundo:zap_end`，R 调 `league_drmundo:dose`；没有主包的伤害传感护盾；
  - 被动 `league_drmundo:pleases`：每个 tick 看他身上的硬控，被动好了（身上没有 `p_cd`）就清掉、扣血，挂 `p_drop_n`；数据里
    3 tick 一次的自检看到它就给冷却、短暂免控、丢药罐（药罐的区域、捡起回血、减冷却、被敌人踩碎都还是数据）；
  - R 是普通的点目标施放，放不放由本包的 AI 钩子 `league_drmundo:ai` 看他的真实生命决定（不放时改成普攻）；
  - 药罐是数据丢的：跟着他飞 20 tick，落在他**落地那一刻**站的地方（他身上挂上 `can`）。被动在 `can` 出现的那个 tick 记下
    位置，`can` 没了（捡起、被敌方英雄踩碎、过期）才忘掉；药罐落地后、他生命不满 85%、身边 35000 以内没有敌方英雄时，
    AI 钩子让他走过去。0.1.0 在挣脱控制的那个 tick 记下药罐，下一个 tick 看到身上还没有 `can` 就把它忘了，所以一次都没
    走过（游戏日志 TANK 0 次；模拟器里 8 个药罐 8 个都在落地前被忘掉）；R 留着不放时基础 AI 每 tick 都要放 R，0.1.0 的
    药罐判断排在它后面，也被挡住。模拟器里接上同样的钩子（12 种子 × 两批对六个基础上单）：0.1.0 −0.90 / −0.92、每局走 0
    次；0.1.1 −0.81 / −0.97、每局走 3.6 次、走过去捡到 2.2 个；有敌人时也去捡 15000 以内的药罐那一版 −1.15 / −1.19，没要；
  - 0.1.2（用户：「塔姆和蒙多互打时模型会卡住」——蒙多站着不动）：主包的药罐区域其实只有落地后的第一节（120 tick），
    后面的节挂在区域的 end_effects 上，可这种区域（RangePeriodProjectile）的 end_effects 从来不执行，身上的 `can` 却还挂着
    600 tick；0.1.1 让他走到早就没有区域的地方，站着等一个捡不到的药罐（主包 0.121.1 改成药罐落地时就用 Delayed 排好每一节）。
    另外：已经站在药罐上（4000 以内）就不再「走过去」，不然药罐落地后还没生效的 60 tick 里他会站在上面干等；身边有没有敌人
    看所有活着的敌方英雄，选不中、看不见的也算（潜进地下的塔姆、隐身的敌人），0.1.1 只算选得中的；R 留着不放时，R 的目标
    选不中了就打最近的敌方英雄（0.1.1 是「走到自己脚下」，也就是站着不动），一个都没有就让基础 AI 放 R。模拟器里蒙多对塔姆
    6 局：0.1.1 站着等药罐 6–73 tick 一局，有一次连续 2 秒不动；0.1.2 都是 0；
  - 四个技能的说明开头加【附加包】，游戏里看说明就知道附加包有没有生效。
- 同一局游戏同时跑几份模拟（预模拟 + 画面那份），实体编号都一样：被动在他出生时挂一个这份模拟的编号（buff
  `league_drmundo_sim:<编号>`），灰色生命、药罐位置、生命记录按（编号, 实体）分开记（塔姆、莫德凯撒、蛮王附加包的做法）。
- 数值：从英雄数据的 `passive.params` 来，`tests::the_numbers_match_the_kit` 读主包的参数表核对。

## 日志

`%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_drmundo.log`，每次启动游戏重写：`SHAKE`（挡下控制）、`SAW`（Q 按当前
生命补的伤害）、`BONK`（E 按已损生命补的伤害）、`ZAP` / `ZAP END`（灰色生命存了多少、回了多少）、`R GO` / `R HELD`（大招放
或不放的原因）、`DOSE`（大招回了多少）、`TANK LANDED`（药罐落地，离挣脱控制的地方多远）、`TANK:`（开始走去捡：几成血、
离多远、为什么能去）、`TANK GONE`（药罐没了：捡起 / 碎了或过期 / 没落地，是不是走过去的）。R 和药罐的行各数各的（0.1.0 共用
一个计数，R 每 tick 都在等，前 40 行以后只写第 50、100… 行，药罐的行写不进去）。`STUCK`（0.1.2 的诊断：他活着、
30000 以内有敌方英雄，却 90 tick 既没挪过位置、也没有任何动作或控制——记下 AI 钩子最近一次的决定和他身上的 buff；正常对局里
应该没有这一行）。

## 构建

```bash
python addons/league_drmundo/make_override.py
cd addons && cargo test -p league_drmundo && cargo build --release -p league_drmundo
```

单独装：`league_drmundo.dll` + `mod.mod_info` + `mod.override_info` + `override/` + `text/` 放进
`<游戏>/mods/league_drmundo/`；一般随附加包合集（`league_addons`）一起装。
