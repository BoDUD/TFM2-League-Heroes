# 芮尔附加包（测试版 v0.1.0，可选）

**不装这个附加包，主包里的芮尔也是完整的**：被动溃敌沉力（打中英雄削减护甲魔抗、自己拿到双抗）、Q 裂阵（直线冲击、晕眩）+ E 全速冲锋
（和队友加速、下一击爆炸）、W 驭铁术（轰落下马 / 驾临上马冲锋）、R 极涌（待命，等到 2 个敌方英雄或被控住的敌人才放）都在主包数据里。
主包是纯数据：**待机、跑步、受击、阵亡的动画不能在运行中换**（所以主包里她一直骑马，下马只是一层铁甲光环），**数据读不到目标身上自己的层数**，
**没有破盾的效果**，**看不出谁在朝谁跑**。这个附加包用原生代码把这四件事做成英雄联盟的样子（用户 2026-10-16：「方案可以」，做附加包）。

| | 主包（纯数据） | 装了附加包 |
|---|---|---|
| 下马作战 | 待机、跑步、受击、阵亡还是骑马的画面，身上一层铁甲光环 | **整个身体换成披甲步行的她**：站着、走着、挨打、普攻、放裂阵、阵亡都是步行的样子（游戏 0.6.4），上马换回骑马 |
| 溃敌沉力 | 每次命中给目标挂一层 5 秒的 -3% 双抗、给自己 +3 双抗，按她的出手频率大约同时 4–5 层 | **每个英雄身上单独叠，最多 5 层**，每次命中刷新；**第一层时记下目标当时的双抗**，她每层拿快照的 3%（至少 2）——英雄联盟的规则 |
| 裂阵 | 伤害 + 晕眩 | 另外**打破命中单位身上所有护盾**（英雄联盟的裂阵先破盾） |
| 全速冲锋 | 她和一名队友加速 15%，1 秒后 30% | 一直 15%，**她或那名队友朝最近的敌方英雄、或朝对方跑时再加 15%**（英雄联盟：朝敌人或彼此时翻倍） |

## 怎么做的

- `mod.override_info` 把主包的芮尔换成 `override/` 里的副本（`make_override.py` 用 `tools/kit/build_rell.py` 的 `native=1` 生成，主包的芮尔改了就重跑）：
  被动是本包的 `league_rell:iron`（数字在 `passive.params`）；普攻、技能、技能2 的说明开头加【附加包】。
- **整身换形态**（`src/view.rs`）：照杰斯 / 奈德丽附加包的显示钩子，游戏每帧更新显示时，名字是 `league_rell`、身上有主包的下马 buff `league_rell_foot` 的实体，
  正在播的 `idle / run / hit / attack / skill / dead` 换成图里的 `f_*`（高清帧由 league.dll 自动换成 `hd_f_*`）。轰落、驾临、极涌的动作照主包。
- **按目标叠层**：数据里每个打中英雄的地方调 `league_rell:mold`，用 `entity_stack_buff` 在目标身上叠 `league_rell_p_shred`（最多 5 层，每次刷新 `p_t`），
  第一层时把目标当时的护甲 / 魔抗写进一个只记数字的 buff 名（`league_rell_p_snap:<护甲>:<魔抗>`）；被动每 tick 数各个敌方英雄身上的层数和快照，汇总成她身上的
  `league_rell_p_steal`（变了才重写）。状态都在 buff 里，同一局的两份预模拟和画面互不干扰。
- **破盾**：裂阵每个命中调 `league_rell:shatter`，`entity_clear_shield` 清掉目标的护盾层。
- **朝向加速**：被动每 tick 看身上有全速冲锋加速（`league_rell_e_ms / e_ms2`）的友方英雄，这一 tick 的位移朝着 120000 内最近的敌方英雄、或朝着另一个被加速的人
  （夹角 45° 以内），就给 3 tick 的 `league_rell_e_toward`（+`e_toward`% 移速，刷新不叠）。
- 日志：`%APPDATA%\TeamSamoyed\TeamfightManager2\data\league_rell.log`：`FORM`（模拟里下马 / 上马、画面里换形态）、`MOLD`（叠层和快照）、`STEAL`（她拿到的双抗）、
  `SHATTER`（破了谁的盾、多少）、`TILT`（朝向加速）、`ECAST`（全速冲锋）、`RFIRE`（极涌放出时身边几个敌方英雄），都限了条数。

## 在游戏里测

1. 主包（League of Legends Heroes 0.125.0 以上）要装着并启用。
2. 用附加包合集 `league_addons`（里面已经包含本包），或者把整个 `league_rell` 文件夹放进 `<游戏目录>\mods\`（文件夹里要有 `league_rell.dll`、`mod.mod_info`、
   `mod.override_info`、`override\`、`text\`）。
3. 进游戏，鼠标停在芮尔的技能上，说明开头是【附加包】就说明副本生效了；打一局后看日志里的 FORM / MOLD / SHATTER / TILT / RFIRE。
