# 希维尔特效交接

本包完成 16 组特效素材，共 86 帧。所有图形均由图像生成工具制作；脚本仅做裁切、等宽排版、统一缩放、颜色和 alpha 清理、镜像及预览。保留了每张采用的未经修改 PNG 原稿。

## 文件使用

- 根目录的 `sivir_fx_*.png`：优先导入的整理版，尺寸与附件每条 Layout 一致，PNG RGBA，alpha 仅 0/255；颜色严格限制到各条指定色阶，只有刃物体允许深色描边色。
- `raw/`：未经修改的生图原稿，含半透明和非标准画布。请勿用整理版的裁切坐标切 raw。
- `manifest.json`：`assets[].frames[].rect = [x,y,w,h]` 是整理版逐帧坐标；`source_frame_rects` 对应原稿。索引从 0 开始，逐行从左到右。
- `previews/`：20 个 GIF，三段特效各有独立的出现、持续、消失预览；10 FPS 用于查看，实际播放时长由游戏定义。
- `USED_PROMPTS.md`：每张实际生图提示词，序号与下表、manifest 的 prompt_id 对应。
- `fx_list.json`：原包绑定和游戏尺寸清单。
- `validation.json`：色数、有效像素亮度等测量；`QA_REPORT.json`：最终文件检查。
- `FX_OVERVIEW.png`：16 组特效总览，深色背景仅用于预览。

## 导入要点

1. 整理版是高分辨率素材条，尚不是游戏最终 atlas。按 manifest 的 `scale_reference_frame` 所指帧的 `content_bbox` 对齐 `target_game_size`，为同一资产的全部帧使用同一个缩放系数。不要把首帧的小光点单独放大到满格，也不要把画布留白计入技能可见范围。
2. E 护盾及 R 加速：第 1 行 indices 0–3 出现，第 2 行 4–7 持续循环，第 3 行 8–11 消失。ThreePhase 标签见 manifest。整理版 W 光点、E 护盾、R 风环逐帧严格左右镜像，持续段中心透明。
3. Q 飞刃同一条分别绑定 q_out、q_back。飞行物出生空帧由导入程序添加；素材自带的 4 帧不包含空帧。
4. 施法特效按原包已定稿出手帧的刃、手、胸口或脚底位置安装。manifest 的 anchor_normalized 是素材锚点建议；不能替代角色动画的绑定坐标。R cast / hunt 画在角色下方，其他特效在角色上方。
5. 若导入管线保留原稿柔光，使用 raw；若要求硬透明和指定色阶，使用根目录整理版。使用最近邻缩放，再按游戏尺寸检查亮度和可读性。

## 验证与边界

最终静态检查通过：16 张、86 帧，全部指定画布尺寸，所有 rect 完整无重叠，所有帧非空，指定色阶，alpha 0/255，三组挂身循环逐帧左右对称且中心留空；raw 的 SHA-256 与选用的生图原文件一致。每张最亮一成像素的平均亮度至少 248/255。

生图中的弯刃细节、粒子个数、旋转角度和闪烁相位是近似；整理版未重构成统一的逻辑像素网格。硬透明处理会去掉很淡的碎光，亮带的循环接缝还需按游戏帧率观察。以上具体差异已列在每张备注中。

尚未做游戏代码绑定、最终 atlas 合图或游戏内播放测试；这些属于导入环节。参考贴图 `refs/lol_fx_ref.png` 未放入交付包。E 首版的底座方案和未选用的 R 风环候选也未放入交付包。
