# 劫：第 1 步造型交付

日期：2026-10-09。本轮交付两个游戏尺寸的静态造型，供选择头盔比例。

## 交付文件

- `zed_design_1.png`、`zed_design_2.png`：1024×1024 透明画布，严格 8 倍最近邻放大。
- `zed_design_1_1x.png`、`zed_design_2_1x.png`：128×128 原尺寸画布，位置与放大图一致。
- `zed_design_1_sprite_1x.png`、`zed_design_2_sprite_1x.png`：紧裁的 27×40 透明精灵。
- `zed-comparison.png`：两版在浅色、暗色底上的比较，以及 1× 预览。
- `zed_design_1_raw.png`、`zed_design_2_raw.png`：内置 image_gen 生图原稿；`zed_design_1_raw_initial.png` 是未选用的首稿。
- `palette.hex`、`palette.png`：24 个预设颜色；每张成品实际使用 22 色。
- `generation-prompts.txt`：实际生图提示词。
- `source-brief.md`：压缩包内制作参考说明的副本。
- `regrid_zed.py`：可复现的逐格提取、调色、整行整列删除、像素整理与检查脚本。
- `validation.json`：成品读回尺寸与检查记录。

## 成品读回结果

| 项目 | 版本 1 | 版本 2 |
|---|---|---|
| 可见宽×高 | 27×40 格 | 27×40 格 |
| 齿尖行 / 脚底行（0 起算） | 60 / 99 | 60 / 99 |
| 头盔高度 | 7 格 | 10 格 |
| 头盔顶行 | 65 | 62 |
| 两道眼缝所在行 | 69 | 68 |
| 颜色数（不含透明） | 22 | 22 |
| Alpha | 仅 0 / 255 | 仅 0 / 255 |
| 放大图像素块 | 严格 8×8，对齐原点网格 | 严格 8×8，对齐原点网格 |

可见范围是 1× 画布的 x=51..77、y=60..99；放大画布脚底占 y=792..799。第 100 行及其下完全透明。x=64（放大图 x=512）位于两脚间隙内。每腕两根单格宽银刃，银刃间保留透明格，刃尖在脚底线上方。眼部两组红橙像素在同一行，这两种颜色只用于眼缝。

## 制作与范围说明

采用新生成的粗像素稿，按它的方格逐格读取，没有把上一轮大幅插画直接缩小。生成器输出不是严格 8px 网格，因此成品做了颜色归并、二值透明、整行整列删减与对齐。为落实 7/10 格头盔及清楚的同排眼缝，头盔、兜帽、双刃间隙和脚底像素进行了定点整理。版本 2 生图稿作为大头外观参考；成品使用版本 1 的共同身体，以保证两版除了头盔与兜帽外相同。头盔遮挡范围内的背饰局部会被兜帽覆盖，底层造型共用。

本轮静态造型和技术检查已完成。尚未制作动作帧、影分身或技能特效，也未写入游戏或进行游戏内实测。选择版本后再进入第 2 步动作帧制作。
