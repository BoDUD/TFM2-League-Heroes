# 劫网格 C：清理 B 的碎色

交付 zed-grid-C.png（1024×1536）及 zed-grid-C_1x.png（39×59）。使用内置 image_gen，以全部四张附件为参考重画平涂，再将生成图统一采样到 B 的尺寸，用原 B 透明掩膜锁定剪影、用固定 9 色调色板量化，并合并同材质的孤立颜色格。角色形状来自生成图和已确认 B，不是程序拼画新身体。

验证结果：B 与附件的格线参考逐格匹配（附件为 B 从 [2,1] 开始的裁切）；C 与 B 的透明剪影差异为 0 格，仍有 796 格可见像素，头、背刃、肩甲、腕爪的轮廓位置不变。两格亮红眼在原坐标，亮眼红不用于衣服。大图每格 26×26 单色，左上角对齐；右侧 10px、底部 2px 全透明；与 1x 完全对应，alpha 仅 0/255。

孤立格定义：一个可见格的上下左右没有任何一个格与其 RGBA 完全相同。按此规则重新测量 B 为 338（与附件记载的 283 不一致，本次没有直接采用该数字）；C 为 134，达到少于 180 的目标。量化初始为 229，经一轮同材质颜色合并降到 134。实际颜色共 9 种。详细数值见 validation-C.json。

钢色、红色、金色分别合并成连贯块面，去掉白色小高光与多档碎色。原剪影含一些窄刃、单格尖角及边界转折，严格锁定剪影时仍会保留；孤立格未追求归零，以免抹掉眼睛和武器细节。轮廓和金边并非每一处都验证为连续单格线，剩余细节可按视觉需求再精修。
