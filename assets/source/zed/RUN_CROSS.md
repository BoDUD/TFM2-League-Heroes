# 劫：跑步重画成交叉步（给 Codex）

用户问：「走路有交叉步没」。现在的跑步是我（Claude）用造型的腿整条从胯部摆出来的：两条腿**各在一边交替迈步，从来不交叉**
（`refs/zed_run_now.png`）。我试过直接把两条腿交叉，近侧那只长靴子会整个盖在远侧腿上，看起来像一条腿上飘着一只靴子。
用户选了：「像奥拉夫那样给 Codex 准备一个跑步腿部的素材包，照英雄联盟的跑姿画交叉步」。

## 要做的

只画**跑步 8 帧**（120 毫秒一帧，格子、站位点和现在一样）。

1. **上半身不动**：`upper/zed_run_upper.png` 是 8 帧的上半身（定稿的 85% 造型：兜帽、面罩红眼、金肩甲、红披巾、两只前臂和爪刃；
   爪刃已经按跑步前后摆，身体在第 1、5 帧低 1 行）。**腿已经擦掉**，只画胯以下：两条大腿、护胫、靴子。
   **红披巾和两只爪刃画在腿前面**（腿被它们挡住的部分不画），它们一个像素都不要改。
2. **腿照 `guide/zed_run_guide.png` 画**：每帧画了两条腿该在的位置——
   - **红 = 近侧腿（图右那条，脚尖尖的长靴子，画在前面、压住远侧腿）**，**蓝 = 远侧腿（图左那条，被近侧腿挡住的部分不画）**；
   - 圆点从上到下是胯、膝盖、脚踝，框是靴子（近侧 9 格长、远侧 5 格长，都是 3 行高，脚尖朝右）；
   - 框的底边就是靴底：在红色脚底线上的 = 着地，离开脚底线的 = 抬起几行。
3. **动作要点**（英雄联盟 `refs/league_run.png` 的交叉步，幅度收到约六成）：
   - **两腿交叉**：每半圈换一次前脚，抬起的那条腿从着地的腿旁边越过去（第 2 帧远侧腿越过近侧腿，在它后面；第 5 帧近侧腿越过远侧腿，在它前面）；
   - **着地的脚每帧往后退约 2 格**（近侧脚第 7、8、1、2 帧着地，远侧脚第 3、4、5、6 帧着地）——脚踩住地，身体从它上面过去，不要原地踏步；
   - 离地的脚：先在身后把脚跟往上踢（最高 5 行，小腿朝后、靴底朝后上），再屈膝往前带，伸到前面落地；
   - 两只靴子不要在同一高度挤成一团：越过时离地的那只至少高出 1 行，或者被近侧腿挡住。
4. **大小和待机一样**：腿的粗细、护胫、靴子照 `design/zed_parts.png`（待机就是造型本身），两条腿一样粗、一样颜色（远侧腿不要画暗）。

## 共同规则

- 颜色只用 `design/zed_palette.png` 的 9 色，每个像素对齐 8×8 方块，透明度只有 0 和 255；外轮廓 1 格近黑描边（#100F19）；
  脚底线（每格第 81 行）以下没有像素。
- **排版和 `upper/` 条完全一样**：3584×1536，4 列 2 行，每格 112×96 方块，站位点 (56, 70)，帧 N 在同一格。背景透明（做不到用纯青 `#00FFFF`）。
- 上半身（胯以上、红披巾、爪刃）一个像素都不要改；腿和胯可以整片重画。
