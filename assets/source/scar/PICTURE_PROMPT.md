# 刀疤（金铲铲之战 · 第 13 赛季）：第 0 步，先画像素风原图（给 Codex 的提示词）

> 刀疤是金铲铲之战第 13 赛季的三费卡（野火帮 / 监察），双城之战里**艾克手下的野火帮哨兵**：一个**瘦高、紫色皮肤的祖安人**，脸上戴着**白色的骷髅面具**，头顶一撮**蓝紫色的莫西干尖发**，脑袋两边各一只**又大又尖的红色蝙蝠耳**，手里一杆**长矛**。金铲铲里他**弯着腰、懒洋洋地站着，长矛竖着握在近处身侧、矛尖朝下**。这一步画两张，**格子大小一样**，用户从里面选一种做游戏造型：
> - **头**（附图 3、6 特写）：**白色 / 象牙色的骷髅面具**盖住整张脸：两个**黑色的大圆眼窝，眼窝里各一个白色小圆点（瞳孔）**，一个小小的倒三角鼻孔，下半张脸是一排**竖条的牙齿栅格**（像骷髅的牙）；面具额头一角有一个**小铁片 / 铆钉**；面具后面露出的皮肤是紫色的；头顶一撮**蓝紫色的莫西干尖发**，往后上方一根根翘起；**两只又大又尖的耳朵**向两边斜着伸出去，**耳朵里面是鲜红色 / 珊瑚红，外圈是紫色**，耳根处各有一个白色小圆环（耳钉）。脖子上围着一圈**高高的黑色皮围脖**。
> - **身上**：**紫色 / 淡紫色的皮肤**，肩膀、胳膊很结实但人很瘦长；**一件芥末黄 / 土黄色的马甲**，马甲边缘和几条横带是**深藏青 / 黑色的皮带**，胸前有几个**金色的方扣**；**近处肩上一块棕色的皮护肩，钉着几颗铜色的大铆钉**；**远处那条胳膊从肩到手腕缠满了米白色的绷带**，近处的胳膊光着（紫色）；手指细长、有黑色的尖指甲，一只手戴**棕色的露指护手**；腰上一条深色腰带，**腰侧挂着一个深蓝色的小皮包**；**裤子：前面一大块洋红色 / 品红色**，其余是**深紫色**，接缝处有几道黑色的缝线；膝盖上是**灰绿色的尖角护膝**；**深藏青色的高筒靴，棕色的厚鞋底和鞋头**。
> - **长矛**（附图 4、7）：**大约从脚底到他下巴那么长**；矛杆是**深紫 / 深藏青色**，上面有几道**铜色的箍**和缠布；矛头是一个**宽大的箭头形刀刃**，**紫色底上有金黄色的涂鸦花纹**（野火帮的涂鸦风），后端有一个**深色的配重头**。
>

> - **A：待机**（金铲铲原样，附图 1、2、10a）：**3/4 朝右**，**弯着腰、背有点驼，脖子往前伸，下巴微抬**，两腿并得比较近、膝盖微屈；**长矛竖着握在近处（画面右）身侧，矛尖朝下、离地面不远**，矛杆上端靠在肩旁；远处那只（缠绷带的）手垂着或搭在腰边。整个人很瘦、很高、有点吊儿郎当。
