# 拉莫斯像素造型参考图

依据用户提供的 rammus_pack0.zip 中的角色和风格参考，使用内置 image_gen 生成两张造型参考图。此交付为二维 PNG 原画，不是带网格、骨骼或动画的三维模型。

## 文件

- rammus-A.png：3/4 朝右待机造型。
- rammus-B.png：头和四肢完全收起的刺球造型。
- raw/rammus-A.png、raw/rammus-B.png：原始生成文件，与对应交付图相同，未重采样或修图。
- generation-prompts.txt：实际提示词、参考图对应关系及生成工具。
- validation.json：图像尺寸、透明度和轮廓边界测量。

## 检查结果及限制

两图均为 1254×1254 RGBA PNG，含真实透明背景，非绘制棋盘格。主体尖刺完整，无文字、地面或特效。A 保留橙金甲壳、浅黄尖刺、青绿皮肤、长臂短腿和暗红挽具；B 无外露头或四肢。

生成器未精确执行参考文档中的 1536×1536、11px 网格、人物660px高、底部146px留白与全硬alpha约束。两图 alpha 均包含256级透明度，边缘有半透明像素；不能直接当成严格逐格的游戏精灵。A双眼大小和高度也并非严格一致。B的尖刺分布大致平衡，但不保证90度旋转对称。后续需要按实际游戏网格重新定稿、统一尺寸和落点、清理边缘，再制作动画。未做游戏导入或动画测试。

原始文件保留是为了便于继续设计，不将生成请求中的目标参数误报为已达成的实测参数。
