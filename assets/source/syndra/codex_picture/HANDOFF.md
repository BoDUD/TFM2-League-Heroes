# 辛德拉模型原画交付

已根据 syndra_pack0.zip 的角色与风格参考，通过内置 image_gen 生成两版全身像素风模型原画。

## 文件
- syndra-model-A.png：双臂向下张开，一腿弯起的悬浮待机。
- syndra-model-B.png：画面左手举至头旁，另一手弯至胸前，双腿并拢。
- generation-prompts.txt：每次生成实际使用的完整提示词。
- qa.json：尺寸、alpha 和主体边界检查数据。

## 验证
两图均为 1536×1024 RGBA PNG，背景存在真实 alpha=0 透明区域。头盔、弯角、银发、双手、裙摆与靴子完整，无球体或独立技能特效。B 使用 A 作为造型参考，但生成式重绘仍有局部细节差异，并非逐像素相同部件。

## 后续制作须知
本次交付为模型选择用原画，尚未制作游戏尺寸精灵、动画帧或安装到游戏。生成器未严格遵循约760px人物高度和8–10px大像素块：alpha≥128 主体高度 A=995px、B=910px，边缘留白较少，内部像素较细。两版请视为候选原画，不能宣称通过游戏最终尺寸或地形/UI测试。进入约40–42行的游戏精灵制作时，须重绘/规范像素、统一尺度，不能直接缩小就认定完成。

PNG 的透明像素仍保留背景 RGB 颜色；忽略 alpha 的预览器可能显示黑底和彩色柔光。交付保留工具返回的原始 alpha，没有用程序修改生成图片。
