# 辛德拉第1步：游戏尺寸造型候选

依据 syndra_pack1.zip 的模型规格完成两版造型候选。两版均沿用原画A的悬浮姿势：双臂向下张开，一膝向右弯起，一腿垂下。此处A/B指40行和42行的尺寸选择，不是第0步的两种手势。

## 交付
- syndra_design_A.png：1024×1024，角色30×40格，脚尖第99行。
- syndra_design_B.png：1024×1024，角色30×42格，脚尖第99行。
- syndra_design_A_1x.png、syndra_design_B_1x.png：128×128透明画布，每格对应一个游戏像素；角色有效尺寸如上。
- comparison.png：前五个为素材包中的现有英雄，最后两个为辛德拉A、B，同一脚底基线、同为8倍像素。
- palette.json、palette.gpl、palette.png：25色候选色板，最终两图各实际使用20色。
- generation-prompts.txt：内置image_gen三次生成实际提示词。
- raw/generation-1.png、generation-2.png、generation-3.png：全部未经修改的生图原稿。
- raw/generation-3-grid-readback-1x.png：第三稿按原稿格子取回的30×50格源图。
- qa.json：尺寸、色数、位置、删行记录。

## 制作与验证
艺术源由image_gen生成。前两稿像素密度过高，未作为最终图。第三稿仍为约30×50格，按素材包提出的格子取回与整行删减方法整理：逐格取代表色、映射指定色板，删减整行保护脸部原始第17–22行；未对原画做平滑缩小，未绘制程序化替代人物。A删10行、B删8行，详见qa.json。

已逐像素读回检查：1024×1024、每个8×8块纯色且一致、alpha仅0/255、各20色、A高度40/B高度42、两版宽度30、最低行99、脚尖列64、脚尖以下全透明。画布A有效边界x46..75/y60..99，B为x46..75/y58..99。

## 视觉复核与范围
已检查整理后的放大图和现有英雄对照。洋红眼睛、红唇、紫金头盔、银发和屈膝悬浮轮廓可读；源图已大幅简化，爪子、双片裙摆和新月弯角的结构仍有近似，A的角更短。头发较原画向左展开。数值规格通过不等于用户已接受造型，后续应由用户在A/B中选定或提出局部修订。

仅完成第1步模型候选；未制作动作帧、技能特效、图集导入或进行游戏内测试，也未执行素材包中写给其他代理的仓库操作。
