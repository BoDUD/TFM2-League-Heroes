# 嘉文四世跑步双腿重画版

依据 jarvaniv_run_pack.zip，使用内置 image_gen 分帧重画双腿。交付 8 帧供动作审核；没有修改游戏或外部工程。

## 文件

- jarvaniv_run_1.png … jarvaniv_run_8.png：1536×1536，透明背景，12×12px 全局网格。
- jarvaniv_run_1_1x.png … jarvaniv_run_8_1x.png：128×128，与大图逐格对应。
- run-preview.gif：8 帧循环预览，每帧 125ms，按原参考中的时间间隔制作；深色背景仅供预览。
- contact-sheet.png：8 帧并排检查图。
- raw/jarvaniv_run_<n>_raw.png：每帧选用的 image_gen 原始输出，未经修改。
- raw/initial_run_2.png、initial_run_3.png、initial_run_4.png、initial_run_6.png：未采用的先前尝试，供追溯。
- generation-prompts.txt：实际提示词、骨架坐标说明及参考图顺序。
- qa-frame-<n>.json、qa-summary.json：逐帧结构检查结果。
- processing/：格子读回与预览打包代码，记录实际处理方式。

## 绘制与整理方法

角色腿部画面来自 image_gen，没有用脚本另画替代角色。首轮整幅参考容易导致重复腿姿，故对部分帧改用腿部骨架近景，并重画第 2、3、4、6 帧。

最终第 1 帧用整画布生成结果读回；第 2–8 帧采用局部生成结果。局部参考从输入帧无重绘裁取 (480,1080,600,336)。原始生成尺寸由服务返回，均原样保存在 raw/。

为保证「裙甲以上一格不动」，交付图 y<1176 的所有像素直接复制对应 now/ 原帧。只从生成图读取 y=1176…1403 的腿部：按对应画布位置读回逻辑格，每格取样投票并映射到批准造型的原调色板，硬化透明度；没有脚本重摆骨骼或凭空绘制腿甲。最后输出 128×128，按最近邻 12 倍展开为 1536×1536。地面 y=1404 以下保持全透明。

## 已验证

8 帧均通过：尺寸正确；y<1176 与原帧逐像素相同；alpha 只有 0/255；颜色全部来自造型调色板；12px 格子与 1x 副本逐格相同；地面线下无可见像素；8 帧内容各不相同。具体计数见 JSON，相关错误计数均为 0。

视觉检查可辨后踢、收腿、交错及反向迈步，未见残留骨架、文字、绿线或红色地面线。

## 仍需审核的动作细节

结构检查通过不等于动作形状完全通过。生成结果对骨架点位仍是近似；第 2、3、6 帧在交错与遮挡处腿甲偏细，膝甲、靴子体积存在帧间变化；近远腿金色明暗也未逐段严格复刻。尚未证明「每排腿宽与设计差不超过 1 格」或每个膝踝点严格吻合。因此这是一套可直接查看和读回的重画帧，**仍需对腿甲体积与动作连贯性做美术审核，不能标为最终通过的游戏动画**。

建议先看 run-preview.gif 和 contact-sheet.png，决定这版腿姿是否采用；本轮未改动画表、帧时长或任何游戏文件。
