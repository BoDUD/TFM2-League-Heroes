# 皇子像素造型原画

使用内置 image_gen，基于 jarvaniv_pack0.zip 内的外观和像素风格参考生成。

- jarvaniv-A.png：竖枪待机，全身、王冠、羽冠及骑枪完整。
- jarvaniv-B.png：双手低持斜枪备战，全身及骑枪完整。
- raw/：两张未经修改的原始生成图，与对应交付 PNG 内容相同。
- generation-prompts.txt：实际提交的提示词及参考顺序。

## 检查与限制

两张都是带真实透明通道的 PNG，透明角点 alpha=0。视觉检查未见背景、文字、地面或特效，角色与武器完整。

生成器未严格遵守提示词中的 1536×1536 和统一 11px 网格；A、B 实际均为 1254×1254。像素块、描边宽度、身体占比和脚底高度也没有达到可逐格直接读回的规格。A/B 的铠甲细节、羽冠与身材比例仍有差异。因此交付定位为两版造型原画，而不是已可用于游戏的同模型动作帧或 3D 网格模型。

后续可选定姿势与外观，再按实际游戏网格重绘统一设计，制作动画。没有修改游戏或其他项目文件。
