# 沃利贝尔：游戏尺寸造型候选

本包使用新附件内的素材，以内置 image_gen 生成。没有用 Python 逐格绘画或改图；Python 仅用于读取 PNG 尺寸和 alpha 统计。本次共生成六次，交付四张候选并保留全部原图。

## 四张候选

- volibear-model-B-1.png：3/4 正面朝右，第一稿，细节较多，像素格偏细。
- volibear-model-B-2.png：3/4 正面朝右，采用追加粗格修正；比第一稿更接近目标密度，但脸部和符文更简化。
- volibear-model-side-1.png：侧身朝右第一稿，身体仍有3/4角度倾向。
- volibear-model-side-2.png：采用追加粗格侧身修正，身体轮廓更窄，远侧手臂遮挡更多。

## 原始图与记录

raw/ 下六张 PNG 均为生成工具的未经修改原图。raw/volibear-model-B-2.png 和 raw/volibear-model-side-2.png 是未选为最终第二稿的初始结果；带 grid-correction 后缀的两张是当前第二稿来源。其余两张与对应候选一致。

generation-prompts.txt 记录初始四次完整提示词及参考路径；correction-prompts.txt 记录两次追加修正提示词；validation.json 记录四张最终候选的实测数据。

## 验证结果及未达标项

四张均为1254×1254 RGBA PNG，确有透明区域，并非画出的棋盘底。四张都含半透明像素，不满足alpha仅0/255的要求。

alpha>=128主体包围盒（右下为排他边界）：

| 文件 | 包围盒 | 主体高度 |
|---|---|---|
| B-1 | (85,84)-(1189,1238) |1154px|
| B-2 | (92,85)-(1156,1211) |1126px|
| side-1 | (257,74)-(980,1237) |1163px|
| side-2 | (305,86)-(988,1211) |1125px|

要求的耳顶84、脚底1197并未被生成工具严格落实。第二稿的粗像素密度明显更接近目标，但并未验证为严格21px、从(0,0)开始的统一网格，也未逐格确认恰好53行。第一稿明显更细。双眼、铁环、爪子等细节有不同程度简化；侧身图的头部朝向接近3/4，但前后肢位置尚需确认。

因此这是供选择和进一步修正的造型候选包，尚未达到附件规定的全部游戏精灵验收标准。未制作动画帧、骨骼、游戏导入或修改游戏仓库。
