# 蔚奥莱跑步：8 帧重画稿

本轮按 violet_run_pack.zip 逐帧使用 image_gen 重画，共 run1–run8 八张；raw/ 保留未经处理的生成原稿，根目录是其同名副本。generation-prompts.txt 记录实际提示词。

本次修正重点：近侧腿保留藏青大腿，远侧腿用紫褐色；第 1–5 帧近腿向前，第 6–8 帧远腿向前，近腿收至后面。contact-sheet.png 供逐帧查看；run-preview.gif 用同一画布、同一缩放播放原稿，不单独裁剪或自动对齐各帧。

validation.json 记录根据成图人工目测的两只靴尖坐标、与 feet.json 的目标偏差及观察到的领步腿，坐标估计误差约 12 px。不把参考坐标当作实测坐标。领步腿的交换已在这批稿里出现，但严格规格尚未通过：靴尖位置超出允许的 2 格误差，12 px 网格与逐格一致的头部不达标；部分原稿有半透明边缘。没有宣称该稿可以无校正直接导入游戏。

没有用代码逐格画身体、换色或移动腿，也没有用复制原跑步帧冒充重画。所有角色画面由 image_gen 绘制；脚尖定位与网格仍需进一步校正。本包是新一轮重画原稿，尚不是通过坐标/网格验收的生产动画。未修改源项目或游戏安装。
