# 蔚奥莱（金铲铲之战 · 第 13 赛季）：第 0 步，先画像素风原图（给 Codex 的提示词）

> 蔚奥莱是金铲铲之战第 13 赛季的一费卡（家人 / 搏击手），双城之战第一幕里**少女时代的蔚**：祖安街头的小拳手，爆爆的姐姐、范德尔的养女，**两只手上各戴一只比头还大的铁拳套**。金铲铲里她**两脚大大分开、压低重心站着，两只拳套垂在身前两侧**；打架时**双拳举起、近处的拳套往前顶**。这一步画两张，**格子大小一样**，用户从里面选一种做游戏造型：
> - **长相**：十几岁的少女，**洋红 / 玫粉色的头发**，头顶往后、往一侧梳，**一大片斜着垂到远处（画面左）的脸颊和耳朵边**，近处那边剃短 / 贴着头；**眉毛是深棕色的、有点粗，眉尾往上挑**；**浅蓝色的眼睛**，眼神倔、不服气；**近处的脸颊上有两三道浅色的旧伤疤**；嘴唇抿着，一脸不好惹；皮肤很白（略带粉）。
> - **身上**：**一件酒红色 / 暗红色的短马甲**（没有袖子，前面敞开，有几颗小铜钉），**脖子后面一个红色的兜帽堆在肩上**；里面是**浅灰绿色的短袖衬衫**，胸前缠着**淡黄绿色的绷带**；腰上是**深棕色的腰带，挂着一个铜扣**，腰间还挂着一圈**红色的布带**；**宽松的裤子**：**深紫褐色**，**近处的大腿上一大块深藏青色的补丁**；膝盖往下缠着**橄榄绿的绑腿**；**深棕色的短靴**。远处的肩上有一块**棕色的皮护肩，挂着一小段铁链**。人很瘦、很精干，但站得很稳。
> - **铁拳套**（附图 1、2、4、9）：**两只都要画**，每只从手肘一直包到拳头，**比她的头还大**：前臂是**蓝灰色的钢板**，上面有**铜色的活塞管**；拳头是**方方的金黄色铁框**，正面有几排**深色的小方孔 / 铆钉**，指节处是一条**金黄色的厚护板**。两只拳套样子基本一样。
>
> 请 Codex 画**两张**（**格子大小一样**）：
> - **A：站姿**（金铲铲原样，附图 1、2、10a）：**3/4 朝右**，**两脚大大分开、膝盖微屈、重心压低**，像拳手准备开打；**两只拳套垂在身前两侧**（远处的在画面左下、近处的在画面右下，拳头离地面还有一段）；抬着下巴、不服气地看向右前方。
> - **B：格斗架势**（附图 7、10b）：**3/4 朝右**，前后脚分开（前脚在右）、身体略往前倾；**两只拳套举在胸前**：近处的拳套（画面右）往前顶、在上，远处的拳套收在胸口护住；眼睛盯着右前方。
>

> - **长相照金铲铲的模型**（附图 1、2、5、7 是模型的渲染，附图 3、6 是脸部特写：**头发、眉毛、眼睛、伤疤以附图 3、6 为准**；附图 4 是她把一只拳套举过头顶，看拳套的正面；附图 8 是她跳起来上勾拳，附图 9 是她弓步出拳，只看拳套和身体的比例）。
> - **比例**：Q 版人类，**头约占身高的三分之一**（脸要大、要清楚，头发算在头里），身材瘦，但**两只拳套又大又显眼**（每只拳头比她的头还大一点）。
> - **脸要清楚**（附图 3、6 特写）：皮肤 3 档（偏白）；**两只眼睛一样高**，每只至少 1×2 格，浅蓝色，各有一格白色反光；**深棕色的眉毛**压在眼睛上、眉尾上挑；**近处脸颊上 2–3 格浅色伤疤**；嘴一格暗粉色；**头发斜着盖住远处的脸边和耳朵，但不能盖住眼睛**。

> - 不画任何技能特效（拳风、电光、击飞的冲击波都放到后面单独画）；不画地面，不画投影。
> - 交付：`outputs/violet-picture/violet-A.png`、`violet-B.png`（1536×1536，**真透明背景**）；原始生成图原样放进 `outputs/violet-picture/raw/`；附一个 `generation-prompts.txt`，写明实际用的提示词；**最后**在同一个文件夹写一个 `HANDOFF.md`（交付说明），再打包成 `outputs/violet_picture_done.zip`。

## 后面要用到的动作（这一步**不画**，只是让你画造型时心里有数）

客户端里有蔚奥莱自己的动作（我已经按动作片段渲染出来了），所以造型里这些部件要**画得清楚、彼此分得开**：一张脸用在所有帧、两只拳套（直拳、勾拳）、两条腿（跑步、弓步、跳起落地）。

| 动作 | 金铲铲里怎么做 / 我们的技能 |
|---|---|
| 待机 | 选 A：两脚分开压低站着、拳套垂在身前；选 B：双拳举起的格斗架势 |
| 移动 | 双拳套举着小跑（金铲铲原样） |
| 普攻「铁拳直拳」 | 蓄一下力，弓步往前一记直拳（金铲铲原样） |
| 技能1「1-2-3连招」 | 两记刺拳，再跳起来一记上勾拳把对方打飞（金铲铲的施法动作） |
| 技能2「冲拳」 | 压低身子往前冲，一拳把敌人打退（金铲铲的第二种攻击） |
