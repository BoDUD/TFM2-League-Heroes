# 奥利安娜像素造型初稿

本次交付为二维像素风造型参考，不是 3D 网格、骨骼模型或已校准的游戏精灵。

## 文件

- `orianna-A.png`：待机，一手放在胸前，另一手放下，球悬浮于右侧。
- `orianna-B.png`：抬手指挥球；沿用 A 的造型和配色。
- `raw/orianna-A-raw.png`、`raw/orianna-B-raw.png`：原始生成文件，未做修改；与对应交付 PNG 相同。
- `raw/orianna-A-initial-draft.png`：第一轮细节偏密的原始草稿，仅供追溯。
- `generation-prompts.txt`：实际提示词、引用图片顺序、生成方式。
- `validation.json`：实际尺寸与透明通道检测结果。

## 已检查

两版都保留金色短发与发髻、瓷白面部、青绿双眼、银色胸甲、金色齿轮裙和分节金属四肢。人物与球视觉上分开，没有地面、文字和技能特效。使用内置 image_gen 生成，参考来源限于附件和由其生成的 A 图。

## 规格差异，尚待校准

- 实际画布均为 **1254×1254 RGBA**；生成器没有遵循提示词要求的 1536×1536。
- 有真实 alpha 透明背景，但存在大量半透明像素，并非要求的全硬 alpha。A 半透明像素 284116，B 为 320711。
- 11 px 统一网格、2 格描边、72 格角色身高、脚底位置和逐材质 3–4 色限制未严格实现，也未经逐格重建。
- 两版主体设计接近，但细节不是逐像素一致；还不适合直接按统一网格读回或导入游戏。
- alpha 非零范围包含边缘低透明度像素，不能直接以原始 alpha bbox 作为人物裁切框。

本包可用于选造型与姿势。若继续制作游戏素材，需要重建统一像素网格、统一尺寸和硬 alpha，并分别导出人物与球；本次没有改动游戏文件。
