# 奥利安娜第 1 步：人物与球，两稿原始生成图

本轮已使用内置 image_gen 分别生成四张图。交付为供选择与后续读回的造型原稿；严格游戏尺寸规格尚未通过，不能视为可直接导入的游戏素材。

## 交付文件

- `orianna-model-1.png`：人物第一稿，无球，细节较丰富。
- `orianna-model-2.png`：人物第二稿，无球，头部更大、内部色块更简洁。
- `orianna-ball-1.png`：独立球第一稿。
- `orianna-ball-2.png`：独立球第二稿，色块更粗，画面占比也更大。
- `raw/`：四张原始生成图，与上面对应 PNG 的字节完全相同，已核对。
- `generation-prompts.txt`：四次实际提示词、参考图顺序和原始生成路径。
- `validation.json`：尺寸、alpha、主体包围框、文件一致性与 SHA-256 检测。

所有图保持生成器原样，没有缩放、regrid、调色板重建、裁切或 alpha 修正。检查用 Python 只读取图片并写报告，没有绘制或修改图片。

## 参考与外观检查

以本轮包内选定 A 为外观依据，以 target_body、layout、head 和像素风格图为参考。每次调用最多支持五个参考文件，因此按人物与球的用途分别选用五张，具体顺序见提示词文件。

人物沿用待机姿势：近侧手垂下、远侧手在胸前；金发髻和短发、瓷白脸、青绿双眼、齿轮徽章、银色胸甲、分节四肢、金色关节与尖刺裙均可见，图内没有球。球单独成图，包含银色球壳、紫色窗格、双金环和顶部金脊。没有技能特效、文字、地面或可见网格。

## 实测偏差

四张实际均为 **1254×1254 RGBA**，没有达到要求的 1024×1024；均有真实透明背景，也有半透明像素，没有达到 alpha 仅 0/255。

以下包围框只统计 alpha ≥128 的像素，右下坐标为排他边界：

| 文件 | 主体包围框 x0,y0,x1,y1 | 主体宽×高 | 半透明像素数 |
|---|---|---|---|
| model-1 | 352,268,903,1234 | 551×966 | 205807 |
| model-2 | 354,199,898,1223 | 544×1024 | 227208 |
| ball-1 | 489,483,766,797 | 277×314 | 71027 |
| ball-2 | 410,435,841,896 | 431×461 | 153978 |

因此没有实现人物的 32×57 格、发髻 y276 / 下巴约 y468 / 脚底 y960，也没有实现球的 14 格 / 168 px 直径。12 px 全局统一格、眼睛等宽同高、材质严格 3–4 档和描边连续性尚未逐格验证，不应标为合格。球轮廓略偏椭圆。人物第二稿的头身比比第一稿更夸张，需选稿时比较。

## 下一步

本包保留四稿供选择，不替用户选定。后续若采用其中一稿，需要按其实际方块尺度读回，统一比例与调色板，校准人物和球的游戏尺寸，并修正透明通道后再做游戏内对比。尚未生成动作帧，也未修改游戏文件。
