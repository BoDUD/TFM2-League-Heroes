# 兰博第1步：B-1 / B-2 图像模型重画稿

状态：两张重画候选已交付；严格63格游戏资产验收尚未通过，不能直接标记为最终游戏模型完成。

## 文件清单
- rumble-B-1.png、rumble-B-2.png：最终一轮图像模型重画稿，均为1254×1254 RGBA PNG，原样复制生成结果。
- raw/rumble-B-1-raw.png、raw/rumble-B-2-raw.png：对应生成原图，和上述文件逐字节相同。
- raw/rumble-B-1-first-raw.png、raw/rumble-B-2-first-raw.png：首轮未选用候选，原样保留。
- generation-prompts.txt：全部实际提示词及最终采用提示词。
- correction-prompt.txt：最终两张共用的修正提示词、参考图角色分配。
- validation.json：只读测量结果。

## 制作方法
全部图像由内置 image_gen 绘制，共生成首轮两张及修正轮两张。首轮使用包内原稿、尺寸目标、布局、头部及布里茨风格图；因为工具最多支持5张输入，不能在同一次附全7张。包内全部7张均已查看。

首轮仍太细且偏大，因此最终轮以2_target_B.png为编辑底稿，4_head.png作为脸部身份参考，克烈与布里茨作为风格参考，3_layout_B.png作为布局参考。最终B-1与B-2各使用相同提示词单独生成。

未用Python逐格绘画、未对交付图做缩小、压扁、重排网格、调alpha或重新定位。Python仅只读检查像素数据并写JSON；交付主图与对应raw文件哈希一致。没有将之前rumble-sized-v4的压框导出复用为本次成果。
