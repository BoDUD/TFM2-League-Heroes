# 茂凯第 1 步：四稿生成与检查

本轮使用内置 image_gen.imagegen，按 maokai_model_pack.zip 的已选原画、目标尺寸图、细节与风格参考，生成 A 两稿、C 两稿。每张单独生成。没有用脚本绘制造型，也没有对生成图重新定格、缩放、量化或改变透明度。

## 文件

- maokai-model-A-1.png：保留原造型细节的茂凯稿。
- maokai-model-A-2.png：强调较大色块和简化木纹的茂凯稿。
- maokai-model-C-1.png：较多原画细节的树苗稿，仍有远侧小蓝眼。
- maokai-model-C-2.png：更简化的单蓝眼树苗稿。
- raw/：四张 image_gen 原始生成文件，逐字节保留，和上层同名图一致。
- generation-prompts.txt：四次实际提示词、工具与参考图顺序。
- validation.json：尺寸、透明通道统计、alpha≥128 的边界框，边界右下坐标不包含在内。

## 检查结论：四稿已生成，严格游戏尺寸规格尚未通过

四张实际都是 1254×1254 RGBA，均有真实透明通道，同时存在大量半透明像素。不是要求的 1024×1024、alpha 仅 0/255。未宣称已经达到严格 11px 网格、A 48格/C 14格及精确落地线要求。生成器仍偏向较高密度的原画，不能直接按 11px 网格读取。

| 图 | 主要可见边界框 alpha≥128 | 可见区域高 |
| --- | --- | --- |
| A-1 | (323,498)-(992,1234) | 736px，包含顶叶 |
| A-2 | (297,428)-(1036,1238) | 810px，包含顶叶 |
| C-1 | (513,833)-(773,1223) | 390px |
| C-2 | (552,1018)-(706,1233) | 215px |

视觉上 A 两稿包含巨臂蓝色鬼脸、木头额头、树冠、背后灯笼、紫布与手中树苗；眼睛等细节仍需最终定格审核。C-2 比 C-1 更接近简化、单蓝眼的方向。四稿都供用户比较，没有代替用户选定造型。

## 后续

先选定 A/C 稿，再按实际像素台阶读取并定格到游戏目标尺寸，统一调色板、硬 alpha 和落地线；规格通过后再制作动作帧。本轮没有包含动作或特效，也没有修改游戏仓库。
