# 奥拉夫瘦身动作条重画：待审稿

已重画跑步、普攻、Q、E、R、受击、死亡七组，共 42 帧。以包内已通过的动作条与瘦身 B 造型作为参考，使用图像生成工具逐组编辑。此次没有导入游戏。

## 文件

- 根目录七张 PNG：按原文件尺寸、格子、帧顺序输出。
- raw/：图像生成原稿；prompts/：各张实际使用的提示词。
- native/：42 张逻辑分辨率单帧。
- preview/：动画、逐帧联系表、总览，以及原稿左／重画右的对比 GIF。
- manifest.json：格子矩形、原始 pivot 和时长、bbox、整体平移、脸部颜色定位。
- validation.json：8×8 格、二值透明、21 色、脚底线，以及尺寸和面积差异检查。

## 检查结果与限制

七张导出图的尺寸与布局正确；8×8 纯色方块、二值透明、指定色板、脚底线以下为空均通过检查。

美术要求未全部达到，因此本包标为待审稿：身体没有在所有帧中统一收窄 10–15%；头、手、斧头与靴子的形状和位置存在细微差异，不能视为对原动作逐像素保留。不得将总不透明面积或含斧头的整体 bbox 当作肩宽测量。

生成器输出经过色板映射、格子多数采样和整帧位置校准；没有拼接头或肢体，也没有单独压缩身体。生图原稿保留，方便比较导出差异。

manifest 中眼睛和嘴的位置来自蓝色／红色像素检测；缺失嘴色时使用参考位置，缺失眼色时为 null。它们尚未经过逐帧解剖位置确认，不应直接当成可靠的贴头锚点。
