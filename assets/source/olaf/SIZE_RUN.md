# 奥拉夫：动作改回待机的大小 + 收敛版跑步（给 Codex）

用户看了游戏里的效果：「奥拉夫跑动时为什么变大一圈 好违和」「还有跑动姿势太浮夸了吧」，选了「收敛版跑步」「一起改」。

**原因**：待机已经是瘦身 B（`design/olaf_design.png`，43 行高、36 格宽），动作条还是照英雄联盟原版画的大身材——跑步侧身前冲宽 48–62 格、靠近我们的手臂很粗；靴子和背心的皮革面积是待机的 1.5–4.7 倍；R、受击、死亡整体面积是待机的 1.2–1.8 倍（`refs/too_big.png`：左边待机，右边几帧现在的动作，同一条地面线、同样放大）。

## 要做的

1. **所有动作和待机一样大**（普攻、Q、E、R、受击、死亡）：`now/olaf_<动作>.png` 是现在的动作条，**姿势、在格子里的位置都不变**，只把身体各部位画回待机的大小——`design/olaf_parts.png` 标了每帧都要守住的尺寸：
   - 头（角尖到下巴）18 行，头盔、角、脸的大小不变（导入时会换成定稿的头）；
   - 靠近我们的上臂约 7 格粗、远侧更细；拳头、护腕和待机一样大；
   - 背心身体约 18 格宽；毛皮围腰、腰带和待机一样；
   - 靴子 4 行高、约 10 格长；护胫和待机一样；
   - 两把斧和待机里的斧一样大。
   举手、张开手臂的姿势本来就比待机宽，这没关系；**但每个部件不能比待机的大**。
2. **跑步重画成收敛版**（8 帧 × 120 毫秒，一样的格子）：沉稳的小跑，不是压低身体的冲刺——
   - 身体基本直立，只微微前倾（头比待机向前 1–2 格），每步上下起伏 1 行（第 4、8 帧最低）；
   - 小步交替：两只脚相距不超过 10 格，抬起的脚只抬到小腿高（2–3 行），**不要后脚踢到胯部、不要大弓步**；两条腿前后交替、交叉走（每半圈换一次前脚）；
   - 双斧握在胯边，跟着步子小幅前后摆（拳头离待机的位置不超过 4–5 格），**斧头不举过肩膀**；
   - 整个人和待机一样大：高 42–44 行，宽不超过约 42 格（含斧）；
   - 节奏和幅度参考 `refs/darius_run.png`（包里已通过的德莱厄斯跑步，只看动作幅度，不照他的样子）。
   每帧两只脚的位置（单位：格，站位点为 0，右为正；抬 = 脚底离开地面几行；左腿/右腿 = 造型图里图左边/右边那条）：

|---|---|---|---|---|---|
| 1 | +2 | 0 | -5 | 3 | 0 |
| 2 | +0 | 0 | -1 | 2 | 0 |
| 3 | -3 | 1 | +4 | 1 | 0 |
| 4 | -5 | 1 | +4 | 0 | 1 |
| 5 | -5 | 3 | +2 | 0 | 0 |
| 6 | -1 | 2 | +0 | 0 | 0 |
| 7 | +4 | 1 | -3 | 1 | 0 |
| 8 | +4 | 0 | -5 | 1 | 1 |

## 共同规则

- 长相、颜色只照 `design/olaf_design.png`（21 色），每个像素严格对齐 8×8 方块，透明度只有 0 和 255；外轮廓 1 格近黑描边；脚底线（每格第 81 行）以下没有像素。
- **排版和 `now/` 条完全一样**：同样的图片尺寸、同样的格子（112×96 格，站位点 (56, 70)），帧 N 在同一格。背景透明（做不到用纯青 `#00FFFF`）。
- 不要用脚本整体缩小、删行删列或拼装部件；照尺寸重画。

## 交付

`outputs/olaf-size-run/`：7 张 `olaf_<动作>.png`（8 倍）、`native/` 逐帧 1 倍图、`manifest.json`（每帧格子、pivot、bbox、两只眼睛和嘴的位置）、生图原稿 `raw/`、最后写 `HANDOFF.md`（每张有没有做到尺寸）。最好打成 zip（`olaf_size_run_done.zip`）。

## 自查

- [ ] 每帧的头、上臂、背心、靴子、斧头不比 `design/olaf_parts.png` 标的大；
- [ ] 跑步直立小跑，脚距 ≤ 10 格、抬脚 ≤ 3 行，斧头不过肩，宽 ≤ 42 格，两腿交替交叉；
- [ ] 其他动作姿势和 `now/` 条同一帧一致；
- [ ] 格式（方块、二值透明、21 色、脚底线）。
