# 奥拉夫尺寸与收敛跑步重画

使用内置 imagegen，以待机设计、部件尺寸标注与原动作条为参考。七组动作共 42 帧。跑步重新画为直立、低双斧、小幅步态；其余动作按原姿势重画较小部件。没有导入游戏。

## 格式检查

七张图尺寸、格子、帧序、原 pivot 和时长保留。8×8 方块、二值透明、指定 21 色、脚底线以下无像素检查通过。raw/ 保留生图，prompts/ 保存实际提示词；native/ 单帧；preview/ 含动画和三方同尺度对比。

导出进行了色板映射、格子多数采样与整帧平移；未通过脚本缩小单个人物、删行列或拼装部件。跑步位置按中心与地面校准，其他动作按原帧包围盒中心与底部校准。

跑步要求宽≤42、高42–44；实际宽度 [35, 32, 32, 32, 34, 32, 33, 33]，高度 [40, 40, 39, 37, 40, 41, 39, 38]，严格尺寸检查为 False。

跑步比旧版收敛，但八帧两腿互换、脚距≤10、抬脚≤3及精确下沉节奏尚未全部验证达标。其余动作的姿势、头手脚位置存在生图差异；每一帧的头18行、上臂7格、背心18格、靴子4×10与斧头待机尺寸尚未逐部件验收。因此本包是可审阅重画稿，不能宣称游戏中的尺寸跳变已彻底修复。
