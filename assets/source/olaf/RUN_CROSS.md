# 奥拉夫：跑步重画成交叉步（给 Codex）

用户看了上一版跑步：「走路对吗？ 感觉像在平移」「你看看对吗 交叉步都没有？」。上一版的问题：**图右那只靴子 8 帧一直钉在原地，图左那只原地踏步**，没有一只脚往后蹬，也没有一次两腿交叉——身体往前走、脚不动，就像在地上滑。上一包里的脚位表这次一定要照着画。

## 要做的

只画**跑步 8 帧**（120 毫秒一帧，格子、站位点和上一版一样）。

1. **上半身不动**：`upper/olaf_run_upper.png` 是现在 8 帧的上半身（定稿的头、和待机一样大、斧头低握），腰带以下已经擦掉。**腰带以上照原样保留**，只画腰带以下：胯（毛皮围腰的下沿）、两条大腿、护胫、靴子。
2. **腿照 `guide/olaf_run_guide.png` 画**：每帧画了两条腿该在的位置——
   - **红 = 近侧腿（图左那条，画在前面、压住远侧腿）**，**蓝 = 远侧腿（图右那条，被近侧腿挡住的部分不画）**；
   - 圆点从上到下是胯、膝盖、脚踝，框是靴子（约 10 格长、4 行高，脚尖朝右）；
   - 框的底边就是靴底：在红色脚底线上的 = 着地，离开脚底线的 = 抬起几行。
3. **动作要点**（英雄联盟 `refs/league_run.png` 的交叉步，幅度收到约六成）：
   - **两腿交叉**：每半圈换一次前脚，抬起的那条腿从着地的腿旁边越过去（第 2、6 帧正好越过：远侧腿越过时在近侧腿后面，近侧腿越过时在前面）；
   - **着地的脚每帧往后退约 3 格**（近侧脚第 8、1、2、3 帧着地，远侧脚第 4、5、6、7 帧着地）——脚踩住地，身体从它上面过去；
   - 离地的脚：先在身后把脚跟往上踢（最高 5 行，小腿朝后、靴底朝后上），再屈膝往前带，伸到前面落地；
   - 第 4、8 帧落地，身体最低（上半身已经画好往下沉了 2 行）。
   - 不要大弓步、不要整个人前扑，斧头不举过肩（这些上半身已经是对的）。
4. **大小和待机一样**：大腿、护胫、靴子照 `design/olaf_parts.png` 的尺寸（靴子 4 行高、约 10 格长，护胫和待机一样粗），两条腿一样粗、一样颜色（远侧腿不要画暗）。
