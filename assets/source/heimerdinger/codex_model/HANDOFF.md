# 大发明家：第1步游戏尺寸造型重绘稿

本轮使用用户提供的 heimerdinger_model_pack.zip 作为设计资料，用内置 image_gen 重新绘制。没有调用上一轮平滑缩小修复脚本，也没有用程序逐格绘制角色。本轮只读程序用于检查PNG，并未改写图像。

## 交付内容

- heimerdinger-model-A-1.png：3/4朝右待机，细节较多。
- heimerdinger-model-A-2.png：同一角色和姿势，色块更简洁，建议优先比较此稿。
- heimerdinger-model-T.png：小炮台，正面，双排气筒、四腿和四只红脚。
- heimerdinger-model-X.png：巨型炮台，正面，左右齿轮、双管、红转盘和三脚架。
- raw/：上述四张原始生成PNG，主目录文件与raw逐字节一致。
- rejected/：T的两次未选稿。T-too-detailed.png格子过细；T-lost-rear-legs.png重画后丢失后腿，不能用于后续动作。
- generation-prompts.txt：六次实际图像生成提示词，最终T对应T-final-redraw。
- image-qa.json：只读尺寸、alpha、网格与主体包围盒检查。

炮台身份按新包更正：T为四腿排气筒款；X为齿轮三脚架款。没有沿用旧包的相反命名。只画了A两稿、T、X，没有画侧面或动作帧。新包“Claude收到后”章节是后续背景，本次未操作游戏仓库、安装模组、制作技能或发布。

## 验收状态：候选重绘稿；严格网格与alpha门槛未通过

四张尺寸均1254×1254，均有真实透明通道。已目视检查：A两稿均有双红框青蓝镜片、白胡子、金发、放大镜、外套、双工具及分开的靴子；T最终稿四腿可见；X齿轮、转盘、第三脚可见。大体正面结构对称，但没有像素级严格对称证明。

生成器仍有以下偏差：

- 四张alpha均含0与255之外的数值，并非全硬alpha，细节边缘仍有半透明。
- 像素台阶近似20/28/24px的粗格画法，但并非严格从(0,0)对齐的恒定整数网格；存在更小台阶和细节。
- 可见主体（以alpha>=128计算）A-1为y79..1247，A-2为y55..1218，T为y310..1210，X为y88..1192；未精确达到源包要求的y100..1180、y336..1176、y96..1176。
- A-1比A-2更细，不应当作54格合格版；T曾因格子过细重画，第一次重画又丢了后腿，因此再次用图像模型重画四腿结构。最终图仍不可声称严格30格。
- image-qa.json的estimated_dominant_step_px仅是强颜色边界的近似周期分析（限定在目标格宽附近），不是逐格读回或证明。精确网格检查和硬alpha检查均为false。

遵照本阶段设计资料，没有另做平滑缩小版、自动减色版、alpha阈值修复版或程序重绘版来伪装验收通过。后续按格读回之前，仍需取得严格网格合格稿或人工像素整理；本包不等于可直接导入游戏的动作资产。

## 本轮经验

高细节批准图容易使生成器保留过密台阶；将低分辨率target置于第一参考后，A-2的色块更简洁。T简化时容易丢失后腿，必须把“四条腿逐条可见”与像素密度一起检查。后续同时检验主体结构、网格和硬alpha，不能仅以画布尺寸或PNG有透明通道就判定通过。
