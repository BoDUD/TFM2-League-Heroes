# 沃里克九张动作姿势原画

日期：2026-10-20。素材来源为本轮提供的 `warwick_pose_pack.zip`。使用内置 imagegen 逐张生成，未调用 Python 绘制、移动身体部件、替换头像或处理透明度。

## 交付

- `warwick-pose-crouch.png`：低蹲蓄力，双臂撑开。
- `warwick-pose-rear.png`：挺胸后仰，双爪抬起。
- `warwick-pose-leap.png`：腾空飞扑，双腿收起。
- `warwick-pose-bite.png`：低位落地撕咬。
- `warwick-pose-howl.png`：直立嚎叫，双臂下垂；采用修正版。
- `warwick-pose-strike.png`：前扑下抓；采用修正版。
- `warwick-pose-raise.png`：远侧手高举、近侧手外展；采用修正版。
- `warwick-pose-stagger.png`：中招后仰、双臂甩开。
- `warwick-pose-lie.png`：身体向左伸展、头在右侧的倒地姿势。
- `raw/`：以上九张的未经修改生成原图，与对应主文件字节相同。
- `generation-prompts.txt`：九次初稿和三次修复的实际提示词、输入参考顺序。
- `qa.json`：逐图尺寸、主体范围、alpha、严格网格检查和 SHA256。

## 修复与排除

初版嚎叫出现过长颈部与肩部多余耳状形，重新生成后已去除明显的多余粉色耳形。初版下抓触及右边界，初版举爪脚部触及底边，分别修复后替换。被排除的三张初稿不放在主文件或 raw/ 中，避免误用。

## 实测

九张均为1254×1254 RGBA、有真实透明通道。以 alpha≥128 测得最终九张主体均未直接接触画布边界；蹲伏、飞扑、撕咬等部分图距右边界仅约9px，留白偏窄。

全部仍有256级 alpha，未达到仅0/255的硬透明要求；半透明像素不只在边缘。全部未通过“自左上角起，每个12×12块内RGBA完全一致”的严格网格检查。不能把视觉上的像素风当作严格12px游戏像素模型。

|---|---:|---|
| crouch | 1214 | 脚/手底边低于目标地面1176；脸部比例与定稿有偏差 |

| bite | 1176 | 低蹲/咬下动作可读，头部有转角，非固定头像逐格复制 |
| howl | 1225 | 比初稿改善，仍有头身比例与肩部铜片重复/偏移，拳头形状需清理 |
| strike | 1167 | 修正右边缘接触；远侧腿与躯干重叠，缺少清晰独立轮廓，需补足 |
| raise | 1244 | 修正脚部截边，但脚底仍低于目标地面；头/手臂大小需统一 |
| stagger | 1206 | 后仰动作可读，脚底及头部位置偏离骨架 |
| lie | 1200 | 横躺可读，头部明显小于其它姿势，肢体/装备需重新核对；并非固定母版头像 |

所有图均沿用蓝紫毛、白鬃毛、铜护臂、绿药剂与橄榄色短裤的身份设计，但并未做到同一张头像逐格平移、肢体长度严格相同、每个关节严格重合骨架。无可见骨架线、网格线、文字和大范围技能特效。尾巴除倒地外均抬起。躺姿表情仍张嘴、眼睛亮，按提供的固定头要求生成，未额外设计闭眼死亡脸。

## 当前可用范围

本轮完成九种姿势的生成原画与检查交付，可用于动作方向与轮廓参考。尚未通过游戏动作帧验收；需要统一头像、读格、调色板、肢体比例、脚底锚点和硬透明后，才能接入动画。未修改仓库/游戏安装目录，未制作合成GIF，未进行游戏内测试。不要直接把本包标记为可发布的游戏动作素材。
