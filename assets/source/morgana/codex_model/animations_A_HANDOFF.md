## 尚未满足的规格，导入前必须处理

1. 原图尺寸不符合目标 768×768 单格。3×2 图为 1536×1024，4×2 图为 1774×887，受击 2×1 也是 1774×887。先按 manifest 中的 rect 切图，再整理回目标格子。不得直接按 768 切原稿。
2. 原稿不是严格 8×8 网格，颜色数超过定稿的 26 色，仍有抗锯齿与细节变化。需按游戏尺寸取色并映射至附带 native 基准色板。
3. 背景是品红，不是真透明；需抠底和清理边缘，避免误删羽翼上的洋红颜色。
4. 头、角冠、头发与眼睛未逐像素复制，存在帧间变化。应换回基准头并整理；双眼各 2×2、间隔两格皮肤，#C83CA6 仅用于眼睛。待机推荐直接复制基准六次。
5. 人物大小、水平站位和脚底线尚未精确对齐。用附带 morgana_cells.json 校准，正常帧底边 632 之前，死亡第 4–8 帧最多到 648 之前。manifest 的 reference/target 字段只是要求，不能当作实测结果。
6. 帧数和排版已视觉检查；测量确认各格存在人物且未接触格子边界。尚未进行游戏内播放验证，严格像素与脚底验收未通过。

原始 PNG 未经程序重采样、抠色或绘制。morgana_native.png 和 morgana_cells.json 原样复制自此次新包。旧 B 版图片不混入本包。

preview.html 支持按原定时长播放、暂停、前后逐帧和整图查看；页面保留原稿品红底，不代表游戏内最终效果。
