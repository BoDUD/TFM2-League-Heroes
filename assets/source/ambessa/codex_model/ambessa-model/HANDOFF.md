# 安蓓萨第1步：Q版造型四稿

本包为图像生成模型重画的四张候选造型；尚未成为可直接按13px读回的合格游戏像素稿。

## 文件
- ambessa-A-1.png、ambessa-A-2.png：朝右3/4待机，两次独立生成。
- ambessa-SA-1.png、ambessa-SA-2.png：朝右正侧面，两次独立生成。
- raw/：对应四张原始生成图，字节原样保留。
- generation-prompts.txt：实际提示词和附图顺序。每种视角使用相同提示词分别生成两次。工具最多接受5张参考图，因此用了原稿、目标、布局、头部和俄洛伊风格图。
- validation.md：尺寸、主体包围盒、原稿半透明像素数量及13px网格检查。
- compare.html：本地四稿对比，双击可打开，不依赖网络。

## 做了什么
使用内置image_gen重画，保留原稿的银白波浪短发、深棕皮肤、青绿毛领、黑铁甲与铜缝、红围巾和腰布、双龙犬刃和铁链。头发与脸的总高度接近全身三分之一；侧面为单眼侧视。没有用脚本绘制造型，也没有缩小或重采样生成图。根目录PNG只将原图alpha按128阈值整理为0/255，颜色、像素位置和尺寸保持不变。原始alpha保存在raw中。

## 检查与偏差
四张画布均为1254×1254。根目录图为真透明背景，alpha仅0/255。两把刀均可识别，甲片有分层，Q版头比例较第0步增大。

生成器没有遵守严格的13px方格，也未精确落在y117发顶、y1209脚底。不能将这些稿子声明为84格高、每眼2×2格、每种材质仅2–4色、或完整1格描边。A-2右侧武器外轮廓接触画布边缘；A-1的右侧和底部留白也不足13px。详见validation.md。四张的头发与面部画法相近，但还不是共用同一个已定稿的像素头部。

后续应先选择A与SA的造型，再以选定A的头为标准统一头部，按原稿实际像素结构人工精修/读回84行，修正双眼、描边、刀尖边距、色板和头脚定位后再接入游戏。不要将raw平滑缩小或把本包当作已经完成13px网格验收。没有制作动作帧、骨骼或修改游戏仓库。
