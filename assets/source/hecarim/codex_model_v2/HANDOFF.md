# 赫卡里姆造型重画 v2：生图原稿交付

已使用内置 image_gen 重新绘制两版，修正方向是小头盔、侧向骷髅面甲、单个眼睛方点、暗冷灰分层盔甲，以及取消整圈米白描边。版本 2 的生成提示要求头盔进一步缩短一格。

## 本次文件

- `hecarim_design_1_generator.png`、`hecarim_design_2_generator.png`：生成器直接输出，未缩小、未隔格取样、未改颜色、未删行列。
- `hecarim_design_1.png`、`hecarim_design_2.png`：分别是对应原稿的原样副本，便于沿用造型文件名；不是已规范化的游戏精灵。
- `generation-prompts.txt`：实际使用的提示词与修改提示。
- `validation.json`：只读检查结果。

## 读回结果与未达标项

两张实际画布均为 **1254×1254**，没有达到提示词要求的 1024×1024。生成器未严格形成 8×8 单一像素网格，因此不能可靠地把原稿中的头盔和人物换算成整数格数，也不能宣称版本 1 已达到总高 45 格 / 头盔 8 格、版本 2 已达到总高 44 格 / 头盔 7 格。

| 实测项目 | 版本 1 | 版本 2 |
|---|---:|---:|
| alpha≥128 的人物边界（右/下界不包含） | (62,407)–(1220,1166) | (59,407)–(1223,1165) |
| 对应源图像素高度 | 759 px | 758 px |
| alpha=255 区域的 RGB 色数 | 444 | 372 |
| 半透明像素数 | 363435 | 366537 |
| 按画布原点检查的不统一 8×8 块数 | 6445 | 6396 |

两版可用于评审重新绘制的造型方向，但**不是已经通过生产规格的游戏精灵**，两版之间的身体也未保证逐像素相同。保留原稿优先于上一轮造成碎点的强制取样缩小；本次没有生成或交付伪造的 `*_1x.png`。

严格 1024 画布、1× 精灵、45/44 格总高、8/7 格头盔、32 色上限和固定脚底线仍需完成。当前交付不应直接覆盖游戏模组里的生产资源。
