# 史密奇（金铲铲之战 · 第 13 赛季）：第 0 步，先画像素风原图（给 Codex 的提示词）

> 史密奇是金铲铲之战第 13 赛季的三费卡（炼金男爵 / 伏击专家），双城之战里祖安的**炼金男爵之一**：一个**矮小、驼背、脾气很坏的小怪物（gremlin）**，**两条巨大的橄榄绿机械手臂**末端是**一把细长的黄铜利爪**，**两条细细的黄铜机械高跷腿**。金铲铲里他**直挺挺地站在高跷腿上，近处的爪子举在脑袋边，远处的爪子垂在身前**。这一步画两张，**格子大小一样**，用户从里面选一种做游戏造型：
> - **头**（附图 3、6 特写）：**头又宽又扁，脸上是灰褐 / 灰粉色的短绒毛**，两颊和下巴各炸出几撮毛；**两只又大又尖的耳朵朝两边横着伸出去**（比头还宽，外面灰褐色，**里面是鲜红 / 橘红色**，耳尖有缺口）；**淡黄色的大眼睛、小黑瞳孔，眼眶一圈暗红色**，眼神凶、眉头压低；**粉红色的小鼻子**；嘴是一道往下撇的不高兴的线。额头上一撮**金橙色的尖刺头发**。头顶戴一顶**又高又细的青绿色高礼帽**（帽身略微往后歪，一块紫色补丁、几道缝线），帽子中段箍着**一副黄铜护目镜**（圆圈黄铜框、**粉红到金黄渐变的镜片**），帽檐下面缠一圈灰绿色的布条。脖子上**一圈黄铜颈环**。
> - **身上**：**紫色燕尾小马甲**（金色纽扣），里面**淡黄色的衬衫和领巾**；**红棕色腰带**；**深蓝色短裤**到膝盖。**两条机械手臂**（附图 4）：从肩膀到手腕是**粗大的橄榄绿金属护臂**，一节一节、**黄铜箍**分段，上面**嵌着几颗发亮的荧光绿菱形灯**；手腕下是**五根细长、关节分明的黄铜爪指**（每根都比他的脸还长，像骨头一样细，指尖弯钩）。**腿**：膝盖往下是**细长的黄铜机械高跷**（几节铜管、铜关节，脚踝处一圈铜箍），脚上**一双深紫色的尖头小鞋**。
>
> 请 Codex 画**两张**（**格子大小一样**）：
> - **A：待机**（金铲铲原样，附图 1、2、10a）：**3/4 朝右**，**站得直直的**，两条高跷腿并得比较近；**近处（画面左）的爪子举到脑袋旁边**，爪指张开朝上；**远处的手臂往前伸、爪子垂在身前**，爪指朝下张开；头和礼帽朝右前方。
> - **B：伏击蹲姿**（附图 7、10b）：**3/4 朝右**，**两腿大大地叉开、蹲得很低**（前脚在右，膝盖弯得很厉害），**身体往前压、头放低**，**两只爪子向两边张开**（前面的爪子伸向右前方贴近地面，后面的爪子拖在身后），像要扑出去；眼睛盯着右前方。

> - **脸要清楚**（附图 3、6 特写）：脸灰褐 3 档；**两只眼睛一样高**，每只至少 2×2 格，淡黄眼白 + 黑瞳孔 + 一圈暗红眼眶；**粉红鼻子**至少 2×1 格；嘴是一道往下撇的短线；**耳朵**外灰褐、内红色各 2–3 档，横着伸出去，各至少 8 格长。**金橙头发** 2–3 档，几个尖。

> - 不画任何技能特效（爪痕、绿色微光、火花都放到后面单独画）；不画地面，不画投影。
