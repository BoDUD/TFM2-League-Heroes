# 妮蔻游戏格子模型：两张候选稿

状态：已生成两稿，严格技术验收未通过，尚不能直接导入为最终模型。

## 文件

- neeko-model-A-1.png：粗像素候选一，细节较多。
- neeko-model-A-2.png：粗像素候选二，色块更简洁。
- raw/：上述两张原始 image_gen 输出的原样副本。
- generation-prompts.txt：初次与修正时实际使用的提示词。
- qa.json：只读检查得到的尺寸、alpha 级数和 alpha>=128 的可见边界框。

## 制作

仅使用 neeko_model_pack.zip 中的参考素材。所有角色图均由内置 image_gen 绘制，无 Python 逐格绘制、缩放或程序改图。Python 仅用于读取图像属性作检查。生成器每次最多接收 5 张参考，因此初次选用原画、目标、布局、头部、佐伊；修正时以目标图为首参考，配头部与粗像素风格图。未修改游戏或外部仓库。

保持纤细肩腰、双手胸前相合、朝右 3/4 角度、上卷尾巴；按新目标放大头部。眼睛、花朵、贝壳与腿纹用更粗的色块重绘。初次两稿仍过细，已排除，没有混进候选文件或 raw/。

## 验收结果

两张均为 1254×1254 RGBA，有真实透明区域，角色全身与尾巴完整。A-1 可见边界为 (352,68)-(919,1215)，A-2 为 (351,80)-(904,1220)，这里以 alpha>=128 判断；并不满足顶部 y=110、脚底 y=1210 的精确坐标要求。

两张 alpha 均有 256 个级别，未达到只有 0/255 的硬透明要求。像素块比初次更大，但仍有细碎边缘、色阶及网格偏移，不能宣称为精确 11px、100 行的格子成品。宝石、手指等细节也需要继续审查，尤其第二稿宝石色彩有偏差。两只脚仍有高低差，未完全落在同一基线上。

后续需要精确 regrid、硬 alpha 清理、基线和细节修复后重新检查；本包不是通过验收的游戏模型，不应直接进入动作帧制作或视为本步骤技术完成。
