# 妮蔻特效交付

共 16 张动画图集、67 帧。所有特效原画由内置 image_gen 绘制，程序仅做拆帧、取色、像素整理、对齐、透明与对称处理，没有程序绘制替代特效。

## 使用文件

- 根目录 `neeko_fx_*.png`：16 张 8 倍最近邻预览图集，每张只有一行帧。
- `pixel_1x/neeko_fx_*.png`：16 张游戏原尺寸横向图集，导入时使用这里的文件，按 manifest 的 cell_1x 从左到右切格。
- `raw/`：最终选用的 16 张生成原稿，保持原样。原稿大小、格子和 alpha 不作为导入合同；其中部分原稿为两行，不能按最终横向图集直接切原稿。
- `manifest.json`：帧数、cell_1x、对称轴、建议绑定、原稿布局、取色偏移、亮像素数与哈希。
- `generation-prompts.json`：最终选用的实际生图提示词、参考图使用情况及布局。
- `qa/overview.png`：全部图集在暗底上的总览。
- `qa/animation-preview.gif`：16 组同时播放的预览，预览节奏不代表引擎动画时长。
- `qa/validation.json`：静态导出检查结果。

## 整理方法与修正记录

原稿经清单对应的等分格取样，统一到指定颜色表。前景 alpha 以 128 为阈值；最终只有 0/255，透明像素 RGB 清零。按前景覆盖率至少 20% 保留格子，再取前景多数色。为避免原稿的白芯在极小格中消失，若该格已有浅亮像素占前景至少 8%，优先保留原稿里的浅亮色。这是多数取色的明确例外，并非纯粹逐格众数。没有凭空添加原稿中不存在的亮芯。

镜像前先沿要求的对称轴对齐原稿亮芯；之后以左半边／上半边逐格镜像。蓄力、禁锢和加速按 manifest 中的 body_clear_rect 清理遮挡区域。禁锢和加速仅保留腿脚宽度，不能把角色头部的整宽当作脚部宽度，否则会把两侧藤蔓和光环一起清掉。

大幅横向原稿容易压扁花朵，q_burst、q_bloom、r_jump、r_land 改用多行原稿再排成最终一行；有裁切的中间版本已排除。多行原稿切格时内缩 3 个源像素，去掉原稿偶发的分隔线。生成原稿存在细像素、半透明及尺寸偏差，最终使用文件已整理成严格整数游戏像素。
