# 佐伊第 1 步：游戏尺寸造型候选稿

本次按 zoe_model_pack.zip 的素材和本阶段设计说明，使用内置 image_gen 绘制 A 待机、S 侧身朝右，各两稿。仅完成本阶段候选图；未执行文档中给后续制作者的游戏接入、动作帧或外部发布事项。

## 交付文件

- `zoe-model-A-1.png`：待机第一稿。
- `zoe-model-A-2.png`：待机第二稿，色块和腰扣更清楚。
- `zoe-model-S-1.png`：侧身第一稿，实际躯干仍偏正面，侧向不足。
- `zoe-model-S-2.png`：侧身第二稿，躯干更窄，腿部重叠、脚尖朝右，更接近侧身基础姿势。
- `raw/*-original.png`：四张生成器原图，原样保留；候选 PNG 与对应原图字节一致。
- `generation-prompts.txt`：实际提交的四条完整提示词，包括每张图的参考角色说明。
- `validation.json`：逐图尺寸、透明度、可见边界与严格整格检查结果。

画面比第 0 步更粗，但所有稿件都未通过从(0,0)开始的严格19×19全平色网格检测，也未达到 alpha 仅0/255 的要求。眼睛均保留左紫右蓝，但尺寸仍有透视差异，不能认定为等大验收通过；S-1 身体偏正面，S-2 的局部细节仍比目标更细。

## 使用建议

可先比较 A-2 的待机设计和 S-2 的身体方向。它们是供挑选造型和继续修正的候选原稿，尚不是可直接接入游戏的合格精灵。后续必须处理53格统一高度、19px对齐、脚底基线、硬alpha、等大双眼和手臂分离，再开展动作帧制作。不要根据本包推断网格已经验收。

生成器每次最多接受5张参考图，所以没有在单次调用附上包内全部9图；各调用实际选图及用途记录于提示词文件。所有输入参考均来自本次素材包。
