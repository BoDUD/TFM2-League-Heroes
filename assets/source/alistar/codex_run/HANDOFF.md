# 阿利斯塔跑步重画交付

只更新跑步双腿。上半身逐像素使用提供的 alistar_run_base.png，不改变体型、颜色、站位。

- alistar_run.png：4096×1536，4列×2行，8帧，每格1024×768；逻辑格128×96，8倍整数像素。
- alistar_run_1x.png：512×192，供像素检查。
- alistar_run_cells.json：站位点(60,70)，每帧125ms。
- preview_run.gif：统一画布循环预览。GIF时间单位为10ms，因此交替120/130ms，整轮1000ms。
- raw/：三次生图原稿与局部放大骨架参考。最终使用第三次局部腿稿，前两次仅留作过程记录。
- validation.json：逐帧可见腿像素数与骨架目标坐标。

制作：生成短粗紫色毛腿和棕色牛蹄；取出腿部，对各腿按骨架进行整数格尺寸及位置配准，交叉帧复用生成的屈腿与蹬腿素材。映射到定稿调色板，去除背景与孤立杂点，最后把原始上半身覆盖回去。未程序绘制新腿部造型。

检查通过：上半身所有不透明像素与原稿完全相等；两腿每帧各有可见像素；透明度仅0/255；严格8×8纯色块；所有不透明颜色均属于定稿调色板；第82行及以下无像素。两蹄前后顺序按参考在周期内交换两次。

尚未在游戏内验证。本包只含跑步替换素材，不包含安装或修改游戏文件。
