# 玛尔扎哈第3步：13张特效交接

本次用原生image_gen生成全部特效，未用程序拼出光球、虫子、裂隙、触手或护盾。共13张动作条、58帧；为保留细节进行了8次重生成，共21张生图原稿。所有raw文件与生成服务原文件逐字节相同。

## 交付文件

- 根目录13张`malzahar_fx_<tag>.png`：pixel_1x的8倍最近邻展开，每块8×8，透明底。
- `pixel_1x/`：13张原尺寸逻辑动作条，导入应优先使用此目录切格。帧从左往右，没有间隙。
- `raw/`：全部21张原始生成稿；同名文件是所选最新稿，`-attempt1` / `-attempt2`为被替换稿。
- `manifest.json`：帧数、切格矩形、调色板、对称轴、空位大小、绑定和已有时长规则。
- `generation-prompts.txt`、`generation-records.json`：全部实际提示词、参考文件名、稿次和原稿路径。
- `readback-details.json`：读回窗口及校验前后细节。
- `validation.json`：自动校验结果。
- `preview.png`：暗底4倍总览，仅供查看，不是导入资产。
- `scripts/read_fx.py`与`fx-specs.json`：读回流程留档，可在此目录结构中复算；需要Pillow、NumPy、SciPy。原始生图不是脚本产生。
- `HANDOFF.md`：本说明，最后写入。
- `malzahar_fx_pack_done.zip`：完整交付压缩包。

## 读回方法（必须与原稿区分）

生成使用包中允许的纯黑背景回退。模型未按提示的16px方块和超宽画布精确输出，所以先按帧区建立归一化采样窗口，再逐格读取。先将源像素归到该素材允许的调色板；黑色作为背景键，不参加前景颜色投票。格子前景覆盖至少25%时，取前景多数颜色，否则透明；这不是把背景也参与投票的严格多数alpha法。透明度最后只有0/255。原图的读取窗口与间距在manifest/readback-details中逐张记录，部分源窗口的横纵间距不同。

对称规范：左右素材复制左半，飞弹复制上半；奇数中心格保留。指定的人形矩形留空区清为透明。护盾从最大连通光圈确定读取范围，排除外侧光点。Q收尾帧裁出自己的两条裂口，避开模型越界的前帧光束。除此之外没有代码补画新特效形状或增加亮芯。最终8倍图完全来自pixel_1x。

## 自查结果

- 13张/58帧齐全，所有帧非空；13张8倍动作条和13张pixel_1x均在。
- 全部alpha仅0/255，8倍图逐格单色，无抗锯齿和半透明边。
- 58帧逐RGBA像素对称：a_bolt/e_bolt上下，其余左右。
- 全部颜色来自各提示指定的色阶，不含黑描边颜色#000000（黑色仅透明键）。
- e_hit、e_mark、w_swarm、r_grasp、p_shift规定的矩形留空区全部透明，没有画人。
- Q第5帧保留相撞光束，最后帧无光束；R领域有打开、内部循环与末尾光圈。两个飞弹朝右；两虫为镜像互相朝向。
- 原始贴图和角色参考没有拷贝到交付目录或ZIP。这里的原稿仅为模型生图。
- 原文“Claude导入时”是接收方说明：本次没有修改仓库、导入游戏、绑定技能数据或运行游戏测试。

## 视觉限制与导入前复核

硬透明、对称、帧数、调色板、空位与8倍对应已通过自动检查。原稿没有严格遵循16px原生格子，当前pixel_1x属于归一化多数前景读回，不是原稿自身格子的一比一还原。小光点和纹理仍有取样损失；裂隙实际间距、虫体9×8外形、光环1格厚度并非每帧精确达到文字数字。护盾矩形留空区会切掉斜角部分的弧线，形状有断续；细节请与raw并排评审。
