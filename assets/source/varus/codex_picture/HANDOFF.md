# 维鲁斯像素角色原图

已交付两张 1024×1536 PNG，使用内置 image_gen 根据压缩包参考图生成。

- `varus-model-A.png`：左手提弓的待机姿势。
- `varus-model-B.png`：Q 穿刺之箭拉弓蓄力姿势。
- `generation-prompts.txt`：实际生成与修订提示词。

文件为 32 位 RGBA，已检查画布边缘和角色间隙的 alpha 为 0，角色区域存在非零 alpha；保留生成的原始透明通道。部分预览器显示透明像素中的暗色 RGB，但背景实际透明。

这些是角色原图，可用于后续绘制游戏尺寸精灵；不是三维网格、已绑定模型或动画精灵表。生成图仍含较细像素与半透明边缘，后续约 40 行的游戏精灵需要重新整理像素网格、配色与脚底基线。
