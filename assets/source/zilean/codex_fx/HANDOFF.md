# 基兰特效：最后一步素材交付

19 种特效、110 帧已全部生成并导出。此包完成特效美术制作和文件检查，尚未写入游戏，也未完成战斗中的技能绑定、遮挡、帧速和范围验证。

## 使用哪个文件

- 根目录 `zilean_fx_*.png`：19 张透明横向条图。按 `manifest.json` 的 `assets[].frames[].rect` 切帧；坐标为左上角起点，索引从 0 开始。
- `raw/`：19 张选用的生图原稿；`raw/rejected/` 保留 3 张被替换的初稿。原稿切帧用 `raw_frames[].rect`，不要套用根目录条图的坐标。
- `game_pixels/`：按要求的游戏画布尺寸缩小的参考候选。微小钟面、指针和刻度会合并，正式导入宜从根目录条图或原稿调整。
- `previews/`：每种特效的 GIF、总览、110 帧检查图。GIF 使用暗底和演示帧速，不等于游戏内最终播放时间。
- `prompts/`：对应提示词和原始需求文字。第 17 条重做时使用的完整提示词另存为 `r_cast_retry.txt`。
- `QA.json`：亮度和透明度统计；`validation.json`：文件尺寸、帧矩形、调色板、非空帧及哈希检查。

图案均由 imagegen 生图。代码仅进行切帧、透明边清理、规则像素网格采样、限定色阶和条图排版，没有用代码绘制特效形状。清理稿去掉每个色阶的最深一档，避免深色描边。原版 `lol_fx_ref.png` 未包含在交付包里。

## 导入衔接

manifest 保留绑定名称、目标游戏尺寸、放置位置与持续时间。共享有效区域和透明留边应按整条动画统一处理，不要逐帧分别裁边或放大，否则会产生大小跳动。

- 普攻 / Q / E 出手特效对齐角色动作第 5 / 4 / 4 帧的手部。
- 附着炸弹 4 帧×125 ms；地面炸弹前 10 帧循环用于 3 秒倒计时，最后两帧放在爆炸前。
- 眩晕 / 减速 / 加速 / 符文分别排满 1.25 / 2.5 / 2.5 / 5 秒。
- 普通爆炸与双炸弹爆炸都使用 30000 距离单位伤害半径；后者视觉更亮。
- 锚点字段为原需求建议值，非测得值。正式导入时检查手部、胸口、脚底、角色前后遮挡、左右朝向和实际覆盖范围，并修正上表列出的相位与循环近似。

本说明在最终美术和文件检查完成后写入。此包可以交给导入端继续接入；不含已验证可运行的游戏 Mod。
