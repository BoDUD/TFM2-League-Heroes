# 伦妮动作姿势包

交付内容：19 张姿势 PNG（9 个动作、8 帧跑步、2 帧死亡），`raw/` 原始生图、`generation-prompts.txt` 实际提示词（含修订）、`manifest.json`、`validation.json`、`pose-contact.png` 和 `run-preview.gif`。

绘画方式：全部由内置 image_gen 依据包内定稿、头部、模型动作及骨架参考生成。跑步八帧经过额外生成修订，强调单手低位拎锯、自由手臂和交叉换腿。没有用代码拼画人物或制造动作姿势。

整理图规格：1254×1254 RGBA；统一 12px 方块网格，从画布左上角对齐；最低可见点到 y=1176；alpha 仅 0 或 255。原图保留不动。整理只做可见颜色多数取样、128 色调色板整理、必要的全图等比容纳和地面基线对齐。原稿本身的像素块和透明边缘可能不规整，导入重采样时优先查 raw/。

注意：这些是动作造型素材，不是已经安装或经过实战验证的游戏动画。生成模型不能保证每帧头部逐像素相同；上举、举持、死亡姿势与定稿存在视角、表情及尺度差异。导入时仍须按定稿头部对齐、按最终游戏尺寸检查，并匹配实际动画帧数和时序。逐格技术检查通过不等于这些视觉差异已经消除。清单中的 fit_scale 和 baseline_shift_y 记录整理时的容纳比例与基线移动。

核对：19/19 文件齐全，尺寸、网格、硬 alpha、最低点和画布边界检查结果见 validation.json；原图 SHA256 见 manifest.json。预览背景和文字仅用于检查，交付姿势 PNG 本身透明。
