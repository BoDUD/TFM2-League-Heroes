# 伦妮（荏妮，金铲铲之战 · 第 13 赛季）：第 0 步，先画像素风原图（给 Codex 的提示词）

> 伦妮是金铲铲之战第 13 赛季的三费卡（炼金男爵 / 格斗家），双城之战里祖安的**炼金男爵之一**：一个**结实、凶悍的女人**，扛着一把**巨大的黄铜双导板链锯**。金铲铲里她**两脚叉开站得很稳，链锯竖着扛在近处肩上**。这一步画两张，**格子大小一样**，用户从里面选一种做游戏造型：
> - **头**（附图 3、6 特写）：**橘红色的背头 / 莫西干**，头发往上往后梳成一大片尖尖的发浪，**两侧剃短**（剃过的地方是浅肤色，带几道橘红发茬）；**脸很苍白（象牙白），两颊带一点粉红**，**眼睛周围是深色的烟熏眼妆**，眼神凶、眉头压低，嘴角往下撇；**鼻子上扣着一块灰色金属鼻夹**（像小面罩，上面几个小孔），鼻夹两边各连出一根**发亮的荧光绿导管**，横过脸颊绕到耳后的小金属夹上；近处耳朵上有一个小金属耳钉。脖子上是**一圈洋红色 / 紫红色的高领**，领子边缘一道白色细边。
> - **身上**：**一大团墨绿 / 青黑色的羽毛披肩**盖住远处的肩膀和背后（3/4 朝右时在画面右边，羽毛一根根往外、往下炸开，羽尖带一点亮绿）；**紫色无袖紧身上衣**，胸前一块深色皮带 / 金色小扣；肩膀和上臂露出的皮肤是浅肤色、很结实；**深蓝紫色的长手套一直到上臂**；腰上**棕色皮带 + 黄铜扣**，**腰侧挂着两三个发绿光的小药剂罐（微光）**；**宽松的紫色裤子**，小腿处挽起、扎紧成一圈深色裤脚；**深紫 / 黑色的靴子，绑着几道棕色皮带和黄铜扣**。
> - **链锯**（附图 4、7）：**一个圆鼓鼓的洋红 / 紫色引擎**，侧面一个**发亮的荧光绿转子圆盘**（像一圈绿色的灯），引擎后面一根**灰蓝色的握把**；引擎前面伸出**两条平行的黄铜导板**（长条形、圆头，边上一圈黄铜框，中间是深色的槽，槽里一排灰色的圆孔 / 铆钉）。**整把链锯大约和她的腿一样长**，很重、很显眼。
>

> - **A：待机**（金铲铲原样，附图 1、2、10a）：**3/4 朝右**，**两脚叉开、膝盖微屈，站得很稳**；**链锯竖着扛在近处（画面左）的肩上**，引擎在肩膀高度、靠在身侧，两条黄铜导板**朝上竖起，高过她的头**；近处的手握着握把，远处的手搭在引擎上；羽毛披肩在画面右边炸开。

## 后面要用到的动作（这一步**不画**，只是让你画造型时心里有数）

客户端里有伦妮自己的动作（我已经按动作片段渲染出来了），所以造型里这些部件要**画得清楚、彼此分得开**：一张脸用在所有帧、链锯（扛、平端、举过头顶、砸地）、两条胳膊（握把、扶引擎）、两条腿（跑、弓步）、羽毛披肩。

| 动作 | 金铲铲里怎么做 / 我们的技能 |

| 待机 | 选 A：链锯竖着扛在肩上；选 B：双手平端链锯的架势 |
| 移动 | 弓着身子跑，链锯低低地拎在身侧（金铲铲原样） |
