## 检查结果和限制

- 最终六张均为 **1254×1254 RGBA**，均有真实透明通道。
- 没有文字、网格线、地面、投影或技能特效；保留橙色迷你形态与红蓝巨型形态的主要造型。
- 透明通道仍含中间值，**未满足 alpha 仅 0/255**。不能仅凭画面看起来透明就视为硬 alpha。
- 方块已经比第 0 步更粗，但**没有严格形成从 (0,0) 对齐的 A=20px / M=12px / SM=10px 方格**。头顶、眼线、脚底和外描边厚度也未严格符合布局。
- M-2 为避免右手触边进行了整体构图修正，因此人物占画布比例更小，不能把它与 M-1 按同一显示缩放直接比较体型。需要量实际像素台阶后读回各自的逻辑像素。
- A-2 下边和右边留白较紧，M-1 右侧与 SM-1 下边留白也不足目标的一整格。没有将这一点计作通过。
- 迷你双眼已做局部修正，但眼睛仍不保证精确 4×4 格；各稿之间的骨饰、牙齿、毛刺与局部身材有生成差异。M/SM 的朝向和造型一致性属于候选设计水平，尚不是动画共用的统一模型表。
- 网格诊断数字只描述强颜色边缘与指定网格的接近程度；`visible_height_in_requested_cells` 是像素高度除以目标格长，**不是实际已数清的逻辑格数**。没有以这些近似量宣称 48/66 格验收通过。
