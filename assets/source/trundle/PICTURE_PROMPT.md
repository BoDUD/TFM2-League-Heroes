# 巨魔之王 特朗德尔：第 0 步，先画像素风原图（给 Codex 的提示词）

> 特朗德尔是英雄联盟里**弗雷尔卓德的巨魔之王**：一个**又大又驼背的冰霜巨魔**，拿一根**巨大的寒冰狼牙棒**（"碎骨者"，一整块蓝色的冰）当武器，打架靠咬人、啃对手的力气。这一步画两张，用户从里面挑定样子：
> - **长相**：**灰蓝色的巨魔皮肤**（身上有深一点的斑点）；**一大蓬乱糟糟的深红 / 玫红色头发**往上、往后炸开，和**同样深红色的大胡子**连成一片，把整张脸围起来；脸是浅灰青色，**大鹰钩鼻（米黄色、像一块骨头）**，**一双亮蓝色的眼睛**，眉头紧压、凶巴巴的；**下巴伸出两颗米白色的大獠牙**；**尖尖的长耳朵**从头发两边伸出来。
> - **身上**：脖子和背后围着一圈**很大的白色毛皮领子**（一簇簇尖尖的白毛，像一圈刺，从后面把头框起来），领子里面是一块**深棕红色的皮披风**；两肩是**大大的圆形肩甲**——**青绿色的宝石面 + 金铜色的边框**，边上也有白毛；胸前和腰上交叉着**深棕色皮带**，腰带中间垂下一块**金黄色的长条腰布**，上面一块**青绿色的盾形宝石扣**；**粗壮的胳膊**，小臂套**金铜色皮护腕**；**短粗的腿**穿**深棕红色的皮裤**，膝盖上一块**青绿色圆护膝**，小腿一圈**白毛皮靴口**；**光着的大脚**，灰蓝色，脚趾是**米黄色的粗爪子**。
> - **武器**：右手（画面左边）握着**寒冰狼牙棒**：上面一截握柄是**冰块拼成的粗棒子**，往下越来越粗，末端是一大块**多面体的冰疙瘩**，冰是**浅蓝 / 天蓝色**，有几道亮白的高光面；狼牙棒差不多和他一样长。
>
> 请 Codex 画**两张**（**格子大小一样**，都是 **3/4 正面朝右**），用户从里面挑一张当造型：
> - **A：待机**——英雄联盟里的待机：**驼着背、膝盖弯着、两腿叉开**，像大猩猩一样蹲着；**右手（画面左边）拖着冰狼牙棒，棒头杵在地上**；左手（画面右边）握拳垂在身侧；头往前探、看向右前方（附图 1、2、3、9a）。
> - **B：站直的样子**（他的大招"强权至上"）——**站直了、挺胸**，嘴张开在吼；右手（画面左边）把冰狼牙棒斜斜拖在身后的地上，**左手（画面右边）往前伸、手掌张开**，像在抓对手的力量（附图 6、9b）。**和 A 同样的格子大小**。
>
> 选定后，第 1 步再按游戏格子做游戏尺寸的造型。你画的原图会按格子直接读回，所以**像素块要清楚、整齐、大小一致**。附图 10–13 是本包里的沃利贝尔、布隆、奥恩、努努和威朗普，**只看风格**。
> - **长相照英雄联盟原版**（附图 1–4、6；附图 5 官方原画看气质和颜色——**炸开的深红头发和大胡子、两颗獠牙、骨头一样的大鼻子、亮蓝眼睛、白毛皮领子、青绿宝石肩甲、灰蓝色皮肤、巨大的冰狼牙棒最重要**）。
> - **比例**：Q 版。**头比原版大很多**（头发连脸约占身高的三分之一），脸朝右前方；身子**宽厚、敦实**，胳膊粗，腿短；冰狼牙棒还是很大（他的招牌），但不要比他整个人还宽。
> - **脸要清楚**（附图 3 特写）：浅灰青色的脸 3 档；**两只亮蓝色的眼睛一样高**，每只至少 2×2 格（一格最亮）；眉头压低；**米黄色的大鼻子**；**两颗米白獠牙**从下唇往上翘；红头发和红胡子**不能盖住眼睛**。
> - **颜色**：皮肤 灰蓝 3–4 档（加几个深一档的斑点）；头发和胡子 深红 / 玫红 3–4 档（一档偏橘的亮色）；脸 浅灰青 3 档；眼睛 亮蓝 2 档；鼻子和獠牙、脚爪 米黄 / 米白 2–3 档；毛皮领子和靴口 白 / 浅灰 3 档；皮披风和皮裤 深棕红 3 档；皮带 深棕 2 档；肩甲、护膝、宝石扣 青绿 3 档 + 金铜边框 2–3 档；腰布 金黄 2–3 档；冰狼牙棒 浅蓝 / 天蓝 3–4 档 + 一档亮白高光。
> - **画布用正方形 1536×1536**。**A：从头发顶到脚底 / 棒头最低处约 484 px，也就是约 44 格**；宽约 40 格（含狼牙棒，最多 48 格）。**B：同样的格子大小**，站直了更高：头顶到脚底约 52 格；宽最多 55 格（比附图 9b 收得紧：狼牙棒更靠近身体、伸出去的手短一点）。脚底在离画布底边约 146 px 的地方（附图 9a、9b 的灰线）；站的位置照附图 9a、9b。狼牙棒、毛领、伸出去的手全在画面里，不能出画。
> - **像素块**：大小一致的方块，**每块 11 像素**，横平竖直对齐成网格；**外轮廓一圈 2 块宽的近黑描边**；每种材质内部 3–4 档平涂，不要零散的单个杂色格。暗处用这种材质自己最暗的一档，不要一圈黑。
> - 不画任何技能特效（冰柱、冰面领域、咬的特效都放到后面单独画；狼牙棒本身是冰，可以有亮面，但不要外发光）；不画地面，不画投影。
> - 交付：`outputs/trundle-picture/trundle-A.png`、`trundle-B.png`（1536×1536，**真透明背景**）；原始生成图原样放进 `outputs/trundle-picture/raw/`；附一个 `generation-prompts.txt`，写明实际用的提示词；**最后**在同一个文件夹写一个 `HANDOFF.md`（交付说明），再打包成 `outputs/trundle_picture_done.zip`。
