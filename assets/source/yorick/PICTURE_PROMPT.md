# 牧魂人 约里克：第 0 步，先画像素风原图（给 Codex 的提示词）

> 约里克是英雄联盟里**暗影岛的掘墓人**：一个**又高又壮的阴郁大个子**，拿一把**长柄铲子**当武器，能召唤**雾行者**（小个子的食尸鬼）和**迷雾室女**（一个高大的女幽灵）帮他打架。这一步画两张，用户从里面挑定样子：
> - **约里克**：**深紫色的大兜帽**罩着头；脸**瘦长、阴沉**，**灰蓝色的皮肤**，眼窝深陷、眼睛发出**淡青白色的光**，鹰钩鼻，**灰白色的山羊胡**；**极其粗壮的两条光胳膊**（灰蓝色皮肤），小臂套着**深色钢护腕**；肩后竖着一块**巨大的棺材板一样的钢肩甲**（暗青绿色金属、边上有铆钉），从两肩后面高高翘起，像一对弯弯的翅膀；身上是**墨绿近黑的皮背心**，胸前挂着一个**发青色光的小灯瓶**；**宽腰带**，中间一块**青钢带扣**；深灰色的长裤，**黑色靴子加钢护腿**；身后一件**长长的破烂黑斗篷**从肩膀垂到小腿（英雄联盟的模型里斗篷是布料模拟的，渲染图里把它藏了，**请按文字画上**）。手里竖拿着一把**长柄铲子**：深色木柄，**下端是一块盾牌形的青钢铲头**（上面刻一只眼睛的纹样），**上端是长矛一样的尖头**加两条**绿色水晶坠子**。
> - **迷雾室女**（大招召唤的女幽灵）：**弓着背、飘在空中**；身体和长袍是**深紫 / 深蓝黑色**，下摆**破烂、拖到地上**；**头部是一团发光的青色雾气 / 面纱**（看不清五官，只有亮青色）；肩膀后面竖起**一圈像骨爪一样的尖刺**，像王冠；**两只细长的手臂**，**长长的骨爪手指**。
> - **雾行者**（小个子食尸鬼）：**驼背、矮壮**；**淡青蓝色的皮肤**；整个脑袋就是**一张张开的大嘴**，嘴里**紫色**，**一圈象牙白的尖牙**；**两条长胳膊**缠着**紫褐色的绷带**，手上是**象牙白的大爪子**；小腿也缠着绷带。
>
> 请 Codex 画**两张**（**格子大小一样**，都是 **3/4 正面朝右**），用户从里面挑：
> - **A：约里克待机**——英雄联盟里的待机：站得稳稳的、两腿分开，**一只手竖握铲子、铲头杵在地上**，另一只胳膊垂在身侧，头微微低着往右前方看（附图 1、2、3、9a）。
> - **B：迷雾室女和一个雾行者**——**同一张图里并排**，室女在左、雾行者在右（附图 6、7、9b）。**和 A 同样的格子大小**：室女大约和约里克一样高，雾行者只有约里克一半出头高。这两个后面做成技能特效，这一步先把样子定下来。
