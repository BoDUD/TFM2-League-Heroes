# 约里克动作姿势交付

日期：2026-10-25（Asia/Tokyo）

完成 `yorick_pose_pack.zip` 的 17 张关键姿势：普攻起手/砸下、Q 举铲/重砸、W 举铲/插地、召唤、E 起手/投掷、R 举铲/立铲、跑步1–4、死亡倒下/飘起。

- 根目录的 `yorick-pose-*.png` 是交付图，均为 1254×1254 RGBA，11px 对齐像素格，透明度只有0/255。
- `pixel_1x/` 是同一图的114×114逻辑像素版，放大11倍与根目录图逐像素一致。
- `raw/` 保留生图模型的未修改原稿；`raw/rejected/` 保留被替换的立铲与落铲初稿，不能拿它们覆盖最终图。
- `contact-sheet.png` 是17张姿势总览，供查图使用。
- `manifest.json` 记录图幅、网格、底线锚点、平移量与原稿规格；`validation.txt` 是自动检查结果。
- `generation-prompts.txt` 记录每张最终图的实际提示词；`generation-history.json` 包含初稿与修订提示词，供追溯。

所有人物姿势均由内置 image_gen 绘制，沿用包内定稿、头部和各姿势骨架/原版动作参考。代码只做原稿像素取色、硬alpha、整张锚点平移和必要的整体画布适配，没有用代码画替代身体、拼几何腿或生成新动作。

检查中重画了立铲的握铲手和两张落铲的低重心姿势。接地锚点统一到y1188，浮起死亡帧以地上的铲子为锚点；举铲帧为避免顶端裁切做了小幅整体适配。脚底锚点由下半身靴子色块辅助定位，不能代替导入后的动作审查。

此包是后续rig制作的关键姿势源图，不是游戏已安装的动画atlas。生图没有保证17个头部逐格完全相同；导入时按原包约定，以定稿头部统一替换，量头定比例、统一调色板，再核对短腿、手臂和83格长铲。待机与受击使用定稿，不包含在这17张中。没有改动仓库、绑定技能或进行游戏内验证。
