# 约里克技能特效交付

日期：2026-10-25（Asia/Tokyo）

完成 `yorick_fx_pack.zip` 的18张特效表，共84帧。原稿由内置 image_gen 绘制；脚本只负责取色、切格、对齐、硬alpha、指定对称及整数放大，没有用代码画特效替身。

## 文件

- 根目录 `yorick_fx_*.png`：8倍最近邻放大预览，每格8×8px。
- `pixel_1x/yorick_fx_*.png`：实际导入源，严格按 `manifest.json` 的帧数与 `cell_1x` 横向等宽切格。
- `raw/`：原始生图PNG，未经改写。`raw/rejected/e_mark-too-much-mist.png` 是小尺寸不够清楚的旧标记，不应导入。
- `preview/`：18个深色背景动画GIF，仅供预览；100ms/帧是预览速度，不是游戏动画时序定义。
- `contact-sheet.png`：每种特效选取一帧的总览。
- `manifest.json`：帧数、每格尺寸、对称轴、1倍图哈希、原稿尺寸与绑定对应关系。
- `validation.txt`：逐表检查结果。
- `generation-prompts.txt` 和 `generation-history.json`：最终提示词及初稿/修订追溯。

## 校验与导入

18张均检查了目标图幅、所有帧非空、动画存在变化、RGBA硬透明（只有0/255）、8倍与1倍逐像素一致。`e_mist` 每帧严格上下对称，其余17张每帧严格左右对称。原稿没有天然满足这些技术条件，必须使用已处理的 `pixel_1x/` 导入。

处理时先映射该特效指定调色板、按源块多数色取回，再对齐单元和镜像。室女升起/抓击按头部中心纠正原稿帧中心偏移，避免切格后出现双头；雾行者出土/围咬为中央目标留出16格透明宽度，取回时减少了额外高雾对召唤物主体的挤压。标记另行简化重画，确保主体是倒三角里的眼睛。低矮地雾、坟墓与室女按各自单元留边。

雾行者与室女保留人物自身的紫色、青蓝皮肤、绷带、牙爪与近黑描边补充色；光雾使用对应特效的海绿、青、紫、土和白骨色。低分辨率多数色读取会简化原稿中的细小手印、牙齿和符印细节，原稿供需要时重新提取。

绑定见清单：小表 `league_yorick_fx`，大表 `league_yorick_big`；大表包括w_wall、e_cloud、r_spawn、r_maiden。室女与召唤物按原方案跟随目标并放在身后（z=-1）；不要把身后召唤物改成盖住人物的前景图。没有画中央被攻击的英雄。

这是特效素材交付，未修改游戏数据、atlas、动画时间轴或运行时绑定，也没有进行游戏内验证。将1倍表导入后仍需检查实际播放时序、目标遮挡及战场亮度。
