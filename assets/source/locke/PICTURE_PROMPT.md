# 灰烬驱魔人 洛克：第 0 步，先画像素风原图（给 Codex 的提示词）

> 洛克是英雄联盟 2026 年的新英雄 **灰烬驱魔人**：一个**瘦高、笑嘻嘻的年轻驱魔人**，背着一只**黑色棺材形状的封印匣**（大招扔出去的"封印法器"），手里拿**银色的驱魔大钉**当匕首用、也能扔出去。这一步画两张，用户从 A 定样子，B 是同一张图换成他 W 的变身配色：
> - **长相**：**金色头发往后梳、头顶翘起一撮**；**一副小小的圆形紫色 / 品红色镜片眼镜**（细黑框）；**咧着嘴笑**，一脸轻松自信；耳朵上一个小银耳钉；皮肤白里透一点暖色。
> - **身上**：一件**很长的深青绿色风衣**，**立起来的高领子**，袖子挽到小臂（袖口一圈浅青绿）；风衣下摆在身后**分成三四条长长的尖飘带**，从深青绿渐变到末端的**银灰色**（上面有浅色的花纹）；里面一件**宝蓝色衬衫，领口敞成很深的 V 字**；腰上**皮带和两个深紫棕色小包**，胯边一排**银色钉子插在钉带上**；**修身的深青黑色长裤**；**浅灰色的皮鞋**。小臂上有几道浅色纹身线。
> - **背上**：一只**又长又窄的黑色六边形棺匣**，斜背在背后（从肩膀上方到大腿），匣身是**炭黑 / 黑紫色**，**几道品红紫色的箍带**，上面镶着**银色菱形钉**；一根**深色背带**斜跨胸前。
> - **手里**：前面那只手（画面右边）**反握一根长长的银色驱魔大钉**，钉尖朝下、朝前。
>
> 请 Codex 画**两张**（**格子大小一样**，都是 **3/4 正面朝右**）：
> - **A：待机**（定造型）——英雄联盟里的待机：**站得很松、重心在后脚**，肩膀微微往后，下巴抬着、看向右前方，在笑；前面的手反握银钉垂在身侧；棺匣斜背在身后（附图 1、2、3、4、9a）。
> - **B：同一个姿势，换成 W"灵焰仪式"的样子**（附图 6、9b）——**姿势、轮廓、每一格的位置都照抄 A**，只换颜色：**皮肤变成深蓝 / 靛紫色**，**头发变成深靛蓝（几缕亮蓝）**，**眼睛和镜片发白光**（一两格纯白），**西装和长裤变成白色 / 浅淡紫**，身上一道道**亮蓝色的发光纹路**，**棺匣变成深蓝色的水晶匣、边缘青色发亮**，飘带变成**浅淡紫到白**，皮鞋变白。**不加外发光、不加火焰**，发光只用亮色的格子表现。后面 W 期间的动作帧就照 B 的配色换色，所以 **B 一定要和 A 一格一格对得上**。
>
> 选定后，第 1 步再按游戏格子做游戏尺寸的造型。你画的原图会按格子直接读回，所以**像素块要清楚、整齐、大小一致**。附图 10–13 是本包里的格雷福斯、塞拉斯、杰斯、梅尔，**只看风格**。
> - **长相照英雄联盟原版**（附图 1–4；附图 5 官方原画看气质和颜色——**金发、紫色圆眼镜、咧嘴笑、宝蓝敞领衬衫、深青绿长风衣和分叉的长飘带、背上的黑棺匣、手里的银钉最重要**）。
> - **比例**：Q 版。**头比原版大很多**（头发连脸约占身高的四分之一多一点），脸朝右前方；身子**瘦长**，腿长，但不要细成竹竿；棺匣还是要看得出是他的招牌，但不要比他人还宽。
> - **脸要清楚**（附图 3 特写）：皮肤 3 档；**两片圆镜片一样高**，每片至少 2×2 格，紫 / 品红 2 档 + 一格亮的反光；**嘴角上扬、露一点白牙**；金发**不能盖住眼镜**。
> - **飘带不能躺在地上**：风衣的飘带垂在身后，最低到脚踝上面一点，**末端离开地面**（附图 9a 里的飘带拖得太长，收短、收拢一点，不要拖地）。
> - **颜色（A）**：头发 金黄 3–4 档（一档近白的高光）；皮肤 3 档；镜片 紫 / 品红 2 档 + 1 格高光，镜框近黑；衬衫 宝蓝 3 档；风衣 深青绿 3–4 档（袖口、领子内侧浅一档）；飘带 深青绿渐到银灰 3–4 档；长裤 深青黑 2–3 档；皮带和小包 深紫棕 2–3 档；钉子和手里的大钉 银白 / 浅钢蓝 3 档；棺匣 炭黑 / 黑紫 3 档 + 品红紫箍带 2 档 + 银菱形钉 2 档；皮鞋 浅灰 2–3 档。
> - **画布用正方形 1536×1536**。**A：从头发顶到脚底约 528 px，也就是约 48 格**；宽约 30 格（含棺匣和飘带，最多 36 格）。**B：和 A 完全同样的格子大小和位置**。脚底在离画布底边约 146 px 的地方（附图 9a、9b 的灰线）；站的位置照附图 9a、9b。棺匣、飘带、手里的钉子全在画面里，不能出画。
> - **像素块**：大小一致的方块，**每块 11 像素**，横平竖直对齐成网格；**外轮廓一圈 2 块宽的近黑描边**；每种材质内部 3–4 档平涂，不要零散的单个杂色格。暗处用这种材质自己最暗的一档，不要一圈黑。
> - 不画任何技能特效（扔出去的钉子、灵魂火、冲刺的残影、封印法器的光都放到后面单独画）；不画地面，不画投影。
> - 交付：`outputs/locke-picture/locke-A.png`、`locke-B.png`（1536×1536，**真透明背景**）；原始生成图原样放进 `outputs/locke-picture/raw/`；附一个 `generation-prompts.txt`，写明实际用的提示词；**最后**在同一个文件夹写一个 `HANDOFF.md`（交付说明），再打包成 `outputs/locke_picture_done.zip`。
