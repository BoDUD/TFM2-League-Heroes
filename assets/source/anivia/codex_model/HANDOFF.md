# 艾尼维亚第 1 步：四张重画候选稿

## 状态

四张均由内置 image_gen 参考本轮素材包独立重画，原样保存；未用脚本逐格绘制，未做中心采样、缩放、重网格、调色板归并或 alpha 修改。候选图已生成，但严格游戏尺寸规格尚未完成，不能把本包视为可直接导入游戏的验收终稿。

## 交付文件

- `anivia-model-A-1.png`：待机第一稿，羽毛分区与双爪。
- `anivia-model-A-2.png`：待机第二稿，更粗的像素形状。
- `anivia-model-B-1.png`：重生冰蛋第一稿。
- `anivia-model-B-2.png`：重生冰蛋第二稿。
- `raw/`：四张未经任何修改的生成原图，与同名交付图逐字节一致。
- `generation-prompts.txt`：四次调用实际提示词及参考图角色说明。
- `validation.json`：实测画布、主体边界与半透明像素数量。

## 视觉检查

A 两稿保留左翼向下展开、右翼扬起后下弯的姿势，小头比例、冰冠、紫色额晶、洋红眼睛、深蓝身体和两只下垂爪子。两稿在羽毛分区和像素块表现上略有区别。B 两稿保留直立椭圆冰蛋和向外展开的冰晶巢，蛋内没有鸟的影子。未自行替用户挑选终稿。

## 实测偏差：仍需处理

提示词明确要求 1024×1024、11px 同相网格、二值 alpha 和目标坐标，但生成器未严格遵守。四张实际均为 **1254×1254**，均含大量半透明像素，并非只有 alpha 0/255；网格与位置不能按要求验收。

边界为 alpha≥128 时的 [左, 上, 右开区间, 下开区间]：

| 图 | 实测主体边界 | 半透明像素数 |
|---|---|---:|
| A-1 | [39,490,1244,1244] | 479277 |
| A-2 | [37,482,1232,1245] | 483153 |
| B-1 | [330,834,927,1246] | 154831 |
| B-2 | [281,744,973,1243] | 211337 |

目标要求仍为 A 约80×53格、B约38×26格，每格11px；A顶y407、B顶y704、底部y990。本次没有为满足数字而对原画再做有损采样。下一步应先由用户选稿，再按真实像素阶梯识别和保护头部、额晶、眼睛的方式整理游戏网格，核实双爪各三个尖端及两形态统一密度。

本轮不包含第2步动作、骨骼、三维网格、特效或工程集成。
