# 迅捷蟹（金铲铲之战 · 第 18 赛季）：第 0 步，先画像素风原图（给 Codex 的提示词）

> 迅捷蟹（官方名「峡谷迅捷蟹」，英文 Scuttle Crab）是金铲铲之战第 18 赛季的二费卡（峡谷野怪 / 主宰），技能「这种快乐你懂吗？」：**一只圆滚滚的河道螃蟹，背着一个大大的青绿色甲壳**。这一步画两张，**格子大小一样**，用户从里面选一种做游戏造型：
> - **甲壳（全身最大的一块）**：圆鼓鼓、前高后低的大甲壳，由**一片片叠起来的甲片**组成（像龟壳 / 鳞片那样一圈一圈往后叠），颜色是**青绿色**（4 档：深青、青绿、浅薄荷绿、边缘一圈**柠檬黄绿**的亮边），甲片之间用深一档的线分开，甲壳后沿和两侧有**一排短短的柠檬黄绿尖刺**（附图 4、5）。
> - **脸（全图的"脸"）**（附图 3、6 特写）：甲壳正前方下面，一块**灰色的石头面甲**（3 档灰，上面有几道裂纹，像一张石头做的小脸），面甲下沿是嘴缝；面甲两边各一根**很短的深色眼柄**，顶端是一颗**发光的柠檬黄绿色眼睛**。
> - **两根长触角**：从脸的上方伸出来，**深青蓝色、一节一节的**，先往上拱再往后弯，搭在甲壳上方，末端是**柠檬黄绿色的弯钩尖**（附图 1、4、8）。
> - **腿和钳子**：甲壳下面一圈**短短的腿**（左右各三条），加上前面**两只小钳子**，都是**深青色、像一片片尖叶子那样的甲片**（3 档），腿尖朝下点地。
>
> 请 Codex 画**两张**（**格子大小一样**）：
> - **A：待机，3/4 朝右**（附图 1、2、10a）：低低地趴在腿上，身体稍微转向右前方，**石头面甲和两只发光的眼睛正对着我们、清清楚楚**；两根长触角在上方往后弯；腿和钳子在甲壳下面一圈。**比高宽**。
> - **B：同样的待机，正侧面朝右**（附图 4、10b）：侧过来，**面甲和眼睛在右边**，长长的甲壳往左后方伸，甲壳上一片片的甲片和后沿的尖刺看得清；触角搭在甲壳上方往后弯。
>
> 选定后，第 1 步再按游戏格子做游戏尺寸的造型。你画的原图会按格子直接读回，所以**像素块要清楚、整齐、大小一致**。附图 11–14 是本包里的远古石甲虫（背壳怪）、深红锋喙鸟（野怪）、斯卡纳（甲壳、腿和钳子）和绯红印记树怪（野怪），**只看风格**。
> - **长相照金铲铲的模型**（附图 1、2、4、5 是模型的渲染；附图 3、6 是脸的特写，**脸的样子以附图 3、6 为准**；附图 7 是跳舞时站起来，**只看腿和钳子的形状**；附图 8 是触角举高，**只看触角和末端的弯钩**；附图 9 是从上面看，**只看甲壳上甲片怎么排**）。
> - **比例**：Q 版，**脸（石头面甲 + 两只眼睛）比模型大很多**（模型里脸很小、缩在甲壳下面，要放大到面甲、嘴缝和两只发光的眼睛都能看清——它就是这个英雄的脸），甲壳还是**圆鼓鼓的一大块**，腿短，钳子小而好认，两根触角细长、末端的黄绿弯钩清楚。
> - **脸要清楚**（附图 3、6 特写）：石头面甲**至少 8×6 格**灰色（3 档），一道深色的嘴缝；**两只眼睛各至少 2×2 格**柠檬黄绿（亮的一档 + 一格近白高光），眼柄 1 格宽、深色；面甲和青绿甲壳之间有一圈深色的边分开。
> - **画布用正方形 1536×1536**。**A：从最高点（触角顶）到最低点（腿尖）约 350 px，也就是约 32 格**，宽约 38–46 格（最多 52 格）；**B：同样的格子大小**，约 32–34 格高，宽约 42–50 格。最低点在离画布底边约 146 px 的地方（附图 10a、10b 的灰线）。**附图 10a、10b 是按模型原比例渲染的，只看位置、高度和最低点线。** 触角、尖刺、腿全在画面里，不能出画。
> - **像素块**：大小一致的方块，**每块 11 像素**，横平竖直对齐成网格；**外轮廓一圈 2 块宽的近黑描边**；每种材质内部 3–4 档平涂，不要零散的单个杂色格。暗处用这种材质自己最暗的一档，不要一圈黑。甲壳画成**一片片清楚的大甲片**，片与片之间用深一档的线分开，每片的后沿一条亮边；腿和钳子画成**清楚的尖叶形甲片**（一亮一暗两面）；触角画成一节一节的细条。
> - 不画任何技能特效（舞蹈的冲击、加速神龛、护盾光、钻地的土都放到后面单独画）；眼睛和触角尖的黄绿色是它身上本来就有的，要画，但不要光晕；不画地面、水面，不画投影。

## 后面要用到的动作（这一步**不画**，只是让你画造型时心里有数）

客户端里有迅捷蟹的十几段动作（后面的骨架包会附上），所以造型里这些部件要**画得清楚、彼此分得开**：石头面甲和眼睛（用在所有帧）、两根触角（要能举高、摆动）、腿（要能快速横走、站起来跳舞）、两只钳子（跳舞时举起来）、甲壳（要能整个缩进去只剩一个壳）。

| 动作 | 我们的技能 |

| 待机 | 选 A：3/4 趴着、触角往后弯；选 B：正侧面 |

| 普攻「螃蟹舞」 | 站起来举钳子扭一段舞，打身边一圈的敌人（金铲铲原技能） |
| 被动「绿霸符」 | 身边的队友掉到低血量时，给他回一大口血（每人一段时间一次） |
| 技能1「疾行神龛」 | 在脚下放一个加速神龛（一圈水纹），队友在圈里移动和攻击变快 |
| 技能2「蟹壳护盾」 | 腿和脸全缩进甲壳里，得到护盾；壳被打碎时让身边的敌人减速 |
