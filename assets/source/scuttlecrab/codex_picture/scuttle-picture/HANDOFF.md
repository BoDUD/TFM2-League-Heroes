## 导出与检查

原始生成稿没有遵守请求的画布尺寸和统一网格，因此保留原稿后，将轮廓采样到固定逻辑格，再以 11 倍整数方式打包；没有用程序几何体代替原画。两图共用 18 色材质调色板，A 使用 18 色、B 使用 17 色。透明度仅 0 / 255，无柔边。

| 项目 | A | B |
|---|---|---|
| 画布 | 1536×1536 | 1536×1536 |
| 逻辑尺寸 | 46×32 | 50×33 |
| 格子 | 11×11 px | 11×11 px |
| 可见区域，右下边界不含 | (506,1038)–(1012,1390) | (484,1027)–(1034,1390) |
| 身体高 | 352 px | 363 px |
| 底部透明留白 | 146 px | 146 px |

视觉检查：青绿叠片甲壳、灰色石头面甲、两眼、两根后弯触角、黄绿钩尖及短叶形腿均保留；无地面、水面、投影或技能特效。

## 使用边界

这两张是像素造型原图。B 为侧向造型，但脸部仍略带前视透视，不能当作严格正交建模参考。轮廓局部约 1–2 格，未逐格强制修成所有位置都恰好 2 格；眼部高光和面甲裂纹经过小尺寸采样，不能声称每只眼都满足原文的完整 2×2 格加独立高光要求。

后续打包请直接读取 `*-logical.png` 的真实像素，不要再次猜测或缩放 raw 原稿的格子。两版都未经过游戏内 PPU、碰撞、动画或 UI 显示验证。
