## 如何保留上半身

生成服务仍实际返回 1254×1254，且没有逐像素保留上半身。交付没有直接将整张生图作为结果：首先把名义 1536 画布的每个 10px 网格区域投影到返回图上，按区域内像素投票取回，颜色贴到定稿的 39 色；随后只取腰带以下的腿部候选区域，与输入原帧合成。

腰带上方全部原像素保留；原手部、圆盾、长矛杆及矛头、蓝布帘的保护区也取回输入原像素。保护区可直接在同名 mask 中审阅。保护区没有变形、调色或重绘；八帧本次整体位移均为 0。远侧腿的候选颜色按同一调色板加深。对生成的腿做整格向上平移，避免脚底越过地面；具体格数写在 edit-checks.csv。原稿在 raw 中未做任何修改。

这是使用图像模型编辑腿部，再做网格取回与局部合成；没有用脚本重新逐格画人体。保护区域比较通过不代表整张图只修改了完全准确的语义分割，腿与盾、布帘遮挡边界仍需人工核对。

## 检查结果

八帧均通过：

- 大图 1536×1536，1× 为 153×153；每格 10×10px，右侧与底部剩余 6px 透明。
- 大图与 1× 逐格完全一致。
- alpha 只有 0 或 255，所有不透明颜色属于定稿 39 色。
- y>=1410 无非透明像素。
- 所有白色保护格相较输入原帧变化数为 0。

肉眼复查：第 4–6 帧已有亮色近腿向后、较暗远腿向前的区分；3、7 使用补画的收窄交叉姿势，去掉首次第 7 帧多余的小腿轮廓。第 1–2 与第 8 的前踏状态也有更新。

## 仍未严格达到的要求

- 目标髋、膝、脚踝与脚尖坐标没有逐点完全对齐，尤其 4–6 和 8 的前脚仍偏右；不能仅凭文件格式检查判定脚底着地正确。
- 3、7 的交叉效果比首次生成更明确，但前后遮挡仍需审核，脚位与目标有偏差。
- 各帧腿长、护胫宽度和凉鞋细节仍有生成差异；取回与保护区合成处存在细小台阶、遮挡接缝，特别是腿与布帘、盾牌交界。
- 加深远侧腿采用区域规则，不能保证每个重叠像素都被准确分为近腿或远腿。
- 本轮保持原帧上半身位置，未额外根据髋点重做整套上下起伏。原输入八帧已有的位置变化保持不变。

本次只处理跑步，没有修改其余动作、游戏仓库或执行发布操作。
