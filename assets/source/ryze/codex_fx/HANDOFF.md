# 瑞兹特效原稿交接

已生成 19 张 PNG，共 102 格。每张使用内置 image_gen 单独生成；交付 PNG 与生成工具的文件哈希一致，没有用代码绘制、重画、调色或拼接特效。

这批是包中允许交付的生图原稿，不是游戏内最终小尺寸条。所有 PNG 都有真实 alpha；多数边缘含半透明像素，尚未量化到指定色板和单一像素格，部分有深色细边/杂边。

## 切帧与文件

`manifest.json` 的 `assets[].frames[].rect` 为实图像素坐标 [x,y,width,height]，0 起始，顺序先行后列。区域按主要可见形状（alpha ≥ 128）和列间低内容位置测量；外围低 alpha 噪点可能未包含。原稿格子不都等宽，不能用要求画布尺寸直接均分，尤其 q_pop、r_portal。

`generation_prompts.json` 逐张记录最终提示词、实际生成次数、来源和前序尝试。`preview.html` 打开后可以播放、暂停、逐帧查看；符文充能两行分开播放。`validation.json` 记录文件及矩形验证。

## 导入时

E→W→Q 对应图都已齐：e_orb/e_cast/e_hit/flux → w_cage 或 w_slow → q_bolt/q_cast/q_hit/q_pop，另有 runes/rune_out/q_haste。绑定名和目标游戏大小写在 manifest。

flux 使用 4×50ms、每 12 tick 一次；牢笼的 0 起始帧 2–5 保持到 75 tick；传送门的 2–7 保持到 60 tick。其余播放时长交给技能脚本，不用预览速度作为正式时长。

下一步由导入端量化到指定蓝/紫色板、去半透明噪边与深色描边、放回等宽小尺寸条并按脚底/手/胸口定位。飞行三图的严格上下镜像及挂身图的左右镜像尚未达到逐像素验收；不要把这一点标成已通过。暗战场可见度与循环接缝需要导入后测试。

这里只验证了 19 个文件、102 个非空切帧区域、透明通道和生成来源；没有运行游戏或更改技能代码。参考图 lol_fx_ref.png 仅本地使用，未放进交付。
