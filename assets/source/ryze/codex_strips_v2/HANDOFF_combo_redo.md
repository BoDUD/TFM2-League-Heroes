# 瑞兹连招与 R 重画

按用户最后的要求改为中等身材：躯干与手臂比收得过瘦的版本适度加宽，拳头保持小巧，卷轴保留窄长造型。使用内置 imagegen 重绘；定稿头部和站立腿按新附件提供的像素模板合成。

交付 `ryze_skill2.png`（12 帧，3328×2304）和 `ryze_ult.png`（8 帧，3328×1536），每格 832×768，透明 RGBA，严格 8×8 纯色块，只用定稿色板。

帧时序和站位来自这次新解压的 `ryze_cells.json`。连招前 11 帧各 78ms，最后 75ms，E / W / Q 出手帧为 2 / 6 / 9（tick 5 / 23 / 37）；R 各帧 125ms。R 第 2–4 帧与新附件 `now/` 图逐像素相同。

`manifest.json` 包含帧矩形、站位、bbox 和时序；`validation.json` 记录二值透明、源色板、定稿头像、站立腿模板、单一身体连通块和脚底线的核对结果。

`preview/` 为完整画布预览，无裁掉手脚的紧裁切。WebP 保留原毫秒时序，GIF 时间受 10ms 格式精度限制。`raw/` 和 `generation_prompts.json` 留存采用的生成图和提示词。

本包只交付这两张动作图；游戏内导入、特效挂点和实际连招播放未验证。
