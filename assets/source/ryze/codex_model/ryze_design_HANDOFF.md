# 瑞兹游戏尺寸造型交接（第1步）

日期：2026-10-02

本轮交付为两版静态待机造型。A为较小头部，B为较大Q版头部；连招和动作帧尚未制作。

## 文件

- ryze_design_A.png、ryze_design_B.png：1024×1024，严格8倍最近邻放大。
- ryze_design_A_1x.png、ryze_design_B_1x.png：128×128原生游戏像素画布，同一脚底线。
- ryze_design_A_sprite.png、ryze_design_B_sprite.png：27×40透明裁切精灵。
- ryze_design_comparison.png：深色底A/B对比，同时显示8倍和1倍。
- ryze_palette.png、ryze_palette.json：共享色板，候选28色，成品实际27色。
- ryze_validation.json：尺寸、色数、透明度和网格检查。
- ryze_generation_prompts.txt：全部实际提示词与整理说明。
- ryze_generation_sources/：生成器的A/B造型参考稿，非游戏尺寸成品。
- ryze_native_grid_source.py：原生逐格绘制的可编辑源码。

## 工作方式

使用素材包的 MODEL_PROMPTS.md 作为视觉规格，瑞兹原画、面部和卷轴作为外观参考；quality_bar.png、tfm2_style_bald.png作为游戏像素风格参考。第一次、第二次A提示词没有得到要求的低分辨率网格，舍弃；第三次A与B采用更简洁的40格提示词，仍未直接得到合格网格。

最终稿是在27×40原生网格上按外观参考逐格重绘与整理，不是将生成图缩小，也不是只对生成图取中心色。这一点与素材包建议的“按原稿自己的格子取像素”方式不同。保留生成参考稿，方便回看。

## 实测结果

| 项目 | A | B |
|---|---|---|
| 人物占用尺寸 | 27×40格 | 27×40格 |
| 实际占用行 | 60—99，共40行 | 60—99，共40行 |
| 原生画布 | 128×128 | 128×128 |
| 放大画布 | 1024×1024 | 1024×1024 |
| 不透明色数 | 27 | 27 |
| 透明度 | 0/255 | 0/255 |
| 头部设计高度（含外轮廓） | 10格 | 12格 |
| 眼睛亮点所在行 | 71 | 72 |
| 两眼颜色 | 白+浅紫，各2格 | 白+浅紫，各2格 |
| 靴底最低行 | 99 | 99 |

已逐块检查1024图的全部8×8方块：块内为单一RGBA颜色，并与1×图对应；眼睛白色与浅紫共4个像素，只出现在眼睛；双眼同一行；画布第100行及以后全部透明。

## 视觉取舍与未完全实现项

- 原画复杂的符文、卷轴纸层、胡须和皮带在40格尺寸下进行了简化，无法逐项保留大图纹理；没有采用随机碎点或渐变补细节。
- 原稿左右两边的卷轴筒露出量不同，成品主要强调画面左侧的卷轴、铜箍和蓝徽章。
- A/B肩甲、手臂与卷轴采用共享结构；B的腰带与腿部比例同时调整，以容纳更大的头部。
- 精灵横向包围框为x=48—74，实际放大位置x=384—599；与灰色位置参考有小幅水平偏移。脚间透明区跨过画布中央x=512，脚底位置严格一致。
- 当前造型仍需用户选择A或B。不能把本包当作已验证的游戏内效果、完整连招动画或技能代码。

下一步以选定造型为基准制作动作帧，保持27×40量级、同色板和脚底锚点。
