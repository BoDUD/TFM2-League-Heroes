# 洛模型原图交付

本次交付为 Teamfight Manager 2 角色制作的模型原图阶段，参考压缩包中的洛外观与像素造型。图像使用内置 image_gen 生成。

## 文件

- `rakan-model-A.png`：1024×1024，原版待机姿势，金色羽毛靠近下巴，长披风向身后展开。人物可见高度 850 像素。
- `rakan-model-B.png`：1024×1536，收拢舞者造型，一手叉腰，一手持金羽毛，披风缩短至小腿附近。人物可见高度 1250 像素。
- `generation-prompts.txt`：实际使用的两版初始提示词和参考图顺序。工具最多接受五张参考图，因此选用原版全身、头部、背面、展开披风和烬风格参考；全部九张均已查看。
- `generation-correction.txt`：B 版修正提示词与导出处理说明。
- `qa-A.json` / `qa-B.json`：尺寸、透明通道、可见包围盒与留边验证。

## 检查

两版均为 RGBA PNG，最终 alpha 只有 0 和 255，透明区域 RGB 已清零，非黑底或绘制棋盘格。A 四周留边至少 87 像素；B 左右至少 244 像素，上下 143 像素。人物、羽冠、鸟爪完整；白发、红羽冠、青绿双眼、红金领子、金护腕、双鸟头骨、青绿灯笼裤与多色羽毛可见。脚底低于披风末端，无魔法特效。

B 的身体和披风更窄，建议作为后续游戏精灵的起点；A 保留更接近原版的长披风轮廓。两版属于像素风模型参考原图，尚未重绘成约 40 行的最终游戏精灵，也未制作动画图集、技能特效或导入游戏。最终小尺寸可读性和游戏 UI/战场适配须在后续精灵阶段验证。
