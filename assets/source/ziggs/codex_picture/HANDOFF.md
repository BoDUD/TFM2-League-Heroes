# 吉格斯像素造型原画

交付内容：
- ziggs-A.png：双臂展开、两手各托一颗炸弹。
- ziggs-B.png：双臂收拢、两颗炸弹在身前。
- raw/ziggs-A-original.png、raw/ziggs-B-original.png：原始生成图，未修改。
- generation-prompts.txt：两次实际使用的提示词。

使用内置 image_gen 生成。参考来源为用户提供的 ziggs_pack0.zip。B 使用 A 作为角色一致性参考。

## 验证与限制

两张均为 1254×1254 PNG，具备真实透明背景；角色、炸弹和引线完整入画。A 为展开姿势，B 为收拢姿势。当前交付为二维像素造型原画，不包含三维网格、绑定或动作帧。

生成器未严格遵循参考资料的 1536×1536 画布、748 像素角色高度、11 像素网格、等高等大镜片和全硬 alpha 要求。两图有半透明像素，不能直接视为已通过游戏精灵生产规格的成品。若用于游戏，应先确定造型，再进行网格整理及动作制作。原图未做重采样、抠图或缩放，避免在未确定网格前损失细节。

Alpha 检查：A 全透明像素 930404，半透明像素 639391，全不透明像素 2721；B 全透明像素 1056065，半透明像素 514315，全不透明像素 2136。
