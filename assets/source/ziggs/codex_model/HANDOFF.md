# 吉格斯第 1 步：游戏尺寸造型重画两稿

## 文件
- ziggs-model-A-1.png：第一稿，保留选定 A 的张臂托炸弹姿势，重画镜片、白牙、胡子及炸弹标记。
- ziggs-model-A-2.png：第二稿，加强目标尺寸及粗像素约束的独立重画。
- raw/：两张 image_gen 原始生成图的原样副本。
- generation-prompts.txt：实际提示词及每次参考图顺序。
- validation.json：实际尺寸与 alpha 统计。

两张均通过内置 image_gen 绘制；未使用脚本逐格绘画，未进行缩放、重采样、调色板聚类、网格处理或 alpha 修改。素材仅来自用户本次提供的 ziggs_model_pack.zip。每次使用五张参考图（工具上限），用途及顺序见提示词记录。

## 核验结果：当前为候选原稿，生产规格尚未通过

两稿均为 1254×1254 PNG，真实透明背景，完整张臂姿势、两颗红色骷髅炸弹、引线火星。第二稿的像素处理稍简化。两稿的镜片高度及大小仍存在透视差异。

生成器未严格遵循资料要求的 1024×1024 画布、14px 固定网格、头盔到鞋底 48 格、指定坐标和二值 alpha。图像仍偏细，包含半透明像素，不能宣称为已经完成对齐的游戏精灵。第一稿有 632951 个半透明像素，第二稿有 623809 个；详细统计见 validation.json。

本包交付两张模型原生重画候选及完整记录，未以程序修图掩盖上述差异。待确定造型后，后续需量出实际格子并整理为游戏格子，再制作动作；本次未制作动作帧或修改游戏仓库。
