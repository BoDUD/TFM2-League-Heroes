## 文件

- khazix-model-A.png：未进化，双镰刀爪、无虫翼。
- khazix-model-B.png：沿用 A 的身体与蹲姿，增加 Q 锯齿爪、E 绿黄色虫翼、R 青蓝背甲；没有 W 进化背刺。

## 核验与后续使用

两张均为 1536×1024 RGBA PNG，具有真实透明通道；参考来自 khazix_pack0.zip。完整主体、双爪、两根触角与脚爪可见，B 的两片虫翼可见。A/B 采用同一基础身体与待机蹲姿。

这是第 0 步模型原画，尚未生成动作帧/游戏精灵表，也未修改游戏模组或现有仓库改动。

生成结果与包中理想规格存在差异：主体实测高度约 976–977 px，超过约 820 px 的目标；顶部/底部留边较窄。透明边缘包含低 alpha 像素，B 的少量低 alpha 残余接近画布底边；尚非最终游戏用硬 alpha 素材。后续游戏尺寸重绘/打包时应留足边距、统一硬像素边缘，不能直接将大图缩小后宣称已通过游戏 QA。

后续选定 A 或 B 为固定模型后，以同一模型制作约 40 行游戏尺寸精灵、各动作和独立技能特效，并检查 UI 与战斗地图裁切。
