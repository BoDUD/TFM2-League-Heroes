# 阿萝拉第1步：两稿造型候选

## 交付文件
- aurora-model-A-1.png
- aurora-model-A-2.png
- raw/aurora-model-A-1.png、raw/aurora-model-A-2.png：原始生成图，原样保留。
- generation-prompts.txt：实际提示词和参考图顺序。
- QA.json：尺寸、alpha及主体包围盒检查记录。

## 制作
两张均由内置 image_gen 绘制，参考仅来自 aurora_model_pack.zip。未用 Python 逐格画身体或修改图像，导出与 raw 完全一致。只制作3/4朝右待机造型；未制作侧面、动作、技能特效，也未改动游戏工程。

## 可见内容
两稿均保留铜红头发、金框双镜片、紫蓝双眼、兔耳、青绿金边帽、米白高领和长外套、浅蓝披肩、棕腰带、橙尾巴、长袜短靴和肩上魔杖。A-1笑口更明显，A-2轮廓较窄、底部留白更接近目标，建议优先评估A-2。眼睛高低/透视、羽毛轮廓和眼镜闭环仍需最终游戏网格检验。

## 技术检查与未通过项
- 两张实际尺寸都是1254×1254。
- 含真实透明背景，不是画出的棋盘格。
- A-1 alpha=0像素1078877，alpha=255像素2171，半透明像素491468；alpha>=128主体bbox=(315,32,983,1248)，宽668、高1216，底部仅6px，未满足至少16px留白。
- A-2 alpha=0像素1154260，alpha=255像素2208，半透明像素416048；alpha>=128主体bbox=(327,49,934,1208)，宽607、高1159，底部46px。全高接近72×16=1152px，但这不证明逻辑格子数正确。
- 生成器仍绘制了一些小于16px的细节和非统一方格，未严格遵守从(0,0)起的16px网格；帽冠到脚底57格、眼睛y528以及1格连续描边没有通过逐格验收。
- alpha并非仅0/255，硬alpha要求未通过。大面积主体alpha约253，边缘还含其他半透明值。
- 不得将文件名中的model/done当成最终游戏模型已验收的证明；本包是两张重绘候选及完整生成证据，需后续修整技术项。

## 后续
以raw为依据量实际台阶密度，优先检查A-2；独立确认帽冠、耳尖、眼睛与脚底标记，按身体和头部尺度读回。先放到游戏原生尺寸比较眼镜和脸，再决定采用哪稿。所有动作复用同一脸部。完成硬alpha、统一格子及留白修整后再制作动画并做引擎内验收。
