# 纳什男爵像素造型交付

本次交付为两款静态造型原画，使用内置图像生成工具制作；不是 3D 网格、骨骼或已接入游戏的动作资源。

## 当前有效设计

用户后续明确要求「画个腿，不然怎么看出来走动」。因此最终 A/B 均采用一对紫色粗短后腿、弯膝、象牙色三趾脚；原参考文档的无腿平底设计已被用户要求覆盖。两只小蛇头与原有弯爪手臂保留。

- `baronnashor-A.png`：有腿待机造型，S 形躯干，双脚分开承重。
- `baronnashor-B.png`：有腿抬头蓄力造型，沿用 A 的角色部件和配色。
- `raw/`：所有原始生成图，未重采样或修改 alpha；无腿旧图仅留作制作历史，不应作为最终模型。
- `generation-prompts.txt`：实际提示词及迭代记录。
- `validation.json`：最终 PNG 的实际尺寸、alpha 与可见范围检测。

## 检查结果与限制

视觉已检查头冠、黄眼、红嘴、獠牙、青绿腹甲、两只小蛇头、手爪与双腿，完整呈现于画面内。两张图是同一设计的生成变体，尚未按骨骼绑定到逐帧动作。

生成器未严格遵守参考文件中 1536×1536、统一 11px 网格、528/627px 主体高度、底线位置和全硬 alpha 的技术指标。图像有真实透明区域，但也存在半透明像素；不应声称已满足逐格读回标准。实际数值见 validation.json。为保留原稿，没有把高分辨率像素风图伪称为已经规范化的游戏像素源。

后续游戏适配需在同一模型上制作左右脚交替抬落、身体轻微起伏的走路帧，再按实际游戏框尺寸、像素网格与时间契约打包并测试。本次没有更改游戏模组、仓库或运行游戏。
