# 纳什男爵：跑步重画交付

本轮按 baronnashor_run_pack.zip 的新循环与骨架重新生成 8 帧；没有复用、重排上一包旧帧。全部角色图由内置 image_gen 生成/修改，没有代码逐格画角色，也没有对生成 PNG 缩放、取样、强制改 alpha 或拼接。

## 选用结果

- 第 1、5 帧出现脚尖近乎上下对齐的交错姿势。
- 第 2–4 帧暗色远腿在前；第 6–8 帧亮色近腿在前。8 帧的前后顺序检查通过。
- 亮色近侧脚趾均比远侧脚趾亮，手爪与两只小蛇头保持完整。
- 统一采用本轮第 1 帧为后续造型参考，头部黄眼定位锚点相对首帧偏移最大 1.4px；这是定位检查，不代表整个头部逐像素相同。
- 8 张均为 1254×1254 RGBA，文件哈希互不相同，均与对应 raw 原稿逐字节一致。

## 查看与文件

打开 preview.html 可按 [165,170,165,160,155,155,150,150] ms 播放，或暂停逐帧检查；可开启蓝/红目标脚尖圈。该预览仅显示原图，CSS 显示大小不会改写 PNG。

- baronnashor-run-run1.png … baronnashor-run-run8.png：选用的 8 张新原稿。
- raw/：选用版本的原始输出。raw/rejected/：未选版本，包括明暗腿反转或上半身改变的失败修改，不应再当成有效帧读取。
- generation-prompts.txt、correction-prompts*.txt：实际提示词和修订记录。
- source-selection.json：版本对应与弃用原因。feet-targets.json：输入脚尖目标。
- validation.json：实际脚尖、明暗身份、头部锚点、透明度、尺寸与哈希检查。

本包交付跑步重画原稿及核验结果；没有改动游戏模组，也没有进行游戏内动画测试。
