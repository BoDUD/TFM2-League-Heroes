# 纳什男爵蜘蛛腿修订

交付六腿 L6 与八腿 L8 两版，均为 1254×1254 RGBA，11×11 像素网格、硬透明。

- `baronnashor-legs-L6.png`：三对尖端蜘蛛腿。
- `baronnashor-legs-L8.png`：四对尖端蜘蛛腿。
- `comparison.png`：并排预览，带灰底和标签，仅供查看。
- `raw/L6-corrected.png`、`raw/L8-corrected.png`：最终修订的原始生成图。
- `generation-prompts.txt`：生成与去旧腿修订的提示词。
- `validation.json`：导出尺寸、网格、透明度和上半身保留范围。

按用户后续纠正，彻底移除了腹部两侧残留的短后腿、内侧白脚趾及旧腿根。只保留外侧两只大手爪。下半身采用新生成的深紫分节柱及蜘蛛腿。

原稿由 image_gen 绘制。最终通过网格读取和局部合成保留原底图上半身；仅下半身与两处旧腿根区域变化。原底图在 y<880 的像素全部保留，唯 [539,836,638,880] 与 [748,836,825,880] 两小块为用户要求去除的旧腿根修订区域。程序逐像素验证这两个区域以外的上半身与原底图完全一致。

最终导出验证通过：1254×1254、11 px 统一网格、alpha 仅 0/255。腿部颜色映射至深紫色阶，腹甲使用青绿色阶；外侧手爪尖直接使用原底图像素。地面区域边界为 y1144，腿尖的细微错落依原画保留，不声称每一个尖端严格同一水平。尚未制作其他动作或导入游戏。
