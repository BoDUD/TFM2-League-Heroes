# 德玛西亚之翼 奎因：第 0 步，先画像素风原图（给 Codex 的提示词）

> 奎因是德玛西亚的**游侠**，和她的鹰**华洛**一起作战：一个**身材修长的年轻女战士**，穿**深紫蓝色的紧身作战服**，胸前是**棕色皮革的胸甲和皮带**；头上一顶**深蓝色兜帽**，兜帽外面是**金色的鹰翼头盔面甲**（额前一块金色护额，两边向上翘起像鹰翅的尖角）；**深紫色头发**，**琥珀色的眼睛**，红色嘴唇。**近侧（画面左边）肩上一块很大的金色羽毛形肩甲**，腰两侧垂着**金边的羽毛状护甲片**，背后一件**蓝紫色的羽毛披风**。**右前臂上绑着一把金色和钢灰色的连弩**（她的武器，弩臂横在手腕前面）。两条长腿穿**深紫色护腿**，膝盖和小腿前面有**金色护板**，脚上是**尖头的深棕色靴子**。华洛是一只**蓝紫色的德玛西亚雄鹰**：蓝色的头上有一撮冠羽、**金色的弯嘴**、胸前一块**金色胸甲**、翅膀上套着**金色的护带**、深色的爪子。请 Codex 画**四张图**（同一个奎因、同一只华洛，长相、颜色、**格子大小**都一样）：
> - **A：英雄联盟里的待机**（附图 1、2、8a）。两脚前后分开、膝盖微弯，**右手的连弩举在身前朝右**，左手（近侧）垂在身边；脸朝右前方。
> - **B：手臂垂下的站姿**（附图 8b 只看大小和地面线）。两脚稍微分开站直，**两只手臂竖直垂在身体两侧**，连弩还绑在右前臂上、弩口朝下；脸朝右前方。**手臂一定要竖直**（横平竖直），这是后面摆动作用的底子。
> - **V：华洛单独一张**（附图 7、7b、7c）。**侧面朝右、展开翅膀滑翔**，嘴朝右，两只翅膀一上一下张开（近侧的翅膀在前、颜色亮，远侧的在后、稍暗），爪子收在身下。
> - **R：奎因骑在华洛背上飞**（大招「深入敌后」）。同样大小的华洛侧面朝右展翅滑翔，奎因**跨坐 / 半蹲在华洛背上、肩膀后面**，上身前倾，左手抓着华洛的金色护带，右手的连弩朝前（朝右）；她的大小、格子和 A、B 一样。
>
> 选定后，第 1 步再按游戏格子做游戏尺寸的造型。你画的原图会按格子直接读回，所以**像素块要清楚、整齐、大小一致**。附图 11–14 是本包里的阿克尚、薇恩、凯特琳和艾尼维亚（同是射手、德玛西亚的游侠，还有一只大鸟），**只看风格**。
> - **长相照英雄联盟原版**（附图 1–7）。英雄联盟的大招里只看得到一只大华洛，这里按我们的设计画**她骑在华洛背上**。
> - **比例**：奎因**不要画成大头娃娃**，头（从头盔尖到下巴）约占身高的六分之一（约 11 格），身材修长、腿长；华洛的翼展比奎因的身高还宽。
> - **头**（附图 3 特写）：金色鹰翼面甲（3–4 档金色）、深蓝兜帽、深紫色头发从面甲下露出一点；**两只眼睛一样大、一样高、都看得见**（琥珀色，平涂），红嘴唇。
> - **颜色**：深紫蓝的作战服（3 档）、棕色皮革（3 档）、金色的面甲 / 肩甲 / 护甲片 / 护板（3–4 档）、蓝紫色的披风和兜帽（3 档）、钢灰色的弩（2–3 档）；平涂的色块，**不要渐变**。深色的腿和披风一定要有**偏亮的边**，不然在深色背景上会糊成一团。
> - **华洛**：蓝色和蓝紫色的羽毛（3–4 档，翅膀尖更紫），每根飞羽的边要分得开；金色的嘴、金色的胸甲和翅膀上的护带；腿上是浅棕色的羽毛、深色的爪子；两只眼睛看得见的那只要清楚。
> - **姿势**：A、B 都是 3/4 正面朝右（脸朝右前方）。**近侧的手臂和腿在画面左边、颜色亮；远侧的在画面右边、稍暗**。两只脚落在同一条地面线上。V、R 是侧面朝右。
> - **画布用正方形 1536×1536**。A、B：**从头盔尖到脚底约 682 px，也就是约 62 格**，脚底在离画布底边约 146 px 的地方（附图 8a、8b 的灰线）。V、R：翅膀展开约 **1100 px（约 100 格）宽**，放在画布中间。全部在画面里，不能出画。
> - **像素块**：大小一致的方块，**每块 11 像素**，横平竖直对齐成网格；**外轮廓一圈 2 块宽的近黑描边**；每种材质内部 3–4 档平涂，不要零散的单个杂色格。暗处用这种材质自己最暗的一档，不要一圈黑。
> - 不画任何特效（弩箭、华洛俯冲的光、冲击、风痕都放到第 3 步单独画）；不画地面，不画影子。
> - 交付：`outputs/quinn-picture/quinn-A.png`、`quinn-B.png`、`valor-V.png`、`quinn-R.png`（1536×1536，**真透明背景**）；原始生成图原样放进 `outputs/quinn-picture/raw/`；附一个 `generation-prompts.txt`，写明实际用的提示词；**最后**在同一个文件夹写一个 `HANDOFF.md`（交付说明），再打包成 `outputs/quinn_picture_done.zip`。
