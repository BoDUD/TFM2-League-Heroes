# 稻草人方案 B — 模型动作交接

本包为方案 B 的第一版完整动作资产，共 10 张动画图、65 帧，另附已选定的 B 原生图。用于交给 Claude 接入项目；尚未执行游戏导入或游戏内实测。

## 文件与规格

- `fiddlesticks_native.png`：1024×1024，与选定的 B 图逐字节一致。
- `fiddlesticks_<tag>.png`：每格 768×768；逻辑格 96×96；按行从左到右读取。
- 全部动画使用 B 的 15 色色板，严格 8×8 方块，Alpha 仅 0/255，无背景、网格、文字或地面阴影。
- 正常帧最低不透明像素为 y=583；死亡第 4–8 帧最低为 y=599，使用允许的额外 2 格。
- `fiddlesticks_cells.json`：原文件原样保留。实际帧时长以此文件为准，尤其 run 中的 108/109 ms。
- `manifest.json`：逐帧切片矩形、时长、pivot、不透明边界、眼部颜色中心和 SHA-256。
- `preview.html`：解压后直接打开；支持动作选择、逐帧、倍速、站位对齐和辅助线。
- `overview.png`：动作总览，**仅供预览，不参与导入**。
- `generation_prompts.json`：动作图的生成提示词记录。

## Claude 接入顺序

1. 先备份项目中原有的稻草人素材。将 11 张正式 PNG 按项目命名放入 `assets/source/native/`；不要将 overview 当成动画。
2. 按原说明检查导入器的 `PASTED` 配置，移除 fiddlesticks 的旧拼贴处理，再运行 `import_native.py --hero fiddlesticks`。这是压缩包说明中的接入方式，本次未访问项目核验导入器实现。
3. 保持原 JSON 的 `ms`、帧顺序和 `pivot`。位置单位是 96×96 逻辑格，转换成 PNG 像素时乘 8。
4. **原 JSON 的 `head` / `tilt` 来自旧模型，不应直接作为 B 的新特效挂点。** manifest 的眼部中心是颜色测量结果，方便校对，不是已经通过游戏验证的发射点。
5. 在游戏内检查卡面、HUD、列表裁切和血条避让，再检查朝左镜像、动作切换、循环接缝与特效挂点。W 的最后三帧已统一到朝右；该处手臂与镰刀姿势变化仍需结合循环观感检查。

## 验证范围与待校对点

已自动核对所有图尺寸、8 像素网格、透明度、色板、非空帧、脚底线、画布边界、idle 一致性、skill2 空格，以及原始 JSON 与 B 原图的文件一致性；并逐组查看所有帧的静态预览。

动态重绘在麻布破口、木枝细节和头部轮廓上存在帧间变化。死亡第 3 帧仍在倒下，镰刀从第 4 帧起平放；这与原描述中“第 3–8 帧平放”有一帧差异。需追求逐帧严格匹配原动作时，可在本版基础上调整该帧。尚未在目标游戏中验证动画流畅度、挂点或导入结果。
