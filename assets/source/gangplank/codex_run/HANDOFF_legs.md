## 检查与限制
已目视检查八帧、交叉与收腿变化，模板保护区域另做逐像素比对。近侧腿已出现从右侧到左侧的变化，但生成结果仍是近似跟随引导线，尚未达到膝盖、脚踝、脚尖逐点严格重合。尤其第5帧靴子间距仍需对引导线复核；不可将本图视为完成逐关节几何验收。
