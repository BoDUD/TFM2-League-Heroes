# 维克兹像素造型交付

本次交付为静态像素模型原画，两种姿势均为 3/4 正面朝右。A 为触手展开，B 为触手向下收拢。使用内置 image_gen 生成；B 以 A 原图为角色外观参考。

文件：
- `velkoz-A.png`：展开版，1536×1536，透明 PNG，11×11 硬像素网格。
- `velkoz-B.png`：紧凑版，同上。
- `raw/velkoz-A-raw.png`、`raw/velkoz-B-raw.png`：生成器原始图，未经修改。
- `generation-prompts.txt`：实际提示词、参考图顺序与规范化处理说明。
- `validation.json`：原始尺寸、包围盒与最终网格数据。

原始生成图均为 1254×1254，未严格遵守所要求的尺寸、像素格与硬 alpha。交付 PNG 是从生成角色最近邻采样至 62 行逻辑像素后，以每格 11×11 放回 1536×1536 透明画布，alpha 二值化；未用几何图形重绘身体。逻辑区域从 y=682 至 y=1364，实际轮廓可能在区域内留一格空白，最低触手约距参考地面线 26px。A 宽 90 格，B 宽 44 格。外观检查已确认大眼竖瞳、三只小眼睛、金色甲壳与完整卷曲触手。

限制：生成原画的外描边未达到所有位置均匀两格，材质色阶也未逐项手工归并至 3–4 色；不将其描述为逐像素精修完成。最终图已统一网格和硬 alpha，原始图保留便于后续人工精修。尚未制作游戏动作帧、技能特效、3D 网格或运行时模型，也未改动仓库或已安装模组。本次仅参考附件中的原画设计内容，未执行附件面向其他代理的后续集成指令。
