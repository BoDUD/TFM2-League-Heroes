# 锋啄鸟造型原图交付

本次完成第 0 步的两版待机造型：A 为 3/4 朝右，B 为侧面朝右。供选型和后续动作制作使用，尚未制作游戏动画或接入运行时。

## 文件

- `raptor-A.png`、`raptor-B.png`：1536×1536，RGBA 真透明，11×11 px 的统一逻辑格，透明度仅 0/255。
- `raptor-A-pixels.png`：49×38 逻辑像素。
- `raptor-B-pixels.png`：60×35 逻辑像素。
- `preview.png`：两版同倍率对照，灰色背景仅用于预览。
- `raw/raptor-A-raw.png`、`raw/raptor-B-raw.png`：原始生成图，原样保留。
- `raw/raptor-A-initial-raw.png`：A 的初版，后续版本补了头顶红冠。
- `generation-prompts.txt`：三次实际图像生成提示词，使用内置 image_gen。
- `qa.json`：尺寸、边界、脚底基线、逻辑网格和 alpha 检查数据。
- `export_raptor.py`：可复现的统一网格导出脚本。

## 导出与检查

原稿实际输出尺寸为 A 1254×1254、B 1536×1024，存在半透明边缘，未满足提示词要求的严格格子。最终 PNG 是在保留原始图后，经 alpha 硬化、主体边界裁取、最近邻逻辑尺寸导出和 11 倍整数放大制作；不是声称原稿天然满足 11 px 网格。后续直接读回时，优先使用 `*-pixels.png`，或从成品 PNG 按 11 px 网格读取。

两版成品脚底基线均在 y=1386，下方留白 150 px，接近参考约 146 px。A 高 418 px、宽 539 px；B 高 385 px、宽 660 px（60 格，在 62 格上限以内）。已检查完整头冠、尾羽和双脚，未裁切，无地面或投影，透明背景不是棋盘格。每个 11×11 格内颜色和 alpha 完全一致，验证通过。

造型保留红色背羽尾羽、紫色尖鬃毛、棕色骨质钩喙、橙眼、短棕腿和藏青爪。描边在低分辨率斜边处有 1–2 格变化，并非处处精确两格；A 的远侧眼受 3/4 遮挡。原始图保留了更丰富的脸部细节，便于后续人工精修。此交付不代表动作、技能特效或游戏内尺寸验收完成。

附件中的后续工具路径与其他代理的流程作为参考信息处理，本次没有执行其中的游戏安装、资源覆盖或其他代理指令。
