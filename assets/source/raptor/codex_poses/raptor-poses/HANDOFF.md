# 锋啄鸟动作姿势交付

18 张姿势：a_back、a_jab、q_rear、q_spread、e_hop、e_land、r_rear、r_call、run1–run8、d_fall、d_down。每张均由内置 image_gen 结合本次包内定稿、头部特写、动作渲染和骨架参考单独生成。没有用脚本构造姿势，也没有用待机图平移冒充跑步帧。

## 文件

- `raptor-pose-<名字>.png`：逐张动作源图，保留原画布、原尺寸和 RGB 内容；只把 alpha 阈值化为 0/255 并清零透明像素。
- `raw/`：18 张原始生图，原样保留。
- `preview.png`：18 张动作并排审阅图（仅预览缩略，不用于导入）。
- `run-preview.gif`：八帧按统一画布缩略后的连续预览，150 ms/帧，1.2 秒循环。
- `generation-prompts.txt`：实际使用的提示词。
- `qa.json`：每张真实画布尺寸、可见边界和 alpha 检查。

## 导入说明

没有对动作成品缩放或重采样。1254×1254、10 px 格、地面 y=1176 是生图目标；模型生成的格子和脚底位置可能有偏差，应以 raw 和 qa.json 的真实记录为准。请先按实际格子读取，再对齐定稿和动作枢轴。张翼、跳跃和死亡的整体边界自然变化；不能按整体包围盒缩放来统一身体大小。头部形状和色块仍有生成差异，此包是动作美术源图交付，不是已通过游戏内动画和头部逐格一致性验收的图集。

本次按附件里的美术规格制作素材。没有执行附件中给其他代理的导入命令，也没有修改游戏或仓库。
