# 可酷伯（金铲铲之战 · 第 15 赛季）：第 0 步，先画像素风原图（给 Codex 的提示词）

> 可酷伯是金铲铲之战第 15 赛季（K.O. 斗技场）的二费卡（重量级斗士 / 大宗师），一只**又大又圆的约德尔老猫**，武馆里的功夫老宗师。这一步画两张，**格子大小一样**，用户从里面选一种做游戏造型：
> - **长相**：**金橙色的猫毛**，**一对很大的尖耳朵**（橙色，耳尖和耳边是深红棕色，耳朵里是白色的绒毛）；脸被一大圈**雪白的鬃毛 / 胡子**包着：**长长的白眉毛**往两边翘，**白色八字胡**，**浓密的白胡子**从脸颊一直垂到胸口；头顶一个**蓬松的大白发髻**，用一根**蓝色的发带**扎着（发带两头翘出来）；**眼睛小、青绿色**，眯着、很和善，**深紫红色的鼻子**；一脸慈祥又有点得意。
> - **手臂**：**又粗又大的手臂**，毛色是**火焰纹**（橙红 → 橙 → 金黄的火焰状条纹，像身上在烧），**大爪子**，爪尖是**黑色的短指甲**，**掌心有一个发光的金黄色漩涡纹**（看附图 7、8）。
> - **身上**：一件**无袖的蓝色短褂**（宝蓝色，**白色的交领**和白色滚边，衣服上有**白色的祥云 / 漩涡纹**）；脖子上挂一串**深棕色的木头念珠**；腰上缠着一条**粗粗的深红棕色绳子腰带**，腰带前面挂一枚**大大的铜金色圆形铜钱 / 徽章**（上面有漩涡纹），旁边吊着**两个金黄色的铃铛**；下身是**深灰黑色的宽松功夫裤**；小腿**缠着深红棕色的绑腿**；**光着的橙色猫脚**，脚趾有小爪子。人（猫）**又矮又壮、肚子圆**：肩宽、手臂比腿粗得多。
>
> 请 Codex 画**两张**（**格子大小一样**）：
> - **A：捋须**（金铲铲原样待机，附图 1、2、10a）：**3/4 朝右**，身子微微前倾，**近处的手（画面右）抬到下巴、用爪子捋着白胡子**，远处的手（画面左）垂在身侧，抬着下巴、眯眼看向右上方，一副得意的老宗师样子。
> - **B：抱拳行礼**（功夫起手式，附图 4、10b）：**3/4 朝右**，**双腿分开扎稳马步**，**两只大爪子在胸前合掌**（掌心相对、指尖朝上），看向右前方。

> - 不画任何技能特效（护盾、金光、冲击波、晕眩星星都放到后面单独画）；不画地面，不画投影。
