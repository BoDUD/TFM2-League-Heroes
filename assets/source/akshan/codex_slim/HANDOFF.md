# 阿克尚瘦身两稿

依据 akshan_slim_pack.zip，用内置 image_gen 绘制两稿。保留举枪、叉腰姿势及原服装配色，收窄躯干与披风，拉出修长腿部轮廓。图像内容由画图模型生成，没有用 Python 逐格绘制人物。

## 交付文件

- akshan-slim-1.png：第一稿，身体轮廓较直，收窄腰身与贴身披风。
- akshan-slim-2.png：第二稿，整体再窄一些，保留稍多披风饰边。
- preview-comparison.png：放大裁切对照预览，左一稿、右二稿；灰色底仅用于查看。游戏用透明图请使用上面两张原尺寸 PNG。
- raw/：五次生成的原始图，均未修改。第一稿使用 akshan-slim-1-refined.png；第二稿使用 akshan-slim-2-clean.png。带 refinement-rejected 字样的图误带入了模板网格，未用于成品。
- generation-prompts.txt：实际生成提示词，含未采用的中间版本。
- validation.json：最终图尺寸、alpha、网格和位置测量。

## 已检查

两张最终图均1254×1254，10×10px方块网格从(0,0)对齐，alpha仅0或255。头顶在y740、两脚底均为y1200，头顶到鞋底460px，即46格。身体保留在下方中间，上方有大片透明区域。举枪伸出身体框是预期布局。

第一稿下方身体轮廓范围x500–740，宽240px；第二稿x510–730，宽220px。腰附近各扫描行的完整不透明轮廓宽度见validation.json，其中包含披风、手臂等遮挡，不能全都当作躯干腰宽。

## 导出说明

生成模型没有直接严格满足位置、尺寸与网格，因此成品是在生成图基础上做尺寸和位置规范化：采用最近邻采样落到10px网格，并将alpha以128阈值转为0/255。没有逐格新增或手绘人物部件。raw/保留规范化前的图。

第一稿源图头顶/脚底定位520/1228，身体横向定位450–874，导出目标身体横向500–740；第二稿源图定位615/1215，身体横向500–835，导出目标510–730。纵向均对应最终740–1200。头顶位置通过排除枪械后的发髻区域检查，脚底分左右脚检查。

## 细节与使用边界

这两张是供选择的静态像素设计稿。眼睛的精确2格结构、枪钩每处2格厚度、每种材质严格3–4色及全轮廓连续1格描边，没有完成逐部件的像素级认证。缩小落格后，面部和枪械细节会比raw/简化；原参考图的枪形与服装也并非逐像素复用。

尚未重做动作、修改PPU、接入游戏或改动任何游戏工程。选定稿后可继续制作动作资源。
