# 阿克尚走路换皮图

根据用户提供的 akshan_run_swap_pack.zip，使用内置 image_gen，将骨架参考中的角色替换成阿克尚定稿外观，生成一张 4 列 × 2 行、共 8 帧的绿色背景像素风走路图。

## 文件

- `akshan-run-sheet.png`：完整 8 帧原稿。
- `raw/akshan-run-sheet-original.png`：image_gen 原始输出，与交付 PNG 内容相同。
- `generation-prompts.txt`：实际提示词、三张参考图路径及顺序。
- `validation.json`：实际尺寸、绿色值统计、alpha 检查。

## 画面内容

各帧采用深棕长发和发髻、棕色皮肤和胡子、浅蓝白围巾、灰金护肩、橙红斜饰带和金箍、暗红金边披风、青绿腰带前布、深色裤靴。持枪手将双钩回旋镖手枪举在头边，另一手握拳，披风向身后飘开，双腿有迈步、弯膝和前后变化。原骨架的乌鸦与恶魔手臂已去除。

三张输入分别用于布局及走路动作、角色外观、原版跑步动态。没有额外参考图。所有绘制均由 image_gen 完成；未用脚本画帧、裁切、重采样、替换背景或制作动画。Python 只读取图像进行验证。

## 实测与限制

实际输出为 **1862×845**，未达到参考图要求的 **2016×912**。4×2 排列在视觉上成立，但实际宽高不能直接按原参考的 504×456 单元切分。各帧位置、脚底高度、轮廓和像素密度没有与骨架逐格精确一致。

背景是接近纯绿的色域，**并非全图统一 #00FF00**。最常见颜色为 (2,250,2)，左上角为 (18,242,13)，因此不能直接假定仅按精确 #00FF00 抠图。所有像素 alpha 均为 255。

八帧可见步态变化，但没有完成逐格动作骨架一致性、近远腿严格交换、57 格身高，以及同一把枪在各帧完全刚体一致的验收。身体、手臂、枪和衣饰存在生成器带来的帧间差异。此文件适合作为走路换皮候选原稿，尚不是已通过无缝循环和游戏切帧验证的最终动画资产。

本次未修改游戏项目，未执行附件之外的导入或动画接入流程。保留原始输出，便于后续选择与处理。
