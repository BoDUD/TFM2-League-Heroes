# 阿克尚：游戏尺寸造型候选（第 1 步）

依据用户提供的 akshan_model_pack.zip，继续采用 A 举枪待机姿势，使用内置 image_gen 生成两稿。此次交付为二维造型候选，供用户选择；尚未完成严格游戏网格技术验收。

## 文件

- `akshan-model-A-1.png`：修正后的第一稿。脸部更接近正面，两只眼睛都可见；构图和留白更接近目标。
- `akshan-model-A-2.png`：第二稿。色块更粗、更简化；人物位置偏离目标，远侧眼睛未达到要求。
- `raw/take-1-initial.png`：第一稿初次生成，细节过密，已被修正稿取代，仅保留记录。
- `raw/take-1-final-original.png`、`raw/take-2-original.png`：最终两稿原始生成文件，与对应交付 PNG 相同。
- `generation-prompts.txt`：全部三次调用的实际提示词、参考图及顺序。
- `validation.json`：逐像素检查的尺寸、alpha 计数和 alpha>=128 的可见区域边界；坐标为含端点范围。

## 制作方式

全部角色绘制均来自 image_gen。没有用脚本画格子、缩放、量化、抠图或重新排列像素；只复制原始 PNG，读取像素用于验证。每次工具最多接收 5 张本地参考图，因此从包内选择参考；所有输入图均来自本包。

第一稿初次结果过细，因此追加了一次修正生成。最终第一稿加强双眼可见性、简化色块并改善目标留白；第二稿保留独立的较粗像素处理。没有自行替用户选定采用哪一稿。

## 验收范围与未达标项

两张都有真实透明背景，角色、举起的双钩枪和披风完整。第一稿两只眼睛可见，小发髻、围巾、橙红饰带金箍、青绿前布、披风与靴子可辨。

实测两张均为 1254×1254。按 alpha>=128 统计，第一稿可见范围为 x=288..961、y=152..1200（枪顶与鞋底接近要求）；第二稿为 x=274..1010、y=20..1235。第一稿有 423477 个非二值 alpha 像素，第二稿有 525903 个；大部分角色区域 alpha 为 253，接近不透明，但仍不符合严格 0/255 要求。

仍不能认定为严格网格资产：生成模型未保证每个方块恰好 15px、网格从 (0,0) 对齐、57 格身高、44 格宽、精确头顶及鞋底位置；双眼没有通过每只恰为至少 2×2 格且大小完全一致的验收。第二稿双眼尤其不符合要求。PNG 中的非二值 alpha 计数见 validation.json，因此不能宣称满足 alpha 只能为 0/255。保留未经处理的原稿，避免将这些差异掩盖为已达标。
