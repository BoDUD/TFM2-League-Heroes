# 阿克尚像素角色原画

本次交付为二维 PNG 角色原画，不是三维网格模型，也不是已导入游戏的动画资源。

- `akshan-A.png`：举枪待机姿势。
- `akshan-B.png`：胸前平端枪、微屈腿备战姿势。
- `raw/akshan-A-original.png`、`raw/akshan-B-original.png`：生成器原始输出，与上面的 PNG 内容相同，未做重采样或抠图。
- `generation-prompts.txt`：实际提示词、参考图路径和生成方式。

使用内置 image_gen，根据所提供压缩包中的角色与像素风格参考生成。B 额外引用 A 以保持外观一致。工具每次最多支持 5 张本地参考图，因此按角色辨识、姿势和风格选择参考。

## 验证与限制

两张均为 1254×1254 RGBA PNG，背景有真实 alpha 透明通道，角色和武器完整留在画面内。存在非 0/255 的 alpha 值，不是全硬 alpha 成品。

参考文档中的 1536×1536、严格统一 11px 网格、两格描边、770px 身高与指定鞋底基线未被生成器精确实现；脸部双眼大小也不是严格相等。两图适合姿势和造型选择，不能宣称已经满足逐格读回或游戏直接使用的技术要求。请在游戏格子重绘、尺寸校准和动画制作前确认选用姿势。未修改游戏文件、制作动作帧或执行文档里交给其他代理的后续流程。
