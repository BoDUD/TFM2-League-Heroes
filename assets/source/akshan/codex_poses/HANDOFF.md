# 阿克尚：端枪朝前姿势两稿

使用用户提供的 akshan_pose_pack.zip，通过内置 image_gen 修改定稿的举枪姿势，制作端枪朝前的二维像素风原稿。

## 文件

- `akshan-pose-aim-1.png`：第一稿（修正结果），左侧肩膀伸出的棕色手臂横过胸前，金护腕、浅蓝手套握枪，右侧手叉腰。
- `akshan-pose-aim-2.png`：第二稿，采用相同姿势，手臂与武器局部轮廓不同。
- `raw/take-1-original.png`、`raw/take-2-original.png`：两稿未经处理的原始生成文件，与对应交付 PNG 内容相同。
- `raw/initial-wrong-arm.png`：初次结果，误将右侧手臂改为持枪，已废弃，仅保留生成记录。
- `generation-prompts.txt`：三次实际提示词和参考图顺序。
- `validation.json`：实际尺寸、透明通道、可见范围，以及与定稿头部和下半身的同坐标像素比较。

每次使用包内五张参考：定稿、网格、枪臂特写、原版开枪、被否掉的拼法。工具上限为五张，因此省略与定稿重复的原版待机图。没有使用包外的图片。

## 已完成的姿势

最终两稿均有从画面左肩连续延伸到胸前的持枪手臂，金护腕和浅蓝手套相连，武器水平指向右方，双钩一上一下，右侧另一只手保持叉腰。脸和胡子露出，旧举枪位置已清空。最终第一稿的手臂更接近水平伸直。两张均为 1254×1254，具有真实透明背景。

全部绘制来自 image_gen。只复制原始 PNG、读取像素进行验证，没有脚本画格子、裁切、缩放、量化、拼接或 alpha 后处理。没有执行附件中交给其他代理的印章提取和游戏接入流程。

## 未满足的严格技术要求

这两张是姿势原稿，尚不是可直接替换的严格局部像素编辑资产。生成器重新绘制了其他区域：头发、脸、披风、裤靴等与定稿在同一坐标的 RGB 像素并不一致；不能宣称除手臂和枪外每一格完全保留。肩臂、金护腕等比例也需后续对照原造型校准。严格 15px 网格及网格原点未得到保证。

按 alpha>=128 的可见范围（右下端点不含）统计：第一稿为 (109,331)..(1238,1192)，第二稿为 (110,330)..(1235,1186)。枪完整但比要求的最远 x≈1150 更靠右，右侧只有约 16–19px 余量；鞋底也未严格落在 y1200。

alpha 仍非全硬值：第一稿有 459574 个非二值 alpha 像素，第二稿有 455110 个，大多数角色像素 alpha 为 253。真实透明背景已具备，但不满足 alpha 只能为 0/255。请结合 validation.json 查看，不应将本次结果当作全部技术验收通过。
