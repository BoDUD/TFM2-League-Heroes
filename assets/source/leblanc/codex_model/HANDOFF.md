# 第1步：乐芙兰造型草稿，尺寸验收未通过

本轮只生成静态造型。未修改游戏、未制作动作帧。

## 文件

- leblanc_design_A.png / leblanc_design_B.png：1024×1024，严格8×8网格，透明背景，脚底行99。
- leblanc_design_A_1x.png / leblanc_design_B_1x.png：128×128原生画布，一格一像素。
- leblanc_design_A_generated.png / leblanc_design_B_generated.png：对应生成器原稿。
- palette_A/B.txt、palette_A/B.png：实际色板，A26色、B25色。
- comparison.png：暗底4倍和1倍对比，左A右B。
- generation-prompts.txt：所有实际尝试的提示词，标明最终采用的两段。
- validation.json：机器检查数据。

## 检查结果

通过：8×8块严格同网格、二值透明度、颜色≤28、脚底在99行、脚底以下空白、整个人物和法杖可见。

未通过：A原生可见大小51×86格，B47×75格，目标总高分别45/42格；身体38格、头12格和总宽约30格未达到。生成器多次无视原生尺寸要求，仍产生更细的像素簇。未将高分辨率原画缩小冒充原生38格精灵。

脸部2×2眼睛和同一行要求未完整达到；B的法杖水晶低于头发顶，领翼过小，无法作为严格的紧凑版；A/B服饰和体型也存在差异。未证明质量等同于quality_bar，也未进行游戏内验收。

## 整理方式

使用内置image_gen生成。随后按原稿色块边界估计自身网格，取每格中心小区域中位色，一格保留为一个原生像素，不缩小原生行列数；二值化透明度、量化到≤28色、最近邻放大8倍并放到128×128画布。源格子略有不规则，网格恢复是近似，不能视为手工重绘。

本包是可检查的未达标草稿。下一步应重新绘制真正38格身体、12格头部，再验收造型；此包不适合直接进入动作帧制作。
