# 布隆第0步：A/B像素原画

依据 braum_pack0.zip 的 PICTURE_PROMPT.md 制作。内置 image_gen 生成；在此前用户已授权的像素整理范围内，恢复统一6像素网格、合并调色板、整理透明度与位置。此次只交付第0步原画，未导入游戏。

## 文件

- braum-model-A.png：盾在画面右前方立地，远侧手按盾顶，近侧手放松。
- braum-model-B.png：盾在画面右前方举起，盾底在膝盖附近；近侧拳头在腰前。
- braum-model-A-1x.png、braum-model-B-1x.png：1像素1逻辑格版本。正式图为6倍像素块。
- braum-comparison.png：灰底A/B并排展示，灰底只用于预览。
- generation-prompts.txt：实际三次提示词（A首稿、A校正、B编辑）。工具单次最多5张参考，因此生成A选用了正面、盾、头、身体和库奇风格5张；其他来包参考已阅读，未冒称全部11张同时输入。
- raw/：三张生图原稿，逐字节保留，没有覆盖。
- validation.json：尺寸、网格、透明度、配色和头部复用检查。

## 外观与检查

光头、上卷深棕八字胡、胡茬、青绿坠子、裸露粉色大块头、紫红纹身、蓝灰钢肩甲与白灰毛皮、圆形金边公羊腰扣、深棕长裤和蓝灰靴子。盾是竖直的石板灰门板，金色横梁回纹、卷角公羊头、青蓝宝石与眼睛、棕色皮带。

两版均为1536×1024真透明PNG，人物头顶在120行，落地线为899行，人物高度780像素；6×6纯色方块，全硬alpha（仅0或255），四周完整留边。采用共享64色调色板，实际使用数见validation.json；每种材质以平涂层次为主。最终图透明区RGBA清零，不含参考图背景柔光。无魄罗和技能特效。

已查看并排预览。A/B头部指定区域直接复制，保持脸与胡子一致。B的近侧手臂按要求弯曲，因此并非仅盾的像素平移；生成的胸口纹身和盾面雕刻仍有细微差异，未做到两版全身与盾逐像素完全相同。画法与材料识别保持一致，但不可将它们视为已拆好的同一刚体动画层。还需后续造型与动作阶段统一图层；这次没有制作PPU造型或动作条。
