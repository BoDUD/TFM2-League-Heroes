
# 波塞冬高清模型交接

重画待机、跑步、普攻、技能一、技能二、大招、受击、倒地共 64 帧。新角色格 256×256，文件名保留 `_native`，以对应角色资源名。另附完全最近邻放大的 512×512 格图集。三叉戟全套共用一把固定尺寸的独立绘制武器。倒地第四至第八帧使用同一落点。

## 角色图集

- `ragnarok_poseidon_native#sheet.png` + `ragnarok_poseidon_native#anim.fanim` 为建议接入的一组。图集 2048×2048，帧坐标是旧 128 格动画表的两倍，时长逐帧一致。
- `ragnarok_poseidon_hd#sheet.png` + `ragnarok_poseidon_hd#anim.fanim` 是 4096×4096 备选组，和 256 图集显示同一内容。
- 256 角色格的脚底锚点为 (128, 232)，向右为基准，镜像轴 x=128；512 格锚点为 (256, 464)。接入后，应按现有英雄 128 格到 256 格的换算保持游戏内显示比例。游戏运行时 PPU 及接入需实机验证。
- 随包附原版效果图集、效果动画和 cues.json，三份文件与输入字节一致。效果与提示表仍使用原 128 逻辑格坐标；在 256 角色画格的预览中按 2 倍投影。角色资源不要与原 128 图集表混搭。
- grips_hd256.json 提供重画后握点，顺序为 x、y、武器角度、道具杆轴上的握点 x、是否持握。向下为正角度，0° 表示朝右。
- review.html 在本地打开，可以同一大小连播、逐帧、镜像和切换浅色背景。checks.csv 记录坐标、脚底和透明通道检查结果。
