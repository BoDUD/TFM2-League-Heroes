# 绯红树怪（金铲铲之战 · 第 18 赛季）：第 0 步，先画像素风原图（给 Codex 的提示词）

> 绯红树怪是金铲铲之战第 18 赛季的一费卡（峡谷野怪 / 猎人），技能「刃叶」：**就是英雄联盟峡谷里红 buff 旁边的小树怪**（红 buff 树怪的小崽子）。这一步画两张，**格子大小一样**，用户从里面选一种做游戏造型：
> - **身子**：一只**矮矮胖胖、四脚着地的小树皮兽**，像一只小熊 / 小獾：身子是**深紫褐色的树皮**（3 档，最暗的近黑紫），**四条腿短而粗**，**前腿外面包着一块块暖褐色的木头甲片**（有一道道木纹），甲片上有**几块青苔绿的斑**；**每只脚上三根深紫黑色的尖爪**。
> - **树叶鬃毛**（附图 1、2、5）：背上**竖着一排又高又尖的浅绿色大叶子**，像刺猬 / 剑龙背上的刺，中间那片最高；脑袋后面和脖子一圈是**深一点的绿叶**，像领子。浅绿 3 档 + 深绿 2 档，**是全身最大块的颜色**。
> - **木头面具（脸）**（附图 3、6 特写）：脑袋就是**一个圆鼓鼓的木头面具**，由**几块竖着的暖褐色木板**拼成（3 档，木纹清楚），**比身子还显眼**：面具**左半边一只又圆又大、发光的橙红色眼睛**（中间近黄），**右半边刻着一个发光的橙红色螺旋纹**（像一个「G」/ 蚊香）；面具下半截是**一排参差的深色木头尖牙**（嘴），牙缝里透出一点橙红的光。**一只大亮眼 + 一个螺旋纹 + 一排尖牙**就是它的脸，是全图最好认的地方。
>
> 请 Codex 画**两张**（**格子大小一样**）：
> - **A：待机，3/4 朝右**（金铲铲原样待机，附图 1、2、10a）：四脚着地蹲着，木头面具在身子最前面、朝右前方，两条前腿撑在面具两侧（近处那条在画面右边、离我们近），背上的叶子鬃毛高高竖起。**差不多一样高一样宽**。
> - **B：同样的待机，正侧面朝右**（附图 4、10b）：四脚着地，侧过来：面具在右边最前面，**那只发光的大眼睛朝右、看得清**，前腿在面具下面撑地，后腿在后面，背上的叶子鬃毛往后上方竖着。
>
> 选定后，第 1 步再按游戏格子做游戏尺寸的造型。你画的原图会按格子直接读回，所以**像素块要清楚、整齐、大小一致**。附图 11–14 是本包里的绯红印记树怪（**它的妈妈，同一个营地，颜色最接近**）、小木灵（同一个系列的小野怪）、暗影狼（同一个系列的四足兽）和艾翁（树叶），**只看风格**。
> - **长相照金铲铲的模型**（附图 1、2、4、5 是模型的渲染；附图 3、6 是脸的特写，**面具的木板、大眼睛、螺旋纹和尖牙以附图 3、6 为准**；附图 7 是它往前一扑，**只看身子和腿怎么动**；附图 8 是它用后腿站起来，**只看怎么站起来**；附图 9 是叶子鬃毛趴下来的样子，**只看叶子怎么收**）。
> - **比例**：Q 版，**面具比模型大一些**（大到一眼看清大眼睛、螺旋纹和尖牙，约占身子宽的 40%），身子更圆更矮胖，**背上的高叶子保留**（可以稍稍短一点），腿短。
> - **脸要清楚**：面具木板 3 档（上面最亮）；**大眼睛至少 3×3 格**，中间一格近黄、外面一圈橙红；螺旋纹用亮橙红 1 格宽的线画 2 圈；尖牙 4–5 颗，深紫褐色，牙缝 1 格橙红。
> - **画布用正方形 1536×1536**。**A：从最高点（最高那片叶子的尖）到最低点（爪子着地）约 352 px，也就是约 32 格**，宽约 32–38 格（最多 42 格）；**B：同样的格子大小**，约 30–32 格高，宽约 34–40 格（最多 44 格）。最低点（爪子）在离画布底边约 146 px 的地方（附图 10a、10b 的灰线），位置照附图 10a、10b。**附图 10a、10b 是按模型原比例渲染的，只看位置、高度和最低点线，宽度以上面的格数为准。** 叶子尖、爪子全在画面里，不能出画。
> - **像素块**：大小一致的方块，**每块 11 像素**，横平竖直对齐成网格；**外轮廓一圈 2 块宽的近黑描边**；每种材质内部 3–4 档平涂，不要零散的单个杂色格。暗处用这种材质自己最暗的一档，不要一圈黑。叶子画成**几片大而清楚的尖叶**（每片一亮一暗，中间一道叶脉），不要碎点；木头甲片之间用深一档的缝分开，木纹用 1 格的深线，少而清楚。
> - 不画任何技能特效（飞叶、火、灼烧、钻地的泥土都放到后面单独画）；**眼睛、螺旋纹、牙缝的橙红光是它本来就有的，要画**，但只是平涂，**不要光晕**；不画地面，不画投影。
> - 交付：`outputs/cinderling-picture/cinderling-A.png`、`cinderling-B.png`（1536×1536，**真透明背景**）；原始生成图原样放进 `outputs/cinderling-picture/raw/`；附一个 `generation-prompts.txt`，写明实际用的提示词；**最后**在同一个文件夹写一个 `HANDOFF.md`（交付说明），再打包成 `outputs/cinderling_picture_done.zip`。

## 后面要用到的动作（这一步**不画**，只是让你画造型时心里有数）

客户端里有绯红树怪自己的动作（我已经按动作片段渲染出来了，后面的骨架包会附上），所以造型里这些部件要**画得清楚、彼此分得开**：木头面具（一只大眼睛、螺旋纹、尖牙）用在所有帧、四条短腿（要能小跑、往前扑、用后腿站起来）、背上的叶子鬃毛（要能竖起来、甩出去、着火变红、趴下来）。

| 动作 | 金铲铲里怎么做 / 我们的技能 |
|---|---|
| 待机 | 选 A：3/4 四脚着地蹲着；选 B：正侧面四脚着地蹲着；背上叶子一竖一收 |
| 移动 | 四条短腿交替小跑（金铲铲里没有跑步动作，我来做） |
| 普攻「余烬叶」 | 往前一扑，从背上甩出一片带火星的红叶（金铲铲普攻原样的往前一扑） |
| 被动「绯红霸符」 | 每放一个技能攻击力叠一层（金铲铲原技能）；叠满后普攻带灼烧，面具上的眼睛和螺旋烧得更亮 |
| 技能1「刃叶」 | 背上的叶子全部竖起，五片锋利的叶刃飞出、从两边绕弧聚向目标：物理伤害 + 重伤 + 灼烧（金铲铲原技能） |
| 技能2「钻土突袭」 | 钻进地里，从离敌人远一点的地方钻出来（金铲铲出生动作），溅起泥土和碎叶，周围敌人减速 |
| 大招「燎原叶暴」 | 用后腿站起来，背上的叶子着火变成绯红色，几秒内不停地朝附近的敌人射出燃烧的叶刃，自己攻速变快 |
| 死亡 | 往后一翻，四脚朝天躺倒（金铲铲原样） |
