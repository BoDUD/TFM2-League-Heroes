# 阿克尚 全部动作 换皮（骨架 + 皮囊）

用户选了瘦身第 2 稿（`2_角色定稿.png`）。现在把他的**每个动作**都按这个办法做：图1 是一套现成精灵图的动作骨架（一个穿长外套、拿手枪的枪手），把里面的人换成阿克尚。

**每张骨架图单独生成一张**（共 8 张）：`1_1_骨架_idle.png` … `1_8_骨架_dead.png`。每次上传：图1 = 这一张骨架，图2 = `2_角色定稿.png`。

## 每张都一样的要求

参考图1精灵图的动作序列和构图布局，将原有的角色替换为图2角色（影哨 阿克尚）。

1. 保留图1所有帧的位置、大小、排列顺序（从左到右、从上到下，每行最多 4 帧）；每帧角色在格子里的位置和脚底高度都不变。
2. 保留每帧的动作：身体姿势、手脚位置、迈步、跳跃、倒地都照图1。**走路（run）两条腿必须一前一后交叉迈步，每半圈前后交换一次**。
3. 身体结构、配色、特征完全换成图2：深棕长卷发和小发髻、棕色的脸和短胡子、浅蓝白围巾、灰色金边护肩、赤膊、斜挎的橙红饰带和金箍、窄窄的暗红披风、青绿腰带和青绿长布片（金环）、深灰黑裤子、黑色高筒靴（金色饰纹）。**身材和图2一样瘦**：肩窄、腰细、腿长。
4. **武器**：图1 的人两手各拿一把小手枪；阿克尚**只有一把**大的回旋镖手枪（图2，暗红带青铜、前端两道弯钩），**由近侧（前面）的手拿**，大小、颜色、形状和图2完全一样，不要变形；图1 里枪朝哪儿，阿克尚的枪就朝哪儿（举起、平端、朝前开枪）。另一只手空着握拳或叉腰。
5. **不要画任何特效**：图1 里的蓝色光、电花、光圈、子弹全部不要画，只画人。
6. 体型和图2一样大（头顶到鞋底约 61 格），不要变大变小、变胖变瘦；两条腿颜色一样，远处那条腿可以暗一档。
7. 像素画：方块大小和图2一样（每个像素方块一样大，整齐对格），1–2 像素深色描边，不要抗锯齿、不要渐变、不要模糊。

背景保持纯绿色 #00FF00，方便抠图。风格与图2一致。重点在于精准复刻图1的"动作骨架"，只是换了"皮囊"。

## 每张骨架是什么动作（阿克尚的技能）

| 骨架 | 用作 | 说明 |
|---|---|---|
| `1_1_骨架_idle` | 待机 | 轻轻呼吸；**枪照图2举在头边、枪口朝上**（不要照图1垂着） |
| `1_2_骨架_run` | 走路 | 交叉步；枪举在头边或胸前，随步子动 |
| `1_3_骨架_attack` | 普攻（连开两枪） | 照图1 平端手枪朝前开枪 |
| `1_4_骨架_skill1` | Q 去而复还（扔回旋镖） | 照图1 的出手动作，手往前甩 |
| `1_5_骨架_skill2` | E 骄行荡寇（甩钩、翻滚） | 照图1 的冲刺翻滚 |
| `1_6_骨架_ult` | R 恩怨相抵（蓄力连射） | 照图1 平端枪瞄准射击 |
| `1_7_骨架_hit` | 挨打 | 只要第 1 帧（第 2 帧白色剪影不用画） |
| `1_8_骨架_dead` | 阵亡 | 照图1 向后倒下、躺平 |

## 交付

8 张整图（和各自的图1 一样排列、一样大小），文件名 `akshan-<动作>.png`（如 `akshan-run.png`），放在 `outputs/akshan-actions/`，原始生成图放 `raw/`，附 `generation-prompts.txt`，**最后**写 `HANDOFF.md`，再打包成 `outputs/akshan_actions_done.zip`。8 张都画完再交。
