# 孙悟空 全部动作 换皮（骨架 + 皮囊）

用户选了新定稿第 2 稿（`2_角色定稿.png`）。现在把他的**每个动作**都按这个办法做：图1 是一套现成精灵图的动作骨架（一个戴兜帽、拿长杆武器的战士），把里面的人换成悟空，长杆换成金箍棒。

**每张骨架图单独生成一张**（共 8 张）：`1_1_骨架_idle.png` … `1_8_骨架_dead.png`。每次上传：图1 = 这一张骨架，图2 = `2_角色定稿.png`。

## 每张都一样的要求

参考图1精灵图的动作序列和构图布局，将原有的角色替换为图2角色（齐天大圣 孙悟空）。

1. 保留图1所有帧的位置、大小、排列顺序（从左到右、从上到下，每行最多 4 帧）；每帧角色在格子里的位置和脚底高度都不变。
2. 保留每帧的动作：身体姿势、手脚位置、迈步、跳跃、挥击、倒地都照图1。**走路（run）两条腿必须一前一后交叉迈步，每半圈前后交换一次**。
3. 身体结构、配色、特征完全换成图2：棕色猴毛、头顶一撮往上翘的深棕头发、浅粉的脸心、两只绿眼睛、圆耳朵、大红围巾高领、金红大护臂和银灰纹章、金色胸甲、长长的金色鳞纹前摆（红边）、暗栗色袍裙、暗钢色护膝、紫色鞋子金色鞋带、**身后卷起的长尾巴**（每帧都要有，随动作摆）。
4. **武器**：图1 的长杆（顶上有灯笼头）换成**图2 的金箍棒**：橙红棒头、金箍、红色两端、灰色钢段中间，**两头一样、笔直、长度和图2一样**，图1 里杆子在哪、朝哪，金箍棒就在哪、朝哪；握在手里的地方棒身连贯穿过拳头。**不要画灯笼头**。
5. **不要画任何特效**：图1 里的彩色刀光、火焰、光点全部不要画，只画人和金箍棒。
6. 体型和图2一样大（头顶那撮头发到鞋底约 49 格），不要变大变小、变胖变瘦；两条腿颜色一样，远处那条腿可以暗一档。
7. 像素画：方块大小和图2一样（每个像素方块一样大，整齐对格），1–2 像素深色描边，不要抗锯齿、不要渐变、不要模糊。

背景保持纯绿色 #00FF00，方便抠图。风格与图2一致。重点在于精准复刻图1的"动作骨架"，只是换了"皮囊"。
