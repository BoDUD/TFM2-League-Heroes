## 本轮拒绝的修复路线

机械清掉生图头部矩形再粘贴批准头，虽然能让头本身逐像素一致，却会擦掉穿过头旁的枪杆和举枪的手，且留下漂浮发带、断开的颈部。这批试验没有放进成品或候选目录，不能使用该方式批量替换头部后宣称完成。

短提示词“骨架 + 皮囊”已额外重试跑步一次，仍未保持定稿比例。因此没有继续批量生成同一失败路线，也没有压缩身体来掩盖差异。

## 必须完成的后续工作

以批准造型作逐帧像素重绘，分别处理头部遮挡、发带根部、手臂、枪杆和腿部，禁止整块擦除跨越武器的矩形。先过 run 和一组出手帧的母版一致性，再沿同一方法补齐其余动作。所有视觉门槛通过后，实测枪尖/握持点，复核脚底线与 run 循环，再执行导入、模拟和实际游戏 QA。
