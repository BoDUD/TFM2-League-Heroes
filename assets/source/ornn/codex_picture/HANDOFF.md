# 奥恩像素造型 A / B

本次依据用户提供的 ornn_pack0.zip 制作两张像素角色概念图，使用内置 image_gen，透明背景模式。不是三维网格、绑定或动画文件。

## 文件
- ornn-A.png：原版外扩大羊角、大锤版本。
- ornn-B.png：羊角更贴近头部、双锤更小的紧凑版本；熔岩拳头更清楚。
- raw/ornn-A-raw.png、raw/ornn-B-raw.png：生成器原始 PNG，原样保留。当前交付图与对应 raw 相同，无重采样和透明通道修改。
- generation-prompts.txt：实际生成提示词，A 和 B 各一段。
- validation.json：Pillow 读取的尺寸、alpha 和边界数据。

## 检查结论与限制
两张均为 1254×1254 RGBA，具有真实透明通道，不是棋盘格底。可见主体具有双羊角、双锤、红色鬃毛胡须、青铜甲、灰蓝皮肤和短腿，面向右方的 3/4 视角；B 的羊角与锤头明显更紧凑。

生成器未严格遵守参考文档中的制作规格：不是 1536×1536；alpha 有 256 个等级，边缘存在半透明像素；未达到可逐格读取的统一 11px 网格；没有验证恒定两格描边。两版人物在画布中的大小和落点不完全一致。alpha 边界检测包含画布边缘的微弱像素，完整视觉主体虽可见，仍需整理边缘。A 的远侧手掌偏暗，没有完全表现为通红熔岩拳，B 已更清楚表现。

因此这些文件适合作为 A/B 造型选择的概念图，不能视为已通过严格网格验收的游戏成品。后续应统一到游戏逻辑像素、调色板、硬 alpha、比例和脚底基准，再制作动作。本次没有执行文档中指向 Claude 的代码、仓库接入或游戏测试步骤。
