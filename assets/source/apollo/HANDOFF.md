# 阿波罗 · 美术与音频交接

资源 ID 为 `ragnarok_apollo`。以动画第三季第九回合为造型参考。保留粉红长发、金月桂、白底金蓝刺绣衣饰和金蓝拳甲。最终技用独立的阿尔忒弥斯女神像和光索表现，把阿波罗自身作为银箭发射。

## 资源和坐标

- 主图集与独立特效各 8 组，每组 8 帧。逻辑格 256×256，HD 格 512×512，精确 2× 最近邻。请配对使用同分辨率的 `#sheet.png` 和 `#anim.fanim`。
- 默认朝右。逻辑脚底锚点 (128, 232)，特效默认中心 (128, 128)。HD 坐标乘 2。角色大小沿用同批素材的画面比例，由 Claude 对接 PPU。
- `runtime/props/` 提供金色弓身、光弦和女神像。主图集已合成光弓与女神像。`bow-registration.json` 记录握点、弓梢、弦上的拉弦点和离弦位置，逻辑坐标从左上角计。
- 选人立绘 1216×1428，运行选人图 304×405。日轮拳、光丝、光箭和银箭突进图标各 256×256。

## 动作和战斗时点

| 动作 | 关键帧 |
| --- | --- |
| `attack` | 第 4 帧出拳，第 5 帧预览命中。实战命中特效照命中回调触发。 |
| `skill` | 第 4 帧扔出阿尔忒弥斯之丝，命中时在目标位置放收束特效。 |
| `skill2` | 第 3 帧光弓成形，第 4 帧拉弦，第 5 帧放出光箭。离弦点见 `reflection.json`。 |
| `ult` | 第 3 帧女神像显现，第 4 帧蓄力，第 5 帧角色离地突进，第 7 帧落地。突进特效沿出拳手跟随，离地阶段的手部坐标与特效前端坐标在 `follow`。命中位置由战斗逻辑提供。第 5 帧可触发 `voice_silver_arrow`。 |

`cues.json` 记录触发帧和动作起点到该帧的累计毫秒数。帧从 1 开始，预览位置与实战锚点不同。

## 与列奥尼达斯对接

`reflection.json` 对应列奥尼达斯素材提交 `35546c8f5`。投射物 ID 为 `apollo.light_arrow`。两边共用实际世界碰撞点，光箭箭尖到达后停止原来的飞行。当满足反射条件时交给列奥尼达斯的 `confirmed_reflect`，按实战反射方向绘制并更新下游弹体归属。预览用的是上一包的举盾帧和反弹特效，普通命中的闪光在反射分支关闭。

## 预览与交接

- `review/review.html` 提供逐帧、连播、深浅底和左右朝向。选择光之矢时可勾选列奥尼达斯反弹。音频区可单独试听。
- 3 条鈴村健一的日语动画原声保留了部分配乐和环境音，来源、剪辑范围和校验值见 `audio/sources.json`。另有 16 条原创战斗音效。均提供 44.1 kHz 单声道 WAV 和 MP3。
- Claude 对接角色注册、PPU、位移、命中、反弹、技能及 AI，并负责游戏内验证。
