# 纳亚菲利造型图交接

本次按用户提供的压缩包参考生成二维像素造型原图。未修改游戏、仓库、动作帧或技能代码。

## 文件

- naafiri-A.png：本体，朝右的 3/4 视角。
- naafiri-SA.png：本体，朝右的侧面。
- naafiri-P.png：犬群伙伴，朝右的 3/4 视角。
- naafiri-SP.png：犬群伙伴，朝右的侧面。
- raw/：四张原始生成 PNG，原样保留，1254×1254 RGBA。
- preview.png：四图相对尺寸预览，灰色背景仅用于展示。
- generation-prompts.txt：实际使用的英文提示词；生成方式为内置 image_gen，transparent_background=true。
- validation.json：布局及透明度检查结果。

## 已验证

四张布局版均为 1536×1536 RGBA，透明度仅为 0 或 255。通过阈值清理边缘 alpha、按不透明轮廓裁切、等比最近邻缩放和透明画布定位完成素材整理，没有重绘角色。角色最低爪底位于 y=1390，下方留白 146 像素；本体轮廓高 396 像素，伙伴高 220 像素。尾巴、刀刃、爪子都在画布内。

## 使用限制

这是造型参考原图，尚非最终游戏动画模型。生成结果没有严格实现统一 11px 格子、2 格描边和 36/20 格角色高度；布局版的尺寸整理不代表满足这些格子要求。A 的双眼存在透视大小差异；3/4 图的各爪有前后透视高低。头身比例较接近精简原版，未完全达到参考说明中更夸张的大头 Q 版。后续若需按格直接读取，应先测量原图的实际像素台阶并按游戏目标格重画，不能假定每 11px 为一个逻辑像素。未进行游戏内展示及地形遮挡测试。

四图人物造型使用包内角色参考、包内像素画作为风格参考。生成后续侧面时另以对应本轮生成图作一致性参考。
