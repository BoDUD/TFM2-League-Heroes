# 百裂冥犬 纳亚菲利：第 0 步，先画像素风原图（给 Codex 的提示词）

> 纳亚菲利是英雄联盟里**一把暗裔匕首附身的沙漠猎犬群**，她本人是**狗群的头犬**，身边带着几只**狗群伙伴**。这一步两个都画，用户从里面挑：
> - **纳亚菲利**：一头**又大又精瘦的四足猎犬**：**深红色的狼头**，口鼻上一道**白色的斑纹**，尖耳朵，**黄色的眼睛**，咧着嘴露出一排**白色尖牙**，嘴里**叼着一把匕首的骨柄**（刀身在嘴里看不见，只露出一小截柄）；背和肩上是**石板蓝 / 青灰色的甲壳**，上面有**深红色的纹路**；脖子和肩上竖起**一大圈弯曲的深紫色刀刃**，刀刃**镶着薄荷绿的边**，像一圈鬃毛往后张开；背脊上一排**短短的青色尖刺**；**深红色的四条腿**，**黑色的爪子**；一条**长长的鞭子一样的尾巴**，尾巴末端是红色的。
> - **狗群伙伴**：**一只小一些的深红色猎犬**：精瘦的红色身体；头上戴着一顶**石板灰色的骨质头盔**，头盔前面伸出**一片往前弯的刀刃**，罩在口鼻上方；脖子上几根**短短的灰色尖刺**；**一只黄色的眼睛**；**黑色的爪子**；一条**细长的尾巴**，尾巴末端是灰蓝色。
>
> 请 Codex 画**四张全身像**（**两只狗的格子大小一样**，所以伙伴比纳亚菲利小一半左右），用户从里面挑：
> - **A：纳亚菲利的待机，3/4 正面朝右**（附图 1、2、10a）。四脚着地、身子压低、头在前面（画面右边），脸朝右前方，两只眼睛都看得见；刀刃鬃毛往后张开，尾巴拖在身后、尾尖翘起。
> - **SA：A 的侧面，朝右**（附图 4、10b）。同一头纳亚菲利**正侧面朝右**（头朝画面右边，看得见一只眼睛），四条腿都在地面线上，尾巴在背后（画面左边）。
> - **P：狗群伙伴的待机，3/4 正面朝右**（附图 5、6、10c）。
> - **SP：P 的侧面，朝右**（附图 7、10d）。
>
> 选定后，第 1 步再按游戏格子做游戏尺寸的造型。你画的原图会按格子直接读回，所以**像素块要清楚、整齐、大小一致**。附图 11–14 是本包里的奈德丽豹形（四足野兽）、千珏（毛皮）、沃里克（狼人）和沃利贝尔（大野兽），**只看风格**。
> - **长相照英雄联盟原版**（附图 1–8）。
> - **比例**：Q 版，**头比原版大**（头约占身高的三分之一到二分之一，脸清楚），身子比原版短一点、腿比原版短一点；刀刃鬃毛是她最醒目的轮廓，要画得大而清楚，但**不能挡住脸**。
> - **纳亚菲利的脸**（附图 3 特写）：深红色的狼脸，口鼻上的白色斑纹，**两只黄色的眼睛一样大、一样高、都看得见**（每只至少 2×2 格，一格白色高光），张开的嘴里一排白牙，嘴角叼着匕首的骨柄。
> - **伙伴的脸**（附图 6 特写）：深红色的脸，头盔的刀刃从额头往前伸、罩在口鼻上方，**一只黄色的眼睛**清楚可见（至少 2×2 格），嘴里一排小白牙。
> - **颜色**：纳亚菲利：皮毛深红 3–4 档（**不要糊成一团红**，亮边偏橙红），口鼻白色斑纹 2 档，甲壳石板蓝 / 青灰 3 档加深红纹路，刀刃深紫 3 档加**薄荷绿的刃边** 2 档，尖刺青色 2 档，爪子黑灰 2 档，匕首骨柄米黄 2 档。伙伴：皮毛深红 3–4 档，头盔和刀刃石板灰 3 档（亮边偏青白），爪子黑灰 2 档，尾尖灰蓝。
> - **画布用正方形 1536×1536**。**纳亚菲利从最高的刀刃尖到爪底约 396 px，也就是约 36 格；伙伴从头盔顶到爪底约 220 px，约 20 格**（两只格子一样大）。爪底在离画布底边约 146 px 的地方（附图 10a–10d 的灰线）；站在画布中间（附图 10a–10d 的位置）。刀刃、尾巴、爪子全在画面里，不能出画。
> - **像素块**：大小一致的方块，**每块 11 像素**，横平竖直对齐成网格；**外轮廓一圈 2 块宽的近黑描边**；每种材质内部 3–4 档平涂，不要零散的单个杂色格。暗处用这种材质自己最暗的一档，不要一圈黑。
> - 不画任何技能特效（飞出去的匕首、流血、冲刺的残影、怒吼的光、护盾都放到第 3 步单独画）；不画地面，不画投影；一张图里只画一只狗。

## 后面要用到的动作（这一步**不画**，只是让你画造型时心里有数）

动作帧由 Claude 按英雄联盟的动作逐帧拼（必要时再请你照骨架画关键姿势），所以造型里这些部件要**画得清楚、彼此分得开**：纳亚菲利的头和下巴（会张嘴撕咬、甩头扔匕首）、刀刃鬃毛（怒吼时会竖起张开）、四条腿（跑、扑、跳）、尾巴；伙伴的头、四条腿和尾巴（跑、扑咬）。

| 纳亚菲利 待机 / 跑 / 普攻 / 受击 / 死亡 | Idle / Run / Attack1–4 / — / Death | 普攻是往前一扑一咬 |
| **Q 暗裔犬牙** | Spell1 | 甩头把两把匕首往前扔出去（匕首第 3 步另画） |
