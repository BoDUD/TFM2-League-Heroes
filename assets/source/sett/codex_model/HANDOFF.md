# 瑟提第 1 步：游戏尺寸造型

采用用户本轮更新的 sett_picture_pack.zip（内部 sett_model_pack），两版均采用已选待机造型，供选择头身比。本轮不制作动作。

## 文件

- sett_design_A.png / sett_design_B.png：1024×1024 透明PNG，128×128网格的严格8倍图。
- sett_design_A_1x.png / sett_design_B_1x.png：128×128透明原尺寸画布。
- sett_design_A_raw.png / sett_design_B_raw.png：内置image_gen生图原稿，1254×1254，未经缩放或重采样。
- comparison.png：近邻放大的两版对比预览。
- palette.txt / palette.png：25色允许色板，实际两版各使用22色。
- generation-prompts.txt：实际提示词与输出归整说明。
- validation.json：尺寸、位置、颜色与透明通道检查记录。

## 读回结果

两版不透明外接范围均为128画布上的 [51,58,77,100)，即26格宽、42格高。脚底最低行为99，对应8倍图y=792–799；下方透明。整体位于x=512附近。

A：耳尖第58行，下巴第70行，头部13格；B：耳尖第58行，下巴第68行，头部11格。两版第71行以下身体像素完全相同，脸部各有同一行的两眼琥珀色簇。

两版各22种不透明颜色；透明度只有0或255；8倍图由原尺寸近邻放大，每格严格8×8纯色。描边统一为#0B0508。

## 处理过程与限制

生成器未直接输出指定的42格大小及严格网格，因此本交付采用生图后的网格归整、头身分区重采样、指定色板映射、脸部像素修整和身体统一。这与素材说明中“直接按游戏尺寸画、不要先画大再缩小”的理想流程有偏差，不能将最终PNG称为未经处理的直接生图。原稿已完整保留，便于检查和继续修订。

细辫、兽头扣饰及指节在42格下已简化；拳头宽度、两脚透视和脸部朝向仍需用户以预览审阅，未声称所有视觉细节逐格精确匹配参考。两版未经游戏内实机验证，尚未写入游戏目录或仓库。
