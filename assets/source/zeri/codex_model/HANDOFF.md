# 泽丽第 1 阶段：游戏尺寸造型

日期：2026-10-11。参考：用户提供的 zeri_pack1.zip。

本次按选定的竖枪原画完成两种高度的游戏模型候选。A、B 都是竖枪待机，区别是 40 / 42 格高度；不是第 0 阶段的两种持枪姿势。尚未制作动作帧、图集、技能效果或安装到游戏。

## 成品测量

| 项目 | A | B |
|---|---|---|
| 可见轮廓（宽×高） | 30×40 格 | 32×42 格 |
| 1 倍画布 | 128×128 | 128×128 |
| 8 倍画布 | 1024×1024 | 1024×1024 |
| 顶行 / 鞋底行（从 0 开始） | 60 / 99 | 58 / 99 |
| 可见颜色数 | 30 | 30 |
| 透明度取值 | 0、255 | 0、255 |
| 鞋底以下像素 | 无 | 无 |

放大图的每个方块都是严格对齐的 8×8 纯色块；程序读回确认它们与 1 倍图的逐像素重复一致。脚部中心落在画布中间的第 64 列附近（轮廓测量中点分别为 64.5 / 63.5），中线位于两脚之间。

## 整理方法与视觉状态

生成工具的稿件仍然画得偏高，A 的第二稿读回为 37×63，B 稿为 40×62。没有把大原画直接缩小，也没有用几何绘图替代模型。按照素材包描述的方法，按源图自身方块取回像素，限制色数，再删除相近的整行、整列，保留脸部区域，最后仅补缺失描边。

最终两版共用 B 生图源，保持脸、服装和枪的模型身份一致。源图脸部第 15–24 行、15–23 列保留；眼睛、嘴、脸颊创可贴没有在删行删列时重画。两种尺寸均可见竖枪、握枪手、垂下的手、青蓝外套、黄绿双发髻、黄色背心、紫红裤和棕色靴子。

造型仍需用户挑选，技术检查通过不等于视觉或游戏验收。枪口略低于发髻顶，局部内侧黑线和部件轮廓仍受生图原稿影响；未宣称所有造型细节逐项完美匹配，也没有宣称已通过游戏内显示或动画验证。后续动作应继续沿用选定模型，特效另外制作。
