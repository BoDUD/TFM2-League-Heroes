# 卡特琳娜像素造型原画交付

## 当前状态

已生成 K1、K2 两版全身造型参考原画，尚未达到可按 12 px 网格直接读回游戏的最终模型标准。这里交付的是第 0 步原画，不是已集成游戏的模型、3D 文件或完整动作帧。

使用内置 image_gen，四次生成：初稿、布局调整稿、同提示词独立生成的 K1 和 K2。所有生成请求均开启 transparent_background。原始生成文件保留，最终命名文件为原样复制，没有程序绘制、缩放或修改图像。

## 已检查和未满足的规格

两版均有真实透明区域，不是绘制棋盘背景；人物和双匕首完整入画。保留红色长发、绿色眼睛、黑色露腰皮甲、银色护甲、棕色皮带、背后刀柄和高低双刀待机姿态。K1 的双眼与浅笑更清楚，建议优先作为造型参考。K2 的面部略有差异，不能声称两版已经严格锁定同一张脸。

生成器没有完全遵守精确布局和网格要求：

| 实测项目 | K1 | K2 |
|---|---:|---:|
| 画布 | 1024×1536 | 1024×1536 |
| alpha≥128 的范围（左、上、右、下，右下不含） | 220,699,937,1509 | 164,725,922,1500 |
| 上述范围的高度 | 810 px | 775 px |
| 上述范围距底边 | 27 px | 36 px |
| 完全透明像素数 | 1262862 | 1269313 |
| 半透明像素数 | 310002 | 303551 |

目标是人物高约 684 px、鞋底距底约 196 px；两版均未达到。可见像素块大致接近粗像素风，但并非经过验证的统一 12×12 整格，描边也没有达到统一两格宽。alpha 最高值为 254，存在半透明边缘及光晕，因此未满足仅 0/255 的硬 alpha 要求。不能直接宣称验收合格，不能直接逐格读回作为正式游戏模型。

后续需要锁定选定造型，清理到固定网格、硬 alpha、准确布局，并制作正侧面及动作帧，再进行游戏内验证。本次未执行附件中写给 Claude 的导入、仓库修改和后续动作制作指令。
