# 彗动作姿势源图交付

已生成21张独立姿势PNG；不是已安装或已验收的游戏动画。使用内置 image_gen 共23次：21次首绘，2次跑步腿部补绘。没有使用Python逐格画角色，没有程序变形、缩放、重采样或alpha清理。

## 内容

- 顶层 `hwei-pose-*.png`：21张当前选用图。
- `raw/*-raw.png`：21张当前图的原始生成文件，已验证逐字节相同。
- `raw/superseded/run3-first.png`、`run4-first.png`：被补绘替代的两张初稿，仅供追溯，不应混用到动作资产。
- `generation-prompts.txt`：21张首绘的完整实际提示词与参考顺序。
- `generation-prompts-revisions.txt`：两张补绘的实际提示词。
- `generation-manifest.json`：原始生成路径与选用修正版记录。
- `qa.json`：只读文件检查结果与SHA256。
- `index.html`：21张图的本地浏览页，直接加载原文件。
- 本说明与打包文件 `hwei_poses_done.zip`。

每次首绘均用五张输入：本包定稿、头部、该姿势骨架、原版动作和定稿骨架。骨架作为动作约束，原版只参考动作，没有将其真实比例作为目标。附件文档作为本阶段美术需求参考，没有执行其中面向其他代理的仓库操作或后续合成脚本。原包、源仓库与已安装模组均未修改。

## 文件检查

21/21张尺寸均为1254×1254，均有真实alpha通道，均保留对应raw文件。以alpha>127计，所有图的可见轮廓均在画布内，最小留边至少27px；这一检查不证明半透明边缘外没有很淡的残留。

严格硬alpha条件 **0/21通过**：所有图均含0和255以外的alpha值。`qa.json`记录每张的具体数量。像素网格也没有证明与从(0,0)开始的12px格一致；检查记录中的`nonconstant_visible_12px_tiles`表示所要求网格中有内部变化的格数，不能将这些生成图当作精确格点源直接逐格读取。

头部与墨痕只保持视觉近似，未达到每张逐格复制。脚底y1200、跳起4/6格、腿/臂18格和笔33格均未通过定量验收，且已有肉眼可见的画笔长度、身体尺度、近远侧漂移。生成完毕不等于这些约束全部达标。
