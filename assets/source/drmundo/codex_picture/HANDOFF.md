# 蒙多像素原画交付

本次按附件的角色与画风参考，生成两种姿势的二维像素角色原画：A 为待机，B 为举锯攻击前摇。不是三维网格、骨骼或可直接导入的完整游戏动作包。

## 文件

- drmundo-A.png：待机版。
- drmundo-B.png：举锯版。
- raw/A-initial.png：首次待机生成结果。
- raw/A-refined.png：待机修订原图，与最终 A 相同。
- raw/B-generated.png：攻击生成原图，与最终 B 相同。
- generation-prompts.txt：实际使用的三次提示词。
- HANDOFF.md：本交付说明。

## 核验与限制

两张最终图均为 1536×1024 RGBA PNG，背景存在真实 alpha=0 区域，四角透明，武器与人物均在画布内。没有对生成原图进行后期重绘。

生成器未严格满足每格 11px、两格描边、统一网格、有限色板、脚底同一水平线与精确 858px 身高要求。轮廓附近仍有少量柔光及半透明像素，人物实色区域 alpha 多为 253，而非完全硬 alpha=255。两姿势的局部细节也有差异。应作为造型选稿使用；逐格读回游戏前需统一像素网格、量化色板、清理透明边缘、校准身体比例与脚底位置。尚未进行游戏内验证。

使用附件作为造型参考；未执行附件中写给其他程序的仓库改动、后续动作包生成等操作。
