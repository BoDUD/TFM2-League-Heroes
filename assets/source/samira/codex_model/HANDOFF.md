## 为什么未通过造型验收

1. 生成器反复超出指定像素格数。较细且接近选定原画的前几轮仍过大；更简化的最后一轮改变了造型，尤其增加了画面左侧松散长发，不能当作与已选原画一致的正式模型。
2. A/B 均太宽；A/B 头部约多 1 格。B 的身体比例与腿部露肤也偏离选定原画，刀柄红头与刀刃轮廓并不忠实。
3. 眼罩和明亮绿眼的颜色、眉线及像素位置未达到要求。限定色板回取后没有保留独立亮绿眼色。此问题必须明确修复，不能靠“色数合格”掩盖。
4. 当前轮廓与局部黑线仍不够干净；与质量基准相比形状和模型一致性未达到通过标准。

- A 使用 `raw/attempt6_A.png`：原网格 54×31，删除 14 条整行成为 40×31。删除行含上部头发和身体冗余行；未删除脸、眼睛所在行。删除行列表写在 `qa_A.json`。这只是回格候选，不代表造型正确。
- B 使用 `raw/attempt6_B.png`：原网格 49×30，仅删除第 46 条整行成为 48×30；脸部未删。
- 两版均未删除整列，没有把身体宽度强行压缩到目标。
