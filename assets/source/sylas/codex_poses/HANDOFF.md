## 已完成的检查

16 张原图均已视觉查看，覆盖战斗起手与出手、腾空、突进、死亡和四帧跑步，使用白石金边镣铐、长金链、暖肤色、黑发胡子与深青色服装。全身和主要链条没有贴到原图画布边缘；没有骨架线、网格线、文字或魔法特效。部分链条与边缘的余量很小，后续缩放仍需注意。

最终文件统一 1254×1254，真实透明背景，alpha 只有 0 或 255。仅将 alpha<128 清零，其余设为255。倒地图工具返回了 1774×887 横图，因此对它做了等比例最近邻缩放和透明画布归置：可见宽度 1152 px，底部 y=1168。其他图没有进行位置或身体比例修改。raw 保持所有原始生成尺寸与透明度。

`validation.txt` 的 PASS 仅证明画布、二值 alpha、非空和透明背景，不代表下面的严格美术要求已通过。

## 明确保留的限制

这套是动作姿势原画，**尚未通过可直接导入游戏的严格动画验收**：

- 生成器没有保证从(0,0)开始的全局16px网格，部分动作像素密度更细。
- 头部外观相近，但未达到所有帧逐格复用同一张脸；后仰图尤其有头部朝向变化。
- 身体、腿和手臂没有严格沿每个骨架关节点落位，各动作的长度、粗细、镣铐尺寸和脚底高度存在变化。
- 四张跑步画面是关键姿势原画，尚不能视为已验证平滑、稳定缩放的跑步循环。
- 倒地图保留可见脸部，身体呈贴地俯卧支撑，与完全松软趴倒仍有差异。

因此 **16 张文件齐全，不等于骨架、网格和一致性要求全部完成**。manifest 中的 `grid_verified`、`head_pixel_identity_verified`、`rig_alignment_verified` 均为 false，避免下游误当作已经验收。
