# 克格莫第 1 步：游戏尺寸造型比较稿

日期：2026-10-09（Asia/Tokyo）。本轮沿用新包中选定的原画 A，只交付静态造型，不制作动作或安装模组。

## 交付文件

- `kogmaw_design_1.png`：1024×1024，正常触角版，严格 8 倍最近邻放大。
- `kogmaw_design_2.png`：1024×1024，触角区较短的比较版。
- `kogmaw_design_1_1x.png`、`kogmaw_design_2_1x.png`：128×128 原尺寸透明画布。
- `comparison.png`：浅色背景上两版 6× 与 1× 比较预览，不是游戏加载资产。
- `generator-originals/`：三次生成器直接返回的 PNG，未缩放或修改。`kogmaw_design_1_final_raw.png` 是采用的粗像素源；之前两张为过大而未采用的草稿。
- `palette.json`、`palette.png`：24 色限制色板；最终两版实际用色分别为 19、18 色。
- `qa.json`：读取最终文件后的尺寸、包围盒、颜色与透明度检查。
- `generation-prompts.txt`：实际提示词和修订过程。

## 取格方法与剩余差异

采用生成器原稿的方块网格（约 18.25 输出像素一格，原点约205,379）逐格中心取样，每格对应一个游戏像素，没有把插画均匀缩小或平均混色。取回源为46×42格。版本1整行删除源第6、7、13、40行以达到38格，脸和眼睛区域没有删行。统一映射到所附色板，并最近邻放大8倍。

版本2从版本1删除触角区第4、5、6、7行，放回同一脚底线，所以下部身体与版本1保持一致。**此比较版尚未满足“四根触角各自都短4格”的完整条件**：两根高触角缩短4格，两侧触角受到的压缩不同。它可用于比较整体38/34格高度，不应被标为全部规格通过。宽度46格，也略大于约44格的参考目标。

生成稿不是严格人工像素格，取格原点和步长为视觉估计；保留全部生图，便于复核。后续动作帧应基于用户最终选定并修正的1×造型，不应重新生成另一种身体。
