# 崔丝塔娜特效交接

交付：19张独立命名PNG，共102帧；全部使用内置 image_gen 生成。本包按原需求允许的“生图原稿”交付，供Claude缩小、收色、定位并导入。原始PNG未用代码重画或改色。参考的英雄联盟贴图仅在本地查看，未收入交付包。

## 切图与预览

- 以 `manifest.json` 的 `assets[].frames[].rect = [x,y,宽,高]` 为准，坐标为交付PNG的实际像素。不能直接按原提示词总尺寸切图。
- 为避免长条挤帧，多张图改为分行排版；下表给出列数、行数和帧数。均先左到右，再到下一行。未使用的末格不导入。
- 炸弹标记为4行2列：每行一个独立层数状态，0/1/2/3层分别对应 `league_tristana_e_bomb0` 至 `e_bomb3`；各行两帧，每帧5tick，别把8帧串播。
- `preview.html` 可离线打开，提供透明棋盘/深色/游戏绿背景、逐帧和循环播放；显示使用真实alpha。展示帧时长仅用于预览，除炸弹标记外原需求未指定游戏帧时长。
- `target_game_size` 是原包的导入尺寸建议，PNG目前仍是大图原稿。飞行图朝右，E炮口向右下；地面圈不旋转。
- 炮口、蒸汽等 `attachment_hint_px` 是绘制参考挂点，不是已校准的游戏 `y_offset`。请按实际动作出手帧量炮口后调整。

## 尚未达到严格成品标准的部分

这些PNG含半透明边缘和超出指定色板的近似色，不是已经收好色、严格8倍整数格的游戏成品。`validation.json` 如实记录每张的透明度和颜色数量。请导入时先正确读取RGBA，再下采样、硬化alpha、映射原包色板；不要丢弃alpha后把透明区RGB里的光晕当作背景。局部粒子、烟雾上下并非逐像素对称；最终旋转、循环衔接和人物遮挡尚需游戏验证。

尺寸矛盾：原第16条R炮弹写4帧、每格384x256，却把总宽写1152；本次优先保留4帧和3:2单格比例，实际采用2x2排版。

普攻炮口重排图的格界有低透明残线；manifest选区避开格界，原稿仍保留。所有坐标在图内、有效帧非空已检查，不能据此宣称已通过游戏内视觉验收。本次未修改游戏目录或导入技能设置。
