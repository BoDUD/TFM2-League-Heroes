# 小炮跑步腿部重画 V2

只替换胯线以下的双腿，原图胯线及以上 RGBA 逐像素一致；炮身伸到胯线以下的像素也原样保留。按反馈采用原生像素机械绘制，没有再次调用生图模型。

- 近腿亮棕绑腿、浅紫脚；远腿深棕绑腿、暗紫脚。近腿在远腿前，炮在两腿前。
- 1、8 帧近腿着地，4、5 帧远腿着地；2/6 膝盖交叉，3/7 前后腿身份互换。
- 着地脚底为第 81 行；腾空脚底为第 77/78 行，离地 4/3 格。
- 保留原来八帧的格子、站位、上半身起伏与 933 ms 总时长。
- 输出 3072×1536，4×2 格，每格 768×768；原生 384×192，每格 96×96。

脚本已验证：上半身全分辨率 100% 一致，26 色板以内，透明度只有 0/255，严格最近邻 8 倍，脚底线下零像素，每帧一个八邻域连通块，两腿都有可见脚部。详细数据见 validation.json。bbox 使用右/下边界不包含的 xyxy，格子 rect 使用 xywh。

previews/preview.html 按 manifest 时长播放，可暂停逐帧看；GIF 受格式限制按 10 ms 精度播放，仅供预览。before_after.gif 左旧右新。
