# 崔丝塔娜待机模型交付

依据用户“更像英雄联盟”的要求，参考素材包中的原模型与旧精灵重绘。强化白色蓬发、黄铜红框浅蓝镜片、双侧粉色尖耳、琥珀眼睛、淡紫肤色、皮革与橄榄绿衣装，以及横端的木质黄铜炮身和蓝灰喇叭炮口。

## 文件

- `tristana-A.png`：整理后的透明像素模型，1024×1024。
- `raw/tristana-v1.png`：第一轮生成原图，未经修改。
- `raw/tristana-v2.png`：双耳修订原图，未经修改；作为最终模型来源。
- `generation-prompts.txt`：两轮实际提示词及网格整理参数。使用内置 image_gen。
- `HANDOFF.md`：本说明。

## 检查与适配说明

最终图通过尺寸、alpha 仅 0/255、11×11 单色方块网格及脚底以下透明检查。有效范围为 x=187..835、y=400..960，高 561px，51 格。已查看最终图，白发保留、双耳可见、炮口朝右、双脚及完整武器可见，无地面、阴影或特效。

生成器没有严格遵守画布大小和硬透明要求，因此最终图由第二轮原图进行最近邻逐格采样和硬透明整理；这与包内“原图不缩放”建议存在差异，故同时保留两轮原图供后续取用。外描边并非所有部位严格两格，内部每种材质也未限制为固定 3–4 色；这些不作为已通过项目。重绘保留原站姿与持炮方向，但轮廓和头部比例不是旧精灵逐像素描摹。

这是单张待机模型设计图，不是完整动画包或已安装游戏模组。未修改 D:/TFM2-Workshop 项目及已安装模组，未做动作、技能、头像裁切或游戏内验收。后续动作应以此同一模型为基础制作，并单独检查最终游戏缩放、持炮出手点和各 UI 裁切。
