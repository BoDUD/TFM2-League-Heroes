## 检查结果
八张图的尺寸、硬alpha、非空与9px网格检查通过。但靴尖位置未达到±2格要求，因此没有生成 vander_run_done.zip，也不能称为通过跑步验收的最终帧。支撑靴普遍太靠右，部分抬脚高度与参考不一致，人物头和身体的摆动也不是逐关节完全匹配。第8帧两腿重叠，解剖腿归属仍有目视不确定性。

靴尖测量使用人工确认的靴子区域，沿参考的“脚跟到靴尖”方向取最前的不透明轮廓格，未用最近目标点冒充实测。参考数据中的骨骼toe关节与可见鞋头轮廓可能不是同一位置，本包按说明要求记录的是可见轮廓。必须再对照图核验，不能只把validation中的位置当成完美标注。

原稿按定稿配色取格，前景颜色投票与alpha覆盖分开处理；输入alpha阈值128、35%覆盖保留，输出alpha仅0/255。纵向/横向画布不同的生图只做整张等比适配，然后统一整帧地面；没有变形单独关节。1176不能被9整除，完整9px网格把最低点放在1179，比地面线低3px，已记录。
