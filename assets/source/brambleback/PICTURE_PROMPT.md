# 绯红印记树怪（金铲铲之战 · 第 18 赛季）：第 0 步，先画像素风原图（给 Codex 的提示词）

> 绯红印记树怪是金铲铲之战第 18 赛季的四费卡（峡谷野怪 / 狂战士），技能「猩红之怒」：**就是英雄联盟峡谷里的红 buff 树怪**。这一步画两张，**格子大小一样**，用户从里面选一种做游戏造型：
> - **身子**：一头**弓着背、四肢着地的树皮巨兽**，像一只大猩猩：**深红褐色 / 深咖啡色的厚树皮**（3–4 档），身子由一块块棱角分明的树皮甲片拼起来；**两条前臂又长又粗**，撑在地上，**前爪是三根又大又尖的红橙色爪子**（爪尖最亮），比脑袋大；**两条后腿短而粗**，脚上也有小一些的红爪。
> - **红色纹路**（附图 1、2、5）：树皮甲片上**刻着发光的暗红色裂纹和螺旋纹**（前臂、肩膀、后腿上最明显），用亮红 2 档画成细细的线条和小螺旋，不要密密麻麻。
> - **树叶领子**（附图 1、2、5）：脖子和肩膀上**一圈绿色的大树叶**，锯齿边，像一圈毛领子，是全身唯一的绿色，**3 档绿**。
> - **背上的枝杈和红核**（附图 1、5、8）：背顶上**几根弯弯曲曲的深色树枝**往上翘、往后卷，像鹿角一样，**树枝的内侧是亮红色**；树枝中间透出**一团发光的红橙色核心**（红 buff 的火种）。发光只是**亮红到橙色平涂 2–3 档**（最亮一档近黄的橙），不要光晕、不要柔光。
> - **头和脸**（附图 3、6 特写）：**一颗不大的树皮脑袋**，**低低地压在树叶领子下面、身子最前面**，形状像一个往前尖的**楔子 / 鸟喙**（下巴往前伸）；**额头上一个发光的橙色螺旋纹**；**两只发光的红橙色眼睛**，斜斜的、凶狠，在额头两侧——这就是它的脸，是全图最好认的地方。没有嘴缝、没有鼻子。
>
> 请 Codex 画**两张**（**格子大小一样**）：
> - **A：待机，3/4 朝右**（金铲铲原样待机，附图 1、2、10a）：四肢着地弓背蹲着，两只长前臂撑在身前两侧，近处（画面右边）那只前爪离我们近、在前面，远处那只在后面；脑袋低在树叶领子下面，两只红眼朝右前方；背上的树枝和红核在最上面。**比高宽**。
> - **B：同样的待机，正侧面朝右**（附图 4、6、10b）：还是四肢着地弓背蹲着，但**侧过来**：近处的长前臂往前伸撑在地上，后腿在后面，背上的树枝在最上面，脑袋在前面、低在领子下，**红眼朝右、清楚可见**。
>

> - **脸要清楚**（附图 3、6 特写）：树皮脑袋 3 档（额头最亮）；**每只红眼至少 2×1 格**，一格近黄的高光；额头的橙色螺旋 3–4 格；绿叶领子紧压在脑袋上面。

> - 不画任何技能特效（火焰、灼烧、红光、爪痕、扑击的拖影、咆哮的声波都放到后面单独画）；不画地面，不画投影。

## 后面要用到的动作（这一步**不画**，只是让你画造型时心里有数）
