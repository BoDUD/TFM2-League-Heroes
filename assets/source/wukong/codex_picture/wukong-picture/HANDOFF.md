# 悟空像素造型交付

本次按素材包的第 0 步制作两张二维像素风角色造型参考图。不是带骨骼的三维模型，也不是已接入游戏的动画精灵。

## 文件

- wukong-A.png：展开手臂、斜持金箍棒的待机造型。
- wukong-B.png：收拢手臂、竖持金箍棒的备战造型。
- raw/wukong-A-original.png、raw/wukong-B-original.png：生成器原始 PNG，未经后处理；当前交付图与原始图一致。
- generation-prompts.txt：实际执行的提示词与参考图列表。

使用内置 image_gen，设置 transparent_background=true。仅使用素材包参考图及本次生成的 A 图作为参考。

## 检查结果与限制

两张均为 1254×1254 RGBA PNG，透明通道包含 0–255，因此有真实透明背景，也有半透明边缘。生成器没有遵循提示词中的 1536×1536 尺寸、严格 11px 网格及全硬 alpha 要求。构图也没有严格落在指定地面线；不能直接按 11px 格子读回游戏。未通过程序缩放、抠图或重绘来掩盖这些偏差。

目视确认 A/B 姿势有区分，具有棕毛、尖发、绿色眼睛、红围巾、金红护臂及银灰圆章、金色前襟、暗色裙摆、紫鞋和上翘尾巴。三分之四视角下两眼大小并不完全相等，部分细节与原版存在生成差异。

后续用于游戏时，应先选定造型，再以实际游戏分辨率重绘统一网格、硬边透明和动画帧。本包是造型草案，尚未达到素材说明中逐格导入的生产标准。
