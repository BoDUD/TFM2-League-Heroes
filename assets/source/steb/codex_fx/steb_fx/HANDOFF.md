# 斯特卜特效与技能图标素材

交付13条特效序列、共79帧，以及3个64×64技能图标。全部美术由内置 image_gen 生成，随后从原稿提取像素、按指定色板归色、统一硬透明、逐帧对齐并整理为横向表；未使用代码创造替代特效形状。

## 文件
- `steb_fx_*.png`：8倍最近邻放大的透明横向序列表。
- `pixel_1x/steb_fx_*.png`：真正游戏像素尺寸的横向表，直接按 manifest 的 cell_1x 切帧。
- `steb_icon_skill.png`、`steb_icon_skill2.png`、`steb_icon_ult.png`：64×64图标，2px方格。
- `raw/`：选用的原始生成图，原样保留。
- `generation-prompts.txt`、`generation-repair-a_hit.txt`：实际提示词及普攻命中特效的重画记录。
- `manifest.json`：每条的帧数、cell_1x、对称方式、循环标记、来源与尺寸。
- `validation.json`：透明通道、尺寸、8倍对应关系、逐帧左右对称、帧非空和帧差异检查。
- `reference-fx-list.json`：参考包原始绑定清单。
- `preview/`：深色底逐条GIF和总览；预览底色没有写入透明素材。

## 整理说明
生图时将极宽的原始横条要求改成规则接触表，以避免生成器的宽度限制，最后再打包为指定帧数的横向表。原稿不保证原生方格与最终游戏像素一致。每帧以左侧作为权威半边反射，最终颜色和透明度逐格严格左右对称；半透明光晕经提取变为硬边像素。护盾原稿的外侧列有内缩，已按实际椭圆中心重新取框，避免镜像时收成一条竖线。

普攻首版混入治疗十字，已拒绝并重画为纯青金冲击闪光。技能图标是生成图缩采到32格再2倍放大，细节会简化。

技术检查已通过。视觉上与参考的具体十字数量、齿轮数量、闪烁相位和单个光点位置仍是近似，未声称逐格复制原特效。源稿部分带柔光，最终以 pixel_1x/ 的硬透明提取版为准。本包没有做游戏绑定、运行时技能机制或实机测试。
