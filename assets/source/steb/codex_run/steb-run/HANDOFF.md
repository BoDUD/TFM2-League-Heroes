# 斯特卜八帧跑步素材

交付 `steb-run-run1.png` 至 `steb-run-run8.png`，均为1254×1254 RGBA、9px方格和硬透明。`raw/` 为最终选用的生图原稿；`generation-prompts.txt`、`generation-repairs.txt` 保存实际提示词。角色由 image_gen 画出，程序只整理已有图的网格、透明通道与整格锚点。

run4、run7 已重画为较窄的交叉姿态。run1、2、3、8 使用较暗的前侧远腿，run5、6 使用较亮的前侧近腿。run3 的一次修色生成出现三条腿，已拒绝并定向重画；错误图没有进入交付目录。最终八帧已重新目视检查：每帧两条腿、两只靴子。见 `rejected-generations.md`。

`steb-run-preview.gif` 是深色底循环预览，帧时长为135/102/102/102/102/102/102/135ms，总880ms，采用参考包后面的明确导入时长；不是文档开头的1.30秒。`contact-sheet.png` 是整套对照图；`boot-grid-review.png` 是带坐标的腿部检查图。

**严格参考对齐未通过。** 最终脚尖位置与 feet.json 的部分偏差明显超过2格，交叉帧的靴尖也没有完全上下对齐；上半身和头部逐格一致性尚未得到证明。`validation.json` 提供从诊断网格手工读取的近似实际坐标、参考坐标和差值，没有将参考数值冒充实测，也没有把数量/网格通过当作动作完全通过。因此本包可作为齐套的动作源素材，但不能标记为严格坐标验收通过的最终游戏跑步动画。

`reference-feet.json` 是用户提供的原参考数据，`manifest.json` 是文件与来源记录。最低点优先使用1179（与要求1176相差3px）以保持9px网格；原稿不会被覆盖或删除。本包没有修改游戏工程或完成实机检验。
