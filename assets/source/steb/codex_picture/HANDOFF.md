# 斯特卜 A / B 像素造型交付

本次范围是参考包第 0 步的两款角色造型；不是游戏动作全集或已安装的游戏模组。参考文档中的后续 Claude 工作流只作为背景，未执行仓库修改、安装、发布或技能制作。

## 文件
- `steb-A.png`：站立待机，远手扛肩警棍、近手竖直向下的警棍。
- `steb-B.png`：双腿分开蹲姿，双警棍横持。
- `raw/steb-A-raw.png`、`raw/steb-B-raw.png`：原始生成图，原样保留。
- `generation-prompts.txt`：实际成功调用的提示词和参考图对应关系。使用内置 image_gen，未使用 API CLI。
- `packing-report.json`：原图尺寸、主体包围盒、打包网格与位置。
- `validation.json`：最终 PNG 的尺寸、透明通道、网格一致性验证。

## 技术规格与检查
最终 PNG 为 1536×1536 RGBA，每格 11×11 像素，透明度仅 0/255；没有背景、地面线、投影和技能特效。A 主体包含武器共 40×54 格，B 为 50×40 格；脚底线 y=1386，距底部 150 像素（接近参考约 146）。角色、背包、武器、靴子均在画布内。

原图实际是 1254×1254，有半透明边缘，且生成器没有遵守严格 11px 网格。因此最终图使用确定性的格点采样与硬 alpha 打包；没有新增几何替代身体。原图不能声称原生 11px 像素画。B 为控制宽度至最多 50 格，横向进行了较小幅度压缩。

视觉核对：保留浅海绿脸、青绿飞机头、鱼鳍耳、蓝金制服、浅色胸甲、棕色药包/背带/背包、灰紫长裤、墨绿金环长靴、双警棍。未逐像素保证每材质仅 3–4 色、全轮廓恰好 2 格、每眼至少 2×2 格及两耳都清楚外露；小尺寸中部分眼睛、棍把与鳞片细节简化。这些属于严格美术规格的剩余偏差，不应把本次交付标记为所有细节验收通过。

后续若接入游戏，需先确定 A/B 与游戏 PPU，再做动作帧、动画契约、UI/战斗尺寸和实机验证。本次没有改动既有工程或声称已完成这些验证。
