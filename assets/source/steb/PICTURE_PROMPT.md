# 斯特卜（金铲铲之战 · 第 13 赛季）：第 0 步，先画像素风原图（给 Codex 的提示词）

> 斯特卜是金铲铲之战第 13 赛季的一费卡（执法官 / 格斗家），双城之战里皮尔特沃夫的**鱼人执法官**，背着急救背包的**战地军医**：一个**高个、瘦长结实的年轻男人**，**皮肤是浅海绿色**，**耳朵是尖尖的鱼鳍耳**。这一步画两张，**格子大小一样**，用户从里面选一种做游戏造型：
> - **头**（附图 3、6 特写）：**青绿色（蓝绿）的头发往后梳成高高的飞机头**，两侧剃短；**脸是浅海绿色**，下巴尖、脸长，**脸颊和眼角下有几颗青色的小鳞片斑点**，**眼睛周围一圈淡淡的暗红色**，**浅青色的眼睛**，眉毛细、颜色深一点，**嘴唇偏紫**，表情平静、有点疲惫；**两只鱼鳍耳朝两边尖尖地伸出去**，是绿色的。
> - **身上**：**皮尔特沃夫执法官的蓝色制服**：**金边的高领**、**肩上一对蓝色带金边的大肩甲（里面一块暗红色）**；胸口是一块**浅薰衣草色 / 奶白色的胸甲**；胸前挂着**一排棕色皮质小药包**和交叉的**棕色皮背带**，带金色扣；**深棕腰带 + 金扣**，腰两侧挂**棕色皮小包**；下摆是蓝色的短衣摆，金边；**灰紫色的长裤**；**深墨绿色的手套**和**深墨绿色的高筒靴**，靴口和脚踝有**金色的环**。
> - **背包**（附图 5、8，**很显眼**）：背后一个**很大的棕色皮背包**（比他的上身还宽一点），几道深棕色的皮带和金色扣，侧面挂着小袋子——战地军医的急救包。
> - **两根警棍**（附图 4，**手里的武器**）：一对**带侧把手的警棍（拐棍 / 托法棍）**：**蓝色的钢管**，一头是**黄铜色的粗头、上面有发光的青色符文**，另一头是**细一点的银灰色钢杆**，中间伸出一根**木头色的侧把手**，把手末端也有一点青光。
>
> 请 Codex 画**两张**（**格子大小一样**）：
> - **A：待机站姿**（附图 1、2、10a）：**3/4 朝右**，站直、两脚分开与肩同宽；**远处的手（画面左边）把一根警棍扛在肩上**，棍子横在肩后、往左上方伸出去；**近处的手（画面右边）握着另一根警棍，棍子竖直朝下、杵在脚边**；背包在背后露出一大块；眼睛看向右前方。
> - **B：战斗蹲姿**（附图 7、10b）：**3/4 朝右**，**两脚大大分开、深蹲**（前脚在右），身体前压；**两手握着警棍平举在身前**，棍头朝右前方；背包在背后；眼睛盯着右前方。
>

> - **比例**：Q 版人类，**头约占身高的三分之一**（脸要大、要清楚，飞机头算在头里），身材修长但结实；**背包和警棍要认得出来**，但别画得比他本人还大。
> - **脸要清楚**（附图 3、6 特写）：脸浅海绿色 3 档；**两只眼睛一样高**，每只至少 2×2 格，浅色眼白 + 浅青色眼珠，眼睛周围一点暗红；**脸颊上 2–3 颗青色鳞片小点**；嘴是一道偏紫的短线。**鱼鳍耳**每只至少 3 格长，尖朝外。**青绿色飞机头** 3 档。

> - 不画任何技能特效（治疗的绿光、护盾、通缉标记、警棍的打击光都放到后面单独画）；不画地面，不画投影。

## 后面要用到的动作（这一步**不画**，只是让你画造型时心里有数）

客户端里有斯特卜自己的动作（我已经按动作片段渲染出来了），所以造型里这些部件要**画得清楚、彼此分得开**：一张脸用在所有帧、两根警棍（扛肩、朝下、平举、挥击、砸下）、两只手、两条腿（跑、深蹲）、背后的背包（大招要打开它）。
