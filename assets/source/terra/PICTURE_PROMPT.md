# 泰拉（金铲铲之战 · 第 7 赛季）：第 0 步，先画像素风原图（给 Codex 的提示词）

> 泰拉是金铲铲之战第 7 赛季（巨龙之巢）的五费卡（巨岩龙 / 龙神），技能「地震」：**一头四条腿着地的大地巨龙，身上披着岩石，待机时趴伏着、翅膀收在身体两侧**。这一步画两张，**格子大小一样**，用户从里面选一种做游戏造型：
> - **身子**：**四条腿着地**，身子低低地趴伏、往前探，像一头准备扑过来的野兽。**头、脖子、肩膀和背上盖着一大片一大片的岩石甲板**（灰绿 / 鼠尾草绿的石头，亮面近米白，暗面偏深橄榄绿，石缝里长着**几块苔藓绿**）；甲板边缘是尖尖的、往后翘的石片，像一排排石刺。**肚子、四条腿和尾巴是红褐色的皮**（深咖啡到红棕，3 档），腿粗壮，**爪子是深褐色的大弯爪**。
> - **翅膀**（附图 1、5、7）：**两只大翅膀收在身体两侧往后折**，翼骨是**米白 / 浅灰褐的石头**（像一根根石头骨架，节节分明，边上带尖刺），骨架之间是**橙色的翼膜**（橙到深橙，里面有一格格更深的橙色网纹）。收起来时，翅膀从肩膀往后、往上折成几道尖尖的石骨，橙色翼膜从石骨之间露出来。
> - **尾巴**（附图 9）：细长的红褐色尾巴拖在身后，**末端是一簇张开的灰绿色石刺**（像一把石头扇子 / 一只石爪）。
> - **头和脸**（附图 3、6 特写）：头**像一块棱角分明的岩石**，往前探、口鼻长，灰绿石色；**眼睛是发光的亮黄色**（黄到金黄，中间亮一格近白），眼眶上压着一道石眉，表情凶狠；**嘴张着，上下两排白色 / 米色的尖石牙**，嘴里是深色；两颊和后脑往后长出一排尖尖的石片（像腮 / 头冠）。
>
> 请 Codex 画**两张**（**格子大小一样**）：
> - **A：待机，3/4 朝右**（金铲铲原样待机，附图 1、2、10a）：四条腿着地趴伏，头低低地往右前方探，脸朝右前方，嘴微张露出石牙；两只翅膀收在背上往后折，橙色翼膜露在石骨之间；尾巴拖在左后方，末端的石刺扇子在最左边。比高宽得多。
> - **B：同样的待机，正侧面朝右**（附图 4、6、10b）：还是四条腿趴伏，但**侧过来**，能更清楚地看到**长长的岩石脑袋、发光的黄眼、两排石牙、背上一排排的石甲和石刺、收起的石骨翅膀和橙色翼膜、红褐色的腿和大爪、拖在后面的尾巴和石刺尾端**；近处的眼睛清楚可见。
>

> - **脸要清楚**（附图 3、6 特写）：灰绿的岩石脑袋 3 档；**亮黄色的眼睛**至少 2×2 格（近处那只更清楚），中间亮一格（近白）；石眉压在眼睛上方一道深色；**两排石牙**一格一格分得开（米白，2 档），嘴里深色；两颊的石片 2–3 片看得清。

> - **像素块**：大小一致的方块，**每块 11 像素**，横平竖直对齐成网格；**外轮廓一圈 2 块宽的近黑描边**；每种材质内部 3–4 档平涂，不要零散的单个杂色格。暗处用这种材质自己最暗的一档，不要一圈黑。**岩石甲板**画成几大块（每块亮面 / 暗面分明，石缝一道深色线），不要碎点；**苔藓**只是几小片成块的绿色；**橙色翼膜**是连成片的大面，网纹最多几道。
> - 不画任何技能特效（地震、裂缝、碎石、尘土、光圈、闪光都放到后面单独画）；不画地面，不画投影。
