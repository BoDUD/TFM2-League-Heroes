# 远古巨龙（金铲铲之战 · 第 18 赛季）：第 0 步，先画像素风原图（给 Codex 的提示词）

> 远古巨龙是金铲铲之战第 18 赛季的五费卡（顶级掠食者 / 峡谷野怪），技能「绝伦火热」：**就是英雄联盟峡谷里的远古巨龙**。这一步画两张，**格子大小一样**，用户从里面选一种做游戏造型：
> - **身子**：一条**四条腿着地的大翼龙**，身子压低、前高后低，**脑袋低低地伸在前面**；四条细长有力的腿，脚上是**黑色的弯钩大爪**。皮是**深石板灰 / 靛紫色**（3–4 档），肚子偏**深青色**；背上、翅膀骨和尾巴上一排排**发青色光的水晶尖刺**（亮青到白，像荧光的尖片）。
> - **脖子和胸口**：一大团**白色 / 银灰色的水晶鳞片鬃毛**（像一片片尖尖的白色晶体叠起来，3 档），从后脑勺一直盖到胸口，是全身最亮的一块。
> - **头和脸**（附图 3、6 特写）：脑袋不大、往前伸，**深色的尖嘴（像鹰嘴一样的上颚）**，**两侧各一只往后弯的蓝色大角**（贴着下巴往后上方弯）；**整个下巴和嘴里是发青色光的一大块**（亮青色，里面一排白色尖牙），**两只小小的青色发光眼睛**在嘴上面；下巴底下垂着一圈白色晶刺。**这张发青光的嘴 + 两只弯角 + 白色晶体鬃毛**是全图最好认的地方。
> - **翅膀**：两只**很大的蝙蝠翼**，翼膜**深紫色**，翼骨末端和每根翼指尖都是**青色发光的爪尖**；待机时**半张开、往上往后举着**（附图 1、4）。附图 7 是翅膀收起来的样子，附图 8 是翅膀高高举起来的样子，**只看翅膀的形状**。
> - **尾巴**：一条**很长的细鞭尾**，末端是一把**扇形的尖刺**（黑色 + 青色尖）。
>
> 请 Codex 画**两张**（**格子大小一样**）：
> - **A：待机，3/4 朝右**（附图 1、2、10a）：四条腿撑地压低身子，脑袋在前面（画面右边）低低地往前伸，**发青光的嘴和两只弯角朝右前方**，白色晶体鬃毛盖着脖子和胸口；两只大翅膀半张开往上后方举着（远处那只在后面露出一部分）；长尾巴在身后（画面左边）**往上卷起来**，别平拖在地上。近处（画面右边）的前腿在前。**比高宽**。
