# 赛芬（金铲铲之战 · 第 7 赛季）：第 0 步，先画像素风原图（给 Codex 的提示词）

> 赛芬是金铲铲之战第 7 赛季（巨龙之巢）的四费卡（幽影龙 / 格斗家 / 龙神），技能「暴走」：**一头用两条反关节腿弓着身子直立的飞龙（双足翼龙），他的两条前臂就是翅膀**。这一步画两张，**格子大小一样**，用户从里面选一种做游戏造型：
> - **全身**：瘦长、弓背、肌肉结实的身材；**皮肤是浅灰 / 灰白色**（亮面近白的浅灰，暗面中灰，3 档）；**胸口和肚子上是一排横着的深青黑色肋甲**（像一根根横条，边上亮一点的青灰），**大腿、小臂、小腿上也缠着几道深青黑色的甲带**。
> - **脖子和背**（附图 3、5、6）：从后脑一直到背上，是**一片片往后翘的甲片，颜色从宝蓝渐变到紫色**（像一排鳞甲的背鳍），每片尖端往后上方翘起。
> - **头和脸**（附图 3、6 特写）：头往前伸、比较长，**头顶到口鼻是一整块品红 / 洋红色的头甲**（亮面粉红，暗面深紫红，上面有几道棱），**口鼻前端是蓝紫色**，长长的嘴微微张开，**露出一排白色的尖牙**；**头两侧各一根很大的深酒红 / 暗红色弯角**，带一圈圈的横纹，从头侧往后、往上弯，尖端朝上；额头上方还有一根往后翘的深紫色小尖刺。眼睛在头甲下沿，**一只发光的粉紫色小眼睛**（近处那只要看得见）。
> - **翅膀 = 手臂**（附图 1、2、7、8）：两条**很长的浅灰色前臂**，外侧一排**亮粉 / 洋红色的水晶小尖刺**；**翼膜就长在前臂下面**，**紫色到品红色**（上深紫、下亮品红），被几根深色的翼骨分成几条，**翼膜下缘每根翼骨尖上有一个弯钩**；手的位置是**三根深钢蓝色的弯钩利爪**。
> - **腿和尾巴**：两条**反关节腿**（大腿浅灰，膝盖往前、脚跟抬起），缠着深青黑色甲带；**脚是深紫黑色的三趾利爪**；**一条很长的尾巴**，上面是一节节深青黑色的甲片和尖刺，**尾巴尖是一把弯弯的浅钢灰色刀刃**。
>

> - **A：直立待机，3/4 朝右**（金铲铲原样待机，附图 1、2、10a）：弓着身子站着，两腿分开、膝盖微弯；**画面左边那条翅膀手臂抬起来收在身后**，翼膜像斗篷一样往下垂，下端露出钢蓝利爪；**画面右边那条手臂往前下方垂着**，利爪张开；尾巴从两腿之间往后拖到左下方，刀刃尾尖翘起来。
