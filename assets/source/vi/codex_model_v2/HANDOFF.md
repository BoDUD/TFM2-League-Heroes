# 蔚新造型主稿交付

用户明确选择“保留这张认可的造型与细节，先交主稿”。本包按该选择交付A主稿及一张可选脸部微调，不继续把人物压到38–40格，也不把B/C替代稿当成已选造型。

original/vi_approved_master.png 与用户称赞的附件SHA256完全相同，原图1254×1254，完整保留。根目录vi_design_A.png 是原方块读回、色板整理后的1024×1024版本；逻辑画布128×128，每格整数8倍，人物43格宽、59格高，脚底第99行，中心列64。它不是38–40格游戏定稿。源图网格自动估计约12.65×12.175原图像素，各原有方块只读一格，没有删行或把59格身体缩到40。

造型由原生imagegen生成，oppi仅提供头肩连接、紧凑躯干和拳击架势的结构参考，没有复制其像素。代码只读原方块、映射本方32色色板、平移整个人、整数8倍导出，没有画或拼装身体。原图作为外观基准；读回版会舍去边缘抗锯齿与方块内细小颜色变化，不等同于原图每个像素。

vi_design_A_face.png 是可选嘴型微调：先以imagegen修改眼睛/嘴巴，最终保留主稿已有眼睛，仅在相同原方块网格读回生成稿的闭合红色唇像素。其余像素与A读回版逐像素相同。它未获得用户选择，默认仍以vi_design_A为主。第一张脸部生图画了细线眼嘴，不采用。

检查结果见audit/validation.json。导出尺寸、8倍方块、二值透明、色数、脚底线与原稿身份检查通过；38–40格检查明确为未通过，按用户选择延期。没有导入游戏，暂未重做动作条。本包包含实际生成提示词、原稿、逻辑版和对照预览。
