# 蔚造型交付说明

本轮只制作静态造型 A/B。附件中的造型提示词用于制作参考，未执行其面向 Claude 的后续导入流程。

## 文件

- `vi_design_A.png`、`vi_design_B.png`：1024×1024，透明背景，逻辑画布 128×128，每格严格 8×8。角色头顶第 62 行，鞋底第 99 行，总高 38 格。
- 同名 `_1x.png`：游戏大小的逻辑像素图。
- `raw/`：原生工具生成的各轮原稿，供比较和继续修改；原稿不满足最终尺寸、色板、二值透明要求。
- `generation_prompts.json` 和 `final_generation_prompts.json`：各轮实际提示词、参考图记录以及最终选稿和采样参数。使用内置 image_gen，未用桥接或 CLI 生图。
- `manifest.json`：实测尺寸、站位参考点、不透明区域、色板和验证结果。
- `palette.gpl`：整理版共用的 24 色候选色板，单张实际色数见 manifest。

## 整理方法和限制

多轮生图均未稳定遵守 38 行逐格绘制。最终图是从生图原稿的角色区域重新采样，以中心 3×3 不透明像素的通道中位数取色，映射到固定色板，再按 8×8 纯色格导出。它们是游戏尺寸造型草稿，**不是原生逐格绘制的合格成稿**。这与附件希望“按原稿格子读取、不缩小”的要求有偏差。

尺寸、网格、二值透明、最大色数和脚底线可机械验证；这些通过不代表所有造型细节合格。A/B 的脸部眼睛未做到同高同大的 2×2 眼睛；眼睛专用蓝灰、眉毛和嘴的精确像素位置未达到要求。拳套的仪表盘、四指块、拇指和蓝水晶尺寸也未完全达到规定。单圈外描边、头部 11/13 格比例以及所有材质 2–3 阶未逐项通过。本包未做游戏内测试，也未导入游戏。

建议将清楚的原稿作为外观参考，在最终游戏尺寸中继续手工修整脸和拳套，再固定头部模板并进入动作制作。不要将本包当作已通过所有造型验收的动画母版。
