# 蔚 V4 动作原图交接

完成 50/50 帧。每帧独立使用原生图像生成，frames 中的 PNG 是生成器原图的逐字节副本。没有缩放、拼身体、贴头、网格回读、颜色/透明度后处理。

参考造型：reference/vi_approved_master.png；位置参考：reference/vi_scale_guide.png。

## 文件

- frames/：生成原图，仅此目录用于下一步导入。
- previews/：查看动作的缩略接触表和 GIF；仅预览缩放，不能当作导入原图。
- generation_prompts.json：50 帧提示词、每次调用结果、选用版本和检查记录。
- animation_manifest.json：动作、顺序、时长、出手帧与目标站位。
- qa_dimensions.json：实际画布、alpha、轮廓边界及原图 SHA-256。
