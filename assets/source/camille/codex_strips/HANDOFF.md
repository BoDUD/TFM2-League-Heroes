## 制作与提示词

每条使用内置图像生成，附定稿、对应 now、pose，跑步及踢腿另外附 parts。完整提示词按表中动作键保存在 `generation_prompts.json`。Q 第二踢另有针对第三帧的下劈修订提示词；只保留修订输出的第三格，其余格沿用最初生成稿。

生成稿没有直接达到严格 8 像素方块。按 brief 允许的流程读回网格中心、吸附定稿色板、清理二值透明度、放回动画格子；身体来自生成的栅格图，没有用代码重画几何身体或自行拼造服装。头部直接复制原包 `camille_head_1x.png` 的不透明像素，领口复制定稿中的高立领；死亡最后两帧头部转 90 度。普攻、两次 Q、W、E 冲刺与 R 的收尾直接复制定稿待机位图，以便回到同一造型。

## 检查结果

保存后的每张 PNG 已检查：尺寸与 now 条一致，1 倍放大 8 倍逐像素相等，alpha 仅 0/255，颜色均来自定稿 49 色，头部不透明像素与原包一致，眼睛青色在头部之外为 0，人物为一个 8 邻接连通块，空格为空，脚底禁区无越界。帧数、时长与 pivot 对照原包 JSON 一致。跑步头部横向偏移固定，上下变化不超过 2 格。详细结果见 `QA.json`。

`camille_<动作>_preview.gif` 可直接查看动作；GIF 时长单位为 10ms，跑步 125ms 无法在 GIF 中精确表达。`preview.html` 使用原始毫秒时长播放，可暂停和逐帧查看，并按 pivot 将人物居中。灰底和文字仅在预览文件中，透明动作条中没有。

## 未完全做到与使用范围

动作是基于参考重新生成的像素版本，并非英雄联盟原动画逐格复刻。金色电路纹和胸甲明暗在不同姿态中有简化，不能保证每帧服装细节拓扑完全一致；Q 第二踢出手帧仍比原版斧劈更接近弯腰落腿。两腿步幅与前后关系、跑步首尾衔接、细手套可读性需要结合 GIF 和游戏中实际播放继续审阅，数值 QA 不代表这些视觉项目已经完美。

本次交付仅为角色动作源素材，没有加入钩索、刀光、力场等特效，没有改技能数据、导入模组或验证游戏 UI / 战场裁切。导入者应沿用原包 `camille_cells.json` 和提供的出手帧时机，再做运行预览。
