# 芮尔第1步：四稿选稿包

日期：2026-10-16。依据 rell_model_pack.zip 制作。四稿均由内置 image_gen 实际生成，未用脚本逐格画图，也未进行缩放、量化、重网格或alpha修正。Python仅用于读取图片元数据、统计alpha和复制文件。

## 交付文件

- rell-model-A-1.png：骑马第一稿，保留较多甲片结构细节。
- rell-model-A-2.png：骑马第二稿，更粗的色块，双眼更易辨认。
- rell-model-B-1.png：下马重甲第一稿，较细的脸部和甲裙分片。
- rell-model-B-2.png：下马重甲第二稿，更粗的像素块与简化配色。
- raw/：上述四张的未经修改原图副本。
- generation-prompts.txt：四次调用的实际提示词、参考图列表和生成方式。
- verification.json：逐张实际尺寸、alpha取值、半透明像素数量及alpha>=128的主体包围盒；包围盒为左、上、右、下，右下为排他坐标。

## 实际检查结果

四张均为1254×1254 RGBA，有真实透明背景，但均包含1–254的半透明像素，且大部分主体像素也存在半透明，不能视为仅边缘问题。生成器未严格执行1024×1024、12px统一网格、指定头顶/下巴/地面位置，A/B之间的头部大小也未精确统一。四稿均不能直接按12px格读取或直接导入游戏。

| 稿件 | alpha>=128包围盒 | 半透明像素数 |
|---|---|---:|
| A-1 | (20,177)–(1236,1222) | 604812 |
| A-2 | (16,185)–(1228,1219) | 581252 |
| B-1 | (207,76)–(1137,1254) | 501623 |
| B-2 | (274,183)–(1124,1254) | 414023 |

B-1/B-2主体达到画布底边，下方留白不足，需留意靴底/枪尖是否完整。A-1脸部偏侧面，未实现两只同等大小眼睛。A-2双眼更明显；B两稿双眼的尺寸和水平仍需校正。图中的甲片亮边和枪身裂纹可见，但不是严格格数验收通过的最终游戏素材。

## 后续

此包供用户比较造型方向，尚未选定任何稿件。选稿后仍需按实际像素阶梯读回、恢复全不透明主体、对齐A66格/B60格、头部大小、基线和留白，并在真实游戏大小比较。严格网格整理及动作包均未在本次制作。
