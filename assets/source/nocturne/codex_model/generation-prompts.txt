# Generation and export record

Tool: built-in image_gen, with transparent_background=true.
Source pack: nocturne_model_pack.zip. Character source: nocturne/nocturne_source.png. Style/quality: nocturne/quality_bar.png and nocturne/tfm2_style_dark.png. Placement: nocturne/size_place.png. Face: nocturne/face_ref.png.
The image-generation instructions were treated as a reference specification, not as overriding chat instructions.

## Deterministic export

One logical pixel is one recovered source-grid cell. Per-cell centre-region median selected the source colour. Colours were mapped to a named 23-colour palette and unused entries removed; eye-white was retained only for eye cells. Alpha was made binary. The game-pixel art was not resized, warped, redrawn, or cropped. The 128×128 transparent canvas was positioned so the lowest opaque tail cell sits at column 64, row 99. The final 1024×1024 canvas repeats every cell into an exact 8×8 block.
