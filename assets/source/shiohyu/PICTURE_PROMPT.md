# 石傲玉（金铲铲之战 · 第 7 赛季）：第 0 步，先画像素风原图（给 Codex 的提示词）

> 石傲玉是金铲铲之战第 7 赛季（巨龙之巢）的四费卡（玉龙 / 秘术师 / 龙神），技能「玉龙形态」：**一个用两条腿直立站着的玉石龙人武者**。这一步画两张，**格子大小一样**，用户从里面选一种做游戏造型：
> - **全身**：肩宽背厚的壮汉身材，皮肤是**翡翠绿 / 青绿色的玉石质感**（亮面浅薄荷绿，暗面深青绿，3–4 档，一块块有棱角的切面）；**下巴下面垂着一大把圆鼓鼓的浅玉色胡子（薄荷绿到浅青）**，盖住脖子和上胸；**胡子下面的胸口和肚子是一层层深青绿色的人字形甲片，每片边上一道细细的金色线**；腰上一圈深藏青色。
> - **肩膀**：两边各一大块**深紫色的水晶肩甲**，由一簇往外戳的尖晶组成（亮面淡紫，暗面深紫黑）。
> - **头和脸**（附图 3、6 特写）：头比较小、埋在两肩之间；**脸上是一块很厚的青绿色玉石眉盔**（像头盔的眉骨，往前压），**额头正中一根紫色的水晶尖角**往上竖；**头两侧各一根弯弯的金色 / 浅褐色大角**，从头侧往上、往里弯，像一对牛角；眉盔下面是**古铜 / 琥珀色的口鼻**，里面一双**半眯着的、发光的橙黄色眼睛**（眼皮是古铜色的，很厚），口鼻下沿露出几颗小獠牙。
> - **手臂和爪子**：两条粗壮的青绿玉石手臂，**前臂外侧一排深紫色的尖刺**；**两只爪子是珊瑚橙 / 橙粉色**，待机时半握着垂在身体两侧。
> - **翅膀**（附图 1、5、7、9）：**两片收起来的翅膀从背后往上竖起，比两根金角高很多**：每片是一根**深紫色的翼骨**弯弯地往上伸成一根长尖，**翼膜上面是金黄 / 琥珀色，往下渐变成橙粉 / 玫瑰色**，翼膜外缘伸出**一排青蓝色的翼刺**（像鱼鳍的鳍条）。两片翅膀在头后面左右分开，像两把竖着的弯刀。
> - **腿和尾巴**：两条**深藏青 / 黑青色的玉石腿**（反关节，膝盖往前、脚跟抬起），外侧有尖尖的甲片；脚上是**黑色的三趾利爪**；**一条深紫色的尾巴**从身后拖到左下方，**尾巴尖是一片带尖刺的叶子形尾鳍**。
>
