## 每张采用的生成方案

全部使用定稿造型、当前 now、当前 zoom 和位置 guide 的四张参考；通用提示词加本轮逐帧全身动作。跑步沿用英雄联盟 8 帧的高踢、换脚和整体弹跳；普攻保留单脚与双臂甩开；Q 是大弓步双掌前推；W 是俯身后伸掌；E 是上举再挥下；R 是合掌与鼓起裙片；死亡是跪下后向右扑倒。

Q、W 初稿混入原版的大号弯骨饰，追加图像编辑移除大骨饰并恢复小象牙饰片。普攻、E 初稿胸腰偏窄，追加图像编辑加宽身体、手臂和裙片，保持原动作。具体文本分别在三个提示词 JSON 中。

## 技术整理与验证

生成器原稿的画布尺寸和物理像素网格未完全遵守要求。因此每组动作按首帧 42 格高计算一个统一的整人比例，全部帧用相同比例整理，并整体平移到站位与脚底线；未单独缩放头、压缩躯干或改变手脚姿态。原稿两行的分界按透明空隙定位，避免脚尖/饰物越过名义中线而被错切。随后按目标格取多数颜色、映射定稿色板，输出严格 8 倍方块。

46 个新帧的透明度均为 0/255，所有不透明颜色属于定稿色板，脚底以下没有像素。8 张输出精灵条全部逐像素核对对应的 8×8 原生色块；E、R 末格为空。8 个 GIF 的实际动画帧数均已读取核对。播放页 JavaScript 已通过语法检查，未进行浏览器自动化交互测试。

## 仍需审阅的差异

1. **头部是生成绘制，不是定稿像素的复制。** 发型、额饰、眼睛、玉环有逐帧差异。整人运动保留，但不能宣称头部逐格一致。可查看头部序列图；后续统一眼睛时应跟随每帧头的位置。
2. 小骨饰的数量、形状和位置有变化；部分帧饰片偏大或比四片多。头/腰饰物的区分仍不完全等同定稿。
3. 身体比例已有修正，但某些单脚/俯身帧仍更窄；面积并非始终与定稿相同。部分后腿色块过暗，尤其 Q 上步帧会像深色长袜，需复核是否改成光腿。
4. 全身姿态参考了原版，但不是严格逐关节复制。跑步左右腿的辨识、前后高踢和首尾衔接，Q 双掌与裙片高度，W 前俯幅度，E 后仰幅度，仍需并排检查。
5. 死亡末帧为头在右的卧倒姿态；第 3–8 帧落地的玉环和骨饰位置仍有偏移，未为了锁定饰物而脚本拼装部件。
6. 宝石、双眼和掌心坐标大部分由色块估计，不能直接视为最终引擎锚点。死亡第 8 帧宝石 [74,60] 已人工核对；双眼闭合或遮挡，坐标留空，未编造可见眼点。其余估计也须人工核对后再用于贴眼或特效定位。
7. 本轮没有导入游戏、修改技能时机或运行游戏模拟。

建议先用播放页和并排 GIF 审阅全身协调性，再处理眼睛、小骨饰和上述局部差异，最后进行游戏导入与出手 tick/头像/血条空间测试。
