# 索尔 Q 版动作重绘

依据《终末的女武神》动画官方索尔设定重画。胸腹和上臂在单肩白披布之外露出。保留金色眼与脸纹、长红发、层叠深色腰封、金纹双片裙摆、金色腿甲与巨型雷槌。整体以约 45 逻辑像素的站立身高配准。透明显式处理，HD 用 2 倍最近邻。

- `q_sheets` 是成对替换的身体图集和动画表。重排了矩形，保留全部 36 个动作条目、原顺序和逐帧时长。用 `registration.json` 对照锚点。维持原 PPU，在游戏里检查脚底位置、投锤脱手和接锤切换。
- `thor_guard/atlases` 是单独的铁手套格挡包。保持原 216×168 帧格、原事件时间和特效文件，偏移跟随重画后的手套位置。验证运行时绑定既有 `skill2` 格挡资源，投锤仍使用角色主表的动作。
- `review/preview.html` 支持逐帧、播放、深色底和可选战斗特效。各动作的高清帧图默认展示身体和武器，方便检查五官、手臂和步态。站立、肌肉和服饰参照在下方。
- 主表附带原索尔资源中的雷弧、地雷和终极技闪电，重新配准到新动作的施放、命中和蓄力阶段。既有运行时独立特效、语音、图标及插画文件沿用。
- 已校验图集边界、运行时条目、时长、HD 抽样像素、ZIP 完整性和素材 SHA-256。需由 Claude 在实际游戏里验证身体配准、播放、伤害帧、技能、投掷物、格挡闪光、HUD 和回放。

美术使用内置 ImageGen。提示词围绕动画造型与原 MOD 的分辨率、朝向、分帧约束，重点锁定露出的宽肩胸腹、长红发与金瞳、三角纹白裙、握锤手与面部的暗线、同一人物的前后腿交叉、以及两手在同一根短锤柄上的接触点。官方设定见 [《终末的女武神》索尔角色图](https://ragnarok-official.com/1st/wp/wp-content/themes/ragnarok-main/_assets/images/char/main/tor.png)。
