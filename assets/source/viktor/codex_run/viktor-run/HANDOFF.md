## 制作方式

第1次附参考包五图生成整套跑步，但没能清楚交换两脚。第2次附3D动作、定稿、固定上半身，单独重画8帧的完整双腿，逐帧明确近腿/远腿的迈步、抬膝和前后顺序。交付腿来自这张新生图，没有使用旧定稿的静态腿当零件平移，也没有以代码绘制新腿形。

按生图的逻辑网格整理蓝灰色腿和深蓝灰赤脚，保留大腿金色护甲条及金踝环；薄金色细节按材质合并计票，避免三档金色分散后在取格时消失。近远脚使用定稿中相邻深浅档，遠脚较暗。只使用定稿29色，透明度为0/255，透明RGB清零。新腿整体按原生腿区整理到腰甲至脚底的位置，再原样覆盖参考上半身；腰甲和腿接合，法杖及斗篷保持原遮挡关系。

## 交叉与脚的位置

两脚横向差是“近脚可见像素中心−远脚可见像素中心”，单位为原生像素，正数表示近脚在右，负数表示近脚在左：

| 帧 | 横向差 | 姿态 |
|---:|---:|---|
| 1 | +11.8 | 近脚向前，远腿在后弯曲；落地高度。 |
| 2 | +7.3 | 两腿向身体下收。 |
| 3 | −7.3 | 远脚抬起经过近腿，远脚已到近脚右侧。 |
| 4 | −12.8 | 远腿向前，近腿向后弯。 |
| 5 | −11.1 | 远脚在前，近脚在后；落地高度。 |
| 6 | −7.8 | 近腿向身体下收。 |

| 8 | +12.0 | 近腿前伸，衔接第1帧。 |

近侧腿在交叉时保留前景明暗，远腿较暗。所有帧都有两只脚的可见像素；第1帧远脚大部分在固定法杖后面，只有3个原生像素露出，第8帧也较小。这是保留完整法杖和既有遮挡的结果；导入后应重点看这两帧在实际显示尺寸下的可读性。
