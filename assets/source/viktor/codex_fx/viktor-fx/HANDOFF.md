# 维克托技能特效交接

最终整理完成后撰写。共 **23 张、113 帧**。生成路线为内置 image_gen，每张单独生图；全部造型来源于生成原稿，随后进行像素取色、透明度清理、对称、位置修正和切格，没有用代码拼方块替代特效美术。

## 文件使用

- `pixel_1x/`：实际切格导入用，1格=1像素，RGBA，alpha仅0/255。每张均为单行等宽格。
- 根目录同名 PNG：上述像素版最近邻放大16倍，全部16×16块一致。
- `raw/`：23张未经修改的生图原稿，包含半透明/柔光/分格等生图瑕疵，仅供追溯。
- `prompts/`：每张实际发送的提示词 `.txt` 和包内原始英文提示词 `.original.txt`。
- `manifest.json`：格子宽高、帧数、每帧切格矩形、可见bbox、对称方向、保护区域、原稿hash。
- `validation.json`：最终PNG文件重新读取验证的结果。
- `fx_list.json`：原包绑定表原样保留；特别注意 `q_charged` 绑定 `q_buff`。
- `preview/`：23个GIF和总览。GIF大多160ms/帧，风暴6帧总计1000ms；这只是预览节奏，未修改或验证游戏动画时长。

## 规格取舍

生图时为保证每帧可读，改成2×2、3×2或5×2的紧凑网格，而非请求超长画布；交付整理为原提示词规定的单行长条。尺寸以每条英文Layout的单格尺寸为准，例如E为144×28格，而绑定表140×26是运行时显示尺寸，两者不要混用。
原稿经过按格采样、指定色板量化；非风暴图最深色统一提亮一档，去掉暗描边；低透明度柔光被去除。按生成原有颜色复制到镜像位置来实现精确对称。人物附着特效对中央区域清空，避免实心光遮住身体。所有这些都是后处理，未请求另一套人物造型。

护盾、风暴、进化中央空区按文件规格保护；实际42格高、30格宽角色与护盾26×34的运行时比例不完全一致，导入时仍需按原包的锚点/显示尺寸验收。此处未合成或烘焙特效到动作条。
