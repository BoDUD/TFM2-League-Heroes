# 派克：跑步换皮（给 Codex 的提示词）

> 上一轮的跑步是把造型的腿整条转 45°，锯齿多、没有交叉步，我这边用造型自己的腿平移也只像在滑。这一轮**只画跑步**，用「骨架 + 皮囊」：图1 是一个同样弓身深蹲、拿着武器的英雄的跑步（8 帧，两腿交叉迈步、身体随落地起伏），只用它的**腿的动作和身体起伏**；图2 是派克的定稿造型（皮囊）。
> - **上半身就是造型图的上半身**（图4：皮带以上，头、两肩骨白獠牙、青蓝外套、深蓝下摆、腰带金徽章、红腰布、高举的鱼叉和后手、垂在前膝外的爪子手），每帧逐格一样，只允许整体上下起伏 1 格（落地那帧低 1 格）。不要画骨架角色的头、身体、武器。
> - **腿**照图1 的腿：同样的帧数、每帧两条腿的位置和弯曲、交叉的时机（第 1、5 帧两脚分得最开，一前一后；第 3、7 帧两腿在身体下方交错），但用派克的裤子和靴子：灰绿色宽松长裤、**近侧腿（画面左边那条）膝盖前是棕色大护膝和金扣**、棕色皮靴；**远侧腿暗一档**（同样的材质，颜色深一级），交叉时不会糊成一团。两胯收在身体下方，不要露出皮肤大腿。
> - 大小：和造型图一样（光头顶到脚底 40 行）；格子、排版、脚底线、站位照图1：4 列 × 2 行，每格 128×96 方块（1024×768 像素），脚底在每格第 81 行（像素 648–655），第 82 行以下什么都不能有；站位点在每格第 64 列，头相对站位点的横向位置每帧一样。
> - 每个像素一个严格对齐的 8×8 纯色块，只用造型图的颜色，一圈近黑描边，没有抗锯齿、模糊、半透明。背景纯绿 `#00FF00` 或透明。
> - 交付：`outputs/pyke-run/pyke_run.png`（4096×1536）、`pyke_run_1x.png`（512×192）、生图原稿 `raw/`，**最后**写 `HANDOFF.md`；最好打成 `pyke_run_done.zip`。
