# 赛娜第 1 步：游戏尺寸待机精灵

依据本次 senna_model_pack 的 A 版角色、目标剪影和现有英雄像素范例，完成肩扛遗物炮的正面 3/4 待机造型。

## 文件

- `senna_design.png`：1024×1024 RGBA，128×128 逻辑像素精确放大 8 倍，每格是统一的 8×8 方块。
- `senna_design_1x.png`：128×128 RGBA，可按逻辑像素取回编辑。
- `raw/senna-generation-01.png`、`02.png`、`03.png`：三轮内置 image_gen 原稿，按生成器输出字节原样复制，未缩放、移动、重采样；03 为最终细节修订稿。
- `generation-prompts.txt`：实际生成、目标剪影修订与细节修订提示词。
- `normalize-senna.ps1`：成稿网格提取、限色及面部像素整理过程，可从此目录的上级项目根目录复现。
- `validation.json`：尺寸、格数、颜色、透明度、8 倍网格一致性与原稿 SHA-256。

## 读回实测

所有行列均从 0 开始计数。

- **兜帽顶部轮廓到脚底：40 格**，顶部轮廓在第 60 行，脚底第 99 行，两端计入。
- 白色兜帽填色从第 61 行开始，顶部描边使用 `#1E1424`。
- 全部可见像素框：`x=36..80，y=54..99`，即 **45 格宽、46 格高**。炮爪比兜帽顶高 6 格；接近说明中的约 48 格整体高度。
- 两脚之间空隙的中心在逻辑 x=64，即放大图 **x=512**。
- 脚底在放大图 `y=792..799`，下方完全透明。
- **27 个不透明颜色**，透明度仅 0 或 255，没有半透明、插值边缘、网格、文字或特效。
- 两只绿眼各由深绿和亮绿两格组成；红唇一格。白金兜帽、黑色金环脏辫、梅紫服装、青白长飘带和金尖短靴保留。
- 遗物炮保留向右上方的两支金爪、兜帽左侧的金环与暗色中心、向左下方的酒红翅板与青白水晶刃、下面的青色圆筒。小尺寸下细金边和水晶亮边已简化为像素阶梯线。

## 制作方法与边界

先由 image_gen 重新绘制较低细节的新像素稿，再依目标剪影修订尺寸，随后修订脸部与武器细节。生成器未直接满足精确网格、限色及硬透明要求，因此最终稿从**新绘制的第三轮稿**按网格取色，对齐脚底并收敛到指定调色板；额外整理了四格眼睛和一格红唇，统一深色轮廓。没有将 A 版大型原画直接缩成成稿，也没有通过脚本构造整个人物的大色块。

原稿仍保留生成器的半透明边缘与更多颜色；上述网格、颜色和透明度检查只适用于两张最终 design 文件。最终稿是一张待机造型精灵，不包含动画帧、技能特效或游戏集成。
