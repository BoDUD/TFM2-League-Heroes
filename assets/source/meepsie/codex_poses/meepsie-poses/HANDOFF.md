# 米普西：20 张动作姿势交付

以本次 meepsie_pose_pack.zip 的 0_design.png（原始 A 第一稿，137×115 格定稿）为造型参考，逐张附驾驶舱特写、对应动作参考和骨架，使用内置 image_gen 绘制。上一轮 50×40 的42帧动作没有复用。

## 文件清单

- meepsie-pose-a_raise.png / a_punch：普攻抬拳和砸拳。
- meepsie-pose-q_raise.png / q_smash：月尘震地蓄力和砸地。
- meepsie-pose-e_ready.png / e_call：治疗木灵准备和张手欢呼。
- meepsie-pose-r_jump.png / r_air.png / r_land.png / r_slam.png：起跳、空中双拳高举、落地和压低。
- meepsie-pose-run1.png 至 run8.png：八张完整步态姿势。
- meepsie-pose-d_fall.png / d_down.png：跪倒和驾驶员缩回驾驶舱。
- raw/：20张原始生成PNG，原样保留。
- manifest.json：逐文件尺寸、包围盒、整数位移、原稿哈希及限制。
- qa.json：尺寸、硬透明、地线、未重采样及原稿一致性检查。
- generation-prompts.txt / generation-records.json：20次实际生图提示词与原始保存路径记录。
- preview-contact-sheet.png / preview-run.gif：仅供检查的缩略图与步态循环预览，不用于读取原格。

## 处理与检查

20张主图均为1254×1254 RGBA，真透明，alpha只有0/255。只对生成器的软透明边缘作阈值清理，并做整数垂直位移，使最低可见像素边界统一为y=1176。主图未缩放、未重采样、未用代码重画身体；不透明像素的RGB与raw对应位置一致。跳跃两张也对齐同一地线，离地高度留给导入方添加。主图四周没有不透明像素贴边裁切。

## 已知限制，导入前必读

图像模型没有严格输出从画布原点对齐的统一6px网格；每张实际格距及身体、拳头和驾驶舱比例也有变化。为遵守“不缩放或重新取样”的要求，没有用规整处理掩盖这些差异。不能宣称驾驶舱逐格相同、20张身体尺寸完全一致或已经达到无缝动画标准。应先量每张raw实际格距，再以定稿驾驶舱和身体为基准校准；这些属于后续导入/修整工作。

已检查八张行走下半身各不相同，包含抬脚、送脚、落地和换侧；这不等于已完成游戏内步态平滑验证。死亡末张驾驶员不可见，但仍为前折跪倒姿势。所有动作图不含技能特效。未修改游戏工程或运行时数据。
