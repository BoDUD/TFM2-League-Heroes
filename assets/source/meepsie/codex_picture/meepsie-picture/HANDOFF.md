# 米普西 / 小木灵造型交付

本包完成 pack0 对应的两张待机像素造型：A 为朝右 3/4，B 为朝右侧面。作为后续动画制作的造型源，不包含动作帧、游戏导入或技能实现。

## 交付文件

- meepsie-A.png：1536×1536 RGBA，角色 50×40 格，即 550×440 px；左上锚点 (493,950)。
- meepsie-B.png：1536×1536 RGBA，角色 26×40 格，即 286×440 px；左上锚点 (625,950)。
- meepsie-A-pixels.png / meepsie-B-pixels.png：一格一个像素的直接读取版本，建议后续打包优先用这两张。
- preview.png：两张造型的同倍率并排预览，灰背景仅用于预览。
- raw/：四张原始生成 PNG，完整保留，未覆盖。
- generation-prompts.txt：实际四次生成/修订提示词及后处理路线。
- pack_meepsie.py：可复现后处理脚本，依赖 Pillow、NumPy。
- qa.json / raw-inspection.json：最终尺寸、网格、锚点、透明度及原稿检查记录。

## 制作与检查

采用原包角色和风格参考，通过内置 image_gen 生成 A/B 及粗像素修订稿。原始生成器输出均为 1254×1254，且带有半透明抗锯齿，不能直接当作 11px 网格源。经用户明确授权后，使用 Python 提取角色、统一 20 色材质调色板、规整逻辑像素、修补驾驶员眼睛高光与天线，再用最近邻放大 11 倍并定位到交付画布。

两张主文件均为真透明背景，alpha 仅 0/255，统一 11px 网格，角色顶部 y=950，脚底边界 y=1390，距底边 146px。两张共享月岩、靛蓝岩、紫色、绿叶及小木灵色阶。没有地面、投影、文字或技能特效。A 的两眼为各 2×3 格黑色块并带单格白色高光；B 为侧面单眼。描边随小部件存在 1–2 格变化，未宣称所有转角均精确两格宽。

## 后续接入

读取 pixels 文件即可获得确定的逻辑网格，不必重新推测 raw 原稿格距。保留原始模型与 raw 供细节参考。两种造型尚未经过用户 A/B 选择、游戏 PPU/并排大小确认或动作、卡片、HUD、地图遮挡验证；因此本包只表示造型原画交付，不表示游戏角色或全套动画完成。未修改现有模组、存档或工程。
