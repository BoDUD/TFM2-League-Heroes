参考图1精灵图的动作序列和构图布局，将原有的角色（李青）替换为图2角色（慎：蒙面的蓝衣忍者）。

1. 保留图1所有帧的位置、排列顺序：3×3 共 9 帧，从左到右、从上到下；每帧角色在格子里的左右位置和脚底高度都不变。
2. 保留每帧的动作：两条腿一前一后**交叉迈步**（前腿伸出去落地、后腿弯膝往后上方抬，两腿在中间交错换位）；两只手随步子一前一后摆动；身体上下起伏、略微前倾。
3. 身体结构、配色、特征完全换成图2：一样的兜帽和银色护额、灰色金属面罩和发光的紫色眼睛、银边的蓝色护肩、裸露的古铜色上臂、蓝色护臂和棕色手套、腰间蓝色系带和中间的银灰色前襟、左后方垂下来的蓝色后摆（挂在腰带上，跟着身体走，不要单独飘在外面）、宽大的紫色灯笼裤、高筒棕色靴子（紫色鞋底）；背上的弯刀照图2背着，刀柄从左肩上方露出、冰蓝色的柄头。
4. **体型和图2一样大**：图1的李青比慎矮（李青约 36 格高，慎从脚底到兜帽顶约 40 格、到刀柄顶 46 格），换成慎时按图2的大小画——脚底仍在图1的脚底高度，头和身体按图2的比例往上长；头和身体比例、裤腿和靴子的宽度都和图2一样，**不要把腿画细**。
5. 像素画：方块大小和图1、图2一样（每个像素方块一样大，整齐对格），1 像素深色描边，不要抗锯齿、不要渐变、不要模糊。

背景保持纯绿色 #00FF00（和角色差异最大的纯色），方便抠图。风格保持与原图一致。重点在于精准复刻原图的"动作骨架"，只是换了"皮囊"。
