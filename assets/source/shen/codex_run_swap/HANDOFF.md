# 慎跑步重画交付

根据本次参考包，使用内置 image_gen 重画九帧跑步图，再按用户已授权的本地脚本方式整理导出。提示词保存在 prompts.json，原始生图保存在 raw/，参考图和原始需求保存在 reference/。

- shen_run_3x3_green.png：1440×1440，3×3九帧，纯绿色 #00FF00。
- shen_run_3x3_transparent.png：相同布局，透明底，alpha仅0/255。
- shen_run_3x3_1x.png：180×180逻辑像素透明图。
- shen_run_strip.png：4320×480，九帧从左到右。
- frames/：九张480×480透明单帧及60×60逻辑单帧。
- previews/run.gif：九帧循环预览，100ms/帧，仅为观看设置。
- manifest.json：裁切坐标、原图脚底位置、角色30色调色板和导出说明。
- qa.json：像素网格、透明度、色板和脚底位置校验。

角色保持宽紫裤、棕靴、蓝色忍者护甲和银色面罩；纠正初稿多余举手，让剑固定在背后。末稿已逐帧检查构图与腿部交错。

格式校验通过。每帧最低脚底均在逻辑第55行，与参考一致；水平位置按原图轮廓中心注册，取整误差不超过半个逻辑像素。整体从刀柄到脚底46格。动作、每个膝踝与手臂位置为AI参照重画，不能宣称与原图逐像素一致。

本次是新要求的九帧版本，旧动作包为八帧跑步，因此另存为独立包。尚未替换旧包中的运行时动画配置，也未安装或进行游戏内测试。
