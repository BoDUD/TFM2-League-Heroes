# 索尔：第 1 步游戏尺寸造型候选

2026-10-24。来源：用户提供的 `aurelionsol_model_pack.zip`。本次完成悬浮 A 两稿、飞行 B 两稿的粗像素重画；严格网格与硬 alpha 验收尚未通过，不应直接当作最终游戏帧。

## 交付文件

- `aurelionsol-A-1.png`、`aurelionsol-A-2.png`：3/4 朝右的悬浮造型，两张独立生成。
- `aurelionsol-B-1.png`、`aurelionsol-B-2.png`：3/4 朝右的飞行造型，两张独立生成。
- `raw/`：四张原始生成 PNG；与同名交付图逐字节一致。
- `prompt-A1.txt` 等四份：每张实际提示词。
- `generation-prompts.txt`：全部实际提示词与两次未采用尝试的提示词。
- `image-qa.json`：尺寸、alpha、可见边界、粗色块连续长度统计、SHA256 和 raw 一致性。

## 制作与目视检查

使用内置 image_gen 重画，没有用脚本逐格造型，也没有平滑缩小原画。由于工具一次最多五张参考，采用 target（尺寸姿势）、Smolder（粗像素风格）、上一轮原画（身份配色）、layout（位置）、head（脸部）五张。首轮 A 依旧过细，被排除；首轮 B 为横幅，被排除，重画成方形。未采用图留在工作区，不在交付包候选中。

四张都保留浅色骨质脸、青色双眼、金冠金角、紫红鬃毛、深蓝胸甲、青色纹线、紫色爪子与蓝紫星云尾巴。B-2 的正方形留白和姿态较稳；A-1 的近眼更明亮，A-2 的大色块更简洁。可从 A-1 / A-2 和 B-1 / B-2 分别选外观，再处理游戏尺寸。目视检查不能证明眼睛、牙齿和每根爪子都符合精确格数。

## 实测结果及未通过项

全部为 1254×1254 RGBA，真实 alpha 背景，不是画出的棋盘格。但四图均含 256 级 alpha，未达到只允许 0/255 的要求；材质中也残留颜色细微变化，不是严格有限调色板。

| 文件 | alpha≥128 的可见框 [x0,y0,x1,y1) | 可见宽×高 | 常见横向色块长度（粗略） |
|---|---|---|---|
| A-1 | [236,26,1157,1254) | 921×1228 | 主峰 16 px，邻近 15/17 px |
| A-2 | [229,22,1139,1253) | 910×1231 | 主峰 15–16 px |
| B-1 | [26,528,1234,1241) | 1208×713 | 主峰 13–14 px |
| B-2 | [39,540,1220,1228) | 1181×688 | 主峰 12–13 px |

色块长度统计只作辅助，不代表精确像素格测量。A 未满足冠顶 y112 / 尾尖 y1190；A-1 底部有可见像素触边，A-2 也只有极小底边余量。B 接近上沿 y533，但下沿和总宽高仍偏大。四图均未证明从 (0,0) 对齐的统一 A14/B13 网格，也未证明严格 77/51 行。

## 后续交接

先选造型；按 raw 实际像素台阶读取，保留脸框、双眼和牙齿，再统一到 A77 行、B51 行与目标位置，清理 alpha、边缘和调色板。资料中建议的 A PPU1.75 / 44 游戏像素高度仍是后续目标，本次没有制作 hd/idle.png 或 hd/run.png，也没有写入运行模组。严格网格、脚底/尾尖留白、爪缝及头像缩放需要通过后才能接动作帧和游戏内 QA。
