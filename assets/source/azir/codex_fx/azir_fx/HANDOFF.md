# 阿兹尔特效包交付

已完成17组、77帧特效。沙流、沙尘、太阳金光及护盾画面由内置 image_gen 生成，再按参考要求读回游戏像素。特效中没有绘制阿兹尔、沙兵、禁军或太阳圆盘本体。本轮仅制作素材，不修改仓库或游戏安装目录。

## 文件

- 顶层 azir_fx_*.png：17张8倍单行帧表，最近邻放大；每个游戏像素对应8×8实像素。
- pixel_1x/：17张原尺寸单行帧表，可直接按manifest里的cell_1x切格。
- raw/：采用的17张未经修改生图原稿。raw/rejected/为未采用稿，不应导入。
- manifest.json：帧数、单格尺寸、整表尺寸、对称方式、循环标记、色板与参考绑定信息。
- generation-prompts.txt：实际提示词、参考图及定向重画记录。
- qa.json：原稿哈希、源图切格坐标、对齐偏移、逐帧像素数、非空/重复/色板/透明度及对称检查。
- preview.html、preview.png：动图浏览页和静态总览；preview_gif/内逐组动图统一120ms/帧循环，仅供检查，不代表游戏最终播放速度。

## 读回处理

为避免极长画布漏帧，大部分原稿生成在紧凑网格里；原稿按从左到右、从上到下读取，交付时重排成单行。两种弹道朝右，尾部在左；其余效果逐帧左右对称。

每个目标格先将源像素映射到该效果提示词允许的色板，再对可见性投多数票；可见占多数时取其中出现最多的色板色。原稿alpha≥32计为可见，以保留消散阶段较浅的沙尘，纯黑背景像素作为透明。最终PNG只有0/255透明度，没有抗锯齿或柔光边。此过程读取生图内容，没有用代码构造沙浪、沙粒或光柱的替代图形。

逐格对称采用镜像成对像素中较亮的已有生成色，保留原画的亮点。太阳光束先按每帧白色核心水平居中，避免镜像后变成双柱。d_rise原稿行间距不均，使用人工检查过的行边界切格，避免将上一行光柱的底圈切进下一行。

E护盾已经重画成薄壳；按原稿外圈可见边界读入38×44的外轮廓，位于40×46单格内部。中央留空为宽30×高38的椭圆身体开口，不是实心矩形遮挡；开口内alpha逐格为0。最终外圈和青色上下闪光完整可见。所有颜色来自生成稿投票，不由程序补画轮廓。

普攻命中、禁军命中和太阳光束的消散末帧已定向重画，避免末帧粒子过细读回消失、或最后一帧仍残留整根光柱。旧稿隔离在raw/rejected/。

## 验证和使用

17张、77帧均已检查：每格尺寸正确、所有帧非空且互不重复、0/255硬透明、限定色板、要求方向的逐格对称，以及8倍图与pixel_1x严格逐像素一致。采用原稿与哈希一致。没有黑色描边色。

导入请优先使用pixel_1x/，第i帧左上角为(i×cell_1x宽,0)，索引从0开始。绑定名称沿用参考包，其中减速标签用slow；清单中的绑定是导入建议，尚未写进游戏数据。

本包尚未进行游戏内叠加、地形遮挡、播放节奏或实际技能触发验证；不能把素材检查通过当作运行时技能验收。需要引擎导入后复核定位、层级和帧时长，尤其是护盾身体开口、光束落点和大招沙墙的战场宽度。
