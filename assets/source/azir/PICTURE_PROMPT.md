# 沙漠皇帝 阿兹尔：第 0 步，先画像素风原图（给 Codex 的提示词）

> 阿兹尔是英雄联盟里**恕瑞玛的沙漠皇帝**，拿一根长权杖指挥**黄沙士兵**，大招召来一排**举塔盾的禁军**，被动能立起一座**太阳圆盘**。这一步把他和三样召唤物都画出来，用户从里面挑：
> - **阿兹尔**：身材**修长**的半神皇帝，**头就是一顶鹰首金盔**（前面一个**鹰嘴**，头顶一道**冠羽**，两颊各一片**金色翅膀**），面甲里两只**发青蓝光的眼睛**；**金色铠甲**上镶着**青蓝色宝石**（肩甲、胸口、腰两侧各一颗）；里面是**深紫色长袍**，背后一件**深紫披风**，下摆拖着几条**很长的紫色飘带**；小腿**灰蓝色**，套**金色护胫**；手里一根**比他还高的金色权杖**，杖头分叉，中间一颗青蓝宝石。
> - **黄沙士兵（T，被动 / Q / E 用）**：一个**深色皮肤、肌肉结实**的士兵，**金色鹰首头盔**盖住整张脸，**金色肩甲**，胸口光着，**深橄榄色短披风**，腰上金片护裆，**金色护胫**，手里一根**长矛**（矛头是金色的叶形刃）。
