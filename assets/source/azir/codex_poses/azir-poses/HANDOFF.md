# 阿兹尔动作姿势交付

本轮按 azir_pose_pack.zip 的参考内容制作 19 张姿势候选，人物和召唤物动作画面均由内置 image_gen 生成。素材包内给后续代理的组装、调色和游戏导入说明只作为阶段背景读取；本轮未执行游戏运行资产修改。

## 文件与动作顺序

| 用途 | PNG 文件（共同前缀 azir-pose-） |
|---|---|
| 普攻号令 | c_wind.png → c_point.png |
| 狂沙猛攻 | q_wind.png → q_thrust.png |
| 流沙移形 | e_dash.png → e_land.png |
| 禁军之墙 | r_raise.png → r_lift.png → r_sweep.png |
| 跑步 | run1.png → run2.png → run3.png → run4.png |
| 死亡 | d_stagger.png → d_kneel.png |
| 沙兵刺矛 | s_lift.png → s_stab.png |
| 禁军冲锋 | g_push1.png ↔ g_push2.png |

- raw/：采用的每张图的原始生成文件，未经修改。
- raw/rejected/：未采用过程稿，包含竖幅画布、持杖侧错误、禁军多出长矛，以及尺度偏小的召唤物初稿。不要当成动作源。
- generation-prompts.txt：全部实际提示词、参考图路径及采用/过程稿记录。
- qa.json：画布尺寸、原稿 SHA256、可见边界、透明通道检查及画布触边记录。
- preview.png：19 张的排列预览，仅供查看，缩略尺寸不是交付动作的尺寸。
- preview.html：本地逐张浏览页，点击可打开原尺寸 PNG。

## 处理和核对

最终动作 PNG 为 1254×1254。原始生成器仍输出半透明边缘，交付 PNG 只用阈值 128 将 alpha 整理成 0/255，并清除全透明像素的隐藏 RGB。没有用代码绘制身体、拼装动作、移动部件、重采样网格、缩放或调色。所有画图和重画均由 image_gen 完成。

召唤物初稿因直接引用窄幅参考而生成了竖幅，已重新调用画图模型。重画时使用将包内原有造型放进方形画布的参考（有一版只加边，有一版将参考按其既有像素块以最近邻放大到目标参考尺度）；这些是输入参考准备，不是把生成的姿势缩放成交付稿。两版过程图均隔离。

已查看整组预览，并检查：主模型保留金色鹰盔、青蓝眼睛和宝石、紫金服装；普攻有举爪/前指，Q 有斜举/横刺，E 有腾空/落地，大招有展臂/高举/下挥，死亡有踉跄/跪地和地面横杖；沙兵正面双手持倒矛；禁军朝右持盾。修正了跑 1 将权杖换到另一只手的问题，重新生成跑 4 以交换抬起的腿；禁军移除了初稿额外长矛。具体最终采用文件以顶层 19 张 PNG 为准。

## 精度边界

这些是供后续按格读取、统一头部与比例的动作姿势稿，尚未成为最终游戏动画。图像模型没有逐像素保证同一鹰盔、严格 13/20/24 px 网格，或每条腿 14 格、手臂 15/23 格、权杖 71 格。头盔细节、肢体厚度、肩甲、脚底基线和武器长度存在逐帧漂移；个别动作对骨架关节位置也只有近似匹配。不能把画面完整、动作可辨认或透明通道通过当作上述严格数格要求已通过。

优先复核横刺/落地帧的持杖臂连接、跑步四帧的明暗腿与足底锚点、高举帧的身体尺度，以及沙兵/禁军的相对大小；鹰盔仍需按包内 1_head.png 统一读回或替换。所有直杆武器已经按笔直轴向要求生成，但离散像素、局部遮挡和各帧长短差异仍需在最终网格上量直线，而非只看缩略图。

本次不包含补间帧、原生动画时间表、精灵图集、PPU、技能特效、数据接入或游戏内 QA，也没有将候选姿势覆盖到安装目录。后续应从 raw/ 的采用原稿读取，先统一尺度和鹰盔，再验证动作连续性；raw/rejected/ 的过程稿禁止混用。
