# 雷恩加尔特效：第 3 步交接

交付状态：20 组生图特效原稿已完成并整理为横向等宽帧条，总计 92 格：88 个动画帧、4 个凶残值静态状态。按照输入说明接受生图原稿的交付方式制作；这些 PNG 尚未转为游戏原尺寸、也未安装或在游戏中运行。

## 文件与制作方式

- 根目录 `rengar_fx_*.png`：20 张透明 RGBA 横向帧条，文件名与清单一致。
- `manifest.json`：`assets[].frames[].rect = [x,y,width,height]` 是根目录帧条的实际切帧区域；索引从 0 起。含原稿切片区域、透明留白偏移、锚点参考和原清单的绑定说明。
- `raw/`：20 张选用的原始生图文件，保持原文件字节；大部分是 2×2 或 3×2 布局，5 帧原稿的第六格为空。
- `PROMPTS.json`：逐张保存输入提示词编号、原提示词、实际生成提示词、修订提示词和选稿结果。
- `previews/`：20 个暗底 GIF；只是逐帧预览，凶残值 GIF 是状态轮播，单次效果 GIF 为方便观察重复播放。预览速度不代表游戏时间。
- `OVERVIEW.png`：暗底总览。`QA.json`：格式、切片和像素保留校验结果。

所有图形均由内置 image_gen 生图及生图修订完成，没有用程序拼方块绘制。程序只进行整帧裁切、透明留白、横向排版、预览及打包。交付图没有重新绘制、缩放或量化图形，裁片 RGBA 像素与所选原稿逐字节一致。

为了避免极宽生图画布被压缩，生成提示词将原来的一行改为两行，保持单格比例与帧序，随后整帧重排成一行。尘土切片内缩 2 像素去掉原稿分格细线；Q 上挑的实际行界线改为 y=768，避免第三帧顶部光点进入第一帧；烟雾第二、三帧之间的切片界线左移 21 像素，保留完整峰值云团。切片偏移补回透明留白，参考锚点保持在原名义格子中的位置。

## 导入注意

`target_game_cell_size` 和 `requested_cell_size` 是输入文件给出的目标，`actual_cell_size` 才是当前 PNG 单格尺寸。按 `rect` 切帧后，再由导入端按目标范围统一缩放和确定脚下／头顶锚点。`anchor_hint` 是每格内的参考坐标，需要实际游戏叠图确认。

`playback=states` 的 f_stack：第 0–3 格分别绑定 f1–f4，不连续播放。`loop`、`one_shot` 与 `binding_from_input` 按输入清单记录，未修改任何游戏配置。地面效果和烟雾的效果类型应继续按原清单设置。

请保留 alpha 通道进行预览和切帧。完全透明像素可能有残留 RGB；直接丢弃 alpha 会显示原稿中的底色或边缘色。半透明边缘、局部中间色、像素颗粒大小并未转换成严格游戏网格／固定色板，粒子也并非逐像素严格镜像。光环内部已检查为空，暗底亮度已检查；循环首尾、实际技能尺寸、脚下位置和时间尚需导入端在游戏里核对。
