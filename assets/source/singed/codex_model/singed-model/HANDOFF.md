## 制作方式

使用内置 image_gen 重绘两稿及修正两稿，共4次调用。已查看包内全部7张图；工具最多支持5张路径参考，首轮使用原稿、目标图、布局、头部、普朗克风格图；修正轮以目标图为首参考，并使用原稿、布局、普朗克风格图。保留已认可的红金夹克、灰蓝围巾、蒙脸布、光头、亮绿药罐、近侧盾板、远侧药瓶、深蓝细腿和大靴子。没有生成侧面、动作或技能图。

没有用 Python 逐格画角色，也没有缩小或平滑处理原稿。Python 仅用于读取、检查像素和生成检验记录。所有生成 PNG 均原样复制。
