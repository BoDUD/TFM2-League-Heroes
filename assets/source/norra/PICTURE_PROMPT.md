# 诺拉与悠米（金铲铲之战 · 第 12 赛季）：第 0 步，先画像素风原图（给 Codex 的提示词）

> 诺拉是金铲铲之战第 12 赛季（魔法大乱斗）的五费卡「诺拉与悠米」：一个**约德尔人小法师**，悠米原来的主人，会开**次元门**。这一步画两张，**格子大小一样**：
> - **长相**：**全身米黄 / 浅杏色的绒毛**，**两只又长又软的大垂耳**从头两侧垂到肩膀下面（像长头发一样，末端毛茸茸）；**一副很大的粉色 / 品红圆框眼镜**，镜片浅蓝、透出一双**蓝眼睛**；粉色小鼻子，小嘴；
> - **头上**：一顶**很高的青绿色礼帽**（帽身上有浅色的卷云花纹），帽子底下一圈**红色的头巾**（在前面打结，正中一块**灰绿色六边形宝石**和几颗白珠子），帽子中间套着**一圈米白色的骨珠环**（像一个宽帽檐的圈，用红绳绑着，下面挂着几个**白色圆形小骨片**），帽子一侧插着**一根亮蓝色卷羽毛和一根品红 / 粉色羽毛**，往上翘；
> - **身上**：一件**长到脚面的蓝紫色长袍**（宝蓝 / 紫，上面浅色的卷云纹，下摆一圈更亮的紫），前襟敞开，正中垂着一条**红色长围巾 / 腰带**（上面深红色卷纹）；脖子上一条**红围巾**，喉咙前面一颗**白色圆形骨扣**；长袍里面是深棕色；袖口宽，挂着**几个金色小穗子**，手腕一圈**青绿色珠子手链**；背后背着一个**棕色皮背包**（两根背带从肩上过来）；脚是深色的小鞋，只露出一点。
> - **B：悠米**（金铲铲版，和联盟悠米一个样子但配色不同）：一只**蓝紫色（长春花紫）的小猫**，脸和胸口偏浅的淡紫白色，**胸前一团深海军蓝的蓬松毛**，**粉色的耳朵内侧**，**一双大大的青绿色眼睛**，粉色小鼻子；头顶一个**金色叶子形的小王冠**，两边脸上**金色的卷须饰品**（像胡须），脖子上一个**金项圈**；头上伸出一根**细细的金色天线**，末端一颗**亮蓝色的玻璃球**（球边一片小金叶）；背上几道金色花纹；她**趴在一本打开的厚书上**——书皮是**棕红色皮革，四角和搭扣是金色**，书页米白。
>

> - **A：诺拉的待机**（定造型，附图 1–6、10a）：**3/4 正面朝右**，安静站着，**两只手自然垂在身体两侧、离开身体一点**（看得见小手和袖口的穗子），脸朝右前方，长袍下摆盖住大半个脚。**两只大垂耳垂在脸两边**，近的那只（画面右）在脸前面一点，远的那只在后面、暗一档。
