# 奈德丽（狂野女猎手）：先画像素风原图（第 0 步，给 Codex 的提示词）

> 奈德丽还没有原图。她有**两种形态**，这一步请 Codex 画**四张**全身像素风原图：人形两张（A、B 只差**标枪怎么拿**，人、脸、衣服、标枪完全一样），美洲狮两张（A、B 只差**姿势**，同一只豹子）。用户各挑一版，之后第 1 步再按它画高清（PPU）造型：**人形的所有动作都用 3/4 正面**，**美洲狮的所有动作都用侧面朝右**。
> - **人形 A = 标枪竖直立在身边**：远侧手握着枪杆，枪头朝上、枪尾着地，近侧手放松垂在身侧；**人形 B = 标枪水平端在肩上**：近侧手在肩后握枪杆、枪头朝前（画面右边），远侧手向前伸出瞄准，随时要投。**标枪始终是一根笔直的直线**，A 完全竖直、B 完全水平，不弯、不歪、不斜。
> - **美洲狮 A = 四腿站立、警觉**（侧面朝右，头抬起看前方，尾巴自然垂下再上翘）；**美洲狮 B = 压低身子、准备扑**（前腿弯、后腿蓄力、头压低、尾巴平伸）。
> - **主参考是用户给的两张设定图（附图 A、B，放在最前面）**：人形的造型、比例、衣服、标枪，美洲狮的造型和鬃毛，**都先照 A、B 画**；英雄联盟渲染图（附图 1–10）只用来补细节。下面的文字和设定图不一致时，**以设定图为准**。
- **人形长相照英雄联盟原版**（附图 A 和 1–6）：奈德丽，一个**野性的丛林女猎手**，自信敏捷。**古铜偏红棕的皮肤**，脸上、胳膊、腿上有**白色的部落纹彩条纹**；**乌黑的头发在头顶扎成一个又高又蓬的大马尾**，用红绳绑着、马尾里插着一根黑白羽毛（全身最有特点的轮廓）；**绿色的眼睛**，额头正中一个小小的绿点，耳朵上挂着骨牙耳坠；脖子上一串**深色骨牙项链**。
> - **人形衣服**：**镶白毛边的棕色皮抹胸**，**手腕上一圈棕色毛皮护腕**；腰上一条皮带，挂着**几颗弯弯的象牙色兽牙**，下面是**一片片撕边的棕色皮流苏短裙**；**小腿和脚上裹着又大又蓬的棕色毛皮绑腿**，上面缠着**绿色的绳子**、顶上一圈浅色毛边，深色的鞋底。
> - **标枪（她的武器，要直）**：**一根木头枪杆，上面有几道红色的环纹**，枪头下面绑着**一根黑白相间的羽毛**，**枪头是一片浅灰白色的石头/骨头刃**（附图 1、4）。**长度约等于她的身高**（从地面到头顶附近，比原版短一些，方便做游戏动作），**一根直线**。
> - **美洲狮长相照设定图 B 下半部分和原版**（附图 B、7–10）：**金橙色的皮毛，背上和腿上有几道白色的条纹**，**白色的肚子、下巴和口鼻**，**两颗向下伸出的长獠牙**（剑齿），**绿色的眼睛**，额头上一颗**绿色的宝石**，头后面一圈**往后翘的尖刺状鬃毛**；脖子上一圈**深色皮项圈，挂着几颗弯弯的象牙色兽牙**和一根黑白羽毛；**四只爪子和尾巴尖是深棕色**，尾巴又长又粗、尾尖像一簇毛。**同一个奈德丽**：豹子身上的兽牙、羽毛和人形的一样。
> - **人形姿势**：**3/4 正面朝右**（脸、胸口朝向看画的人），两腿分开站稳：**近侧的腿在画面左边、颜色亮，远侧的腿在画面右边、稍暗、稍高**，两只脚踏在同一条地面线上。标枪和手**不能挡住她的脸和大马尾**。
> - **美洲狮姿势**：**正侧面朝右**（头在画面右边，能看到一只眼睛、一侧獠牙），**近侧的两条腿颜色亮、在前，远侧的两条腿稍暗、在后面露出一点**，四只爪子都踏在同一条地面线上（B 也一样，爪子不离地）。
> - **大小**：两种形态**按同一个比例画**：人形从马尾顶到鞋底约 800 px；美洲狮从耳朵尖到爪底约 470 px，从鼻尖到屁股约 880 px（尾巴另算，可以向上弯，不要出画）。
> - **风格和比例照附图 11–13**（之前画的布隆、卡萨丁、库奇）：清楚的大像素块、一圈近黑描边、每种材质 3–5 档平涂；**头按原版比例，不要大头娃娃**（头约占身高的六分之一到五分之一，马尾另算）；**整体紧凑**。颜色：皮肤古铜红棕（亮部暖橙棕、暗部深红棕）、纹彩白色、头发乌黑带深蓝紫高光、红绳正红、皮革棕、毛边米白、绑腿毛皮棕、绿绳橄榄绿、兽牙象牙黄、枪杆木棕红环、枪头浅灰白；豹子金橙（亮部浅金、暗部橙棕）、条纹和肚子白、爪子深棕、项圈深紫棕。深浅之间分界清楚，不要糊成一团。
> - **画布都用横版 1536×1024**，人和整根标枪、豹子和整条尾巴都在画面里，不出画。
> - 不画任何特效（标枪的光、夹子、治疗的绿光、变身的光都第 3 步再单独画）；鞋底 / 爪底（A 还有枪尾）是最低点，平平地落在同一条地面线上（游戏在脚下画血条）。
