# 亚恒关键姿势目视检查

这张表记录动作语义和明显生成错误的修订，不等于逐像素验收或游戏运行验证。所有图均由内置 image_gen 绘制/修订，没有用脚本逐格画角色。脚本只用于读取图像信息及制作索引总览，不修改交付 PNG。

| 姿势 | 目视结果与限制 |
|---|---|
| a_wind | 双手高举刀、站开蓄力；举刀倾角与骨架有偏差，头部未逐像素锁定。 |
| a_sweep | 低位右扫、双手握杆；头部/腿长及脚底仍须与定稿重新测量。 |
| q_cut1 | 胸前右向平斩；刀尖靠画布边缘，整体位置未严格贴骨架。 |
| q_cut2 | 刀刃右上、展翼；翼幅比骨架半展开更大，整体占画比例有偏差。 |
| q_crouch | 低身持刀、刃向右下；已再绘加强深蹲屈膝，仍需按骨架量关节坐标。 |
| q_up | 离地竖刀上挑；已再绘补全刀尖并留出顶部边距，腿部/离地高度未达到格数证明。 |
| w_thrust | 长刀右向直刺、手臂伸出；前刺重心和弓步仍是近似。 |
| w_pull | 回拽姿势；已移除悬空的重复刀刃，保留单一完整长刀。 |
| e_dash | 低身前冲、后掠翼；已移除多出的上方武器；刀刃右下符合文字，骨架本身刃端左侧与文字有冲突，采用文字刀向。 |
| e_spin | 身后长刀左向抡开；已再绘加强肩背转体，动作仍是近似，不能当作经过验证的旋转中间帧。 |
| r_crouch | 下蹲展翼、刃端左下；翼幅和整体比例未严格匹配骨架。 |
| r_rise | 空中展翼、反握刀刃朝下；长刀有倾斜，离地高度未严格标定。 |
| r_stab | 单膝跪地持竖刀；已修正初稿刀刃向上的错误为大刃向下、小矛头向上。 |
| run1 | 大跨步、后掠翼；两次修订移除多余武器，保留左下大刃/右上小矛头。 |
| run2 | 支撑腿和抬膝姿态；两次修订纠正刀向，保留左下大刃/右上小矛头。 |
| run3 | 跨步、长刀左下至右上；与 run1 的前后腿身份仍需按定稿暗部验证。 |
| run4 | 抬膝、长刀左下至右上；与 run2 的前后腿身份仍需按定稿暗部验证。 |
| d_fall | 后仰、双手空、刀脱手；已移除飞刀杆上的多余手套，头部角度有变化。 |
| d_down | 双膝跪倒、双手撑地、刀横落前方；已修正为大刃朝右、小矛头朝左，头部仍有倾斜，未满足统一头部要求。 |
| rv_kneel | 单膝跪起、一手拄刀一手按膝、刀刃向上；握点偏高，头部未逐像素锁定。 |

共性未通过项：准确 9px 网格、全硬 alpha、定稿头逐格一致、腿 29 格/臂 23–25 格/刀 116 格的测量、骨架坐标和 y1188 基线对齐。四跑步稿的尺度/基线不一，尚未构成经过验证的动画循环。没有合成或声称已完成游戏动画，也没有导入模组。

路线经验：多参考图会让画图模型把待机武器重复画进新动作；明确限定一把长刀并单独擦除多余段，优于一次要求重构所有部件。反向持刀应分别明确大刀刃与小矛头的位置。原始失败图仅保存在 raw/，不能作为额外动作帧导入。
