# 不落魔锋 亚恒：第 0 步，先画像素风原图（给 Codex 的提示词）

> 亚恒是英雄联盟的**暗裔战士**（Darkin）：一个**高大、冷峻的半神武士**，拿一把**很长的金色暗裔长刀**（长柄、弯刃的大关刀），背后两只**收拢的暗裔翅膀**像披风一样垂着。这一步画两张，用户从 A 定样子，B 是同一个人**展开翅膀、举起长刀**的样子（后面大招升空和被动复活用）：
> - **长相**：**皮肤是冷冷的浅蓝灰色**（像大理石）；**一双红眼睛**，眉头压低，表情冷傲；**长长的白金色头发**披到肩后；额头上一圈**金色头冠**，头冠两边伸出**两只又高又尖、往上弯的金角**（角根部一点暗红）。
> - **身上**：胸口、肩膀、小臂是**白色和金色的板甲**（金边、浅金花纹，胸甲中间一点暗红宝石色），肚子和手臂露出浅蓝灰的皮肤；腰上**一条深宝蓝色的长腰布**垂到膝盖下面，一条金色腰带；腿上**深蓝灰的护腿**、膝盖和小腿是金色护甲，**光着的脚**（脚趾有一点爪）踩在金色的脚环 / 绑带里。
> - **背上**：两只**收拢的暗裔翅膀**从肩胛骨后面垂到小腿，像一件裂成几片的披风：**外面深海军蓝 / 深靛色**，**里面浅白蓝带暗红的纹路**，边缘一段金色骨架，翅尖是**几片尖尖的长羽片**。
> - **手里**：一把**比他还长的暗裔长刀**——**深色的长柄**，**一头是金色的大弯刃**（刃背有暗红镶嵌），**另一头是金色的尖矛头**。待机时**斜着握在身前**：前面的手（画面右边）握在柄的中段，刀刃一头朝**画面左上**、矛头一头朝**画面右下**（附图 1）。
>
> 请 Codex 画**两张**（**格子大小一样**，都是 **3/4 正面朝右**）：
> - **A：待机**（定造型）——英雄联盟里的待机：**站得笔直、很高傲**，下巴微抬，看向右前方；长刀斜着横在身前；翅膀收拢垂在身后（附图 1、2、3、4、9a）。
> - **B：同一个人，展开翅膀、举刀**（附图 6、9b）——**脚还踩在地面线上**，站姿和 A 差不多；**两只翅膀在身后向两边、向上张开**（像附图 6 里展开的那只，两只都展开，后面那只暗一档）；**长刀举过头顶斜着**，刀刃一头朝上方。**格子大小、脸、头冠、金角、盔甲、颜色都和 A 一模一样**，只是翅膀和手臂、长刀换了位置。B 不要宽过 60 格。
