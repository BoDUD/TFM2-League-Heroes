# 剑魔游戏尺寸造型稿交付

本轮是 A/B 造型稿，供选择头部比例；未制作动作帧，也未修改游戏或仓库。

## 文件

- `aatrox_design_A.png` / `aatrox_design_B.png`：1024×1024 透明画布，严格 8×8 网格。
- `aatrox_design_A_1x.png` / `aatrox_design_B_1x.png`：128×128 原尺寸画布。
- `aatrox_design_A_sprite_1x.png` / `aatrox_design_B_sprite_1x.png`：裁切的 44×40 原尺寸精灵。
- `aatrox_comparison.png`：暗色底，A/B 的 8× 和 1× 对比。
- `aatrox_palette.png` / `aatrox_palette.txt`：色板。
- `aatrox_design_A_generated.png` / `aatrox_design_B_generated.png`：未经整理的图片生成原稿。
- `generation-prompts.txt`：实际生成提示词和整理方法。
- `validation.json`：机器核验结果。
- `aatrox_design_pack.zip`：以上文件及本说明。

## 实际读回核验

| 项目 | A | B |
|---|---|---|
| 翅膀顶到脚底 | 40 格 | 40 格 |
| 原尺寸边界 | 44×40 | 44×40 |
| 角尖到下巴 | 12 格 | 10 格 |
| 翅膀顶 / 角尖行 | 60 / 64 | 60 / 64 |
| 下巴行 | 75 | 73 |
| 双眼行 | 72 | 70 |
| 脚底行 | 99 | 99 |
| 实际不透明色数 | 18 | 18 |
| 透明度 | 仅 0、255 | 仅 0、255 |

每格为严格对齐的 8×8 纯色块，脚底以下没有像素。两只眼睛同一行，中间一格深色；描边色为 #0A0408。两版使用同一身体、翅膀和剑，仅头及连接的颈部区域有差别。头部测量包括最上面的角尖和最下面的下颌描边。

## 制作说明

使用内置 image_gen 生成。生成原稿未能直接满足 40 格规格，用户明确允许脚本整理后，才进行尺寸采样、色板归一、二值透明、头部和双眼修整、外轮廓补全及最近邻 8 倍放大。因此成品是经整理的低分辨率造型稿，并非声称原稿天然就有 40 格。B 的生图原稿保留；最终 B 从 A 的同一身体派生，以保证除头部比例外一致。

造型已查看暗色背景对比；下一步应由用户选择 A/B 后再做动作帧。
