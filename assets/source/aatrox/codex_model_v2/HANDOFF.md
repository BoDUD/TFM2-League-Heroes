# 剑魔 v2 瘦身造型稿交付

用户明确批准在原生40格画布逐像素重新设计身体，替代包内原先的纯生图流程；同时批准头部原样上移2格。最终身体、手臂、翅膀和腿均为新画，未压窄、切列或缩小旧身体，也未复制oppi的像素。

## 文件

- `aatrox_design_A.png` / `B.png` / `C.png`：最终原生像素稿放大24倍的透明图。它们是逐像素重画后的成稿，**不是声称由生成工具直接生成的40格原稿**。
- `logical/aatrox_design_<A|B|C>_1x.png`：最终原生1x精灵。
- `logical/aatrox_design_<A|B|C>_canvas.png`：1024×1024画布，严格8×8网格，脚底第99行。
- `comparison.png`：暗底8倍和1倍并排对比。
- `metrics_<A|B|C>.json`：核验与定位数据。
- `palette.png`：提供的原色板。
- `generated/aatrox_design_<A|B|C>.png`：图片生成工具的未达标原稿，供追溯，**不要用它们替代logical里的最终图**。
- `generation-prompts.txt`：实际生图提示词。
- `draw_aatrox_v2.py`：原生稿重画过程归档，运行时需要本次工作区参考素材路径。

已核验：二值透明0/255、24色以内、脚底以下空白、原样头部、原样剑、各版像素数范围。通过暗底放大预览和1x预览检查。本轮只有待机造型，未制作动作帧，也未修改游戏仓库。用户选择A/B/C后再制作动作。
