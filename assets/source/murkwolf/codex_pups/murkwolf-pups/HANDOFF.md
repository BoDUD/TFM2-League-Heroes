# 小暗影狼侧身六帧素材

使用内置image_gen，依据本次包内定稿与动作参考生成。一只单头小狼，3/4朝右；朝左及两只小狼的摆位留给后续导入。

## 交付

- murkwolf-pups.png：3列×2行，依次stand、breath、crouch、lunge、recover、settle。二值透明PNG。
- raw/murkwolf-pups-generated.png：首稿，原样保留；扑咬格贴近边缘，不作为最终选择。
- raw/murkwolf-pups-refined.png：选用的修订原稿，原样保留。
- generation-prompts.txt、refinement-prompt.txt：实际两次提示词。
- manifest.json：原稿哈希、尺寸、帧区间、可见像素范围和透明通道检查。

## 重要技术偏差

图像工具两次均返回1774×887，未遵守1200×600；因此本包实际画布为1774×887。不是400×300等分格，也不能宣称严格12px网格或脚底276px通过。每帧读取区间已写入manifest，导入时先测实际像素簇再取色。按照输入包要求，没有对成图缩放或重采样，只把alpha按128阈值清为0/255，保持身体和像素位置原样。原稿含半透明边缘，供导入自行读取。

视觉检查：六格均为单头朝右小狼，保留灰蓝毛、白色腮毛、紫色鬃毛、尖刺、粉色嘴和青眼；扑咬张嘴、蓄力收腿和回收姿势有区别。第4格前爪靠近本格右侧，导入应沿完整轮廓读取，勿按假定400px硬切。未宣称与参考骨架逐像素一致。

未修改原有特效包、仓库或游戏安装。后续从crouch→lunge→recover→settle衔接，stand/breath循环；两只均朝右，左向由导入器镜像处理。
