# 海克斯霸龙（金铲铲之战 · 第 16 赛季）：第 0 步，先画像素风原图（给 Codex 的提示词）

> 海克斯霸龙是金铲铲之战第 16 赛季的五费卡（海克斯机甲 / 皮尔特沃夫 / 枪手），技能「海克斯军械库」：**一只机械霸王龙**，两条鸟一样的爪腿站着，一只前爪是**加特林机枪**，背上的装甲能翻开变成**导弹舱**。这一步画两张，**格子大小一样**，用户从里面选一种做游戏造型：
> - **身体**：**深藏青 / 靛蓝色的机械身体**（关节、腹部、小腿，3 档），外面盖着**一块块铜色装甲板**（亮面浅橙铜、中间铜色、暗面深棕铜，3–4 档），装甲板中间嵌着**发光的蓝色 / 紫蓝色面板**（附图 1、5）。**背上一排蓝色发光的水晶尖刺**。**胯部两边各一个圆圆的深灰色齿轮关节**。
> - **头**（附图 3、6 特写）：**铜色的恐龙头盔**，头顶两根往上翘的**铜色尖耳**，中间一条**深灰色的散热槽**；**口鼻上方一块蓝色的玻璃面罩**；**两只圆眼睛**（白色眼珠，一圈红色眼眶），在头盔两侧、面罩后面；**下巴是钢灰紫色的大下颌**，张着嘴，**一排大大的白灰色三角牙齿**，嘴里一颗**发光的蓝色水晶尖牙**；下颌铰链两侧各一个**深灰色的圆形齿轮**。
> - **前爪**：**近处那只是加特林机枪**（附图 1、3）：一圈**六根铜色枪管**围着一个**发光的蓝色核心**，枪管口是一个个深色的圆孔；**远处那只是铜色的机械爪**，三根尖爪指。
> - **腿和尾巴**：两条**鸟腿一样的机械腿**（深藏青的小腿、铜色装甲的大腿），**铜色的三趾大爪脚**，爪尖带一点紫色；**一条长长的机械尾巴**（铜色装甲段 + 中间蓝紫色的发光条），往后翘起来。
>
> 请 Codex 画**两张**（**格子大小一样**）：
> - **A：待机**（金铲铲原样待机，附图 1、2、10a）：**3/4 朝右**，弓着身子、两腿叉开半蹲，加特林端在胸前朝前，张着嘴，尾巴往后上方翘起。
> - **B：导弹舱展开**（施放「海克斯军械库」时，附图 4、10b）：**3/4 朝右**，**背上的两块铜色装甲往上翻开**，像一对竖起来的翅膀 / 发射架（铜框 + 中间蓝色面板），**加特林放低、平端着朝前**，头往前探，张大嘴。
