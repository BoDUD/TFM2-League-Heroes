# 俄洛伊造型原稿交付

本包包含三张由内置 image_gen 生成的二维像素风造型参考原稿；不是 3D 网格模型，也不是已接入游戏的动画素材。

- `illaoi-A.png`：右向 3/4 待机造型。
- `illaoi-SA.png`：同一人物的右侧造型参考。
- `illaoi-T.png`：深海绿卷钩触手、背鳍、螺旋纹与根部石块。
- `raw/`：三张生成原图的逐字节副本。
- `generation-prompts.txt`：每次实际使用的提示词；内置工具模式。
- `qa.json`：逐像素读取的尺寸、透明像素数与 alpha 数据。

## 实际检查结果与限制

三张图均为 1254×1254 RGBA PNG，存在真实透明像素，但生成器未遵守请求的 1536×1536。三张图均含大量半透明像素，因此不满足全硬 alpha 要求。非零 alpha 的极淡像素使原始边界框接近画布边缘，不能直接作为实际主体边界或游戏占用盒。

画面具备完整人物/触手的主要造型与颜色；但未达到严格统一 11px 网格、人物 640px / 触手 550px 高度、统一脚底 y=1390 的规格。A 的两眼透视尺寸并非严格相同；SA 的躯干仍带一定 3/4 透视，不能算严格正侧视图。高发髻与金鼻环等小部件仍需逐格确认。这些是待修项，不能视为规格已通过。

因此本次状态为“造型参考原稿完成，游戏网格与像素验收未通过”。没有以代码绘制替代人物，没有用程序修改生成图，也没有修改原素材包、仓库或已安装模组。后续应按实际原图像素台阶重新绘制到最终游戏网格、硬化 alpha、统一模型比例与落脚线，再制作动作。不能直接将这三张图用于逐格读回或宣称游戏模型已完成。
