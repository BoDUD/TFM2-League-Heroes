# 布兰德第 2 步动作条交付

使用素材包中的定稿造型，内置 image_gen 为七个动作分别生成一次动作稿。生成稿全部保留；交付动作条随后用定稿部件作一致性校正。没有修改外部仓库、导入游戏或制作施法特效。

## 生成与校正方法

七张原稿的实际画布是 2048×768 或 1774×887，且头部、躯干、手部细节被模型重画，不能直接满足定稿逐格一致性。因此没有把原稿脚本缩小或删行后充当正式图，也没有使用上一轮删行的处理方式。

正式图保留定稿的头部、躯干、裤子和腿，以生成稿与 supplied pose 的动作阶段为参照，将定稿手臂连火焰手作为完整部件围绕肩部旋转；跑步、砸地、跃起用原有腿部部件围绕髋部调整，死亡整体转动。旋转使用原尺寸最近邻像素落点，无平滑缩放。少数旋转造成的孤立1–2格残片被清理，一处死亡手臂残片补接；每帧修正数量记录在 manifest 中。最终统一放回指定格子，仅作8倍整数放大。

非死亡动作的头部逐格来自 `brand_head_1x.png`，只平移，已逐像素检查。死亡按照该动作的具体例外，整体依次向左倒至30°、45°、90°；末两帧一致，并将原头部最顶部火舌熄低（只清空火焰像素，未删画布行、未缩放头或身体）。

## 实际检查

- 八张尺寸及格子排列正确，50帧全部检查。
- 每个8×8块完全纯色，和1×图逐像素对应。
- 透明度只有0和255，仅用定稿22色的子集。
- 每帧最低点不超过第81行；下面没有不透明像素。
- 所有帧各有一个8邻域连通的角色轮廓，没有孤立碎片。
- 非死亡的新动作帧头部与定稿头的非透明形状逐格相同。
- R第2–5帧脚底分别离地3、4、4、2格。
- 死亡第7、8帧逐像素一致。
- 原待机文件SHA256与输入文件一致。
- 出手点落在实际不透明火焰颜色像素上。manifest中的bbox及出手点为格子内原尺寸坐标，rect另附8×坐标；出手点另附动作条全局坐标和8×局部坐标。

## 各动作的处理与仍有差异的地方

| 动作 | 提示词段 | 最终动作 / 差异 |
|---|---|---|
| run | RUN | 两腿交叉交替，远腿减暗；头横向相对pivot固定、上下1格。使用刚性腿部转动，膝盖关节的形变较高清动作简化。 |
| attack | FIREBALL THROW | 收手、举手、右向出手、收回。保留躯干原像素，未重画高清动作中的扭腰与弯胸变形。 |
| skill | PILLAR OF FLAME | 双手抬高、双手向右下砸、恢复。低姿采用整组下移与腿部转动，压低幅度较高清原版浅；未拉伸手臂。 |
| skill2 | CONFLAGRATION then SEAR | 聚拢、张臂、蓄力、向右前推、恢复。第3帧E和第6帧Q时机准确；聚拢阶段的部分手臂可遮挡胸口，胸口源图未修改。 |
| ult | PYROCLASM | 收手、跃起、张臂、落地。跳跃高度已限制在3–4格，腿部是原有部件转动，未重画蜷膝造型。 |
| hit | HIT | 整个角色向左平移后恢复，腿沿用定稿。为了头部逐格不变，没有另画头顶火焰摆动。 |
| dead | DEATH | 受击、举臂、30°/45°倒下、90°躺平、火焰降低、末两帧静止。躺平仍保留定稿膝部的弯曲轮廓，未另画伸直腿。 |

本包是供动作外观评审和下一步导入检查的版本。没有将“像素格式检查通过”当成“高清动作逐帧完全复刻”；上述姿势简化已列明。特效与游戏导入属于后续工作。
