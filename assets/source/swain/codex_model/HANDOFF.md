# 斯维因第1步：四张模型候选稿

本次交付范围：按 swain_model_pack.zip 的选定原画与目标图，通过内置 image_gen 重画常态A、恶魔升华B各两稿。四张全部为图像模型直接生成，未用脚本逐格绘制或处理成格子图。待用户选择；未擅自认定某一稿已获采用。

## 文件
- swain-model-A-1.png：常态第一稿，细节密度较高，保留较多胸甲与长衣细节。
- swain-model-A-2.png：常态第二稿，较粗的像素块，头部和脸部更显眼，胸甲与大衣分区简化。
- swain-model-B-1.png：恶魔升华第一稿，保留较细的胸甲、黑红双翼和赤红手臂。
- swain-model-B-2.png：恶魔升华第二稿，参照A-2制作，较粗色块与简化胸甲、黑红双翼。
- raw/：以上四张图的生成原文件，和顶层副本逐字节相同。
- generation-prompts.txt：四次实际提示词；使用内置 image_gen。
- validation.json：尺寸、alpha统计、可见包围盒、SHA256和原始文件一致性。

## 视觉检查
四张均有银白后梳长发、苍白严肃面孔、紫灰近黑高领长衣、暗红内衬、古铜胸甲、皮带扣和全身长靴；A双手为普通深色手套，B左侧为赤红恶魔手臂并有展开的黑红双翼。未加入地面、文字、网格线或独立技能特效。A-2/B-2相对更接近粗像素方向；两组都保留供用户审阅，不能据此判定通过游戏尺寸验收。

## 尚未通过的硬规格
- 请求1024×1024，实际四张均1254×1254，尺寸检查失败。
- 均有真实透明通道，但含256级alpha而非仅0/255，硬alpha检查失败。
- 严格12px网格未认证，生成画面没有精确遵循目标图的发顶y240、下巴y420、鞋底y960。
- A/B的实际身体高度、头部比例与脚底位置并未逐像素一致；B的翅膀高出头顶较多，尤其B-2，未遵守只高2格的要求，且B-2两侧留白较小。
- 3/4朝向下两眼的同排同宽要求、五根分离手爪、连续方折饰边等仍需选稿后逐格核对，不能宣称全部通过。

所有几何、网格和alpha要求均写入实际提示词；生成器未严格执行。本次按交接需求保留模型原稿，没有用程序缩放、网格化或强制清理alpha来掩盖偏差。因此本包是四张候选生成稿，不是通过全部硬规格的最终游戏模型。

## 下一步
由用户挑选A和B的方向后，再按真实像素台阶读回、统一头/身/翼展/脚底，和目标图及其他英雄按游戏尺寸并排审核。当前未制作跑步、普攻、技能、受击、死亡等动作，未改动游戏安装目录。

附件中的艺术规格用于此次制作参考；写给其他人员的接入与选择流程未作为额外执行授权。
