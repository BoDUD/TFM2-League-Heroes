# 斯维因最后一轮特效交付

完成15种特效、共73帧。所有形状源自内置image_gen；后处理仅做原稿切格、逐格取色、色板整理、二值透明、对称校正、对齐和人物遮挡区域清空，没有用代码另画特效形状。

## 导入与预览
- pixel_1x/swain_fx_*.png：正式切格输入，每张单行横排，无间隔。格子大小和帧数见下表及manifest.json。
- 顶层swain_fx_*.png：对应1倍图的精确8倍最近邻预览。
- raw/：15张采用的生图原稿，保持原始文件；原稿使用2行网格，与最终横排图的布局不同。
- previews/：每种效果的循环GIF，140ms/帧只是审阅速度，不代表最终游戏播放时长。
- CONTACT_SHEET.png：15种效果全帧总览，深色底仅用于展示。
- manifest.json：文件名、帧数、格子尺寸、对称轴、绑定关系、游戏显示大小参考、原稿切分位置与校验值。
- validation.json：独立读取最终PNG执行的检查结果。
- generation-prompts.txt：15次采用图的实际提示词，使用内置image_gen。
- HANDOFF.md：本说明。

## 制作与接入说明
生成器没有稳定返回要求的超宽横条和整齐16px网格，所以先生成2行源图，再按实际图格边界切分，在每组统一尺度下重新居中，按逻辑格多数色取回，最后排成横条。Q、禁锢和魂屑原稿带柔光背景，后处理保留亮能量与紫色烟/乌鸦，清掉背景；因此较暗的原始尾迹与细烟会有所减少。极小特效的羽毛、手爪和闪电细节在游戏格子下有所简化，不能把结构检查视为所有视觉细节与原版完全一致的证明。

二值透明和逐格对称以pixel_1x/为准，原稿不具有这些保证。对称校正使用原稿一半反射，不是把两侧叠加。光效边缘的最深红/洋红轮廓提亮；若多数色缩减丢失白芯，将已有能量中的最亮色调映射到白色，不另加几何图形。r_cast、e_hit、r_flare保留中央人物区域；魂屑和新星首帧按需求允许胸口闪光。

按清单未另画r_wings翅膀光环，也未把英雄本人画进特效。manifest里的view绑定来自输入清单，是接入参考；本次未修改游戏文件、运行时绑定或技能逻辑，未进行游戏内播放、落点、地形和遮挡验收。导入时仍需按游戏真实帧时长、脚底锚点和技能范围复核，尤其w_eye、r_cast、r_flare的地面位置，以及e_hit的腿部遮挡。

完成范围是这份特效素材包，不等于整个英雄模组已经通过游戏内验收。
