# 斯维因双形态原图交付

本包提供常态 A 与恶魔升华 B 两张生成原图，用于后续游戏尺寸像素重绘。它们不是已完成的游戏动作模型或可安装模组。

## 文件
- swain-A.png：常态；银白长发、紫灰黑色高领长衣、暗红内衬、古铜色层叠胸甲与普通手套。
- swain-B.png：恶魔升华；沿用 A 的人物、朝向与站姿，增加黑红羽缘翼、近侧赤红恶魔手臂、亮眼与胸甲裂纹。
- raw/swain-A-generated.png、raw/swain-B-generated.png：工具原始输出，逐字节保留；顶层 PNG 是对应原文件的副本。
- generation-prompts.txt：实际执行的 A/B 提示词与工具说明。
- validation.json：自动读取的尺寸、透明通道及可见像素包围盒。

## 检查与限制
已目视核对全身、右前三分之四朝向、长发、大衣、胸甲、两形态角色一致性；B 的双翼和手爪均在画面内，无地面、文字或独立特效。两张均为实际 RGBA 透明 PNG。

严格规格尚未通过：工具实际返回 1254×1254，而非1536×1536；存在半透明像素；没有形成严格11px统一方格，描边也并非可证明的2格。画面细节密度比提供的游戏风格参考高。因此不能将其标记为可直接逐格读回的最终像素模型。未经重绘、网格清理和实际动作适配，不应直接打入游戏。

A 的 alpha>=128 包围盒为 (361,312)-(937,1214)，B 为 (29,162)-(1223,1212)。主体站姿视觉上接近，但不是经过逐像素对齐验证的共享骨架。B翼展接近画布边缘，后续排版需要扩大留白。

后续接入工作：在1536画布上按同一11px逻辑网格重绘两张，统一头顶/脚底和身体骨架；再制作跑步、攻击、技能、受击、死亡等动作，以及独立技能特效。本次未修改安装目录或任何游戏配置。

生成方式：内置 image_gen。附件中的提示文档作为美术需求参考；其中写给其他工具/人员的接入流程没有作为额外执行授权。
