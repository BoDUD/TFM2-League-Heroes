# 凯南举手里剑手臂 A/B/C

按附件要求，只在原底图透明区域增加远侧手臂和手里剑。原底图所有不透明像素的 RGBA 完全保留；允许区域以外的透明像素也完全不变。头、脸、兜帽、身体、近侧爪子及腿脚均未修改。

## 三版区别

| 版本 | 处理 | 新增范围，1×坐标，上界不含 |
|---|---|---|
| A | 保留生图的斜向弯肘和握持姿势 | x=74–90，y=64–87 |
| B | 基于 A，手和前臂上移一格，肘段更靠外，最多右移两格；手里剑上半部维持高度 | x=75–90，y=64–86 |
| C | 基于 A，手和手里剑下移一格，肘段向内一格 | x=74–90，y=65–88 |

A 的手臂来自内置 image_gen。继续独立生成 B/C 时，工具返回 `usage_limit_reached`（HTTP 429）。因此 **B/C 是 A 的逐格位置变体，不是另外两张独立生图**。位置调整只处理新增图层，不对底图进行变形。实际成功提示词、参考图和整理参数保存在 `generation_prompts.json`，原始生图保存在 `raw/generated_arm_A.png`。

## 交付文件

- `kennen_arm_A.png`、B、C：1024×1024，透明，严格 8×8 像素格。
- 同名 `_1x.png`：128×128 原尺寸。
- `arm_only_A.png`、B、C，以及 `_1x.png`：仅新增图层，方便单独查看手臂与手里剑。
- `base_unchanged_1x.png`：原始底图副本。
- `preview_ABC.png`：灰底比较预览；标签和背景仅存在于预览中。
- `manifest.json`：验证结果；`palette.gpl`：底图原色板。

## 检查结果与制作范围

三版底图原有像素改变数均为 0，允许区域外改变数均为 0。所有新增像素 x≥74、y≥63、y<90；没有越过手里剑顶部的橙线，全部位于腰部以上。原图和新增部分共 21 色，没有新增色。透明度只有 0/255；8×8 网格错误数为 0；鞋底仍在第 99 行。新增像素都与原底图相连，没有独立浮空碎点。脸和眼睛逐像素保持原样。

整理时按原始输出画布的 128×128 逻辑格读取每格中心 3×3 中位色，压到附件指定的袖子、手套、金和钢蓝色，透明阈值 128。仅把读取到的新增像素合成在底图的透明允许区域中；补齐新增彩色部分缺少的外描边，剔除没有连接到底图的碎点。B/C 的逐格移动会使袖口和肘部局部外形发生少量变化，并非完全重画的三种手臂解剖方案。

手套与袖口在眼睛附近，前臂和上臂有斜向弯折，三版可在 `preview_ABC.png` 比较。手肘和袖口局部外轮廓会比 2–3 格的核心手臂宽；像素级自然程度、握持姿势和这一宽度是否满意仍需通过预览判断。未把原稿的精细雕纹硬塞进游戏尺寸，也未修改角色已有的造型。
