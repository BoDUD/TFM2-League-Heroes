# 凯南造型图 A / B 交付

本轮只生成待机造型参考，两版区别为背上手里剑大小。使用内置 image_gen 生成，再按原稿自身的像素格取色整理导出；未把相邻原稿格子缩并为一个像素。

## 文件

- `kennen_design_A.png`、`kennen_design_B.png`：1024×1024，严格 8 倍放大的透明 PNG。
- `kennen_design_A_1x.png`、`kennen_design_B_1x.png`：128×128 原尺寸画布，每个逻辑格为一个像素。
- `raw/kennen_design_A_generated.png`、`raw/kennen_design_B_generated.png`：未经整理的生图原稿。
- `raw/kennen_initial.png`：最初较复杂的稿件，作为过程留档。
- `palette.gpl`：21 色 GIMP 色板，可导入绘图软件。
- `generation-prompts.txt`：实际提示词、参考图说明、格子取色方法。
- `validation.json`：尺寸、颜色、透明度、眼睛坐标及两版差异检查记录。

## 实际尺寸和验证

| 项目 | A | B |
|---|---:|---:|
| 兜帽顶到脚底（视觉辨识帽顶，含描边、不含耳朵） | 约 40 格 | 约 40 格 |
| 含手里剑总高 | 48 格 | 43 格 |
| 轮廓总宽 | 34 格 | 29 格 |
| 实际可见色数 | 21 | 20 |
| 脚底最后一行 | 99 | 99 |
| 8×8 格对齐错误像素数 | 0 | 0 |
| 半透明像素数 | 0 | 0 |

脚底在 y=792–799，下面没有可见像素。背景是真透明，只有 alpha=0/255。两脚中央约在 x=512 附近。

## 尚未严格满足的细节

该版本是素材包允许的最接近稿（兜帽到脚底约 40 格），不是严格 32 格最终造型。A/B 总高未达到 38/35 格，头部也偏大。蓝眼睛仍有一行错位，未严格形成同一行的两个 2×2 眼睛。模型编辑 B 时有少量身体像素变化；两版不是仅武器不同的完全相同身体。已在 `validation.json` 记录蓝色格坐标和身体差异。

请先根据造型选择版本；这些 PNG 可以作为后续整行整列删减、统一眼睛和身体的素材，尚未出动作帧，也尚未导入游戏。
