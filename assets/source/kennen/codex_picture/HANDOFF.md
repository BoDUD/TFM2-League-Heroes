# 凯南像素风原图交付

- `kennen-model-A.png`：待机，两只爪手举在胸前，金色手里剑背在背上。
- `kennen-model-B.png`：准备投掷，手里剑举在头旁边，近侧爪手放低。
- `generation-prompts.txt`：实际生成提示词、参考图列表和 A 版编辑提示词。

使用内置 image_gen 生成，两张 PNG 均为 1024×1536，并带真实 alpha 透明通道。已检查角色外观、两种姿势、完整人物和透明区域。部分预览器会显示透明像素中保留的颜色数据；请在支持 alpha 的图像软件中查看。

素材包作为外观和风格参考。生成工具最多接收五张参考图，因此每版选择三张凯南模型参考、菲兹和乐芙兰两张风格参考。

限制：生成结果人物占画布较大，未精确达到参考文档中的约 1150 px 人物高度；两版适合作为后续精灵制作的原图，尚不是游戏尺寸精灵或动画帧。
