# 克烈双形态造型原图交付

## 本次范围与状态

依据 kled_pack0.zip 的角色与风格参考制作第 0 步造型原图：A 骑乘斯嘎尔待机，B 下马持斧。使用内置 image_gen 生成；B 以 A 为身份参考。未制作动作帧、运行时机制或安装游戏资源。本包是后续模型制作的原图输入，不是已经通过游戏验收的模型包。

## 文件

- kled-A.png：1536×1536 RGBA，骑乘造型。
- kled-B.png：1536×1536 RGBA，下马造型。
- raw/kled-A-generated.png、raw/kled-B-generated.png：工具原始输出，未修改。
- generation-prompts.txt：两次调用实际使用的完整提示词。
- export-kled.ps1：可复现的画布与硬 alpha 导出脚本。
- qa.json：导出文件的尺寸、alpha、可见范围检查。

## 导出与检查

两张导出均为真透明，alpha 仅 0 / 255；轮廓完整，3/4 朝右；没有地面、投影、文字和技能特效。导出仅做 alpha 128 阈值、最近邻等比例缩放及透明画布排版，没有用代码绘制造型。原始生成稿含半透明边缘，因此请读取 raw 时自行留意 alpha。

A 可见框 [568,840,968,1390]，400×550；B 可见框 [560,993,976,1390]，416×397。两张使用同一缩放率 0.468883205456095，脚底基线同为 y=1390；B 的头部沿用 A 的设计，生成细节仍有轻微差异，动画阶段应提取并复用唯一头部母版。

## 与参考规格的差异（不能当作已通过的项目）

生成器没有遵守严格的 11px 单一格网或 2 格外描边，原稿密度比目标细，不能直接按 11px 方格读回。未将其强行缩成 50 格，以免破坏脸部和武器。这是造型原图，而非最终游戏尺寸像素母版；下一阶段需先人工测量实际阶梯并统一重栅格。

B 实际可见高度 397px，高于参考的约 319px；这里采用与 A 相同缩放，优先保留头部尺度。A/B 斧头姿态与轮廓也未像素级共用；制作动画前需统一武器母版和最终 PPU，不能宣称已满足同一模型逐帧复用。

未验证跑步、攻击、受击、死亡、上下马动画，未验证战场地形遮挡、头像裁切和游戏启动，不应据此宣布克烈游戏模型已完成。

## 后续制作建议

以 raw 的身份设计为参考，先制作最终尺度的骑乘/步行像素母版，共用脸、帽子和斧头；定好头部尺度、斯嘎尔腿长及 PPU，再开展动作帧。参考图内的其他英雄仅用于风格，没有作为克烈身体的替换素材。
