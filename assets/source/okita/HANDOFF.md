# 冲田总司美术与音频交接

英雄前缀为 ragnarok_okita。动画角色设定提供红格围巾、浅蓝羽织、深色袴和高马尾。漫画第十回合的红眼「鬼子」为状态演出的依据。三连刺、终结突刺及光效的游戏表现属于 Mod 设计。 [动画角色页](https://ragnarok-official.com/chara/sojiokita.html) [漫画第 22 卷介绍](https://www.coamix.co.jp/topics/ragnarok202407)

## 交付文件

- atlases 包含角色与特效的逻辑版、4× 像素版和逐帧配置。每个逻辑单元 116×92 px，角色脚底参考点 (52, 84)，特效单元参考点 (58, 46)。两个角色图集的 64 帧沿用逐帧检查后的动作组。每组角色和特效各有 8 帧。
- runtime 内含常规与 hd_ 轨、原生 fanim 格式、美术与音效路径。插画为 1216×1428，四枚图标均为 256×256。导入分辨率和地图显示尺寸分别调整，后者以 PPU 调整后在实机中复核。
- audio 内有 44.1 kHz 单声道 WAV 母带和 MP3。sources.json 区分原创音效和角色对白，并记录已核对对白的来源与剪辑区间。本版六条日语对白由 Mod 原创撰写并演绎，供选人、开战、挑战、Q、E 与 R 随机或按事件接入。来源声明记录在 sources.json。
- preview/review.html 支持循环、逐帧、朝向、浅底、独立特效检查和声音试听。该预览用于素材检查。

## 给 Claude 的接入约定

- 素材层不声明伤害、冷却、碰撞、位移和 AI。以 atlases/frames.json 中从 1 开始的帧号和秒数为初始同步点，通过游戏内技能逻辑决定结算。
- 普攻第 5 帧播放刀光和出刀声。三连刺在第 2、4、6 帧各自出刺。鬼子第 2 帧蓄势、第 5 帧红眼启动；如果代码实现持续状态，在有效期叠加 oni_aura，状态结束后停止。终结突刺第 2 帧蓄势、第 4 帧释放。
- sword_hit 与 finisher_hit 是真实命中事件。quick_step 是触地与位移的可选特效，用于脚底附近。镜像时对特效朝向和偏移 X 同步镜像。
- 验收覆盖角色注册、PPU、朝向、选人裁切、UI、伤害触发和回放一致性。当前交付只证实素材和原生动画路径的静态校验。
