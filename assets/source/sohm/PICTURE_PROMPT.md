# 索姆（金铲铲之战 · 第 7 赛季）：第 0 步，先画像素风原图（给 Codex 的提示词）

> 索姆是金铲铲之战第 7 赛季（巨龙之巢）的四费卡（碧波龙 / 法师 / 龙神），技能「潮涌」：**一条一直浮在空中的东方海龙（细长的蛇形身子，像中国龙），长长的身子在身下盘成一个圈**。这一步画两张，**格子大小一样**，用户从里面选一种做游戏造型：
> - **身子**：细长的蛇形身子，**浅水蓝 / 天蓝色**（亮面近白的浅青，暗面偏深的湖蓝，3 档），肚子一侧颜色更浅；**背脊上一整条粉色 / 洋红色的软鳍**，从脖子后面一直到尾巴；**尾巴很长，末端是一片长长的深绿色海草状尾鳍**（像一片弯弯的大叶子，深绿到墨绿，边上带一点紫）。**四条小腿**：两条细细的前臂收在胸前（小手，三根浅蓝色小爪），两条后腿在身子中段，脚是浅蓝色的三趾小爪。
> - **鬃毛**（附图 1、3、5、6）：后脑和肩膀上**一大片往后飘的鬃毛，颜色从青绿渐变到深紫**（上面青绿，下面和里面深紫），一缕缕像海草，盖住脖子和肩膀；下巴底下还有一小撮青绿色的胡须。
> - **头和脸**（附图 3、6 特写）：头**细长、口鼻往前伸**，浅水蓝色，鼻尖略圆；**头顶戴着一顶金橙色的头冠**（左右两片弯弯的金橙色角片，额头正中**一颗菱形的紫色宝石**，宝石上面是几片紫色 / 淡紫的鳞片）；**两根很大的珊瑚红 / 鲑鱼红的鹿角**从头冠后面往上长，每根分出两三个叉，尖端朝上（近处那根角上有一颗小小的金色星星）；**一对尖耳朵**往两边翘，耳朵里面是粉色。**眼睛是细长的杏仁眼，深蓝色**，眼角往后上挑，表情温柔、有点高傲（近处那只要看得清楚）。
>
> 请 Codex 画**两张**（**格子大小一样**）：
> - **A：浮空待机，3/4 朝右**（金铲铲原样待机，附图 1、2、10a）：头和鬃毛在上面，脸朝右前方；身子从脖子往下、往左弯，在身下**盘成一个圈**（像字母 C / 一个问号）；两只小前爪在胸前微微抬起，两条后腿悬在身下；**尾巴从下面往右绕出来，绿色的海草尾鳍往右上方翘起**。她是飘着的，**脚不着地**：最低点是盘起来的身子 / 后脚。
> - **B：同样的待机，正侧面朝右**（附图 4、6、10b）：还是浮空、身子盘在身下，但**侧过来**，能更清楚地看到**细长的口鼻和杏仁眼、金橙头冠和紫宝石、两根珊瑚红鹿角、尖耳朵、往后飘的青绿到深紫的鬃毛、背上的粉色软鳍、绿色海草尾鳍**；近处的眼睛清楚可见。

> - 不画任何技能特效（水浪、水花、水泡、水之花、光圈、闪光都放到后面单独画）；不画地面，不画投影，不画水。
