# 阿卡丽动作资源 v2 — 锐利杏眼

本版根据用户最新要求重新制作造型与全部动作。新版眼睛采用较窄眼白、棕色瞳孔、上挑眼线；近眼略宽、远眼略窄，以保留 3/4 透视。最新要求优先于旧包里“大块矩形眼白、双眼等大”的说明。

## 交付内容

- 根目录 `akali_*.png`：11 张透明动作图，共 64 帧，包含重新制作的待机。
- `native/`：同一套原生分辨率图，每格 96×96。
- `design/`：新版 128×128 造型、8 倍造型、独立头部、闭眼头部及新旧眼睛对比。
- `previews/`：各动作 GIF、无损动画 WebP、逐帧图与全动作概览。
- `preview.html`：独立离线预览，支持选择动作、暂停、逐帧、慢放和显示站位/脚底线。双击后用浏览器打开，不需要服务器。
- `manifest.json`：逐帧矩形、站位、时长、透明边界、头部位置、旋转角及出手帧/tick。
- `akali_cells.json`：保留原包站位和时长数据。
- `generation_prompts.json`：新版造型和十组动作的生成提示词。
- `validation.json`：结构检查结果。

## 制作与检查

十组动作重新生成，未使用被否定的上一批动作图。待机用新造型制作六帧轻微呼吸。每组动作先提取完整人物，再统一到原生像素格，避免生成图人物跨格导致的断脚、断武器；强化普攻补齐了回收帧的远端镰刀。

睁眼头部使用同一块 16×17 像素素材逐帧复制，避免眼睛随机变化；受击第一帧及死亡使用统一闭眼素材，倒地时整体旋转。非循环攻击动作的最后一帧回到新版待机造型。动作身体和马尾仍按各帧动作绘制。

已逐帧查看所有动作图，并自动检查：

- 源动作 PNG 仅使用原包 27 色调色板内的颜色；透明度只有 0/255。
- 每个导出像素严格为同一网格上的 8×8 方块；不使用平滑插值。
- 两张五帧动作的末格完全透明。
- 普通帧没有像素超出原生 y81；死亡第 6–8 帧不超出 y83。
- 两种眼睛专用色在头部范围之外没有像素；未旋转头部的非透明像素与对应头部素材一致。
- 跑步头部相对站位的横向偏移固定，上下范围为 1 个原生像素。

## 导入说明与范围

每格导出尺寸为 768×768，原生尺寸为 96×96。按从左到右、从上到下读取。`rect` 使用导出像素；`rect_native`、`pivot`、`bbox`、`head_rect` 使用原生像素。`bbox` 格式为 `[left, top, right, bottom]`，右下边界不包含；`head_rect` 为 `[x, y, width, height]`。`pivot_px` 为单格内站位的 8 倍坐标。

原包中的 `head` 坐标用于参考，本版实际头部位置以 `manifest.json` 的 `head_rect` 为准。新版待机及新版造型应随整套一起替换，避免回到旧眼睛。普通动作不循环；死亡应保持最后一帧。预览为了便于检查，会循环展示所有动作。

HTML 和 WebP 使用原始毫秒时长。GIF 以 10ms 为时间单位，105ms 跑步帧会有取整差异，不能用 GIF 反推技能时机。技能时机以 JSON 为准。

Q/E 投掷释放帧保留张开的投掷手，不画飞出武器特效。动作姿势是像素重绘，身体轮廓与马尾并非原 3D 参考的逐点复刻。结构检查不等同于游戏内验收：本次未修改游戏目录，未运行导入器或游戏模拟；实际导入后的血条、头像裁切和技能触发仍需在游戏中检查。
