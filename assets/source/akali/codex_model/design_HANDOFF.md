# 阿卡丽 A / B 像素造型交接

本轮交付两版静态造型，无动作帧。按照用户压缩包内 MODEL_PROMPTS.md 的造型要求制作。

## 文件

- `akali_design_A.png`：A 版，保留参考图偏修长的身体比例，1024×1024 透明 PNG。
- `akali_design_B.png`：B 版，大头、短腿的 Q 版比例，1024×1024 透明 PNG。
- `akali_design_A_1x.png`、`akali_design_B_1x.png`：对应 128×128 原生像素图。
- `akali_AB_preview.png`：灰底并排预览，仅用于看图，不是导入素材。
- `prompt_A.txt`、`prompt_B.txt`：实际使用的完整生成提示词。
- `validation.json`：文件级核验结果。

## 使用的方法和提示词

使用内置 image_gen 工具分别生成 A、B；未使用 API CLI 或 bridge。提示词基于包内“akali_design_A.png、akali_design_B.png”英文提示词拆分。

A 输入依次是原造型、尺寸参照、眼睛参照、剑士风格参照、格斗风格参照；强调原造型比例。B 输入依次是剑士风格参照、格斗风格参照、原造型、眼睛参照；强调更大的头脸、更短的腿和原版游戏的简洁色块。

生成底图没有直接满足严格网格和双眼可读性，因此进一步做了统一网格、固定调色板、移除部分孤立杂色、重绘双眼/面罩、加粗纹身/腰布纹样、整理轮廓和脚底基线。此处整理的是新生成底图，并非把用户原图直接缩到约 46 像素游戏尺寸。

## 已核验

- 两版各 29 种不透明 RGB 颜色；包括透明色也不超过 32 种。
- Alpha 仅 0 或 255；透明区域 RGB 清零。
- 原图 128×128；放大图 1024×1024，每个逻辑像素是严格对齐的 8×8 同色方块；无插值。
- 头顶基准 y=32，脚底 y=111，头顶至脚底按含端点计为 80 行；马尾尖不计入。
- 最下面 16 行完全透明；两脚补齐到同一基线，武器位于基线上方。
- A 双眼框为近眼 4×3、远眼 3×3；B 为近眼 5×3、远眼 4×3。每版两眼同高，眼线下有眼白和棕色瞳孔。
- 眼白 #FFF7E5 和瞳孔 #6A3823 仅用于双眼。
- 外边缘采用一格近黑描边，内部原近黑块改为带色暗部；眼线保留近黑。

## 未完全做到／后续需要注意

- A 是对原图的低分辨率重绘，并非形状与比例逐像素一致；为容纳双眼，脸部比底图更偏正面。
- B 头部约 24 行，占 80 行身高约 30%，接近而非精确三分之一。A/B 分别生成，马尾与武器未做到两版之间逐像素同尺寸。
- 大部分关键纹样已加粗，但刀尖、部分刀刃高光、金属连接点和绷带窄处仍可能只有一格，不能保证所有细节都达到至少两格宽。
- 使用全局固定调色板；未逐材质强制恰好 4–5 个实际色阶。仍有少量小色块，不能视为完成了所有单像素细节的手工审校。
- 已整理单圈轮廓，但狭窄尖端和斜角处的视觉厚度仍需结合游戏最终尺寸判断。
- 本轮未做约 46 行的 seam 缩放、实际游戏导入或动画验证。后续应按原说明进行行列删减、检查眼睛与两像素细节，并在游戏暗色卡片上比较后再定稿。

请以 `_1x.png` 作为后续编辑源；避免双线性或双三次缩放。需要查看放大图时使用最近邻。
