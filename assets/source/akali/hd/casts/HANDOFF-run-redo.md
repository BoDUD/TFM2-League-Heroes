# 阿卡丽跑步重画

本包仅交接本轮重画的 4 张跑步图、8 帧。使用内置 image_gen；人物参考来自 `akali_run_pack.zip` 的定稿设计，动作参考来自同包模板和旧帧。主要修正上一轮缺少胯下换步的问题。

## 交付文件

- run_1.png：第 1、2 帧。
- run_2.png：第 3、4 帧。
- run_3.png：第 5、6 帧。
- run_4.png：第 7、8 帧。
- raw/run_1-01.png … run_4-01.png：四张原始生成图，与主目录对应 PNG 逐字节相同。
- generation-prompts.txt：四次实际提示词、工具和输入顺序。
- sheets.json：输入包清单原样复制，跑步时长仍为每帧 105ms。
- validation.json：尺寸、颜色、背景角点、粗边界、原图一致性和 SHA256 检查。
- comparison-preview.png：模板与重画对照，仅供浏览。
- run-preview.gif：按 1–8 帧排列的循环检查预览，仅供浏览。

主目录四张图均实测为 1536×1024、左右两格，未缩放、裁剪、重排、改色。只有诊断预览提取/缩小了单格，不能用预览替代原图读取。GIF 用交替 100/110ms 表示平均 105ms，未修改清单中的原动作时长。

## 逐帧目视检查

| 帧 | 新图中的腿部姿势 |
|---|---|
| 1 | 两脚落下，前后大幅分开。 |
| 2 | 支撑脚收至胯下，另一膝抬起，脚收在腹部下方；没有长后伸腿。 |
| 3 | 单脚支撑，另一膝抬高，双脚聚在身体下方。 |
| 4 | 后腿向后伸、后脚抬起；前腿向前展开。 |
| 5 | 再次收腿换步，支撑脚在胯下、另一膝前抬；按后半周期绘制。 |
| 6 | 后半周期的展开帧，后脚抬起、前脚向前；前后腿以深浅和遮挡区分。 |
| 7 | 收腿过渡，单脚支撑、另一膝前抬。 |
| 8 | 两腿进一步聚拢，一脚支撑，另一脚收在旁边。 |

第 2、3、5、7、8 帧已明显区别于大幅分腿的第 1、4、6 帧。近侧手均持弯钩、远侧手持直刀；没有增加烟尘、速度线或其他动作特效。模板标签、灰线和边框没有复制进四张原画。

近远腿的半周期切换仍需要在最终读回/拼帧时结合腿的遮挡与色阶复核，不能仅凭左右脚坐标认定通过。这份预览没有自动对齐脚底或头部，故也保留了原图本身的尺度和位置差异。

## 实际检查的限制

- 尺寸和原图一致性均为 4/4 通过。
- 生成器仍引入了调色板外的颜色与很浅的背景色差：严格纯白背景和精确调色板均为 0/4 通过，不能标为硬透明或纯白合格图。
- 统一 8px 网格、头顶至面罩恰为 21 格、跨张比例完全相同及脚底 y924 的精确测量尚未通过。人物脚底/中心存在漂移，需要后续按模板对齐；粗边界不是脚底或头部测量。
- 因此本包是腿部动作已重新设计的原画交接包，尚不能宣称为全部像素规格通过的游戏动画。没有修改或安装任何游戏文件。
