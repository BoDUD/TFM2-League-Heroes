## 检查结果

四张均为 1254×1254 RGBA，符合画布尺寸。视觉像素密度较第 0 步明显变粗，人物全身、头发、手与腕藤均在画面内。

但四张 alpha 都有 256 个取值，含半透明像素，未通过仅 0/255 的要求。16px 网格、66 格人物高度和 y128/y1184 基线未通过；水平量化色段只是辅助检查，不是格子大小的严格测量。A 稿主要色段约 13–16px，SA 稿主要色段约 8–12px，仍有更小的细节和非均匀台阶。不能按固定 16px 网格直接读回。
