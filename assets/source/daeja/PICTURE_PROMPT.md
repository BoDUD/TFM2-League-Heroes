# 迭嘉（金铲铲之战 · 第 7 赛季）：第 0 步，先画像素风原图（给 Codex 的提示词）

> 迭嘉是金铲铲之战第 7 赛季（巨龙之巢）的四费卡（幻镜龙 / 龙神），技能「罡风轰击」：**一个用两条腿直立站着的蓝色水晶龙人**。这一步画两张，**格子大小一样**，用户从里面选一种做游戏造型：
> - **全身**：肩宽腰粗的壮汉身材，皮肤是**冰蓝 / 青蓝色的水晶质感**（亮面浅青，暗面深蓝，3–4 档）；**胸口和肚子上是一层层深蓝紫色的人字形甲片**（中间一道淡紫色的亮边）；**肩膀、上臂、前臂外侧长着一排古铜 / 银灰色的尖刺**。
> - **头和脸**（附图 3、6 特写）：头比较小，往前探；**脸上是一副古铜色的龙骨面甲**（眉骨两边像小翅膀一样往外翘，额头中间一根古铜色的尖角往上竖），面甲下面是**一双发光的品红 / 粉紫色眼睛**，面甲下沿露出几颗小白牙；**脖子、下巴和胸口上方是一大团蓬松的浅青蓝色鬃毛（像胡子一样往下垂，中间偏淡紫）**；头后面竖着**两撮青蓝色的火焰状鬃冠**。
> - **双手**：两只拳头 / 爪子是**发光的青色水晶**（最亮的地方近白），待机时垂在身体两侧、微微张开。
> - **翅膀**（附图 1、5、7、9）：**两片收起来的大翅膀从背后往上竖起，高过头顶很多**：每片是一根**深紫色、带一排尖刺的翼骨**，弯弯地往上伸成一根长尖，**翼膜像一把收起的扇子，从青蓝渐变到紫色，外缘一圈尖尖的锯齿**。两片翅膀在头后面左右分开，像两把竖着的弯刀。
> - **腿和尾巴**：两条**深紫黑色的腿**，外侧有尖尖的甲片，脚上是**黑色的三趾利爪**；**一条短一些的蓝色尾巴**从身后拖到地上，背上一排小刺，**尾巴尖是一片古铜 / 灰色的叶子形尾鳍**（附图 1、9）。
>
> 请 Codex 画**两张**（**格子大小一样**）：
> - **A：直立待机，3/4 朝右**（金铲铲原样待机，附图 1、2、10a）：两腿分开站稳，膝盖微弯，身子略往前倾；两只发光的水晶拳垂在身体两侧；两片收起的翅膀从背后竖起、高过头顶；尾巴从身后拖到左下方、尾鳍贴着地面。
> - **B：同样的待机，正侧面朝右**（附图 4、6、9、10b）：还是直立站着，但**侧过来**，能更清楚地看到**往前探的头、古铜面甲和发光的眼睛、垂下来的鬃毛、背后竖起的翅膀有多高、发光的拳头、腿和尾鳍**；离画面近的那只眼睛清楚可见。
>

> - **画布用正方形 1536×1536**。**A：从最高点（翅膀尖）到脚底约 570 px，也就是约 52 格**，宽约 34–44 格（最多 50 格）；**B：同样的格子大小**，约 50–52 格高，宽约 34–44 格（最多 50 格）。脚底在离画布底边约 146 px 的地方（附图 10a、10b 的灰线），位置照附图 10a、10b。翅膀、尾鳍、拳头、鬃冠全在画面里，不能出画。
> - **像素块**：大小一致的方块，**每块 11 像素**，横平竖直对齐成网格；**外轮廓一圈 2 块宽的近黑描边**；每种材质内部 3–4 档平涂，不要零散的单个杂色格。暗处用这种材质自己最暗的一档，不要一圈黑。**水晶皮肤**画成几块有棱角的大面（亮面 / 暗面分明），不要碎点；**翼膜**按扇骨分成几条，每条从青蓝到紫两三档。
> - 不画任何技能特效（风、气流、冲击波、弹幕、光圈、闪光都放到后面单独画）；拳头本身的青色发光照模型画（是身体的颜色，不是特效）；不画地面，不画投影。
