# 锐雯动作图交接

本包包含 10 张新动作图，共 65 帧。使用内置 `image_gen` 生成，经用户明确允许后，用脚本完成像素整理。待机未重新生成，原件放在 `reference/riven_idle.png`。

## 文件

- 根目录 `riven_<动作>.png`：指定排版的 8 倍透明动作图，每格 768×768 像素。
- `native_1x/`：对应的原始游戏尺寸，每格 96×96 像素。
- `preview.html`：离线动画预览，可暂停、逐帧查看、调速、显示站位点和脚底线。
- `previews/`：总览、逐帧联系图及 10 张 APNG 动画预览，APNG 保留毫秒时长。
- `manifest.json`：文件、尺寸、格子、帧时长、出手帧、站位点、不透明包围盒和面积、眼睛中心、头部位置与旋转、文件哈希。
- `prompts/riven_<动作>.txt`：每张图实际使用的完整提示词。Q3 文件另附砸地姿势修正提示词。
- `raw_generated/`：模型生成原图，未达到最终像素规格，不用于直接导入。
- `reference/`：定稿造型、复制的头部母版、原待机和原始规范。
- `validation.json`：参数检查的逐项结果。

## 已完成的整理与核查

65 帧通过 504 项参数检查：指定文件尺寸、帧数和空格；严格的 8×8 同色方块；不透明像素仅使用定稿的 27 色；透明度仅 0/255；脚底线限制；原帧时长与站位点；头部母版中每个不透明像素与原图一致；两只眼睛各 2×2、三色仅出现在眼睛位置。直立头部的双眼同一行；死亡第 5–8 帧的头部整体顺时针旋转 90°，眼睛随头部旋转。

头部从定稿图的 `[50,54,77,72)` 区域提取，去除下缘肩部、衣领像素后直接复制，母版见 `reference/head_master_1x.png`。非跑步、非死亡动作的末帧直接采用原造型站姿，并按该帧站位点移动。跑步头部纵向起伏为基准上下各 1 格。Q3 第 5–6 帧额外用图像模型修正为向下砸剑。死亡倒地帧的断剑使用原造型提取后旋转的母版。

## 没有完全做到的地方

这些文件已经达到上述可测的像素与排版规格，但不能称为对原参考的逐像素完整复刻：

1. 身体与四肢由模型按参考重绘，姿态、手臂粗细、重心和部分收招仍与 3D 动作参考存在差异。为了保持定稿头部及连接位置，若干颈部、手臂连接处做了像素修补。
2. 除死亡倒地帧外，断剑沿用各生成帧的剑形；角度间的长度、宽度、断口和符文并非来自同一张母版，无法保证每帧严格相同大小。
3. 调色板严格限制为 27 色，但“每种材质仅 2–3 阶”和“所有轮廓恰好一格宽”没有做完整语义分割认证，局部可能有较厚的暗边。
4. 帧间不透明面积随姿态而变化，具体数值已记录；不是每帧与待机面积相等。倒地、蜷腿等帧尤其不同。
5. 采用每项动作说明的起手姿态，未强行把每条第 1 帧替换为待机。跑步循环与死亡结尾遵守各自的动作说明。头部原像素得到保留，但其实际位置根据生成的身体和脚底线整理，并非严格照搬 JSON 中的全部 `head` 坐标；两者均保留在清单中供对照。
6. 尚未导入游戏实测动画衔接、角色血条或技能判定。本包不包含技能光效。
7. HTML 预览页已做脚本语法检查，但未完成浏览器交互实测：浏览器工具的 URL 安全策略禁止访问本地 file 协议。没有绕过该限制；PNG 与 APNG 文件已独立核查。

## 坐标与时序

`manifest.json` 的普通坐标使用 0 起算的逻辑像素（96×96 格）。包围盒右、下边界不包含在内。`*_px` 字段使用 8 倍导出像素；`rect_px` 是图集中的绝对格子位置，其余坐标为格内坐标。帧编号、出手帧为 1 起算；tick 直接沿用原表。眼睛普通中心以像素索引平均值表示，导出像素中心额外加 0.5 再乘 8。
