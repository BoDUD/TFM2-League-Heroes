# 锐雯缩小版精灵图

## 文件
- riven_design_A.png / riven_design_B.png：1024×1024透明画布，8倍像素图。
- riven_design_A_1x.png / riven_design_B_1x.png：128×128原尺寸画布，人物可见高度46格。
- comparison.png：同尺度A/B预览，灰底及文字仅用于预览。
- sources/：采用的两张生图原稿。
- generation_prompts.json、manifest.json、export_grid.py：实际提示词、调色板与尺寸记录、可复现整理脚本。

## 造型
白色短发与后束发、绿色衣服、棕色皮革、非对称肩甲和绷带。保留厚重断剑的锯齿断口与绿色符文。A为基础比例；B头脸略大、躯干更短，断刃更紧凑。只有静态模型，未制作动作，未修改游戏。

## 方法
内置image_gen.imagegen生成小构图，B由A编辑。沿用前轮Pillow网格整理：alpha>=128主体提取、预乘alpha缩到46格、共享调色板无抖动减色、二值透明、脚底对齐后最近邻8倍导出。保留绿色材质候选色，避免符文和衣物识别色完全丢失。

## 已检查
- 两张角色高46格，原图128×128、放大图1024×1024。
- A为29色，B为31色，均不超过32色。
- alpha仅0/255，每个像素严格对应8×8纯色块。
- 脚底第99行，即y792–799；y>=800完全透明。
- 放大图缩回1倍再放大逐字节一致。
- 查看过最终对比图：白发、护甲、厚断刃和断口可辨；剑尖高于靴底。

## 限制
脸部及细装饰在原尺寸仍很小，眼睛远近大小、专用眼色唯一性、全轮廓严格单像素尚未逐格认证。未做游戏实机/HUD裁切或动作验证。后续动画应基于选定1x模型制作。
