# 锐雯像素设计稿交付

依据用户提供的 riven_ppu_pack.zip 制作，交付两张静态像素设计图。

## 文件

- `riven-A.png`：锐雯全身待机设计图，白发、绿色肩甲、背后扛断剑、胸前张手。
- `riven-R-blade.png`：独立重铸剑，断剑金属底段与绿色能量延伸段。
- `raw/riven-A-generated.png`、`raw/riven-A-refined.png`：人物原始生成图，未经导出处理。
- `raw/riven-R-generated.png`、`raw/riven-R-refined.png`：重铸剑原始生成图，未经导出处理。
- `generation-prompts.txt`：实际生成与调整提示词。
- `validation.json`：最终图片尺寸、透明度与网格验证结果。

## 导出与检查

生成图通过最近邻采样导出，统一到 11×11 像素方块网格；alpha 以 128 为阈值转为 0/255。原始生成图保留在 raw/ 中。人物使用 77×77 逻辑网格并放入最终画布；武器使用 91×91 逻辑网格。此步骤是导出规范化，不是原图天然满足精确网格。

两张最终图均为 1024×1024 PNG，背景透明，所有 alpha 仅为 0 或 255，11 像素网格检查通过。人物头发顶约 y=297、脚底 y=957，人物高度约 660 像素。无地面、投影和文字。

## 使用限制

这是可继续制作游戏精灵的像素设计稿，不是带骨骼的 3D 模型或已接入游戏的动作资源。未制作动作帧、骨骼、游戏文件或代码提交。

重铸剑根据人物图重新生成，朝向一致为右上方，但角度、金属段尺寸和符文并非逐像素复用。若作为动画替换部件，仍需按剑柄锚点匹配角度与比例；不能直接认定已无缝对齐。材质色阶与外描边宽度未逐区域人工精修至文档的严格要求。
