# 戴安娜跑步腿部加粗（legs3）

本次按附件要求直接在1倍96×96格内逐格修改，使用Python/Pillow描绘原有腿部中线并扩宽。本轮没有调用生图，也没有把大图缩小。

## 交付
- diana_run.png：3072×1536，4列×2行，8帧。
- native/diana_run_1x.png：384×192，原生像素图。
- manifest.json：沿用原清单坐标格式[left,top,right,bottom]，逻辑像素、右下不包含。pivot、eye_mark和125ms帧长保持输入值；bbox已更新。
- previews/width_check.png：待机旁列8帧腿部，标出近/远腿各部位的设计截面格数。
- preview.html：本次/上次/待机对照，可逐帧查看，按125ms播放。APNG为125ms；GIF量化到120ms仅供速览。
- native/leg_anchors.json：实际使用的原生髋、膝、踝及鞋底中心坐标。

## 修改与检查
大腿、膝、小腿、靴和鞋底的独立设计截面采用5格（含两侧描边），落在要求范围内。弯曲关节和相互遮挡处的水平总投影可能较宽；远腿被近腿遮住的部分不可见，因此检查图标注独立截面而非把两腿合并测宽。

材质使用待机色板的深蓝裤腿、金色护膝、银灰护胫和深色靴子。近腿明亮、远腿较暗，护胫色块连续；腿部未使用月刃浅青色。沿输入跑步的髋—膝—踝—脚走向重新铺像素，脚中心的横向距离为4–10格。中线由输入原生图逐帧取整记录，不能把新轮廓边缘当成完全未变的原像素轮廓。

第0–61行与输入逐像素一致，未改头脸；所有帧鞋底位于79行，80行以下透明，无下半身游离像素块。色板、二值透明度、8×8方块、站位点和eye_mark检查通过，详见validation.json。

未修改或导入游戏文件；仍需游戏内确认最终显示效果。
