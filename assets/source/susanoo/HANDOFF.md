# 素盏鸣尊

第十场神方角色美术与音效交接。英雄资源前缀建议使用 `ragnarok_susanoo`。角色地图尺寸和玩法由 Claude 在整合时确定。

## 造型和招式

- 漫画彩页提供深蓝长发、银白刘海、鬼面肩甲和衣着参考。 [Comic Zenon 彩页](https://www.coamix.co.jp/topics/comiczenon2409)
- 神器以鬼切天丛云为参考。持刀动作只用一把刀，两手沿同一刀柄轴线。 [神器与异形架势](https://www.coamix.co.jp/topics/comiczenon2407)
- `skill` 用天魔反的视觉主题做蓄势和剑压。无装剑 `ult` 的角色帧空手，裂光由独立特效表达。特效配色、技能动画时长和游戏内命名为本 Mod 的美术设计。 [第 23 卷发行资料](https://www.coamix.co.jp/topics/zenoncomics_241120)

## 资源与时序

- `atlases/susanoo_actor.png` 有待机、奔跑、普攻、技能一、技能二、终结技、受击和倒地，每组八帧。`atlases/susanoo_fx.png` 有八组独立特效。
- 逻辑单元为 132×96 px，脚底参考点为 (60, 88)，特效默认中心为 (66, 48)。`*_4x.png` 为严格四倍最近邻版本。导入时按已有女武神角色方式设置 PPU，并以实际地图脚底、角色体型和碰撞显示验收。
- `atlases/frames.json` 记录逻辑图集矩形、逐帧秒数与建议释放点。帧号从 1 开始。镜像朝左时同时镜像特效偏移。命中火花和命中音效应由命中确认触发。附带的 JSON 是交接数据，Claude 需接成游戏使用的动画配置。
- `sound/` 为六个原创刀声、剑压与命中音效，44.1 kHz 单声道。`sword_hit` 由命中确认触发，`slash_release` 由挥刀释放触发。官方暂未找到可确认由该角色录制的日语战斗语音。
- `card.png` 为选人插画，`icons/` 为四枚 256×256 技能图标。压缩包只含正式图集、时序、插画、图标与音效。

## 接入验收

先在本地预览检查所有动作和特效，再在游戏里验证镜像、PPU、UI 裁切、技能释放与命中、角色注册和回放。美术分支没有实现技能逻辑。日语角色语音待有可确认的官方素材之后补录。 [动画第四季公告](https://ragnarok-official.com/news/index00300000.html)
