# 可复现部件动画

approved_source/ 保留输入包中的定稿造型、指定头部、色板、待机和站位文件。source_parts/ 是从定稿像素提取出的固定部件，不能替换成别的模型。

运行 `python rebuild.py` 可重新生成八组动作、1× 图、GIF 和 manifest。需要 Pillow 与 NumPy。运行 `python validate.py` 可重新检查磁盘上的 PNG。

脚本仅使用原像素部件平移与整块最近邻旋转，并清理少量转动后孤立的边缘碎片；没有生成代码几何身体、缩小角色或删减格子。站立动作的双腿保留原部件；跑步的腿整块换位并抬脚。45° 旋转有离散网格采样变化，不等于每个像素都被守恒。
