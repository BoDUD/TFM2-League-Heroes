- renekton_run_1x.png：512×192，每格 128×96，供切格导入。

## 这轮修改

腿部从大腿、护膝、小腿到爪子整体重画，不再挪旧小腿。生成的八个姿态经取色和定稿色板量化，近腿与暗一些的远腿随步态交替前后；第3、7帧出现交叉通过。尾巴单独重画并放在人物与武器后面，向左上抬起。

上半身使用包内图5原像素贴回，只随站位整体左右平移、上下0或1格。图5本身有22格旧腿/孤立残片，已清除，坐标完整列在 manifest；除这些明确清理的残片外，上半身保留像素逐帧完全一致。头相对站位点的横向偏移固定，完整月牙刀保留。

## 检查与实际限制

尺寸、8帧布局、严格8倍网格、0/255透明度、定稿23色色板、固定上半身保留像素、每帧第81行脚底及第82行以下全空均通过。

这是按参考姿态指导的生图动画，未执行3D骨架的精确逐帧重定向。腿部的具体摆角、远腿材质暗部、胯部遮挡和首尾循环手感仍是近似表达；胯下的皮裙/长布会遮住部分交叉腿。不能声称逐像素复刻原版骨架。

源生成图的第二行角色整体较高，取腿时已单独校正纵向裁区；腿部整理到同一游戏尺寸后，整层对齐脚底行，没有裁掉超线爪尖。尾巴按固定28×22区域整理，背后大部分会被上半身与刀遮挡，露出的尾尖和背鳞能与刀刃区分。

GIF每帧90ms（GIF只有10ms时长精度），实际导入请继续用原JSON的96ms。尚未修改仓库导入脚本、游戏资源或运行游戏。本交付只替换跑步图；原有其他动作不包含在这个包里。
