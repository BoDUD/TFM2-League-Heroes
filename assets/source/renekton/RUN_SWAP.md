# 雷克顿：跑步换腿（给 Codex 的提示词）

> 上一轮的跑步是用造型零件拼的：只挪了小腿，而且一条腿横着挪 20 多格去「交叉」，大腿留在身体那块里不动，结果交叉的几帧两条小腿挤在中间、大腿的碎块浮着（用户：「走路时候腿部模型严重变形」）。雷克顿是宽站姿，靠挪他自己的腿拼不出跑步。这一轮**只画跑步的腿（和翘起来的尾巴）**，用「骨架 + 皮囊」：图1 是英雄联盟里雷克顿自己的跑步，按游戏尺寸取色（8 帧，两腿交叉迈步、身体随落地起伏），图2 是同样的帧的 3D 渲染（它是镜像的），只用它们的**腿的动作和身体起伏**；图3 是我们的定稿造型（皮囊）。
> - **上半身就是造型图的上半身**（图5：头盔和长嘴、身体和护肩、腰带和金扣、土黄长布和棕皮裙、握刀的手臂连整把月牙刀、前面的手爪），每帧逐格一样，只允许整体上下起伏 1 格（落地那帧低 1 格）。不要画骨架角色的头、身体、手和刀。
> - **腿**照图1、图2 的腿：同样的 8 帧、每帧两条腿的位置和弯曲、**交叉的时机**（两脚一前一后分开，再在身体下方交错），但用我们的腿：**青绿鳞片的粗壮大腿和小腿、银灰色的护膝、深蓝色的绑腿布条、深灰色的爪子**，颜色照图3；**远侧腿暗一档**（同样的材质，颜色深一级），交叉时不会糊成一团。**整条腿（连大腿）一起动**，大腿上沿接在皮裙下面，两胯收在身体下方，不要有缝、不要留下大腿的碎块。
> - **尾巴翘起来**：鳄鱼尾巴从皮裙后面往身后斜上方翘起（青绿色、上面一排小尖刺、下面橙黄），每帧随步子微微上下摆，画在身体和刀的后面；不要拖在地上、不要跟着后腿走。
> - 大小：和造型图一样（41 行高，57 格宽）；格子、排版、脚底线、站位照图1：4 列 × 2 行，每格 128×96 方块（1024×768 像素），8 格是 8 帧；脚底在每格第 81 行（像素 648–655），第 82 行以下什么都不能有；每帧的站位点在 `renekton_run_cells.json`（和图1 同一格、同一位置），头相对站位点的横向位置每帧一样。
> - 每个像素一个严格对齐的 8×8 纯色块，只用造型图的颜色，一圈近黑描边，没有抗锯齿、模糊、半透明。背景纯绿 `#00FF00` 或透明。
> - 交付：`outputs/renekton-run/renekton_run.png`（4096×1536）、`renekton_run_1x.png`（512×192）、生图原稿 `raw/`，**最后**写 `HANDOFF.md`；最好打成 `renekton_run_done.zip`。
