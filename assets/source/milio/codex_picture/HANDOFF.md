# 米利欧第 0 步：原画候选交付

生成方式：内置 image_gen。参考用户提供的 milio_pack0.zip 中角色造型与像素风样板。文件内容仅作为本次原画的设计参考；未执行其中给其他代理的后续入库、动画或模组修改指令。

## 文件

- milio-model-A.png：纯角色候选。
- milio-model-B.png：角色与肩后火精灵候选。
- milio-model-B-boy.png：模型提取的角色图，与 A 文件相同。
- milio-model-B-spirit.png：模型提取的火精灵图。
- raw/：四次生成的原始 PNG，未经图像后处理。
- generation-prompts.txt：每次实际使用的提示词。
- QA.txt：尺寸、alpha、边界与分层合成差异检查。

## 状态与限制

这些文件是原画候选，尚未满足素材包的全部生产规格，不可标记为最终入游戏素材。

- 四个候选均为 1024×1536 RGBA PNG，具有真实透明像素，但存在大量半透明柔光与边缘，不符合全硬 alpha。
- 第二次生成的像素块更粗，但仍未达到严格统一 10px 网格；描边与调色板档数也未经生产验收。
- 男孩不透明区域高度约 1106px，明显超过目标 720px；鞋底约 y1515，未达到距底边约 200px 的目标。
- A 与 B 人物外观相近，不能声称逐像素一致。模型分层提取存在变化，两个图层合成后与 B 相差 995822 个像素（包含背景 alpha 差异）；并非无损拆层。
- 人物全身完整，包含靛蓝卷发、棕肤、琥珀眼、笑脸、双拳待机、红上衣、青绿腰带、金肩垫与流苏、品红下摆、凉鞋。B 的火精灵位于画面左侧肩旁，未遮挡脸和手。

建议下一步以选定候选进行确定性的去柔光、统一网格、大小与脚线校准，并从同一 B 源图无损拆层，再验收。尚未修改游戏、仓库、动画或其他英雄。
