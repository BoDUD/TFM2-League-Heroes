# 卢锡安第一轮交接

## 本轮交付

3 张造型候选、14 张特效图（64 帧），以及对应生成原稿。来源是用户提供的 `lucian_codex_pack.zip`。使用内置 image_gen 生成，随后进行确定性的尺寸、网格、调色板和透明度整理；没有安装工具、修改游戏工程或执行压缩包中的导入命令。

这是**第一轮候选素材**，还不是通过游戏内验收的最终资源。请选择 A/B/C 后，再制作原包要求的 10 张动作图。本轮未生成 `lucian_native.png`，避免把未选定方案当作定稿。

## 文件用法

- 根目录同名 PNG：整理后的规定尺寸版本，优先使用。
- `raw/`：本轮采用的模型生成原稿，未经尺寸/调色板整理。原稿尺寸与根目录不同，不能直接套用根目录分帧坐标。
- `preview.html`：离线造型与动画预览，支持暂停、倍速和背景切换。单次特效为了方便检查会在停顿后重播，不代表游戏中应循环播放。
- `lucian_design_comparison.png`：A/B/C 横向比较；这是带背景与字母的预览，不是导入素材。
- `manifest.json`：整理版实际尺寸、逐帧矩形、pivot、不透明 bbox、帧时长、循环标记、角色绿色虹膜中心及像素检查结果。
- `generation_prompts.json`：每张采用原稿的实际生成提示词及来源章节。角色使用第二轮简化提示词；最初过于细碎的弃稿未打入包中。

仅包含新生成素材，没有把原包中的英雄联盟参考渲染图、特效参考贴图或 TFM2 英雄对照图放入交付包。

## 整理和检查

角色：1024×1024；每个逻辑像素严格为 8×8 纯色块；A/B/C 分别为 23/22/22 色；透明度只有 0 和 255；所有鞋底最下行是 y=792…799，y≥800 无像素。pivot 是 [512,704]（逻辑坐标 [64,88]），脚底逻辑行 99，即 pivot 行 +11。

角色图经过最近邻采样与固定调色板映射；为避免缩小丢失双眼，按文档的近眼 2 格、远眼 1 格、间隔 1 格和三行结构做了眼部像素整理。眼睛使用的三个专用颜色不用于衣服或枪。绿色虹膜中心记在 manifest 的 `qa.eye_center` 中。

特效：全是单行等宽格子，帧数与画布尺寸按 PROMPTS.md；透明度二值化，映射回指定蓝/金/紫/灰调色板，无黑色描边。飞行弹、Q 光束按中线做了上下对称整理。R 子弹各帧另做统一长度拟合，减少原稿第三帧明显缩短的问题。

普攻弹和第二枪的要求尺寸为 1024×86，86 不能被 8 整除，因此它们的纵向方块不严格为 8px；其余特效整理为 8px 网格。这是保留指定画布尺寸的取舍。角色严格 8px 网格不受影响。

## 明确未达到或未验证的部分

1. A/B/C 是独立生成后整理的候选，除了头身比例，衣甲、枪支与头发轮廓也有小差异；没有做到“只有比例不同”。27%/32%/36% 是提示词目标，不是逐像素精确比例验收结果。
2. 约34格身高按原稿头顶位置拟合，枪口高出头顶的格数并非每张都恰好5格。黑描边厚度、每种材质恰好2–3色及无内部孤立色块没有全部逐项通过人工验收。
3. 特效的每帧主形状、峰值尺寸及淡出过程依然有模型生成偏差；其形式满足候选预览，不保证完全逐字复现提示词。循环首尾视觉连贯性仍应结合游戏速度验收。
4. 没有运行原包提到的游戏仓库导入脚本、裁切头像或在游戏内测试。manifest 中的特效 pivot 是文档推导的整合建议，并非引擎现场校准值。

选择一个方案后，应以该方案为唯一角色母版，固定头部、眼睛和配色，再制作10张动作表；逐帧站位和时长继续沿用用户原包的 `lucian_cells.json`。
