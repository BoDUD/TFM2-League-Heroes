# 卢锡安修脸版动作帧交接

按 lucian_strips_pack.zip 的新造型要求制作九组动作，另同步更新六帧待机，共十张动作图、64 帧。采用用户认可的眉毛和嘴部修正版；本包优先于此前第二轮的头部、配色和 Q 枪位要求。

## 文件

- 根目录 lucian_<动作>.png：最终透明动作图，可供项目导入。
- lucian_native.png：修脸后的定稿；before_native.png：本轮修脸前造型，供比较。
- head_master.png、face_master_zoom.png：逐帧复用的头部和放大预览。
- lucian_cells.json：本次压缩包提供的位置和时长，原样保留。
- preview.html：内嵌十张图片，可离线播放、暂停、逐帧、慢放及对齐站位点。
- overview.png：动作关键帧总览。
- manifest.json：每帧尺寸、矩形、站位点、头部锚点、不透明范围、眼色中心及来源。
- generation_prompts.json：修脸、九组动作及后撤腾空修正的完整生成提示词。各动作对应原包 MODEL_PROMPTS.md 同名动画节。
- raw/：模型原稿，仅作来源记录，未经像素规范化，不应直接导入。
- validation.json、preview_validation.json：实际 PNG 和浏览器预览检查。

## 图像整理

每格 96×96 逻辑像素，放大 8 倍至 768×768；只有包内 19 种颜色，透明度为 0 或 255。虹膜 #3F6A74 与眼白 #F4F2EA 仅在头部眼睛中使用。

修脸只调整原生头部的 10 个逻辑像素，身体保留原样。普通动作复制同一头部像素遮罩，死亡倾斜用整数剪切旋转。跑步头部相对站位点横向不变、纵向上下各一格；R 躯干和腿固定；前后冲刺第 5–8 帧完全相同。后撤第 2、3 帧已专门修正为两把枪朝前。

普通帧不低于 pivot.y+11，倒地最多低两格，冲刺腾空允许高于地面线。Q 双枪在肩膀高度。普攻和 Q 的原文同时要求青白闪光及虹膜色仅限眼睛，本版优先保持 19 色与眼色专用规则，闪光使用色表内浅白、冷灰色。W 使用金色闪光。

## 坐标

manifest 的坐标单位为最终输出像素；除以 8 得到逻辑像素。rect=[x,y,width,height]；bbox 是整张图中的 [left,top,right_exclusive,bottom_exclusive]。pivot、head_anchor、eye_center 是格子局部坐标。index 从 0 开始，shot_frames_one_based 从 1 开始。eye_center 是两个虹膜像素中心的平均。

## 验收范围与偏差

- 已检查文件尺寸、网格、颜色、透明度、空格、时长、站位点、头部复制、地面界限和关键共用帧，并检查离线预览交互。
- 身体动作是根据参考重绘，姿态和服装细节并非原始 3D 渲染的逐像素复制。部分双枪姿势有遮挡；轮廓与衣褶会随帧变化。
- 待机六帧完全相同；部分动作首尾复用修正版站姿。死亡倾斜会改变头部轮廓台阶。
- 独立弹体、Q 光束和 R 弹体不在本轮范围；尚未导入游戏，未验证血条遮挡、头像裁切及特效载体高度。导入时应使用本包 cells 数据与新虹膜色重新测量。

本次没有执行参考包中供其他工具使用的游戏导入命令，也未把原版英雄、3D 渲染或导线参考图放进交付包。
