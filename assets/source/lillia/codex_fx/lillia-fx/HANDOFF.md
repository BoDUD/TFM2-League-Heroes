# 莉莉娅特效素材交接

最后一步的特效素材已完成：17 张独立特效条，共79帧。每张均实际调用 imagegen 生图，再整理成指定的原生像素版和16倍展示版；没有用代码绘制特效轮廓或拼出新的花瓣、圆环和星光。文件格式校验通过，尚未导入游戏或验证运行时技能绑定。

## 使用文件

- 根目录 `lillia_fx_<名字>.png`：严格1个游戏像素对应16×16纯色块，尺寸和参考包每条的 Layout 一致。
- `pixel_1x/`：同名原生图，导入时从这里切格；每张均为一行等宽格子。
- `raw/`：全部17张生图原稿，保持原文件。原稿有半透明边缘和不同画布比例，不宜直接导入。
- `PROMPTS_USED.json`：17次实际使用的完整提示词、帧数、格子尺寸、色板、对称与循环要求。每条使用包内对应编号提示词，附加低分辨率、等宽单行、透明底、无人物的约束。生图没有直接粘贴参考贴图。
- `fx_list.json`：参考包的原始绑定清单，原样复制，供后续对接。
- `manifest.json`：每帧原生矩形、bbox、面积、源图取格范围、尺寸归一信息、亮度、色板和建议锚点；循环标记与绑定参考也在这里。
- `qa_report.json`：17张/79帧的14项格式与内容检查。
- `preview/`：逐帧总览、17种特效综合动图、每张独立GIF，以及Q/R/梦尘和定稿人物的叠加动图。预览的文字、人物、底色没有进入特效PNG。

所有FX PNG二值透明，透明格RGB清零。只使用各条规定色板中的亮色，移除了各色阶最深一档，完全没有黑描边。每帧都有亮色芯（亮度至少200/255）。光环是斜上方看的扁椭圆。E种子向右飞，逐格上下对称；Q花环、E落地、W预警及W落地逐格上下左右对称；其余逐格左右对称。R和梦尘的人物空位已清理。

## 整理与检查

原稿未严格遵守目标画布及逻辑格子，因此从既有生图的时间序列分格，去掉外部透明余量，映射到指定原生网格。先将可见源像素归入每条规定的亮色板，再在每格的可见样本内取多数色；覆盖率20%以下的格清空，以保留小光点同时去除薄边噪声。严格对称通过对称位置的取样颜色投票得到。Q/E/W圈的扩张阶段做了现有生图形状的尺寸归一，R/梦尘空位用透明清理；这属于生图后的整理，没有补画新图形。具体取格矩形、调整像素数和尺寸记录见manifest。

已检查：清单17张对应、79帧、尺寸、等宽切格、16×16块、0/255透明、透明RGB归零、限定亮色板、规定逐格对称、R/梦尘空位、Q中央留空、R/腾跃底边、每帧亮芯、每组至少两个不同帧、17张原稿齐全。已查看原稿、原生逐帧总览和人物叠加预览。

形状宽度、花瓣/光点数和逐帧轨迹仍有表中所述近似，不能把格式通过当成原版特效完全还原。GIF统一按100ms/帧播放，仅演示运动；包内没有提供引擎每帧时长，未臆造运行时动画配置。`suggested_pivot_1x` 是原生画布边界坐标的建议锚点，地面圈居中，R/梦尘/腾跃按底部中心；最终偏移仍需导入者结合技能落点与人物位置核对。
