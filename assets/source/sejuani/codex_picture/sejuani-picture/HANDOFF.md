# 瑟庄妮像素造型素材

已生成瑟庄妮与钢鬃的两张完整骑乘造型：A 为待机，B 为向右前方冲锋。使用内置 image_gen；参考来源为用户提供的 sejuani_pack0.zip。未修改游戏或仓库。

## 文件

- sejuani-A.png：待机造型。
- sejuani-B.png：冲锋造型。
- raw/sejuani-A-original.png、raw/sejuani-B-original.png：生成原稿，未重采样或编辑；与对应交付 PNG 相同。
- generation-prompts.txt：两次成功生成实际使用的提示词。最初尝试附 14 张参考图被工具的最多 5 张限制拒绝，未产生图像；成功调用选用了其中的造型、布局和风格参考。
- image-checks.json：实际尺寸、透明通道包围盒和 alpha 级数。

## 检查与用途

两张均为 1254×1254 RGBA PNG，有真实透明背景，alpha 从 0 到 255。视觉上保留青铜头盔、双蓝冰角、紫色铠甲、蓝宝石、白毛领、冰锤链枷，以及灰蓝钢鬃、白鬃毛、粉鼻子和两根象牙色獠牙；无场景、地面或技能特效。

这是造型参考交付，尚未达到参考包中的严格生产规范：不是 1536×1536；没有实现统一 11px 方格、52/55 格角色高度与指定基线；轮廓存在半透明像素和极低 alpha 杂点，不能当作硬 alpha 最终像素帧直接读取。像素细节也比包内游戏风格更密。请勿将此包标为游戏动画或可直接导入的完成模型。

后续需要按确认的造型和原生游戏帧合约重新绘制像素，统一 A/B 尺度、描边、透明边缘与各动作，再检查游戏内显示。本次未制作 3D 网格、骨骼、动作帧表或进行游戏内 QA。
