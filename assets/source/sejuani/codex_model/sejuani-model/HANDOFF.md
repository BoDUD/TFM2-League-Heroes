# 瑟庄妮：第 1 步候选模型交付

## 本次结果

按 sejuani_model_pack.zip 的造型、姿势和游戏尺寸目标，用内置 image_gen 重新绘制四张候选图。A 为待机两稿，B 为冲锋两稿。均保留上一版瑟庄妮与钢鬃的主要颜色和辨识部件。没有修改游戏仓库，也没有制作动作帧或安装进游戏。

这些是供挑选和继续修整的候选图，**严格 18px 网格与硬 alpha 验收未通过，不能标为生产规范已完成，也不能直接逐格读入游戏。**

## 文件

- sejuani-A-1.png、sejuani-A-2.png：待机两稿。
- sejuani-B-1.png、sejuani-B-2.png：冲锋两稿。
- raw/：四张对应的原始生成文件，字节保留，交付 PNG 与原稿一致。
- generation-prompts.txt：实际提示词和参考图顺序；包括被淘汰的首次细像素待机尝试记录。

## 过程与筛选

第一次以细原稿为主要参考生成的待机图仍然细节过密，已淘汰，未放进此交付包。改用粗目标图作为编辑对象、头像作为身份参考、布隆和努努作为风格参考，再生成两张待机和两张冲锋。没有用 Python 逐格画图、平滑缩小、重新采样或改写透明通道；Python 仅复制文件和只读检查原始像素。

## 实际检查

四张均为 1254×1254 RGBA，存在真实透明背景；均有 256 个 alpha 级别，**不是仅 0/255 的硬 alpha**。整体色块较第 0 步更粗，但细节并未全部严格落在从 (0,0) 起的统一 18px 方格上。网格抽样未通过，不能将提示词的 54/56 格视为实际已实现。
