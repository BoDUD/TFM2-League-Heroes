# 北地之怒 瑟庄妮：第 0 步，先画像素风原图（给 Codex 的提示词）

> 瑟庄妮是英雄联盟里**骑着一头大野猪的弗雷尔卓德女战士**，人和野猪（名叫钢鬃）算**一个角色**。这一步把她们画出来，用户从里面挑：
> - **瑟庄妮**：戴一顶**青铜金色的头盔**，头盔两侧各伸出一只**往后弯的蓝色冰角**，额前一颗**蓝色冰宝石**；露出**白皙的脸**、**冰蓝色的眼睛**，表情冷峻；头盔下两缕**浅金色的长发**垂在脸旁；身穿**紫色皮甲**，外面是**青铜金色的铠甲片**（肩甲很大、带尖角），甲片上镶着**发光的蓝色冰宝石**；领口和肩上是**米白色的毛**；手套和靴子深紫；手里握着她的**链枷**：一根**棕黑相间缠绕的长链 / 长柄**，末端是一个**又大又尖的蓝色冰锤头**（青色发光的纹路）。
> - **钢鬃（野猪）**：一头**又大又壮、弓着背的野猪**，**灰蓝色的毛**；从头顶到背上一大片**白色竖起的鬃毛**；**两根巨大的象牙色獠牙**往上弯；**粉红色的猪鼻子**、张开的嘴里是粉红的口腔；**发青蓝光的眼睛**；**耳朵里面粉红**；**深灰黑色的蹄子**；背上一副**橄榄绿 / 青铜色的鞍甲**（两侧大护甲上镶着**蓝色冰宝石**），**棕色皮带**；身后一条尾巴，末端一撮毛。
>
> 请 Codex 画**两张全身像**（**格子大小一样**，都是 **3/4 正面朝右**），用户从里面挑：
> - **A：待机**——英雄联盟里的待机：钢鬃四蹄站稳、低着头、獠牙朝前；瑟庄妮骑在背上，一只手把链枷甩在身后（冰锤头垂在钢鬃屁股后面），一只手握着鞍前（附图 1、2、9a）。
> - **B：极寒突袭**——她的 Q：钢鬃**往前猛冲**，前蹄收起、身子前倾，獠牙往前顶；瑟庄妮压低身子，链枷高高扬在身后（附图 6、9b）。
>
