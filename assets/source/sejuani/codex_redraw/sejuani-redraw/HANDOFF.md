# 瑟庄妮重画交付

## 内容

依据 sejuani_redraw_pack.zip 中选定的 A-2 待机、B-1 冲锋造型，用内置 image_gen 独立重画四次。此次目标是保留外观、颜色、骑乘关系和姿势，增加像素密度，把双眼、眉毛、粉色小嘴、额前宝石、毛领、鬃毛和獠牙画清楚。输入文件中的要求作为本次美术参考使用；未执行其中面向其他工具或其他代理的后续仓库操作。

- sejuani-A-1.png、sejuani-A-2.png：待机两稿。
- sejuani-B-1.png、sejuani-B-2.png：冲锋两稿。
- raw/：四次生成的原始 PNG，未修改；主目录图与对应原稿字节一致。
- generation-prompts.txt：实际使用的完整提示词、参考图路径及顺序。
- image-checks.json：原始图像的只读检查结果。

工具最多允许五张参考，因此每次使用对应姿势的选定图、目标图、布局图、修补脸图，加布隆风格图。两种姿势各用同一段提示词独立生成两稿。

## 视觉检查

四张均保持三分之四朝右的骑乘角色，A 为静止、链枷下垂，B 为前冲、链枷抬高；未出现地面、投影、文字或技能效果。保留蓝色双冰角、青铜头盔、紫甲、米白毛领、蓝宝石、灰蓝钢鬃、白鬃、粉鼻、双象牙色獠牙及冰锤。双眼、眉毛和粉色小嘴可辨。

重画存在局部形状和尺度偏差，不能声称与选定图逐像素一致；远眼与近眼的可见高度也仍受三分之四视角影响，不能声称严格同一行。A-1 的可见高度和位置比 A-2 更接近尺寸目标。最终造型选择仍由用户决定。

## 实际规范检查

四张均为 1254×1254 RGBA，alpha 范围 0–255，确有透明背景。**四张均含 256 级 alpha，硬 alpha 0/255 检查未通过；从 (0,0) 起的统一 14px 网格抽样也未通过。** 因此这是重画候选素材，不能直接作为严格 72/76 行的游戏像素模型读入，也不表示最终游戏帧完成。
