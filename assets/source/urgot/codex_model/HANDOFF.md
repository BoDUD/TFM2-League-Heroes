# 厄加特：游戏尺寸造型两稿

以本轮 urgot_model_pack.zip 为参考，使用内置 imagegen 绘制两稿，均沿用高举炮臂的A姿势。未用Python逐格绘制，未重采样、重排网格或修改生成图。

## 交付文件

- urgot-model-1.png：优先保留A的形态、颜色和细节，纹理仍偏细。
- urgot-model-2.png：强化粗像素、简化色阶和头部可读性，更接近游戏尺寸重画的方向，供用户比较选择。
- raw/urgot-model-1-original.png、raw/urgot-model-2-original.png：未经修改的原始生成图，与对应交付图内容相同。
- generation-prompts.txt：两稿实际使用的完整提示词及参考顺序。
- validation.json：图像尺寸、模式与alpha实测。

## 验收状态

两稿均为1254×1254 RGBA PNG，含真实透明区域，但alpha各有256档。生成器没有严格执行1024×1024画布、alpha仅0/255、统一12px网格、指定y坐标和全身63格高度。因此此次交付是供选择的造型原稿，不能标为已通过游戏精灵技术验收的最终成品。

第二稿视觉上采用了更粗的方块，但仍不能宣称每块严格12px或网格从(0,0)对齐。六腿存在遮挡，部件数量与软管连续性还需在确定造型后的像素制作阶段逐项检查。两稿未制作动画或集成游戏。

## 参考使用

图像工具每次最多5张参考图。稿1使用选定A、目标尺寸图、头部、蒙多和潘森；稿2使用目标尺寸图、布局、蒙多、潘森和头部。其余包内风格图已查看，未作为额外附件传入。素材说明中给其他执行者的后续动画、游戏集成等内容作为背景信息，未执行。
