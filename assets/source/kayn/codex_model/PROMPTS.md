# 生图提示词与整理方式

内置 image_gen 生成；原稿保存在 raw/。以下为最后一轮各版本生图提示词。生成图未直接满足严格网格，因此交付稿另按素材包要求取格、删整行、统一色板。最终 B 用 A 的脸与身体，删去两行头发/角，并保留 B 生图作候选记录。

## base A

Repaint the FIRST small sprite at HALF THE CURRENT NUMBER OF PIXELS. Keep silhouette size but each colored tile TWICE AS LARGE, exactly 16x16 squares on source 1024 canvas (20x20 if output1280). This is aggressive simplification: only 40 block rows from spiky hair tip to soles. Head is LARGE: twelve rows top-to-chin, about 30 percent of total height. TORSO and LEGS tiny compared to head. NO tiny tile under16px! Every color patch a flat cluster, maximum24 flat colors. 3/4 front facing RIGHT, TWO eyes same row gold near and magenta far, no gold accessory, no dark cheeks. Keep all classic Kayn features: pointed black navy hair BLUE stripe, thick long braid, shirtless tan torso with blue mark, mauve obi/crimson rope/tassel, indigo baggy pants/violet apron/purple boots. Relaxed stance near arm down, far hand grips shaft behind hip. Crimson crescent LEFT behind leg with blue edge and red eye. Complete diagonal shaft to lower-right butt spike ABOVE feet. One near-black outline, no AA/no texture/no shading within any tile. Reference2 style demonstrates how few pixels. Transparent outside ONE character. Simplify weapon to bold crescent not multiple layers. Output a much coarser, bigger-headed game sprite, not detailed illustration.

## base B

Precise sprite edit, Classic Kayn B: head TOP SPIKY HAIR TO CHIN now TEN pixel rows instead12; make only head smaller, keep black spiky hair blue lock, gold near eye magenta far eye same row, long braid. Do not change torso feet scythe or pose. All unchanged parts must remain identical. Same enormous coarse pixel squares, same palette maximum24 flat colors, one near-black outline, no AA tiny details noise or gradients. Native small game sprite style. Full body facingRIGHT, entire weapon above soles, true transparent backdrop. Output ONE single B variant, no labels grids ground or shadows. This is a head-size comparison, everything else must remain exactly as A.
