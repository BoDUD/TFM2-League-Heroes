# 奇亚娜短腿修正版

本轮使用内置 image_gen 针对新 guide 重画 13 张；r_leap 首稿仍偏长，额外返修一次，最终版本已替换。未使用代码绘制人物、合成上半身或改写图片。

## 交付文件

- qiyana-legs-{a_wind,a_strike,q_wind,q_sweep,q_end,e_dash,e_hit,r_leap,r_slam,run1,run2,run3,run4}.png
- raw/：对应生成原图，与根目录 PNG 的 SHA256 完全一致。
- preview.html：13 张图的预览页，点击查看原图。
- generation-prompts.txt：实际提示词、参考图映射与 r_leap 返修前记录。
- image-checks.csv：尺寸、透明度、可见轮廓边界、严格网格检查。
- upper-body-samples.csv：与输入 guide 的同坐标参考图案格心抽样比较。

## 视觉结果与限制

13 张均已查看。大多数腿部相对旧稿明显缩短；普攻出手保持离地，Q/E/R 的弓步收紧，R 跃起双腿进一步收起。保留了深色紧身裤、金色纹样和紫棕凉鞋的视觉特征。

这套是**短腿修正候选原稿**，尚未全部满足以下严格要求：

1. **上半身一格不变：未通过。** 生成器仍重画了参考上半身，不能声称原像素完整保留。格心抽样排除多数白底、灰网格和红蓝线后，同坐标 RGB 完全相同的样本仅 0–3 个/图，RGBA 完全相同均为 0。该抽样不是语义分割，也不是完整的上半身遮罩验收，但足以否定逐格一致。
2. **硬 alpha：未通过。** 13 张均含真实透明区域，也均含半透明像素，实际计数见 CSV；没有做 alpha 阈值转换。
3. **严格 13px 网格：未通过。** 每张的 13×13 块内均存在非同色/非同 alpha 像素，不可直接假设精确原点对齐读取。
4. **腿骨长度与粗细：没有完成逐骨精确验收。** 腿已视觉缩短，但膝盖、脚底与 guide 端点仍有差别，不能把目视缩短当作精确 9/6/4 格的证明。
5. **脚底 y1196 与跑步交替：未验收。** 四张跑步呈现着地/抬膝变化，但近远腿亮暗归属、相位交换、等长与稳定头高仍需校准。
6. **画布边缘：存在输入布局带来的问题。** a_wind 左右、q_sweep 下方、r_leap 顶部、r_slam 下方的可见主体触边（见 CSV）。对应 guide 本身也有贴边或越界部分；本轮保留上半身布局优先，没有擅自整体缩放避边。r_slam 等图仍有额外位置变化，需按 guide 对回。
7. r_leap 返修后双脚抬高，但可见最低像素约 y1111，仍低于骨架脚端约 y1072；未宣称此项完全修好。

## 后续衔接

集成时必须从原始 guide 取回已认可的上半身，按项目已有流程锁定位置与调色板；只将本轮新腿区域作为候选来源。之后重新核对每段骨长、腿粗、支撑足与跑步相位，再统一 alpha 和网格。包内提到的其他代理/仓库入库脚本仅作参考，本轮没有执行，也没有修改 D 盘仓库或已安装游戏。

本轮经验：将 guide 作为第一张编辑目标、把旧长腿明确限制为服装参考，能让生成结果明显变短；但生成器不能保证上半身像素级冻结，因此不能跳过最终合成/逐格验收。
