# 塔莉垭跑步素材

根据 taliyah_run_pack.zip 的角色定稿、头部、骨架和原版动作参考，用内置 image_gen 生成四张二维像素风跑步姿势图。四张均为 1254 × 1254 PNG，带透明背景。raw/ 保存未修改的生成原图，顶层 PNG 是同一原图的命名副本。完整提示词见 generation-prompts.txt，文件检查结果见 validation.json。

## 状态与限制

这是生成模型素材初稿，尚未接入游戏或绑定动画。可见角色保持棕发金饰、石片披肩、红外套、靛紫服装与棕靴，采用用脚跑步，没有冲浪巨石。

生成结果未严格满足参考包的逐格规范：头部并非定稿逐像素复制；四帧头部、衣摆、身形尺寸与位置存在变化；近侧和远侧腿的交替仍需复核。尚未证明 11 px 统一网格、29×30 格头部、肢体长度与 y=1188 脚底定位。

透明通道实测含大量 1–254 中间 alpha，未达到纯 0/255 的硬边要求。没有通过代码绘制替代角色，也没有后处理修改原图。后续用于游戏时，应先统一头部、调色板、像素网格、透明边缘与脚底锚点，再检查四帧循环。此包不能视为已通过游戏像素与动画验收。
