# 塔莉垭姿势包交付

## 文件
共14张姿势图：a_wind、a_throw、q_raise、q_cast、e_raise、e_sweep、w_crouch、w_push、r_call、surf1、surf2、surf3、d_stagger、d_down。文件名均为 taliyah-pose-<名称>.png。
- 根目录：1254×1254透明PNG，每个逻辑像素以11×11方块展示。
- pixel_1x/：114×114逻辑像素读回版本，和根目录PNG逐格对应。
- raw/：14张image_gen生成原图，逐字节保留；SHA-256见manifest.json。
- preview.png：14姿势暗底总览。
- generation-prompts.txt：实际提示词和参考输入。
- manifest.json：原稿尺寸、alpha统计、格子、平移及检查状态。
- QA.md：最终文件的程序检查结果。

## 制作方式
全部姿势由内置image_gen逐张绘制，参考均来自用户提供的taliyah_pose_pack.zip。没有用脚本画人物、拼接身体或以旋转直腿代替动作。
原图生成后以原点对齐的114×114网格机械读回：每格按alpha>=128投票判断是否有主体，覆盖率至少50%；对可见颜色取5bit颜色分组中的多数色，再取该组实际颜色中位值。清除透明RGB杂色，alpha固定0/255。仅按整行逻辑像素平移，使着地脚/冲浪石/坐姿最低边落在y1188；最后最近邻放大11倍。没有平滑缩放。所有平移均检查主体未被裁切。

生成器未保证头部逐格复制定稿，面部、发型仍有帧间变化；两眼可见程度也需装配时逐帧复查。
每条胳膊/腿约16格的精确解剖长度未逐关节量证；部分伸展动作的肢体可能偏长。不能把整格化当作长度验收。
三张冲浪石的大小、石面和红布未完全相同，且比目标44×24格更宽大；做连续移动动画前需统一。没有把这三张直接称为稳定循环。
多数色读回会丢弃小于一格的手指、眼睛或金边细节；需参考raw再核对最终脸部。
没有修改原始仓库、安装模组、拼接rig或做游戏内测试。
