# 霞：游戏尺寸静态造型候选交付
## 文件
- xayah_design_1.png、xayah_design_2.png：1024×1024 透明画布，严格8倍放大。
- xayah_design_1_1x.png、xayah_design_2_1x.png：128×128 原尺寸画布。
- xayah_design_1_sprite.png、xayah_design_2_sprite.png：28×40 紧凑精灵工作框。
- comparison.png：与素材包中的洛对比，包含8倍和1倍预览。
- raw/xayah_generated_source.png：选用的未整理生图原稿。
- palette.png、palette.json：24色共用色板；每版实际使用23色。
- validation.json：从交付PNG读回的检查结果。
- generation-prompts.txt：实际生图提示词与选用记录。
## 读回检查
两版可见范围均为原尺寸 x=49..74、y=60..99，即耳尖到脚底 **40格**、可见宽 **26格**，位于28×40工作框内。放大版每格严格8×8纯色，透明度只有0/255，实际颜色23种。第99行是脚底最低行，第100行及以下没有像素。两只眼睛同一行，各一格浅色加一格金色；专用眼睛金色每版只有两个像素。
版本1按7格耳朵区、11格兜帽至下巴区、22格身体区组成；版本2按6格耳朵区、10格头区、24格身体区组成。头区指完整兜帽含下巴的排布区域，耳朵会侧向伸到兜帽区。
## 来源与处理
内置image_gen多次生图未直接满足40格和严格网格规格，未将那些大图当作游戏尺寸成品。选用较简洁的生图按约10px格中心取像素，原始角色约61行；以整行整列删减组合成两版，保留面部连续原稿行，统一色板和硬透明，再局部修正眼睛、鸟头骨、脚尖和手持羽刃。没有将上一轮高清原画直接缩小。
两版由同一个选定原稿派生，保持同一身份、服装和配色。头部/耳朵比例和补偿后的腿长有所不同。
这次交付是供用户选择的两版静态候选；尚未制作动作帧、安装到游戏或验证游戏内显示。文件尺寸和色板检查通过不代表画风已获用户批准。
