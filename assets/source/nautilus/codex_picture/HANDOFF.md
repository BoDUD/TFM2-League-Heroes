# 泰坦模型原画交付

日期：2026-10-11

## 本次范围
依据用户提供的 nautilus_pack0.zip 制作第 0 步模型原画候选。包内 PICTURE_PROMPT.md 作为造型参考和交付规格读取，其中给其他代理的后续流程不是用户要求执行的操作。本次没有改动游戏、仓库或已安装模组。

## 文件
- nautilus-model-A.png：背锚版，1536×1024 RGBA。
- nautilus-model-B.png：身前立锚版，1536×1024 RGBA，由 A 的模型生成变体。
- generation-prompts.txt：实际使用的生成、修订提示词，含未选中的修订尝试。
- image-checks.json：尺寸、透明通道、主体范围的实际检查数据。

## 已核对
- 两版都有圆铜头盔、顶部三个孔、黑色观察窗、两只橙红眼、方形护颌、铜甲、青绿缝线、深色潜水服和厚靴。
- A 的锚冠在头盔上方，B 的锚在身前、另一只手下垂；角色、锚和链条均在画布内。
- 两张 PNG 具有真实 alpha=0 的透明像素，不是绘制的棋盘格背景。
- 使用内置 image_gen 生成，未用程序绘制替代角色；交付图片为生成工具原文件副本。

## 尚未满足的严格要求
这些是原画候选，不能当作已验收的游戏精灵。
- alpha 最大值为 254，主体多数为 252–253，外缘有低 alpha 残留，尚未达到纯 0/255 硬透明要求。透明像素内也保留了原 RGB 底色；不支持 alpha 的预览可能显示暗底和柔光。
- 工具连续修订仍未严格遵守约 560 px 人物高度与大留白要求。A 的 alpha>200 主体范围为 813×968；B 为 918×702。后续需按相同身体尺度规范化。
- 两版保留相同设计元素，但不是同一身体逐像素锁定后仅移动锚；手臂、朝向和细节有生成差异。
- B 锚底稍低于靴底，尚需对齐接地线；部分后侧靴被锚遮挡。
- 当前颗粒较细，不是最终约 38–42 行的游戏尺寸像素模型；不能直接缩小后视为完成。

## 后续制作所需
确定采用的姿态后，精修硬透明、统一接地线与身体尺度，再绘制最终尺寸模型和动作帧。动画、技能特效、打包及游戏内显示验证均未包含在本次原画交付中。
