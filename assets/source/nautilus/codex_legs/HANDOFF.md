# 诺提勒斯腿部重画

交付 run_1x.png（512×256，4×2，8 帧）、idle_1x.png（128×128，单帧），以及 run_8x.png、idle_8x.png、GIF 和腿部对比图。raw/ 保留跑步初稿、跑步编辑稿和待机原稿，未经重采样；prompts.json 是实际内置 image_gen 提示词。

上半身来自本次输入 body_run_1x.png / body_idle_1x.png，所有原不透明像素逐像素不变；腰带所在行及以上的整幅 RGBA 逐像素不变。新绘图只合成在原图透明的腰带下区域，因此锚、手、头盔、胸甲没有受到重画影响。

生图腿部按区域多数颜色读取，归并到指定 23 色，按腰带到地面的高度整理并平移合成。最终透明度仅 0/255，8 倍预览为最近邻纯色块，地面第 99 行以下没有像素。多数色读取后补回靴底单像素近黑边。各帧源腿裁切、腰带位置与平移坐标见 validation.json。

待机改为双腿并拢直立，两脚朝右。跑步前四帧与后四帧使用相反的近远腿明暗身份；生图编辑仍未稳定执行远腿暗一档，因此按左/右腿所在区域归并色板明暗，第 5/6 帧近侧亮腿在后，第 7/8 帧近侧亮腿摆向前。此处是对生图腿部的色彩修正，不是重新生成上半身。

仍有不足：没有逐格完全复刻 guide_run 的膝盖和脚踝坐标；尤其第 1/5 帧的步幅与后脚接地方式、第 3/7 帧的交错位置仍是近似。靴子与护膝的各帧轮廓和粗细也未达到完全一致，腿的像素感比旧稿更粗。明暗交换使腿的身份可辨，不能把它当作所有骨架动作已经严格匹配的证明。这版应按 GIF 审阅，尚未在游戏里验收。

GIF 跑步预览采用前一轮 116ms，GIF 自身会量化为 10ms 整倍数；本次附件未规定新的游戏时序，不修改游戏动画表。未导入仓库或运行 mod。tools/build_record.py 保存制作记录，路径指向原工作目录。
