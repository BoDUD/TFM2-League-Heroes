# 《边境巡团 · 镜海篇》素材交接

本包包含 12 位原创英雄。Claude 负责英雄注册、技能机制、选目标、AI、数值、音画触发和实机验收。资源放在 `mods/border_patrol/`，作者源图、PCM 原件和预览放在 `design/border_patrol/`。

本版统一为日系二次元画风。岑垒为成年男性珊瑚盾卫，绡轮为薄荷蓝潮弩信使，灯弥为杏紫提灯师。灯弥的鳍翼在立绘展开，在跑图时收折在背后。铸沫是铜火锻匠，伏梭是银梭斥候，盐汐是盐晶法师。

- **岑垒**是护后排坦克。接肩标记附近正在受威胁的一名队友，并转移该队友接下来两次受击的一部分伤害。岑垒根据实际转移的伤害累计背压。转移事件需要防止递归和重复计数。横楔在前方扫击，优先打断正在施法的近敌。卸城消耗背压，以扇形推出贴身敌人。三个楔块是同一次扇形命中的视觉，命中逻辑应对同一敌人去重。
- **绡轮**是移动射手。走弦按实际移动距离累积张力，满张力强化下一发普通攻击。切角沿可走的侧向短移后射击，放扣消耗张力换取短时攻速。满弧分三次放箭，每次发射当下重新判定目标。弹体在发射后由项目通用弹道控制，动画资源提供右向单弹。
- **灯弥**是救急辅助。存光从附近友军收到的技能伤害攒灯火。递灯给承压友军短盾，引路给低血队友短时移速。收灯消耗灯火，第一脉冲治疗所选主目标，第二脉冲在主目标附近选最低血量的有效友军。每个目标根部播放一次对应治疗圈。

- **铸沫**是持续缠斗战士。余温按实际普攻命中积攒热量。压坯重击近敌，伤害随热量提高。回火消耗当前热量换取短时减伤。开炉持续升温，AI 根据承受的威胁和敌方距离决定攒热重击或回火防守。余温贴锤头，压坯落地，回火贴身体，开炉以角色脚底为中心。
- **伏梭**是惩罚落单的刺客。数步跟踪持续离开友军的敌人，掠阶优先切向被跟踪目标。留扣在初次施放时记录可回撤点，窗口内按 AI 危险判断返回。回撤点可用第 2 帧做持续标记。错拍先提示锁定目标背后的延迟斩线，再在同一条预告线结算，允许及时横移的目标离开命中范围。预警和命中可按引擎实际延迟分别取特效片段。
- **盐汐**是封走位法师。撒线铺地面盐带，析晶给仍在盐带内的敌人叠结晶。凝结消耗结晶，结算后只给本次层数最高的有效目标短定身。退潮让当前盐带向施法者扫回，晶浪动画按真实移动方向旋转或镜像。盐带持续期间可显示中段形状，收回时播放独立的退潮序列。

- **殷渡**是主动开团坦克。迎汐在朝敌群推进时积攒潮势，强化下一次扣舷减速。扣舷短冲，遇到首个敌人停下并撞击。立标在敌群附近放可见航标。合汛从航标两侧向内合拢，每名敌人最多被推动一次。把合汛动画枢轴放在汇合点，预警持续时间需和实际结算对齐。
- **澜缇**是反击战士。折纹只标记最近一名用技能伤到她的英雄。双棱连打两拳，第二拳消耗镜纹增伤，每次实际命中可播一次拳光。候击减少下一次技能伤害，成功时刷新双棱。还响按近期实际挡下的伤害增强冲击，设置明确上限。
- **鹭芯**是追击刺客。追羽在被她打过的敌人持续远离时留下短时路线。贴风沿目标移动方向追击，抵达近身距离后切击。折鸢在敌人经过处留一道显眼风线，再次穿越的目标减速。收线沿同一目标的两段羽迹切入，各次实际方向分别播放切光，第二刀对低生命值更强。
- **霁砚**是远程炮台。定标在远距技能命中处留下短时坐标。长刻发射细长星束，经过己方坐标时追加小圈伤害。照盘提前在远处放置一个坐标。星历选同一方向的三处错开落点，每处先给独立预警圈，再落一枚星刻并结算。
- **钟砾**是站桩射手。定脚在连续站稳后加攻速，明显移动时解除。压簧强化下一次普攻，在定脚期间附带穿甲。落架部署支架，短时提供护盾并加速定脚，撤步收起。齐鸣固定方向连续发射四次，末发最强。主动离位或被控制时中断后续发射，每发创建单独的右向弹体。
- **雾绫**是控场辅助。闻铃在敌人首次触碰其技能区域后标记，友军命中标记敌人可获得短时移速。系铃放地铃，敌人靠近时触发范围减速。挪幕的竖直短幕供友军穿过后加速。合幕让两侧幕线向内合拢，单次施放每个敌人最多触发一次减速和缚足。

## 资源

- 角色 `champions/<hero>#sheet.png` 与 `#anim.fanim` 中的每格为 **256×256**。八个动作键为 `idle`、`run`、`attack`、`skill`、`skill2`、`ult`、`hit`、`dead`。跑步八帧，合计 0.57 秒。原图朝右，镜像或转向按运行时规则处理。逻辑地面锚点是格内 `(128,184)`，跑步腾空帧底边会略高。请用实际本体和 HUD 校准 PPU、锚点和缩放。
- 特效 `effects/<hero>_fx#sheet.png` 与 `#anim.fanim` 独立。每格 128×128，特效枢轴 `(64,68)`。 `effect_cues.json` 指明附着点和语义。每人有四组专用技能特效、一个普攻或弹道以及一个受击特效。技能特效保留透明度，重点亮部和边缘色可在深浅地图表面区分。全尺寸是画布尺寸，命中盒和技能范围由技能代码决定。
- 选人场景插画位于 `banpick_illustrations/<hero>.png`，游戏版为 304×405，与本地女武神系列插画槽位一致。`design/border_patrol/illustrations/` 提供 1216×1620 的大图。
- 贴图 `portraits/<hero>_full.png` 是全身选人图，`portraits/<hero>_portrait.png` 是 96×96 小头像。48 张独立技能图标使用 `icons/<hero>_<action>.png`。现有英雄三主动槽位可映射 `skill,skill2,ult`，被动图标可供支持它的界面使用。
- `voice_events.json` 有简体中文字幕、事件、MP3 和 44.1 kHz 单声道 WAV 路径及哈希。语音是普通话 AI 试音。建议选人、胜利、死亡按事件，技能在施法起手，移动态、普攻、受击按角色节流。音效触发使用实际事件，避免每个移动 tick 重播。
- `art_index.json` 包含各动作的透明边界、帧时和源图哈希。 `sha256.json` 记录本批运行时文件和音频母带。

## 演出提示

时间从该人物动画首帧开始。下表给初版素材同步点，可按实机时钟转换，技能判定优先由代码的正式时间线驱动。

| 动作 | 发出 / 提示 |
|---|---|
| 普攻 | 第 3 帧开始，约 0.21 秒。岑垒播放盾击接触，绡轮和灯弥生成对应弹体。 |
| 小技能 1 | 第 3 帧开始，约 0.26 秒。横楔和切角朝施法方向，递灯把盾壳放在命中的队友身上。 |
| 小技能 2 | 第 3 帧开始，约 0.26 秒。接肩盾板贴目标，放扣环贴武器，引路脚印贴目标地面。 |
| 大招 | 第 2 帧前摇，第 3 帧开始约 0.40 秒是第一个演出点。卸城播扇形楔浪。满弧在每次实际发射时分别创建一条星弧弹道，各自随弹体移动。收灯两次各按实际受治疗目标播放一个套环脉冲。预览里的连发、落点和脉冲间隔用于演示，游戏内请使用各技能真实事件的时间线。 |

铸沫压坯在第 3 帧落锤，回火的围身金属环跟随自身。伏梭先在原地放留扣锚点，再按技能实际时机闪回。错拍的第 1 帧是细斩线预警，第 3 帧是斩击峰值。盐汐撒线沿盐带起止点放置，凝结特效挂实际爆点，退潮的晶浪随盐带向施法者移动。

接入验收包括全部 12 位均能进选人、比赛和回放，自动对战会使用各自技能。用同场官方英雄对照尺寸，检查贴墙跑步、塔边和多人团战里的遮挡，再查小头像、死亡收尾、语音节流与窗口重叠。素材包没有注册表、技能实现或安装到现有 mods 目录的步骤。
