选了「开始第 0+1 步」：先量（`addons/league_macro_log`），再调游戏的宏观权重。

游戏 0.7 的比赛 AI 有一套队伍计划（EXE 里的 `team_plan` / `team_score` / `objective_*` / `epic` / `serpen` / `siege_breaker`
等模块），按 `asset/base/setting/macro_weights`（资源类型 `macro_weights`）给每样东西定价。原版：

| 键 | 原版 | 本包 0.1.0 | 想要的效果 |
|---|---|---|---|
| gold | 1 | 1 | 补刀、打野的钱（基准） |
| exp | 1 | 1 | 经验（基准） |
| kill | 400 | 400 | |
| death | 400 | 500 | 少送、少硬接劣势团 |
| tower | 500 | 800 | 拿了资源去推塔 |
| epic | 2800 | 3200 | 大龙 |
| serpen | 700 | 800 | 小龙 |
| nexus | 20000 | 40000 | 到了基地就推掉 |

这份权重不在存档里（存档里没有这串数，2026-11-06 查过），Mod 覆盖对所有生涯都生效；游戏启动时读，改了要重启游戏。

（大龙后 90 秒推的塔、到了对面基地又走掉的次数、时长、抱团）。
